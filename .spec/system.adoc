== Executive Summary

Eidos is an open, Git-native development AI ecosystem and orchestration framework. Unlike fragmented tools that only assist in terminal coding (e.g. Aider, Claude Code) or monolithic cloud black-boxes (e.g. Devin), Eidos manages the **full lifecycle of software creation**:

1. **Product Exploration & Discovery**: Rapid spikes, feasibility research, and hypothesis validation.
2. **Product Baseline (Living Spec)**: Domain-driven definitions of business value, actors, entities, and non-negotiable invariants.
3. **Product Deltas (SpecDelta)**: Declarative, machine-verifiable diffs for features, bugs, modifications, and deprecations.
4. **Architectural Guardrails**: Test-bound system invariants and contract-first API definitions.
5. **Multi-Agent Execution**: Pluggable coding harnesses that dispatch tasks to any agent (`agy`, Claude Code, Codex, etc.).
6. **Native VCS Integration**: Full bidirectional synchronization with GitHub Issues / PRs and GitLab Epics / MRs.

== Architectural Philosophy
