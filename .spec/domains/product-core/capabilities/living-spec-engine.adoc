= Capability: Living Baseline Specification Engine
:toc: left

== Intent
Traditional product requirements documents (PRDs) quickly become obsolete. This capability ensures that the `.spec/` directory is treated as living code: every document has an explicit type and JSON/YAML schema, is validated continuously, and forms an in-memory knowledge graph that AI agents can query to understand the system state.

== Key Responsibilities
* Parsing YAML frontmatter combined with AsciiDoc technical specifications.
* Schema validation ensuring strict adherence to typing rules.
* Graph construction linking Personas, Domains, Capabilities, Invariants, and Tests.
