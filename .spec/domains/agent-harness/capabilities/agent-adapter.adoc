= Capability: Universal Agent Adapter Layer
:toc: left

== Intent
Avoids vendor lock-in. Whether an organization prefers running local agents via CLI (like Google Antigravity `agy`), cloud API agents (OpenAI Codex, Claude), or custom internal models, the adapter normalizes input prompts, context windows, and output verification.
