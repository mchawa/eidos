= Policy: Git as the Single Source of Truth
:toc: left

== Rationale
External systems create split-brain development: engineers work from Jira tickets, designers from Figma, product managers from Notion, while the actual code lives in Git. Eidos mandates that product definitions and technical architectures are code assets versioned, diffed, and reviewed within Git. Similarly, rather than scattering historical decisions across detached chronological ADR graveyards (`docs/adr/`), enduring architectural trade-offs (`DEC-*`) and rejected alternatives are embedded directly in the `decisions` block of the living specification (`product/system`, `tech/architecture`, `tech/container`, or `tech/component`) they govern.
