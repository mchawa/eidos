== Architectural Boundary
This container represents the foundational library under `src/eidos/core/` (`spec/`, `lifecycle/`, and `workspace/` subpackages) and bundled schemas under `assets/schemas/`. It owns all specification parsing, JSON Schema validation, zero-config project path resolution, multi-design system scaffolding, W3C token management, SpecDelta lifecycle state machines, and reference checking.

== Quality Attributes & Operational Policies
* **Statelessness**: The core engine operates statelessly. All state is maintained within the Git repository and accelerated by an ephemeral cache (`eidos/.cache/index.db`).
* **Validation Determinism**: Schema validation produces deterministic exit codes and structured reports.
