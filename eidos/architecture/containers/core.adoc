= Container: Eidos Living Specification Core Engine (C4 Level 2 Container & Level 3 Components)
:toc: left

== Architectural Boundary
This container represents the foundational library under `src/eidos/core/`. It owns all specification parsing, JSON Schema validation, multi-design system scaffolding, W3C token management, SpecDelta lifecycle state machines, reference checking, and embedded architectural graph indexing.

== Quality Attributes & Operational Policies
* **Statelessness**: The core engine operates statelessly. All state is maintained within the Git repository and accelerated by an ephemeral cache (`.eidos/cache/index.db`).
* **Validation Determinism**: Schema validation produces deterministic exit codes and structured reports.
