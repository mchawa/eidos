= Container: Eidos Living Specification Core Engine (C4 Level 2 Container)
:toc: left

== Architectural Boundary
This container represents the foundational library under `src/eidos/core/` (`spec/`, `lifecycle/`, and `workspace/` subpackages) and bundled schemas and AsciiDoc prose templates under `assets/schemas/`. It owns all specification parsing, JSON Schema validation, zero-config project path resolution, minimal blueprint scaffolding across all 15 living specification types, W3C token management, SpecDelta lifecycle state machines, and reference checking.

== Runtime & Subsystem Organization
`CNT-EIDOS-CORE` is structured into three internal subpackages plus the packaged `assets/schemas/v1/` schema bundle:

* **Specification Parsing & Validation (`src/eidos/core/spec/`)**: Parses AsciiDoc documents with YAML frontmatter via Rust-backed `fastyaml-rs`, projects frontmatter into typed Pydantic domain models, and validates all 16 v1 document types against JSON Schema Draft 2020-12 (`jsonschema`), recursive `x-eidos-ref` cross-references, bidirectional multi-protocol `CTR-*` contract parity, W3C DTCG token manifests, and AST-verified `INV-*` test bindings.
* **Specification & SpecDelta Lifecycle (`src/eidos/core/lifecycle/`)**: Orchestrates greenfield repository initialization (`--lite` and full), minimal draft blueprint generation from externalized `.template.adoc` templates, reference-safe catalog deletion, SpecDelta state transitions (`proposed` -> `in_review` -> `approved` -> `applied` / `rejected`), Git-baseline post-condition verification, index-scoped tombstone deletion auditing, two-tier archiving (`eidos/deltas/archive/`), and Keep a Changelog compilation.
* **Workspace & Asset Resolution (`src/eidos/core/workspace/`)**: Resolves repository roots (`eidos/`), glob-based `source_path` ownership rules, standard excluded directories, and bundled schema/template assets across editable checkouts and wheel installations.

== Quality Attributes & Operational Policies
* **Stateless Git-Native Execution (`POL-001`)**: Operates statelessly over the Git working tree and commit graph; `eidos/.cache/index.db` is strictly an ephemeral, disposable acceleration cache.
* **Deterministic Validation & Serialization**: Schema validation, reference resolution, and `orjson` report serialization produce deterministic ordering and exit codes with zero external network or AI API calls (`POL-004`).
* **Zero Legacy Shims**: Enforces `additionalProperties: false` across all 16 v1 schemas and derives schema paths 1:1 from `type`.
