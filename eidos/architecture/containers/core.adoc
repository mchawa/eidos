= Container: Eidos Living Specification Core Engine (C4 Level 2 Container)
:toc: left

== Architectural Boundary
This container represents the foundational library under `src/eidos/core/` (`spec/`, `lifecycle/`, and `workspace/` subpackages), bundled schemas and AsciiDoc prose templates under `assets/schemas/`, and the standalone compressed Mermaid parser bundle under `assets/mermaid/`. It owns all specification parsing, JSON Schema validation, in-process QuickJS Mermaid syntax validation (`CMP-MERMAID-VALIDATOR`, `DEC-CORE-IN-PROCESS-QUICKJS-MERMAID-VALIDATION`), zero-config project and monorepo sub-project path resolution, minimal blueprint scaffolding across all 15 living specification types, W3C token management, SpecDelta lifecycle state machines, and reference checking. It explicitly excludes SQLite persistence and lexical/AST indexing (delegated to `CNT-EIDOS-INDEX`), Git diff and drift evaluation (delegated to `CNT-EIDOS-VCS`), CLI presentation (`CNT-EIDOS-CLI`), and web portal rendering (`CNT-EIDOS-PORTAL`).
