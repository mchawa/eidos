== Architectural Boundary
This container represents the autonomous agent interface under `src/eidos/mcp/`. It exposes a stdio JSON-RPC 2.0 server conforming to the Model Context Protocol (MCP) standard, enabling agents in Antigravity, Cursor, and Claude Code to inspect and modify living specifications.
