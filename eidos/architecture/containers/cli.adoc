== Architectural Boundary
This container represents the developer entrypoint under `src/eidos/cli/`. It provides a single canonical command path per operation for authoring, validating, and indexing living specifications across the 15 declarative specification types (`eidos spec`), executing repository drift detection, managing C4 architecture topologies, and orchestrating SpecDelta mutations (`eidos delta`).

== Quality Attributes & Operational Policies
* **Exit Codes**: Exit code `0` on success, `1` on validation failures or detected drift, and `2` on execution errors.
* **Terminal UI**: Uses Rich formatting to provide human-readable tables, syntax-highlighted diffs, and progress indicators.
