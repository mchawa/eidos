:toc: left

== Architectural Boundary
This container represents the developer entrypoint under `src/eidos/cli/`. It provides commands for authoring, validating, indexing, and reconciling living specifications, executing repository drift detection, inspecting C4 architecture topologies, and synchronizing SpecDeltas.

== Quality Attributes & Operational Policies
* **Exit Codes**: Exit code `0` on success, `1` on validation failures or detected drift, and `2` on execution errors.
* **Terminal UI**: Uses Rich formatting to provide human-readable tables, syntax-highlighted diffs, and progress indicators.
