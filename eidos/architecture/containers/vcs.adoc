== Architectural Boundary
This container represents the Git-native drift detection and specification reconciliation engine under `src/eidos/vcs/`. It inspects Git commit ranges and uncommitted working-tree diffs, performs structural AST symbol comparison, verifies static invariant test bindings (`file::func`), and evaluates 1-hop knowledge graph neighborhoods to detect specification-to-code drift.
