= Container: Eidos Git Drift & Lifecycle Engine (C4 Level 2 Container)
:toc: left

== Architectural Boundary
This container represents the Git-native drift detection and specification reconciliation engine under `src/eidos/vcs/`. It inspects Git commit ranges (isolating `--base`/`--head` evaluation to the `--head` commit tree) and uncommitted working-tree diffs, performs structural AST symbol comparison, verifies static invariant test bindings (`file::func`, including `design/` `UIC-*` invariants), enforces `verify_delta_mutations` on newly applied SpecDeltas, enforces declarative `import_boundaries` and `ratchet_baseline` ceilings (`boundary_violations` and advisory `ratchet_shrink_candidates`), evaluates 1-hop knowledge graph neighborhoods to detect specification-to-code drift, and renders remediation and Markdown verification reports. It never executes project test runners or mutates Git history.

== Internal Structure & Key Mechanisms
* **Git Diff & Blob Inspection (`CMP-GIT-DIFF-INSPECTOR`: `src/eidos/vcs/diff.py`)**: Detects shallow repositories across standard checkouts and linked Git worktrees via `git rev-parse --is-shallow-repository` (failing closed on `fetch-depth: 1` single-commit diffs), parses uncommitted working-tree changes via NUL-delimited `git status --porcelain=v1 -z -uall`, classifies executable files under `docs/` as governed code and onboarding artifacts (`AGENTS.md`, `CLAUDE.md`, `.aider.conf.yml`, `.agents/skills/**/SKILL.md`) for integrity checks, and batch-reads historical revisions via `git cat-file --batch`.
* **Snapshot Isolation, Structural Reconciliation, Untouched Consumers & Boundary Ratchet (`CMP-DRIFT-DETECTOR`: `src/eidos/vcs/drift.py`, `src/eidos/vcs/snapshot.py`, `src/eidos/vcs/structural.py`, `src/eidos/vcs/consumers.py`, `src/eidos/vcs/report.py`, `DEC-VCS-STRICT-UI-CONTRACT-DESIGN-DRIFT`, `DEC-VCS-UNIFIED-TEST-BINDING-SEMANTICS`, `DEC-VCS-EXECUTABLE-IMPORT-RATCHET`, `DEC-VCS-UNTOUCHED-CONSUMERS-ADVISORY`)**: Isolates `--base`/`--head` evaluation and onboarding checks in `snapshot.py`, maps modified source files to owning `CMP-*`/`CNT-*` specs, filters intra-component symbol relocations across sibling `source_path` files out of `stale_removed_symbol`, detects non-blocking advisory `untouched_consumers` across reverse imports and 1-hop re-export barrels in `consumers.py`, enforces `verify_delta_mutations` and `_spec_coverage_verdict` on newly applied SpecDeltas, evaluates `import_boundaries` / `ratchet_baseline` constraints (`boundary_violations` and non-blocking `ratchet_shrink_candidates`), enforces bound design subgraph co-evolution, and renders CLI remediation and PR Markdown summaries (`report.py`).
* **Static Invariant Traceability (`CMP-INVARIANT-TRACEABILITY-VERIFIER`: `src/eidos/vcs/invariants.py`, `DEC-VCS-STATIC-INVARIANT-TRACEABILITY`, `DEC-VCS-UNIFIED-TEST-BINDING-SEMANTICS`)**: Scans `policies/`, `domains/`, `architecture/`, and `design/` (`UIC-*`) to verify that every active `INV-*` `test_binding` (`file::func` or `file::Class::method`) resolves to a non-skipped polyglot test symbol explicitly referencing the exact `INV-*` token.

== Quality Attributes & Operational Policies
* **Fail-Closed Git Ref Resolution (`INV-DRIFT-FAIL-CLOSED-ON-GIT-ERROR`)**: Unresolvable `--base` Git references immediately raise a `DriftError` rather than silently reporting a clean tree.
* **Static-Only Verification (`POL-INVARIANT-TEST-ENFORCEMENT`, `DEC-VCS-STATIC-INVARIANT-TRACEABILITY`)**: Never executes project test runners or external toolchains during `eidos drift`, maintaining sub-second, deterministic verification across polyglot repositories.
