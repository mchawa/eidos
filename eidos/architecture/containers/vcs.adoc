= Container: Eidos Git Drift & Lifecycle Engine (C4 Level 2 Container & Level 3 Components)
:toc: left

== Architectural Boundary
This container represents the Git-native drift detection and specification reconciliation engine under `src/eidos/vcs/`. It inspects Git commit ranges and uncommitted working-tree diffs, performs structural AST symbol comparison, verifies static invariant test bindings (`file::func`), evaluates 1-hop knowledge graph neighborhoods to detect specification-to-code drift, and renders remediation and Markdown verification reports.
