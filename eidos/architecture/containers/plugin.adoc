= Container: Eidos Agent Plugin & Extension Manager (C4 Level 2 Container)
:toc: left

== Architectural Boundary
This container represents the Agent Skills distribution, hook execution, and validation system under `src/eidos/plugin/` and `assets/plugin_reference/`. It packages living specification skills, lifecycle hooks, and validation rules adhering to `agentskills.io` across 9 AI coding environments: Google Antigravity, Claude Code, Cursor, Aider, Cline, Kilo Code, OpenCode, GitHub Copilot, and OpenAI Codex.

== Internal Structure & Key Mechanisms
* **Declarative Target Adapter Pipeline (`DEC-PLUGIN-HOOK-CAPABLE-TARGETS`, `DEC-PLUGIN-SKILLS-ONLY-ALL-TARGETS`)**: Synchronizes the 4 bundled workflow skills (`eidos`, `eidos-spec`, `eidos-plan`, `eidos-ops`) and opt-in `--hooks` lifecycle configurations across `.agents/skills/` (Antigravity, Cursor, GitHub Copilot, OpenAI Codex, Cline, Kilo Code, OpenCode), `.claude/skills/` (Claude Code), and `.aider/skills/` (Aider), wiring `.agents/hooks.json` (Antigravity), `.claude/settings.json` (Claude Code), `.cursor/hooks.json` (Cursor), `.clinerules/hooks/TaskComplete` (Cline), `.github/hooks/hooks.json` (GitHub Copilot), and `.codex/hooks.json` (OpenAI Codex) when `--hooks` is enabled on `install` (and preserving the installed hook state on `update`).
* **Canonical `AGENTS.md` Block (`DEC-PLUGIN-AGENTS-MD-MANAGED-BLOCK`)**: Every target projects one marker-delimited Eidos block, rendered from `assets/plugin_reference/agents-md/block.md` (directing agents to inspect `eidos context` for `CNT-*`/`CMP-*`, `DOM-*`, `CAP-*`, `PER-*`, `POL-*`, `design`, `INV-*`, `DEC-*`, and `CTR-*` and run `eidos drift --uncommitted --json` as the unified completion gate), into the repository's root `AGENTS.md`; user content outside the markers is never modified. Claude Code imports it from root `CLAUDE.md` (`@AGENTS.md`); Aider loads it via `.aider.conf.yml` (`read: [AGENTS.md]`).
* **Self-Contained Skills & SpecDelta Blast-Radius Reconciliation (`DEC-PLUGIN-SKILLS-SELF-CONTAINED`, `DEC-PLUGIN-DELTA-BLAST-RADIUS-RECONCILIATION`)**: The 4 bundled skills stay complete in their `SKILL.md` files (including `DOM-*`, `PER-*`, `POL-*`, and `design/*` co-evolution checklists, bottom-up quoted-glob `eidos context -f` reconciliation of `== Implementation Plan` files against 1-hop ownership rules, `UNMODIFIED`-avoidance annotations, `INV-*` test pairing, compliant `DLT-2026-015` few-shot templates, and autonomous pre-presentation 5-Dimension self-review in `eidos` and `eidos-plan`); no `references/` split. No-growth word ceilings, skill-to-CLI parity, and SpecDelta reconciliation rules are enforced in tests.
* **Manifest-Tracked Installation, Hook Health Inspection & Safe Uninstallation**: Records installed file relative paths, SHA-256 digests, and per-target hook intent (`hooks: true/false`) in `.eidos-manifest.json` so `eidos doctor` verifies hook health according to installation intent and `eidos plugin uninstall` removes only Eidos-managed artifacts without disturbing user-authored skills, shared parent directories, or shared user files (`AGENTS.md`, `CLAUDE.md`, `.aider.conf.yml`, `.agents/hooks.json`, `.claude/settings.json`, `.cursor/hooks.json`, `.clinerules/hooks/TaskComplete`, `.github/hooks/hooks.json`, `.codex/hooks.json`).
* **Stateless 1-Turn Stop Hook Continuation (`DEC-PLUGIN-STATELESS-SINGLE-STOP-HOOK`, `DEC-PLUGIN-HOOK-CAPABLE-TARGETS`)**: Executes `detect_drift(uncommitted=True)` at the end of an agent turn (`Stop` / `TaskComplete`) via `eidos hook` and emits a client-aware 1-turn continuation payload (`decision: "continue"` for Antigravity, `followup_message` for Cursor, `cancel: true` with `contextModification`/`errorMessage` for Cline, and `decision: "block"` for Claude Code, GitHub Copilot, and OpenAI Codex) on the first stop when validation or drift issues are present, or a clean allow payload on the retry turn using each client's in-memory `stdin` retry counter.

== Quality Attributes & Operational Policies
* **Non-Destructive File Safety**: Rejects symlink traversal outside the target repository and refuses to overwrite modified user files unless `--force` is explicitly supplied.
* **Standard Conformance (`INV-PLUGIN-SCHEMA-CONFORMANCE`)**: Validates `SKILL.md` frontmatter, skill directory naming parity, `hooks.json`, and PEP 440 -> SemVer 2.0.0 version normalization against `agentskills.io`.
* **CLI-Native Hook Execution (`INV-HOOK-CLI-NATIVE`)**: Invokes `eidos hook` directly (or via version-pinned `uvx --from eidos-spec==<semver> eidos hook`) without shell or Python wrapper scripts.
