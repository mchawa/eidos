= Container: Eidos Agent Plugin & Extension Manager (C4 Level 2 Container)
:toc: left

== Architectural Boundary
This container represents the plugin distribution, hook execution, and validation system under `src/eidos/plugin/` and `assets/plugin_reference/`. It packages living specification skills, commands, and validation rules into standard bundles adhering to `agent-plugins.org v1.0.0` as well as Claude Code, OpenAI Codex, OpenCode, Aider, Cline, Cursor, and GitHub Copilot environments.

== Internal Structure & Key Mechanisms
* **Declarative Target Adapter Pipeline**: Synchronizes the 4 bundled workflow skills (`eidos`, `eidos-spec`, `eidos-plan`, `eidos-ops`), `plugin.json` manifests, and `hooks.json` / `.claude/settings.json` lifecycle configurations across `.agents/plugins/eidos`, `.github/plugin/`, `.github/skills/`, `.claude/skills/`, `.claude/settings.json`, `.cursor/skills/`, `.cline/skills/`, `.opencode/skills/`, `.codex/`, and `.aider/skills/`.
* **Canonical `AGENTS.md` Block (`DEC-PLUGIN-AGENTS-MD-MANAGED-BLOCK`)**: Every target projects one marker-delimited Eidos block, rendered from `assets/plugin_reference/agents-md/block.md` (directing agents to run `eidos drift --uncommitted --json` as the unified completion gate), into the repository's root `AGENTS.md`; user content outside the markers is never modified. Claude Code imports it from root `CLAUDE.md` (`@AGENTS.md`), and Aider loads it via `.aider.conf.yml` `read:`.
* **Self-Contained Skills (`DEC-PLUGIN-SKILLS-SELF-CONTAINED`)**: The 4 bundled skills stay complete in their `SKILL.md` files; no `references/` split. No-growth word ceilings and skill-to-CLI parity are enforced in tests.
* **Manifest-Tracked Installation & Safe Uninstallation**: Records installed file relative paths and SHA-256 digests in `.eidos-manifest.json` so `eidos plugin uninstall` removes only Eidos-managed artifacts without disturbing user-authored skills, shared parent directories, or shared user files (`AGENTS.md`, `CLAUDE.md`, `.aider.conf.yml`).
* **Stateless Single Stop Hook (`DEC-PLUGIN-STATELESS-SINGLE-STOP-HOOK`)**: Executes `detect_drift(uncommitted=True)` once at the end of an agent turn (`Stop`) via `eidos hook` and emits a non-blocking `{"decision": "allow", "systemMessage": "..."}` diagnostic payload when validation or drift issues are present.

== Quality Attributes & Operational Policies
* **Non-Destructive File Safety**: Rejects symlink traversal outside the target repository and refuses to overwrite modified user files unless `--force` is explicitly supplied.
* **Standard Conformance (`INV-PLUGIN-SCHEMA-CONFORMANCE`)**: Validates `plugin.json`, `SKILL.md` frontmatter, `hooks.json`, and PEP 440 -> SemVer 2.0.0 version normalization against `agent-plugins.org v1.0.0`.
* **CLI-Native Hook Execution (`INV-HOOK-CLI-NATIVE`)**: Invokes `eidos hook` directly (or via version-pinned `uvx --from eidos-spec==<semver> eidos hook`) without shell or Python wrapper scripts.
