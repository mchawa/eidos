= Container: Eidos Agent Plugin & Extension Manager (C4 Level 2 Container & Level 3 Components)
:toc: left

== Architectural Boundary
This container represents the plugin distribution and validation system under `src/eidos/plugin/`. It packages living specification skills, MCP server definitions, and validation rules into standard bundles adhering to `agent-plugins.org v1.0.0` as well as Claude Code plugins.

== Arc42 Section 5.2 / C4 Level 3: Internal Building Blocks

[cols="1,1,2,2", options="header"]
|===
| Component ID | Name | Responsibility | Source Path
| `CMP-PLUGIN-INSTALLER` | **PluginInstaller** | Manages installation and file synchronization into `.agents/plugins/eidos` and `.claude/skills/eidos` | `src/eidos/plugin/installer.py`
| `CMP-PLUGIN-VALIDATOR` | **PluginValidator** | Enforces JSON Schema conformance and SemVer 2.0.0 rules for plugins | `src/eidos/plugin/validator.py`
| `CMP-MCP-CONFIG-SYNC` | **McpConfigSync** | Automatically configures client MCP entries and enabled plugin settings in `.cursor/mcp.json`, `.claude/mcp.json`, and `.claude/settings.json` | `src/eidos/plugin/installer.py`
| `CMP-HOOK-MANAGER` | **HookManager** | Validates and coordinates lifecycle hooks (`hooks.json`) and linter runners | `src/eidos/plugin/validator.py`
|===
