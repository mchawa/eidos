== Architectural Boundary
This container represents the embedded relational and lexical indexing engine under `src/eidos/core/index/`. `ArchitecturalIndex` in `graph_index.py` acts as a thin 391-LOC facade delegating persistence, schema versioning, incremental sync, FTS5/CTE graph queries, and tiered context slicing to focused submodules (`storage.py`, `sync.py`, `query.py`, `context.py`, and `ast_indexer.py`). It persists and manages the local SQLite knowledge graph (`eidos/.cache/index.db`), providing sub-millisecond catalog lookups, incremental zero-drift synchronization, AST-derived component and container dependency graphs, FTS5 BM25 search, recursive CTE blast-radius traversal, and tiered context slicing for AI coding agents and CLI commands.
