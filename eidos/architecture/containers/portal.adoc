= Container: Eidos Living Web Portal (C4 Level 2 Container & Level 3 Components)
:toc: left

== Architectural Boundary
This container represents the graphical web interface under `src/eidos/portal/`. It enables non-IDE stakeholders (product managers, architects, designers, and compliance officers) to visually navigate the living architecture, inspect C4 topologies, monitor SpecDelta lifecycles, and explore multi-design system tokens.
