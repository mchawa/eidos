= Container: Eidos Living Web Portal (C4 Level 2 Container & Level 3 Components)
:toc: left

== Architectural Boundary
This container represents the graphical web interface under `src/eidos/portal/` and packaged bundle assets under `assets/portal/`. It enables non-IDE stakeholders (product managers, architects, designers, and compliance officers) to visually navigate the living architecture, inspect C4 topologies, simulate architectural blast radius (`INV-PORTAL-STATIC-SCALABILITY`), monitor SpecDelta lifecycles, and explore multi-design system tokens via hash-based deep linking (`DEC-PORTAL-HASH-ROUTING`).

== Air-Gapped Bundle (INV-PORTAL-AIR-GAPPED-BUNDLE)
The single-file bundle served by `eidos portal serve` and emitted by `eidos portal build` loads zero scripts, stylesheets, fonts, or other subresources from remote origins, so C4 diagrams and the specification reader work in air-gapped environments and from `file://` static sites:

* **Mermaid.js** is imported from npm at the version pinned in `package.json` / `pnpm-lock.yaml` (lazy `import()` folded inline by the single-file build; the ELK layout engine is not shipped, `dagre` is the portal layout).
* **Asciidoctor.js** (`@asciidoctor/core`, `safe: 'secure'`) replaces the former regex AsciiDoc renderer; `include::` is unsupported in the browser.
* **Fonts**: Geist and Geist Mono latin `woff2` subsets from `@fontsource`; the `Inter` / `JetBrains Mono` stacks in `tokens.json` fall through to system fonts.
* **Build & Packaging**: `cd src/eidos/portal/frontend && pnpm build:assets` runs the Vite build and `scripts/build_assets.py`, which writes deterministic gzip-compressed `assets/portal/bundle.html.gz` (marked `linguist-generated=true` in `.gitattributes`) and `assets/portal/favicon.svg`, and refuses bundles with remote references, more than one `</head>`, or more than 5 MiB. CI enforces bundle parity via `python3 scripts/build_assets.py --check`, and `hatch_build.py` synchronizes assets during `uv build`. Node.js is a build-time dependency only (INV-PORTAL-ZERO-NODE-DEP).
