== Architectural Boundary
This container represents the public documentation site under `docs/` and its build pipeline configured by `zensical.toml`. It publishes comprehensive guides, conceptual frameworks, under-the-hood engine mechanics, 16-schema glossaries, and CLI references to GitHub Pages (`https://mchawa.github.io/eidos/`), while embedding the Eidos Living Portal (`site/portal/`).
