= Component: UserGuides
:toc: left

== Responsibility
Provides operational reference manuals for the Eidos CLI (`docs/guides/cli.md`, including `eidos delta show`, `eidos doctor` onboarding governance, and `eidos portal build --single-file`), AI Agent Plugin integration across 9 coding harnesses (`docs/guides/agent-plugin.md`, including the canonical root `AGENTS.md` managed block and session-scoped `Stop` and Cline `.clinerules/hooks/PreToolUse` hook wiring), and Living Web Portal deployment (`docs/guides/living-portal.md`, including `/api/events` SSE live drift and chunked vs `--single-file` static export).

== Key Responsibilities & Collaborators
* **CLI, Agent Plugin & Portal Manuals**: Documents every top-level command, subcommand, and CLI flag exposed by `CTR-EIDOS-CLI` in `docs/guides/cli.md` (including `eidos init --ci` turnkey GitHub/GitLab CI workflow scaffolding, `eidos validate` embedded Mermaid diagram syntax validation, canonical 17-value contract parity covering `rest_http`, `asyncapi`, `json_rpc_stdio`, `code_interface`, `wsdl`, `avro`, `sql_ddl`, `trpc`, `websocket`, `mcp`, polyglot `cli_args`, OpenAPI 3.1 `webhooks`, and bidirectional `json_schema` `$defs`, non-blocking advisory `warnings`, and opt-in `--fail-on-warnings` escalation on `validate` and `drift`, `eidos spec create screen --client`, `eidos spec discover` deterministic brownfield discovery including `.wsdl`/`.avsc`/`.avdl`/`.prisma`/canonical schema `.sql` and code-first `rest_http` controller/router root detection, `eidos context --uncommitted` / `--base`, `eidos index status` (`SCHEMA_VERSION` `2.22.0`), `eidos index sync --no-semantic --json`, `eidos index blast-radius --min-confidence`, `eidos index health` governance health scorecards, epistemic provenance outputs, and `eidos drift` `boundary_violations` / `ratchet_shrink_candidates` / `validation_warnings` diagnostics), the 4 bundled workflow skills (`eidos`, `eidos-spec`, `eidos-plan`, `eidos-ops`), `eidos delta show` active/archived inspection, `eidos delta conflicts` parallel target/blast-radius overlap detection, `eidos doctor` `AGENTS.md` health verification, opt-in native completion hooks (`.agents/hooks.json`, `.claude/settings.json`, `.cursor/hooks.json`, `.clinerules/hooks/PreToolUse`, `.github/hooks/hooks.json`, `.codex/hooks.json`), and interactive SSE (`/api/events`) and static (`--single-file` / chunked) Living Portal workflows.
