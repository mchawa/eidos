= Component: UserGuides
:toc: left

== Responsibility
Provides operational reference manuals for the Eidos CLI (`docs/guides/cli.md`, including `eidos delta show`, `eidos doctor` onboarding governance, and `eidos portal build --single-file`), AI Agent Plugin integration across 9 coding harnesses (`docs/guides/agent-plugin.md`, including the canonical root `AGENTS.md` managed block and session-scoped `Stop` and Cline `.clinerules/hooks/PreToolUse` hook wiring), and Living Web Portal deployment (`docs/guides/living-portal.md`, including `/api/events` SSE live drift and chunked vs `--single-file` static export).

== Key Responsibilities & Collaborators
* **CLI, Agent Plugin & Portal Manuals**: Documents every top-level command, subcommand, and CLI flag exposed by `CTR-EIDOS-CLI` in `docs/guides/cli.md`, the 4 bundled workflow skills (`eidos`, `eidos-spec`, `eidos-plan`, `eidos-ops`), `eidos delta show` active/archived inspection, `eidos doctor` `AGENTS.md` health verification, opt-in native completion hooks (`.agents/hooks.json`, `.claude/settings.json`, `.cursor/hooks.json`, `.clinerules/hooks/PreToolUse`, `.github/hooks/hooks.json`, `.codex/hooks.json`), and interactive SSE (`/api/events`) and static (`--single-file` / chunked) Living Portal workflows.

== Public Surface
* `docs/guides/cli.md`
* `docs/guides/agent-plugin.md`
* `docs/guides/living-portal.md`

== Design Constraints & Operational Notes
* **Automated Command Tree Verification (`INV-DOCS-SYNCHRONIZATION`)**: `tests/test_docs_sync.py` dynamically introspects the live Typer command tree and asserts that every command, subcommand, and CLI flag in `docs/guides/cli.md` matches the implementation.
