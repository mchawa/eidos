= Component: UserGuides
:toc: left

== Responsibility
Provides operational reference manuals for the Eidos CLI (`docs/guides/cli.md`), AI Agent Plugin integration across 9 coding harnesses (`docs/guides/agent-plugin.md`, including the canonical root `AGENTS.md` managed block, its marker grammar, user-content preservation, opt-in `--hooks` native `Stop` hook wiring, and opt-out), and Living Web Portal deployment (`docs/guides/living-portal.md`).

== Key Responsibilities & Collaborators
* **CLI, Agent Plugin & Portal Manuals**: Documents every top-level command, subcommand, and CLI flag exposed by `CTR-EIDOS-CLI` (including `eidos init` monorepo sub-project and explicit `eidos/` path normalization and `eidos doctor` PyPI release update and `Stop` hook health checks), the 4 bundled workflow skills (`eidos`, `eidos-spec`, `eidos-plan`, `eidos-ops`), the 8 Constitutional Guardrails, Discovery-First rule bridge generation across 9 coding harnesses, `.agents/plugins/eidos` integration for Antigravity, Cursor, GitHub Copilot, and OpenAI Codex, project-native Claude Code integration (`.claude/skills/` and `.claude/settings.json` `hooks.Stop`), `.agents/skills/` integration for Cline, Kilo Code, and OpenCode, `.aider/skills/` and `.aider.conf.yml` integration for Aider, opt-in native `Stop` / `TaskComplete` hook files (`.agents/plugins/eidos/hooks.json`, `.claude/settings.json`, `.cursor/hooks.json`, `.clinerules/hooks/TaskComplete`, `.github/hooks/hooks.json`, `.codex/hooks.json`), and interactive/static Living Portal workflows.

== Public Surface
* `docs/guides/cli.md`
* `docs/guides/agent-plugin.md`
* `docs/guides/living-portal.md`

== Design Constraints & Operational Notes
* **Automated Command Tree Verification (`INV-DOCS-SYNCHRONIZATION`)**: `tests/test_docs_sync.py` dynamically introspects the live Typer command tree and asserts that every command, subcommand, and CLI flag in `docs/guides/cli.md` matches the implementation.
