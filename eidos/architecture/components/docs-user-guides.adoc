= Component: UserGuides
:toc: left

== Responsibility
Provides operational reference manuals for the Eidos CLI (`docs/guides/cli.md`, including `eidos config` (`init`, `show`, `schema`), the optional `eidos/eidos.yaml` configuration reference distinguishing `workspace.exclude`, `workspace.tests.exclude`, and `drift.ignore_paths`, `eidos delta show`, `eidos doctor` onboarding governance and `checks.repo_config`, and `eidos portal build --single-file`), AI Agent Plugin integration across 9 coding harnesses (`docs/guides/agent-plugin.md`, including the canonical root `AGENTS.md` managed block, `eidos/eidos.yaml` `plugin.*` targets/hooks/updates configuration, `eidos config init` cross-reference, `.gitignore` guidance for committed `.agents/skills/` and `.agents/.eidos-manifest.json`, and session-scoped `Stop` and Cline `.clinerules/hooks/PreToolUse` hook wiring), and Living Web Portal deployment (`docs/guides/living-portal.md`, including `/api/events` SSE live drift, Team Memory & non-blocking `memory_audit` visibility, automatic interactive rendering of embedded AsciiDoc Mermaid diagrams across specification readers, `eidos/eidos.yaml` `portal.*` defaults, and chunked vs `--single-file` static export).
