= Component: GitDiffInspector
:toc: left

== Responsibility
Inspects Git commit ranges and uncommitted working trees (`get_git_diff_files`), classifies changed files into specs, SpecDeltas, tests, onboarding artifacts, and governed code (`classify_changed_files`), discovers polyglot test suites (`collect_polyglot_test_files`), maps source files to owning C4 components (`map_code_to_components`), and batch-reads historical Git blobs (`batch_read_git_blobs`).

== Key Responsibilities & Collaborators
* **Shallow-Safe Git Ref Resolution, `drift.base_ref` & NUL-Delimited Working-Tree Parsing (`diff.py`, `INV-DRIFT-FAIL-CLOSED-ON-GIT-ERROR`, `INV-DRIFT-SHALLOW-AND-COMMIT-TREE-FIDELITY`)**: Prepends optional `drift.base_ref` from `eidos/eidos.yaml` ahead of built-in default base branch candidates when `--base` is omitted, detects shallow repositories across standard checkouts and linked Git worktrees via `git rev-parse --is-shallow-repository` (failing closed via `GitResolutionError` instead of diffing `HEAD..HEAD` on `fetch-depth: 1` single-commit pushes), and collects uncommitted paths via NUL-delimited `git status --porcelain=v1 -z -uall`.
* **Governed File Classification, `eidos/eidos.yaml` Isolation, `drift.ignore_paths`, Test Discovery & Batch Blob Reading**: Explicitly intercepts `<eidos_dir>/eidos.yaml` ahead of `is_eidos_spec` in `classify_changed_files` so edits to `eidos/eidos.yaml` route strictly to `other_files` (never `spec_files` or `code_files`), honors `workspace.exclude` and `workspace.tests.{include,exclude}` across classification and `collect_polyglot_test_files`, applies `drift.ignore_paths` strictly to suppress `code_files` (never suppressing `spec_files`, `delta_files`, `memory_files`, `test_files`, or `onboarding_files`), restricts `docs/` exemptions to static/prose extensions, isolates top-level `eidos/memory/` artifacts into `ChangedFilesClassification.memory_files` (`INV-DRIFT-MEMORY-FILE-ISOLATION`), scans `.NET` test projects while pruning `is_dotnet_bin_dir` and `obj/`, tracks onboarding artifacts (`AGENTS.md`, `CLAUDE.md`, `.aider.conf.yml`, `.agents/skills/**/SKILL.md`), and batch-reads historical revisions via `git cat-file --batch`.

== Public Surface
* `GitResolutionError`, `ChangedFilesClassification`, `POLYGLOT_TEST_PATTERNS`
* `get_git_diff_files(repo_root: Path, base_ref: str | None = None, head_ref: str = "HEAD", uncommitted: bool = False, *, merge_base: str | None = None, repo_config: EidosConfig | None = None, eidos_dir: Path | None = None, snapshot_root: Path | None = None) -> list[str]`
* `classify_changed_files(files: list[str], repo_root: Path | None = None, eidos_dir: Path | None = None, package_paths: Iterable[str] | None = None, *, repo_config: EidosConfig | None = None) -> ChangedFilesClassification`
* `collect_polyglot_test_files(repo_root: Path, *, eidos_dir: Path | None = None, repo_config: EidosConfig | None = None) -> dict[str, str]`
* `map_code_to_components(eidos_dir: Path, code_files: list[str], repo_root: Path | None = None) -> list[tuple[str, str, str]]`
* `batch_read_git_blobs(repo_root: Path, specs: list[str]) -> dict[str, str | None]`

== Design Constraints & Operational Notes
* **Read-Only Git Execution**: Invokes strictly read-only Git plumbing (`rev-parse`, `merge-base`, `diff`, `status --porcelain=v1 -z`, `cat-file --batch`) and never mutates Git state or history.
