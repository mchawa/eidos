= Component: GitDiffInspector
:toc: left

== Responsibility
Inspects Git commit ranges and uncommitted working trees (`get_git_diff_files`), classifies changed files into specs, SpecDeltas, tests, onboarding artifacts, and governed code (`classify_changed_files`), discovers polyglot test suites (`collect_polyglot_test_files`), maps source files to owning C4 components (`map_code_to_components`), and batch-reads historical Git blobs (`batch_read_git_blobs`).

== Key Responsibilities & Collaborators
* **Shallow-Safe Git Ref Resolution & NUL-Delimited Working-Tree Parsing (`diff.py`, `INV-DRIFT-FAIL-CLOSED-ON-GIT-ERROR`, `INV-DRIFT-SHALLOW-AND-COMMIT-TREE-FIDELITY`)**: Detects shallow repositories across standard checkouts and linked Git worktrees via `git rev-parse --is-shallow-repository` (failing closed via `GitResolutionError` instead of diffing `HEAD..HEAD` on `fetch-depth: 1` single-commit pushes) and collects uncommitted paths via NUL-delimited `git status --porcelain=v1 -z -uall`.
* **Governed File Classification, Team Memory Isolation, Test Discovery & Batch Blob Reading**: Restricts `docs/` exemptions in `classify_changed_files` to static/prose extensions so executable code under `docs/` is governed as `code_files`, isolates top-level `eidos/memory/` artifacts into `ChangedFilesClassification.memory_files` (separate from `spec_files` and `delta_files`, without misclassifying domains such as `eidos/domains/memory/`) so memory edits neither mask structural drift nor defeat `CMP-HOOK-RUNNER`'s zero-edit Q&A short-circuit (`INV-DRIFT-MEMORY-FILE-ISOLATION`), scans `.NET` test projects (`*Tests.cs`, `*Test.cs`, `*_Tests.cs`, `*_Test.cs`, `*.Tests`, `*.UnitTests`) in `collect_polyglot_test_files` while pruning `is_dotnet_bin_dir` and `obj/`, tracks onboarding artifacts (`AGENTS.md`, `CLAUDE.md`, `.aider.conf.yml`, `.agents/skills/**/SKILL.md`), and batch-reads historical revisions via `git cat-file --batch`.

== Public Surface
* `GitResolutionError`, `ChangedFilesClassification`, `POLYGLOT_TEST_PATTERNS`
* `get_git_diff_files(repo_root: Path, base_ref: str | None = None, head_ref: str = "HEAD", uncommitted: bool = False, merge_base: str | None = None) -> list[str]`
* `classify_changed_files(changed_files: list[str], eidos_dir: Path | None = None, repo_root: Path | None = None, *, base_ref: str | None = None, head_ref: str = "HEAD", uncommitted: bool = False, merge_base: str | None = None) -> ChangedFilesClassification`
* `collect_polyglot_test_files(repo_root: Path, *, package_paths: list[str] | None = None) -> list[Path]`
* `map_code_to_components(eidos_dir: Path, code_files: list[str], repo_root: Path | None = None) -> list[tuple[str, str, str]]`
* `batch_read_git_blobs(repo_root: Path, specs: list[str]) -> dict[str, str | None]`

== Design Constraints & Operational Notes
* **Read-Only Git Execution**: Invokes strictly read-only Git plumbing (`rev-parse`, `merge-base`, `diff`, `status --porcelain=v1 -z`, `cat-file --batch`) and never mutates Git state or history.
