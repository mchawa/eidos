= Component: IncrementalSyncEngine
:toc: left

== Responsibility
Synchronizes living specifications (`eidos/`), governed source files (`source_path`), and polyglot test suites into the SQLite knowledge graph (`eidos/.cache/index.db`) using two-tier `mtime_ns` + `SHA-256` dirty detection, AST import dependency derivation, and canonical unidirectional edge reconstruction.

== Key Responsibilities & Collaborators
* **Two-Tier Dirty Detection (`<5ms`)**: Scans `eidos/`, test suites, and governed `source_path` directories via single-pass `os.scandir` (`check_index_dirty`) while excluding nested child sub-project boundaries (`discover_nested_subproject_roots`), refreshing unchanged `mtime_ns` timestamps in-place when `SHA-256` digests match and re-parsing only modified files (`sync_index`).
* **Entity, Method/Test Symbol & FTS Indexing**: Populates `entities`, `code_symbols` (including automated test symbols marked with `is_test = 1` from test suites alongside governed source symbols), `specs_fts` (using sync-scoped symbol state without module-global dicts and projecting `'method'` alongside `'class'`, `'function'`, `'interface'`, `'struct'`, and `'enum'`), and `file_tokens_fts`, while excluding archived SpecDeltas (`eidos/deltas/archive/`) from `specs_fts`.
* **Ownership Precedence & Scalable Edge Reconstruction**: Prioritizes standalone `tech/component` (`CMP-*`) claims ahead of `tech/container` (`CNT-*`) fallback in `_CodeOwnershipResolver`, derives intra-container `consumes_api` and inter-container `depends_on` edges from AST imports, and uses batched `WHERE target_id IN (...)` lookups (`<= 500` parameters per batch) in `rebuild_spec_edges` to scale cleanly past `SQLITE_MAX_EXPR_DEPTH` (`1000`).

== Public Surface
* `check_index_dirty(index: Any) -> tuple[bool, list[Path], list[Path]]`
* `sync_index(index: Any, force: bool = False, dirty_state: tuple[bool, list[Path], list[Path]] | None = None, strict: bool = False) -> IndexSyncStats`
* `rebuild_spec_edges(conn: sqlite3.Connection, updated_doc_ids: set[str] | None = None) -> None`
* `build_spec_path_resolver(conn: sqlite3.Connection) -> Callable[[str], str]`

== Design Constraints & Operational Notes
* **Rename & Tombstone Eviction**: Evicts stale entities and child invariants keyed by `file_path` whenever a specification ID is renamed or a file is deleted from disk, and garbage-collects orphaned `spec_embeddings` rows (`DELETE FROM spec_embeddings WHERE entity_id NOT IN (SELECT id FROM entities)`) while preserving spec-only `content_sha256` embeddings across `sync_index(force=True)`.
* **Incremental Edge Scoping**: Single-spec incremental updates rebuild only edges touching modified documents, their child invariants, and 1-hop graph neighbors.
