= Component: IncrementalSyncEngine
:toc: left

== Responsibility
Synchronizes living specifications (`eidos/`), governed source files (`source_path`), and polyglot test suites into the SQLite knowledge graph (`eidos/.cache/index.db`) using two-tier `mtime_ns` + `SHA-256` dirty detection, AST import dependency derivation, and canonical unidirectional edge reconstruction.

== Key Responsibilities & Collaborators
* **Two-Tier Dirty Detection (`<5ms`)**: Scans `eidos/`, test suites, and governed `source_path` directories via single-pass `os.scandir` (`check_index_dirty`), refreshing unchanged `mtime_ns` timestamps in-place when `SHA-256` digests match and re-parsing only modified files (`sync_index`).
* **Entity, FTS & File-Token Indexing**: Populates `entities`, `specs_fts` (including child `INV-*` rows, embedded `DEC-*` decisions, and projected primary AST `code_symbols`), and `file_tokens_fts` (for `CMP-DELTA-AUDITOR` deletion audits), while excluding archived SpecDeltas (`eidos/deltas/archive/`) from `specs_fts`.
* **Ownership Precedence & AST Dependency Edges**: Prioritizes standalone `tech/component` (`CMP-*`) claims ahead of `tech/container` (`CNT-*`) fallback in `_CodeOwnershipResolver` and derives intra-container `consumes_api` and inter-container `depends_on` edges from AST imports extracted by `CMP-AST-SYMBOL-INDEXER`.

== Public Surface
* `check_index_dirty(index: ArchitecturalIndex) -> DirtyState`
* `sync_index(index: ArchitecturalIndex, force: bool = False, strict: bool = False, dirty_state: DirtyState | None = None) -> SyncStats`
* `rebuild_spec_edges(conn: sqlite3.Connection, updated_doc_ids: set[str] | None = None) -> None`
* `build_spec_path_resolver(conn: sqlite3.Connection) -> Callable[[str], str]`

== Design Constraints & Operational Notes
* **Rename & Tombstone Eviction**: Evicts stale entities and child invariants keyed by `file_path` whenever a specification ID is renamed or a file is deleted from disk, and garbage-collects orphaned `spec_embeddings` rows (`DELETE FROM spec_embeddings WHERE entity_id NOT IN (SELECT id FROM entities)`) while preserving spec-only `content_sha256` embeddings across `sync_index(force=True)`.
* **Incremental Edge Scoping**: Single-spec incremental updates rebuild only edges touching modified documents, their child invariants, and 1-hop graph neighbors.
