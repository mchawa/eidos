Owns the incremental synchronization pipeline (sync_index, check_index_dirty, _is_governed_source_file, _upsert_file_tokens_fts, _can_use_ast_mem_cache, _json_dumps, is_polyglot_test_file, STANDARD_EXCLUDED_DIRS, index_source_file, store_code_symbols, restore_code_mappings, reconcile_code_ownership, _derive_ast_import_edges, rebuild_spec_edges, index_test_bindings, prune_stale_test_binding_edges, delete_spec_fts_rows, _reconcile_invariant_coverage, _project_ast_code_symbols_into_fts): detects spec and polyglot test_binding/source_path/specification_file mutations via SHA-256 and mtime hashing across all governed _GOVERNED_TEXT_EXTS (_CODE_EXTS plus .md, .toml, .json, .yaml, .yml) in eidos/, test suites (tests/, test/, and nested package test files), and declared source_path/specification_file/test_binding paths on both warm and cold syncs using a single-pass recursive os.scandir traversal (_scan_eidos_dir, _scan_code_dir with DirEntry.is_dir(follow_symlinks=False) and DirEntry.stat().st_mtime, excluding STANDARD_EXCLUDED_DIRS) and pre-filtered top_code_dirs path-boundary checks to eliminate duplicate os.stat calls, indexes deduplicated [A-Za-z0-9_-]{3,} identifier and entity tokens into the FTS5 file_tokens_fts table across all governed specification, source, and test files, reuses cached SpecDocument payloads via get_cached_spec_document and SHA-256 keyed in-memory AST extraction caches (_SOURCE_AST_MEM_CACHE, _TEST_BINDING_MEM_CACHE, _FRESH_FTS_BASE_SYMBOLS) while extracting frontmatter metadata through typed FrontmatterModel (doc.model) accessors (effective_domain, effective_source_paths, all_invariants, all_decisions), populates specs_fts.jtbd_or_rule with policy rules and delta motivation while indexing component Responsibility prose in specs_fts.body_text (skipping specs_fts indexing and affects edge generation for archived SpecDeltas under deltas/archive/ while retaining their entity rows for catalog and graduated_from/resulting_deltas integrity), strips AsciiDoc document attribute headers (^:[A-Za-z0-9_-]+:.*$) when building body_clean for specs_fts.body_text, refreshes unchanged mtimes in place, passes dirty_state from _ensure_synced() into sync(), evicts renamed doc_ids, stores AST symbols exclusively in 'code_symbols' (keyed by entity_id with _CodeOwnershipResolver prioritizing standalone tech/component over tech/container) without duplicating AST rows into 'symbol_mappings', filters restore_code_mappings against current extract_entity_paths(fm), materializes inferred_path and indirect container-design edges after reconcile_code_ownership (preserving design/client and design/ui-component styled_by edges), indexes top-level container, standalone component CMP-*, and INV-* entities into entities/specs_fts/edges/symbol_mappings (automatically deriving component consumes_api and container depends_on edges from AST source file imports via extract_imports and _CodeOwnershipResolver alongside contract consumption) and canonical unidirectional relational edges with path-to-ID edge canonicalization across all spec references (realizes, provides, consumes, owned_by, implemented_by, styled_by, extends, governed_by, serves_persona including tech/architecture c4_context.actors, describes_system, contains_container, graduated_from, graduated_to, delivered_by, has_screen, has_flow, uses_screen, implements, contains_component, part_of, asserts, affects) without synthetic reverse edge duplicates ('bound_to', 'domain_member', 'governs', 'implements_client', 'styles_client', 'extended_by'), projects primary AST code_symbols into specs_fts.symbols scoped to target_entity_ids on incremental edits, incrementally scopes rebuild_spec_edges to updated_doc_ids, unidirectional design/client/tech/architecture/container/capability edges, 1-hop neighbors of updated/evicted IDs, and incoming data_json references with anchored slash-delimited LIKE suffix resolution, persists and prunes test_binding_cache rows (functions_json and file_tokens_json via extract_test_file_cache_payload) during index_test_bindings and queries test_binding_cache in _reconcile_invariant_coverage to reconcile invariant has_test_coverage, matching_tests, and test_binding symbol_mappings from existing asserts edges without re-parsing unchanged test files, and updates AST symbol coordinates in sub-5ms.
