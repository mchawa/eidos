= Component: IncrementalSyncEngine
:toc: left

== Responsibility
Synchronizes living specifications (`eidos/`), governed source files (`source_path`), and polyglot test suites into the SQLite knowledge graph (`eidos/.cache/index.db`) across three cohesive submodules: serialized WAL dirty/sync coordination (`sync.py`), code ownership & AST import graph building (`code_graph.py`), and declarative spec & invariant test-binding edge reconstruction (`spec_edges.py`), delegating `ast_http` linking to `CMP-HTTP-TOPOLOGY-LINKER`.

== Key Responsibilities & Collaborators
* **Two-Tier Dirty Detection, `eidos/eidos.yaml` Tracking & Serialized Multi-Process Sync (`sync.py`, `<5ms`, `DEC-INDEX-SERIALIZED-SYNC-AND-CSHARP-NAMESPACES`, `DEC-INDEX-STRICT-FRESHNESS-LOCK-DIAGNOSTICS`)**: Scans `eidos/`, test suites (including root and sibling `.NET` `*.Tests` / `*.UnitTests` directories and literal `workspace.tests.include` roots while pruning `.NET` `bin/` outputs via `is_dotnet_bin_dir`), and governed `source_path` directories via single-pass `os.scandir` (`check_index_dirty`) while excluding `workspace.exclude` globs and nested child sub-project boundaries (`discover_nested_subproject_roots`, honoring `workspace.subprojects_exclude`); tracks the SHA-256 digest of optional `<eidos_dir>/eidos.yaml` in SQLite `metadata` key `repo_config_sha256` (without polluting `indexed_files`) to trigger bidirectional `code/source <-> code/test` reclassification and `test_binding_cache` / `memory_freshness_cache` invalidation on config changes; serializes `sync_index` (and opportunistic `check_index_dirty` mtime refreshes) across processes and threads under `_advisory_db_lock` (`index.db.lock`) + `BEGIN IMMEDIATE` transactions, emits a concise lock-wait diagnostic naming `index.db.lock` and holder PID to `sys.stderr` (without polluting `--json` stdout) when contended before waiting cleanly until the writer finishes, re-checks `is_dirty()` under contention or `PRAGMA data_version` changes so waiting callers reuse newly committed fresh state without duplicate indexing, self-heals previously misclassified `.NET` test files to `code/test`, and gates `_trigger_auto_semantic_refresh` on both `auto_semantic` and `context.semantic.enabled`.
* **Code Ownership & Polyglot Import Graph Derivation (`code_graph.py`)**: Prioritizes standalone `tech/component` (`CMP-*`) claims ahead of `tech/container` (`CNT-*`) fallback in `_CodeOwnershipResolver`, persists `code_symbols` (`http_endpoint`, `http_request`, 1-based `import` coordinates for both production `is_test = 0` and test `is_test = 1` files, declared C#/Java/Kotlin `namespace` symbols, and `is_test` symbols), exports shared polyglot import-to-file resolution helpers (`build_module_to_file_map`, `discover_go_module_roots`, `discover_rust_crate_map`, `resolve_import_target_file`, `resolve_import_target_files` covering Python, JS/TS, Go `go.mod` package directories, Rust `Cargo.toml` library crates + `crate::`/`super::`/`self::`, and C/C++), derives `consumes_api`/`depends_on` edges plus production-only `code_couplings` rows from `is_test = 0` `ast_import`, C#/Java/Kotlin declared `namespace` matches, and `.csproj`/`.fsproj`/`.vbproj` `<ProjectReference>` links, and delegates cross-runtime HTTP route linking to `CMP-HTTP-TOPOLOGY-LINKER`.
* **Declarative Spec Edge, Team Memory Projection, Invariant Coverage, Test Import Backfill & FTS Projection (`spec_edges.py`, `sync.py`, `DEC-INDEX-MEMORY-FRESHNESS-AND-SECONDARY-SLICING`)**: Reconstructs canonical provenance-ranked spec edges (`rebuild_spec_edges`) using batched `WHERE target_id IN (...)` lookups (`<= 500` parameters per batch) including `agent/memory` `anchors_entity` (`targets.entities`) and `promoted_to` edges (preserving `promoted_to` edges targeting embedded `DEC-*` IDs during dangling-edge cleanup), indexes automated test bindings and test-file AST imports (`kind = 'import', is_test = 1`) via `index_test_bindings` with a non-destructive one-time `metadata.key = 'test_imports_indexed'` backfill on existing `SCHEMA_VERSION` `2.22.0` caches, prunes stale test edges (`prune_stale_test_binding_edges`) with `has_test_coverage` reconciliation, persists all `agent/memory` documents in `entities` while indexing only active non-archived `agent/memory` (`status == 'active'`, excluding `eidos/memory/archive/`) `summary`, `category`, and target anchors into `specs_fts` (automatically scoping `spec_embeddings`), and projects governed AST symbols into `specs_fts` while excluding archived SpecDeltas (`eidos/deltas/archive/`).

== Design Constraints & Operational Notes
* **Rename, Memory Freshness & Tombstone Eviction**: Evicts stale entities, child invariants, and `memory_freshness_cache` rows whenever a specification or `agent/memory` document is edited, renamed, or deleted (clearing `memory_freshness_cache` on `force=True` or spec/code deletion), and garbage-collects orphaned `spec_embeddings` rows (`DELETE FROM spec_embeddings WHERE entity_id NOT IN (SELECT id FROM entities) OR entity_id NOT IN (SELECT entity_id FROM specs_fts)`) while preserving spec-only `content_sha256` embeddings across `sync_index(force=True)`.
* **Incremental Edge Scoping**: Single-spec incremental updates rebuild only edges touching modified documents, their child invariants, and 1-hop graph neighbors.
