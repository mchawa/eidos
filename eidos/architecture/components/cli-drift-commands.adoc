= Component: DriftCommands
:toc: left

== Responsibility
Spec-to-code and non-code drift detection (`eidos drift`) across uncommitted working trees and Git commit ranges, resolving both default and custom `--path` (including `--path .` repo roots and subdirectory invocations) via `find_repo_root`, emitting complete machine-readable JSON diagnostics (including unmapped_code_files, validation_errors, uncovered_invariants, and orphan_invariants without stdout banner corruption when combined with --markdown), distinguishing code vs. non-code drift and invariant traceability failures in terminal reports, surfacing explicit Git base resolution errors, and exiting non-zero when --base is invalid or missing in shallow clones.

== Public Surface
Document exported language-level APIs (functions, classes, traits) provided to peer components.
