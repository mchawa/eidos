= Component: DriftCommands
:toc: left

== Responsibility
Exposes the `eidos drift` CLI command for verifying zero specification-to-code drift, schema validity, and static invariant test-binding coverage across uncommitted working trees or Git commit ranges.

== Key Responsibilities & Collaborators
* **Drift Gate CLI Adapter**: Resolves repository and specification roots via `CMP-PROJECT-RESOLVER`, invokes `CMP-DRIFT-DETECTOR` (`detect_drift` with optional `--strict` enforcement, `generate_remediation_prompt`, `build_drift_remediation_and_summary`), and renders Rich terminal diagnostics (distinguishing `structural_code_files` and `body_only_code_files`), CI Markdown summaries (`--markdown`), or `orjson` JSON payloads (`--json`).

== Public Surface
* `register(app: typer.Typer) -> None`
* `drift_cmd(base: str, head: str, uncommitted: bool, strict: bool, markdown: Path | None, json_output: bool, warn_only: bool) -> None`

== Design Constraints & Operational Notes
* **Fail-Closed Exit Semantics**: Exits with code `1` whenever schema validation errors, uncovered/orphan invariants, unmapped structural code files (or uncovered `body_only_code_files` under `--strict`), unverified SpecDelta targets, or invalid `--base` Git references (`GitResolutionError`) are encountered.
