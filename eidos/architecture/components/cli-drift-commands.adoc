= Component: DriftCommands
:toc: left

== Responsibility
Exposes the `eidos drift` CLI command for verifying zero specification-to-code drift, schema validity, and static invariant test-binding coverage across uncommitted working trees or Git commit ranges.

== Key Responsibilities & Collaborators
* **Drift Gate CLI Adapter**: Resolves repository and specification roots via `CMP-PROJECT-RESOLVER`, invokes `CMP-DRIFT-DETECTOR` (`detect_drift`, `generate_remediation_prompt`, `generate_verification_markdown`), and renders Rich terminal diagnostics, CI Markdown summaries (`--markdown`), or `orjson` JSON payloads (`--json`).

== Public Surface
* `register(app: typer.Typer) -> None`
* `drift_command(path: Path, base: str, head: str, uncommitted: bool, json_output: bool, markdown: bool, prompt: bool) -> None`

== Design Constraints & Operational Notes
* **Fail-Closed Exit Semantics**: Exits with code `1` whenever schema validation errors, uncovered/orphan invariants, unmapped structural code files, unverified SpecDelta targets, or invalid `--base` Git references (`DriftError`) are encountered.
