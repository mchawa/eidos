= Component: DriftCommands
:toc: left

== Responsibility
Exposes the `eidos drift` CLI command for verifying zero specification-to-code drift, schema validity, and static invariant test-binding coverage across uncommitted working trees or Git commit ranges.

== Key Responsibilities & Collaborators
* **Drift Gate CLI Adapter**: Resolves repository, monorepo sub-project, and specification roots via `CMP-CLI-APP` (`resolve_cli_eidos_dir`) and `CMP-PROJECT-RESOLVER` (`resolve_spec_and_repo_roots`), loads optional `eidos/eidos.yaml` defaults (strictly from `--head` on commit-range runs, or working tree on `--uncommitted` runs) and resolves `--strict/--no-strict`, `--warn-only/--no-warn-only`, and `--fail-on-warnings/--no-fail-on-warnings` via `resolve_param_from_config` so explicit CLI flags override `EIDOS_*` env vars and config values, invokes `CMP-DRIFT-DETECTOR` (`detect_drift` with effective strict enforcement, which synthesizes remediation via `build_drift_remediation`), and renders Rich terminal diagnostics (distinguishing `structural_code_files` and `body_only_code_files`, listing `schema_errors` and `broken_references`, and surfacing blocking `boundary_violations` alongside advisory `ratchet_shrink_candidates`, non-blocking `validation_warnings`, diff-scoped `ready_to_apply_deltas`—escalating all non-empty `validation_warnings` and `ready_to_apply_deltas` to exit code `1` when effective `fail_on_warnings` is set without effective `warn_only`—and strictly non-blocking advisory `untouched_consumers` and diff-scoped `affected_memories` hints that never fail exit code `0` or `--fail-on-warnings`) or `orjson` JSON payloads (`--json`, including `"validation_warnings"`, `"ready_to_apply_deltas"`, `"untouched_consumers"`, and `"affected_memories"`).

== Public Surface
* `register(app: typer.Typer) -> None`
* `drift_cmd(base: str | None, head: str, uncommitted: bool, path: Path | None, warn_only: bool, fail_on_warnings: bool, strict: bool, json_output: bool) -> None`

== Design Constraints & Operational Notes
* **Fail-Closed Exit Semantics**: Exits with code `1` whenever schema validation errors, uncovered/orphan invariants, unmapped structural code files (or uncovered `body_only_code_files` under `--strict`), unverified SpecDelta targets, or invalid `--base` Git references (`GitResolutionError`) are encountered.
