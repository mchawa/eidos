= Component: GraphStorage
:toc: left

== Responsibility
Owns the embedded SQLite knowledge graph lifecycle (`eidos/.cache/index.db`), canonical `SCHEMA_VERSION` (`2.23.0`) DDL initialization (including `edges.provenance`, `edges.evidence`, `code_couplings`, `public_surface_cache`, `mermaid_validation_cache`, and `memory_freshness_cache`), corruption recovery, `orjson`-backed validation/test-binding/public-surface/Mermaid/memory-freshness and semantic embedding caches (`spec_embeddings`), and the `ArchitecturalIndex` facade.

== Key Responsibilities & Collaborators
* **File-Locked SQLite WAL Schema, Epistemic Provenance & Connection Management (`storage.py`, `DEC-INDEX-FLOCK-WAL-AND-PINNED-ONNX`, `DEC-INDEX-SERIALIZED-SYNC-AND-CSHARP-NAMESPACES`, `DEC-INDEX-HTTP-LINKING-AND-PROVENANCE`, `DEC-INDEX-STRICT-FRESHNESS-LOCK-DIAGNOSTICS`, `DEC-INDEX-PERSISTENT-PUBLIC-SURFACE-CACHE`, `DEC-INDEX-MEMORY-FRESHNESS-AND-SECONDARY-SLICING`, `DEC-INDEX-PRESERVE-EMBEDDINGS-ON-SCHEMA-MIGRATION`)**: Serializes 15-table SQLite WAL DDL initialization (`SCHEMA_VERSION` `2.23.0`, including `edges.provenance`, `edges.evidence`, `code_couplings`, `public_surface_cache`, `mermaid_validation_cache`, `memory_freshness_cache`, and `code_symbols.is_test`), atomic `_immediate_write_transaction` migrations using per-statement DDL (`_CACHE_SCHEMA_STATEMENTS`, never `executescript`), precedence-preserving `upsert_edge` updates (`declared_spec > ast_import > ast_http > ast_symbol > inferred_ownership`), 3-tier certainty mapping (`observed`, `derived`, `inferred`), corruption recovery, and multi-process sync writes via re-entrant per-thread/process OS advisory file locks (`_advisory_db_lock` on `eidos/.cache/index.db.lock` recording holder PID/timestamp metadata and emitting `sys.stderr` wait notices on contention before kernel-blocking wait) and explicit `BEGIN IMMEDIATE` write transactions (`_immediate_write_transaction`) without enabling `PRAGMA mmap_size`.
* **Unified Validation, Resolver, Guarded Embedding Preservation & Non-Blocking Opportunistic Cache Helpers**: Provides shared `NON_AST_SYMBOL_KINDS`, `build_spec_path_resolver`, `resolve_symbol_locations_in_db`, `get_cached_spec_document`, `load_spec_validation_cache` / `save_spec_validation_cache`, `load_test_binding_cache` / `save_test_binding_cache`, `load_public_surface_cache` / `save_public_surface_cache`, `load_mermaid_validation_cache` / `save_mermaid_validation_cache`, and `load_memory_freshness_cache` / `save_memory_freshness_cache` helpers consumed by `CMP-SPEC-VALIDATOR`, `CMP-MERMAID-VALIDATOR`, `CMP-ARCHITECTURE-BOUNDARY-VALIDATOR`, `CMP-INCREMENTAL-SYNC-ENGINE`, `CMP-FTS-QUERY-ENGINE`, `CMP-GRAPH-TRAVERSAL-ENGINE`, `CMP-TIERED-CONTEXT-COMPRESSOR`, and `CMP-DRIFT-DETECTOR` without inducing `query <-> sync` cycles; opportunistic cache reads use `open_cache_connection(..., allow_ddl=False)` (falling back to live disk parsing if `index.db` is missing or mid-DDL) and opportunistic cache writes use `_advisory_db_lock(..., non_blocking=True)` with a short SQLite timeout (skipping persistence on contention with zero freshness loss); `ensure_cache_schema` tracks `metadata` keys `test_binding_cache_ver`, `code_symbol_cache_ver`, and `embedding_schema_ver` (`EMBEDDING_SCHEMA_VERSION = "1"`), verifies `spec_embeddings` column names/types/`NOT NULL`/`PRIMARY KEY` via `PRAGMA table_info(spec_embeddings)`, stamps `embedding_schema_ver` non-destructively on existing current-`SCHEMA_VERSION` caches when strictly absent, preserves `spec_embeddings` rows and normalized `metadata['semantic_sync_complete']` atomically across unrelated `SCHEMA_VERSION` migrations whenever `embedding_schema_ver` and schema match, and drops/recreates `spec_embeddings` (clearing `semantic_sync_complete`) on `EMBEDDING_SCHEMA_VERSION` mismatch, incompatible columns, unversioned partial-table or legacy migrations, or corruption recovery.
* **Thread-Isolated `ArchitecturalIndex` Facade (`graph_index.py`)**: Isolates SQLite connections per thread via `threading.local()`, keys cached index instances by normalized `eidos_dir` (`_INDEX_INSTANCES`), debounces back-to-back in-process `_ensure_synced` dirty checks via `_last_synced_check` (`50ms` monotonic window) while forwarding `PRAGMA data_version` snapshots to `sync(..., auto_semantic=...)`, exposes `edge_counts_by_provenance` while excluding `'namespace'`, `'import'`, `'http_endpoint'`, and `'http_request'` rows from synthetic `'method'` symbol totals in `get_index_status()`, inherits `eidos/eidos.yaml` defaults when `get_tiered_context_slice(..., tier=None, use_semantic=None)` or `setup_semantic(variant=None, ...)` omit explicit overrides, and delegates directly to `fts_query.py` (`CMP-FTS-QUERY-ENGINE`), `traversal.py` (`CMP-GRAPH-TRAVERSAL-ENGINE`), `sync.py` (`CMP-INCREMENTAL-SYNC-ENGINE`), `semantic.py` (`CMP-SEMANTIC-EMBEDDING-ENGINE`), and `context.py` (`CMP-TIERED-CONTEXT-COMPRESSOR`).

== Design Constraints & Operational Notes
* **Stateless Multi-Agent WAL Safety & Guarded Embedding Preservation (`DEC-INDEX-STATELESS-DERIVED-CACHE`, `DEC-INDEX-FLOCK-WAL-AND-PINNED-ONNX`, `DEC-INDEX-PRESERVE-EMBEDDINGS-ON-SCHEMA-MIGRATION`)**: `eidos/.cache/index.db` stores zero unrecoverable state, executes schema migrations atomically under `index.db.lock` + `BEGIN IMMEDIATE` (preserving compatible `spec_embeddings` and `semantic_sync_complete` across unrelated `SCHEMA_VERSION` upgrades via `EMBEDDING_SCHEMA_VERSION`), and isolates threads via `threading.local()`.
