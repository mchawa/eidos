= Component: GraphStorage
:toc: left

== Responsibility
Manages embedded SQLite schema initialization as the single canonical authority for 'SCHEMA_VERSION' ('2.17.0'), 'ensure_cache_schema', and 'open_cache_connection' (with check_same_thread=False for multi-threaded portal serving, skipping DDL/DML write transactions on warm cache hits when schema_version and managed tables already match, performing stateless drop-and-rebuild migration on version mismatch, automatic unlink-and-rebuild recovery on corrupt 'sqlite3.DatabaseError' while preserving 'index.db' on transient lock/busy OperationalErrors, and normalized 'indexed_files', 'entities', 'edges', 'symbol_mappings', 'code_symbols', 'specs_fts', 'file_tokens_fts', 'spec_validation_cache', and 'test_binding_cache' tables without duplicate, write-only, or test-fixture columns), unified SpecDocument and test-binding cache helpers ('get_cached_spec_document', 'clone_spec_document' with reset '_model=None', 'load_spec_validation_cache', 'save_spec_validation_cache', 'load_test_binding_cache', 'save_test_binding_cache') using fast 'orjson' serialization with defensive copy isolation and parse_errors/errors separation inside 'doc_json', unified path resolution via '_resolve_index_paths(repo_root, eidos_dir, db_path)' delegating to 'resolve_spec_and_repo_roots', hydrated 'get_components' and SQL-filtered 'get_entities', dirty-checked 'get_spec_catalog' returning `(specs_by_id, invariant_map)` and pure graph-derived 'compute_delta_impact(mutations, sync=True)' facade methods, 4-query 'get_index_status' combining 'symbol_mappings' and 'code_symbols' counts, canonical 'get_k_hop_neighborhood(entity_id, max_depth=2)' facade delegation without private forwarding shims, db_path-aware 'get_architectural_index' singleton replacement with connection cleanup, WAL mode, read-only SELECT queries without transaction context managers, repository root discovery via find_repo_root, and indexed files tracking.
