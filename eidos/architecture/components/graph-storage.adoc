= Component: GraphStorage
:toc: left

== Responsibility
Owns the embedded SQLite knowledge graph lifecycle (`eidos/.cache/index.db`), canonical `SCHEMA_VERSION` (`2.17.0`) DDL initialization, corruption recovery, `orjson`-backed validation/test-binding caches, and the `ArchitecturalIndex` facade.

== Key Responsibilities & Collaborators
* **SQLite Schema & Connection Management (`storage.py`)**: Initializes the 10-table SQLite WAL schema (`entities`, `edges`, `indexed_files`, `symbol_mappings`, `code_symbols`, `specs_fts`, `file_tokens_fts`, `spec_validation_cache`, `test_binding_cache`, `metadata`), performs stateless drop-and-rebuild migrations on `SCHEMA_VERSION` upgrades, and recovers automatically from corrupt database files.
* **Unified Validation & Test Cache Helpers**: Provides shared `get_cached_spec_document`, `load_spec_validation_cache` / `save_spec_validation_cache`, and `load_test_binding_cache` / `save_test_binding_cache` helpers consumed by `CMP-SPEC-VALIDATOR`, `CMP-INCREMENTAL-SYNC-ENGINE`, and `CMP-DRIFT-DETECTOR`.
* **`ArchitecturalIndex` Facade (`graph_index.py`)**: Coordinates lazy synchronization (`_ensure_synced`) and delegates graph queries, FTS search, blast-radius traversal, and context slicing to `CMP-INCREMENTAL-SYNC-ENGINE`, `CMP-FTS-QUERY-ENGINE`, `CMP-GRAPH-TRAVERSAL-ENGINE`, and `CMP-TIERED-CONTEXT-COMPRESSOR`.

== Public Surface
* `SCHEMA_VERSION: str` (`"2.17.0"`), `open_cache_connection(db_path: Path) -> sqlite3.Connection`, `ensure_cache_schema(conn: sqlite3.Connection)`
* `get_cached_spec_document(...)`, `load_spec_validation_cache(...)`, `save_spec_validation_cache(...)`, `load_test_binding_cache(...)`, `save_test_binding_cache(...)`
* `ArchitecturalIndex`, `get_architectural_index(eidos_dir: Path | None = None, repo_root: Path | None = None) -> ArchitecturalIndex`

== Design Constraints & Operational Notes
* **Stateless Derived Cache (`DEC-INDEX-STATELESS-DERIVED-CACHE`)**: `eidos/.cache/index.db` stores zero unrecoverable state and is safe to delete or rebuild at any time (`check_same_thread=False` enabled for multi-threaded portal serving).
