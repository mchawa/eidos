= Component: GraphStorage
:toc: left

== Responsibility
Owns the embedded SQLite knowledge graph lifecycle (`eidos/.cache/index.db`), canonical `SCHEMA_VERSION` (`2.20.0`) DDL initialization (including `edges.provenance`, `edges.evidence`, and `code_couplings`), corruption recovery, `orjson`-backed validation/test-binding and semantic embedding caches (`spec_embeddings`), and the `ArchitecturalIndex` facade.

== Key Responsibilities & Collaborators
* **File-Locked SQLite WAL Schema, Epistemic Provenance & Connection Management (`storage.py`, `DEC-INDEX-FLOCK-WAL-AND-PINNED-ONNX`, `DEC-INDEX-SERIALIZED-SYNC-AND-CSHARP-NAMESPACES`, `DEC-INDEX-HTTP-LINKING-AND-PROVENANCE`)**: Serializes 12-table SQLite WAL DDL initialization (`SCHEMA_VERSION` `2.20.0`, including `edges.provenance`, `edges.evidence`, `code_couplings`, and `code_symbols.is_test`), precedence-preserving `upsert_edge` updates (`declared_spec > ast_import > ast_http > ast_symbol > inferred_ownership`), 3-tier certainty mapping (`observed`, `derived`, `inferred`), corruption recovery, and multi-process sync writes via re-entrant per-thread/process OS advisory file locks (`_advisory_db_lock` on `eidos/.cache/index.db.lock`) and explicit `BEGIN IMMEDIATE` write transactions (`_immediate_write_transaction`) without enabling `PRAGMA mmap_size`.
* **Unified Validation & Test Cache Helpers**: Provides shared `get_cached_spec_document`, `load_spec_validation_cache` / `save_spec_validation_cache`, and `load_test_binding_cache` / `save_test_binding_cache` helpers consumed by `CMP-SPEC-VALIDATOR`, `CMP-INCREMENTAL-SYNC-ENGINE`, and `CMP-DRIFT-DETECTOR`; `ensure_cache_schema` tracks `metadata` key `test_binding_cache_ver` to auto-invalidate stale `test_binding_cache` entries and mark `code/test` `indexed_files` rows for incremental re-sync without dropping `SCHEMA_VERSION` tables or `spec_embeddings`.
* **Thread-Isolated `ArchitecturalIndex` Facade (`graph_index.py`)**: Isolates SQLite connections per thread via `threading.local()`, keys cached index instances by normalized `eidos_dir` (`_INDEX_INSTANCES`), debounces back-to-back in-process `_ensure_synced` dirty checks via `_last_synced_check` (`50ms` monotonic window) while forwarding `PRAGMA data_version` snapshots to `sync(..., auto_semantic=...)`, exposes `edge_counts_by_provenance` while excluding `'namespace'`, `'import'`, `'http_endpoint'`, and `'http_request'` rows from synthetic `'method'` symbol totals in `get_index_status()`, and delegates graph queries, FTS/Hybrid RRF search, semantic provisioning/sync, `min_confidence`-filtered blast-radius traversal (`get_k_hop_neighborhood`), and tiered context slicing (`get_context_slice`) to sibling submodules.

== Public Surface

* `EDGE_PROVENANCE_PRECEDENCE`, `PROVENANCE_TO_CONFIDENCE`, `CONFIDENCE_RANK`, `VALID_CONFIDENCE_LEVELS`
* `upsert_edge(conn: sqlite3.Connection, source_id: str, target_id: str, rel_type: str, provenance: str = "declared_spec", evidence: str = "") -> None`
* `provenance_to_confidence(provenance: str) -> str`, `normalize_confidence_level(min_confidence: str | None) -> str`, `allowed_provenances_for_confidence(min_confidence: str | None) -> tuple[str, ...]`
* `get_cached_spec_document(...)`, `load_spec_validation_cache(...)`, `save_spec_validation_cache(...)`, `load_test_binding_cache(...)`, `save_test_binding_cache(...)`
* `ArchitecturalIndex`, `ArchitecturalIndex.get_k_hop_neighborhood(entity_id: str | Sequence[str], max_depth: int = 2, min_confidence: str = "inferred") -> list[dict[str, Any]]`, `get_architectural_index(repo_root: Path | None = None, eidos_dir: Path | None = None, db_path: Path | None = None, force_new: bool = False) -> ArchitecturalIndex`

== Design Constraints & Operational Notes
* **Stateless Multi-Agent WAL Safety (`DEC-INDEX-STATELESS-DERIVED-CACHE`, `DEC-INDEX-FLOCK-WAL-AND-PINNED-ONNX`)**: `eidos/.cache/index.db` stores zero unrecoverable state, coordinates multi-process schema migrations via `index.db.lock`, and isolates threads via `threading.local()`.
