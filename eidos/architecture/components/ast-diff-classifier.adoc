= Component: AstDiffClassifier
:toc: left

== Responsibility
Classifies structural public/boundary code symbol diffs (`PublicSymbolDiff`, `has_structural_changes`) and frontend design token / UI contract changes (`classify_design_changes`) across polyglot file revisions for `CNT-EIDOS-VCS` drift detection and `CMP-ARCHITECTURE-BOUNDARY-VALIDATOR`.

== Key Responsibilities & Collaborators
* **Overload-Safe Public & Boundary Symbol Diffing (`ast_diff.py`)**: Builds overload-disambiguated `(kind, parent_symbol, name) -> signature` maps (`public_symbol_map`, `boundary_symbol_map`) across 17 languages (`AST_DIFF_EXTS`), normalizes prose-only CLI help keyword string literals (`help`, `rich_help_panel`, `short_help`, `epilog`) inside Python Typer/Click descriptors (`Option`, `Argument`, `command`, `callback`, `group`) via Python AST before comparing signatures so wording-only CLI help edits classify as body-only while flag/default/parameter edits remain structural, computes added/removed/changed/boundary-export deltas (`diff_symbol_maps`, `diff_public_symbols`), and determines whether a file edit alters public structural surface vs. body-only implementation (`has_structural_changes`).
* **Frontend Design Token & UI Contract Classification**: Inspects CSS/SCSS/TSX/JSX/Vue/Svelte revisions (`STYLE_EXTS`) via `classify_design_changes` to distinguish design token edits (`token`), exported component prop/route/slot contract edits (`ui_contract`), and non-structural edits (`body_only`).

== Public Surface
* `AST_DIFF_EXTS`, `STYLE_EXTS`, `PublicSymbolDiff`
* `public_symbol_map(content: str | None, file_path: Path | str, *, _symbols: list[CodeSymbol] | None = None) -> dict[tuple[str, str, str], str]`
* `boundary_symbol_map(content: str | None, file_path: Path | str, *, _symbols: list[CodeSymbol] | None = None) -> dict[tuple[str, str, str], str]`
* `diff_symbol_maps(old_map: dict[tuple[str, str, str], str], new_map: dict[tuple[str, str, str], str], *, old_boundary_map: dict[tuple[str, str, str], str] | None = None, new_boundary_map: dict[tuple[str, str, str], str] | None = None) -> PublicSymbolDiff`
* `diff_public_symbols(old_content: str | None, new_content: str | None, file_path: Path | str) -> PublicSymbolDiff`
* `has_structural_changes(old_content: str | None, new_content: str | None, file_path: Path | str) -> tuple[bool, list[str]]`
* `classify_design_changes(old_content: str | None, new_content: str | None, file_path: Path | str) -> tuple[str, list[str]]`

== Design Constraints & Operational Notes
* **Acyclic Index Directionality (`DEC-ARCH-MODULAR-COMPONENT-COHESION`)**: Depends unidirectionally on `CMP-AST-SYMBOL-INDEXER` (`ast_indexer.py` / `ast_preprocess.py`) for symbol extraction without introducing reverse static imports back into `CMP-AST-SYMBOL-INDEXER`.
