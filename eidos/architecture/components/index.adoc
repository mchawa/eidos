= Component: Architectural Knowledge Graph & Retrieval Index (C4 Level 3 Whitebox)
:toc: left

== Architectural Boundary
This container represents the embedded relational and lexical indexing engine under `src/eidos/core/graph_index.py`. It persists and manages the local SQLite knowledge graph (`.eidos/cache/index.db`), providing sub-millisecond catalog lookups, incremental zero-drift synchronization, FTS5 BM25 search, recursive CTE blast-radius traversal, and tiered context slicing for AI coding agents and CLI commands.

== Operational Invariants & Quality Attributes
* **Local Cache Persistence**: Persists index state in `.eidos/cache/index.db` without polluting Git tracking (isolated via `.gitignore`).
* **Zero Runtime Dependencies**: Relies exclusively on Python's built-in `sqlite3` with compiled FTS5 and recursive CTE capabilities.
* **Deterministic Synchronization**: Identical repository living specifications always produce isomorphic graph states.
