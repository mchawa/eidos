= Component: AssetLocator
:toc: left

== Responsibility
Locates externalized specification schemas (`get_schemas_dir`), AsciiDoc prose templates (`get_spec_template_path` and `render_spec_template` loading `<name>.template.adoc` beside each `.schema.yaml` under `assets/schemas/v1/`), and canonical plugin reference assets (`get_plugin_reference_dir`) across ordered candidate asset roots (`_iter_assets_roots` spanning installed wheel `eidos/assets`, repository checkouts, and CWD while preferring verified Eidos asset roots and probing all candidate roots in `get_assets_path`).

== Public Surface
Document exported language-level APIs (functions, classes, traits) provided to peer components.
