= Component: HookManager
:toc: left

== Responsibility
Validates agent lifecycle hook configurations (`hooks.json`) and Agent Skills packages for structural conformance, permitting optional lightweight `SessionStart` / `UserPromptSubmit` baseline-snapshot entries alongside `Stop` while forbidding heavy drift gates on intermediate edit events (`DEC-PLUGIN-STOP-SCOPED-DRIFT-GATE`, `DEC-PLUGIN-TURN-SCOPED-STOP-GATE`, `INV-HOOK-CLI-NATIVE`).

== Key Responsibilities & Collaborators
* **Hook Structure & Command Validation**: Parses `hooks.json` via `orjson`, validates structural conformance of `Stop`, `SessionStart`, and `UserPromptSubmit` hook handlers, and verifies that hook commands invoke `eidos hook` natively without wrapper scripts (`INV-HOOK-CLI-NATIVE`).

== Public Surface
* `validate_plugin_package(plugin_dir: Path, version: str | None = None) -> PluginValidationReport`
* `_verify_hook_command(handler: dict[str, Any], hook_name: str, event_key: str, plugin_dir: Path, report: PluginValidationReport) -> None`

== Design Constraints & Operational Notes
* **Completion-Scoped Drift Gate (`DEC-PLUGIN-STOP-SCOPED-DRIFT-GATE`, `DEC-PLUGIN-TURN-SCOPED-STOP-GATE`)**: Ensures full drift gates run only at turn completion (`Stop`) while permitting sub-10ms `SessionStart` / `UserPromptSubmit` baseline capture.
