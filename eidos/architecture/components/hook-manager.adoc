= Component: HookManager
:toc: left

== Responsibility
Manages native lifecycle hook configuration, idempotent upsert and removal, and doctor health verification (`check_target_hook_health`) across all 6 hook-capable AI coding harnesses (Antigravity, Claude Code, Cursor, GitHub Copilot, OpenAI Codex, and Cline) from its dedicated disjoint module (`hook_adapters.py`, `DEC-PLUGIN-HOOK-CAPABLE-TARGETS`, `DEC-PLUGIN-TURN-SCOPED-STOP-GATE`, `INV-HOOK-CLI-NATIVE`).

== Key Responsibilities & Collaborators
* **Multi-Harness Native Hook Adapters (`hook_adapters.py`)**: Non-destructively upserts and removes CLI-native `eidos hook` entries across `.agents/hooks.json` (Antigravity), `.claude/settings.json` (Claude Code), `.cursor/hooks.json` (Cursor with `loop_limit: 1`), `.clinerules/hooks/PreToolUse` + `TaskStart` (Cline `attempt_completion`), `.github/hooks/hooks.json` (GitHub Copilot), and `.codex/hooks.json` (OpenAI Codex) while preserving user-defined hooks and rejecting symlink traversal.
* **Hook Health Inspection**: Maps hook-capable harnesses via `TARGET_HOOK_PATHS` and verifies installed hook presence, JSON/executable integrity, and Eidos command registration via `check_target_hook_health` for `eidos doctor` and `CMP-PLUGIN-INSTALLER`.

== Public Surface
* `TARGET_HOOK_PATHS: dict[str, str]`, `MANIFEST_FILENAME: str`
* `check_target_hook_health(root: Path, target_name: str, hooks_expected: bool) -> dict[str, Any]`

== Design Constraints & Operational Notes
* **Completion-Scoped Drift Gate (`DEC-PLUGIN-STOP-SCOPED-DRIFT-GATE`, `DEC-PLUGIN-TURN-SCOPED-STOP-GATE`)**: Ensures full drift gates run only at turn completion (`Stop` / Cline `attempt_completion`) while permitting sub-10ms `SessionStart` / `TaskStart` baseline capture.
