= Component: PluginCommands
:toc: left

== Responsibility
Implements the `eidos plugin` subcommand group (`install`, `uninstall`, `update`, `validate`, `version`, `info`) for distributing and validating the Eidos Agent Plugin across supported AI coding harnesses.

== Key Responsibilities & Collaborators
* **Plugin Lifecycle Dispatch**: Delegates multi-harness installation, manifest-tracked uninstallation, and version checks to `CMP-PLUGIN-INSTALLER`, and `agent-plugins.org v1.0.0` bundle validation to `CMP-PLUGIN-VALIDATOR` and `CMP-HOOK-MANAGER`.

== Public Surface
* `plugin_app: typer.Typer`
* `plugin_install(target: PluginInstallTarget, path: Path, force: bool) -> None`
* `plugin_uninstall(target: PluginInstallTarget, path: Path) -> None`
* `plugin_update(target: PluginInstallTarget, path: Path) -> None`
* `plugin_validate(...)`, `plugin_version(...)`, `plugin_info(...)`

== Design Constraints & Operational Notes
* **Safe Default Target & Overwrite Guard**: Defaults `[TARGET]` to `project` (`.agents/plugins/eidos`) with `force=False`, refusing to overwrite modified user files unless `--force` is specified.
