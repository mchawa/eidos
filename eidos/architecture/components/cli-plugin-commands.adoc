= Component: PluginCommands
:toc: left

== Responsibility
Agent plugin lifecycle commands (`eidos plugin`) with `orjson` `--json` output: `install [TARGET]`, `uninstall [TARGET]`, and `update [TARGET]` with a single optional positional `TARGET` argument defaulting to `PluginInstallTarget.PROJECT` (`force=False` default and `FileExistsError` symlink/overwrite safety), plus `version`, `validate`, and `info`.

== Public Surface
Document exported language-level APIs (functions, classes, traits) provided to peer components.
