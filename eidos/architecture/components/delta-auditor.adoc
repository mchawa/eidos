= Component: DeltaAuditor
:toc: left

== Responsibility
Audits the reverse-dependency blast radius and residual token leaks for entities removed or deprecated by SpecDeltas (`operation: remove | deprecate`), classifying findings into active spec leaks, active code leaks, and historical archive references using the indexed `file_tokens_fts` table.

== Key Responsibilities & Collaborators
* **Index-Driven Tombstone & Token Scanning (`DEC-AUDIT-INDEX-SCOPED-DISCOVERY`)**: Queries `file_tokens_fts` and `indexed_files` in `CMP-GRAPH-STORAGE` (`index.db`) to locate governed specification, source, and test files referencing removed/deprecated targets or `tombstones.forbidden_patterns` in sub-millisecond time.
* **Leak Classification & Graph Integrity**: Distinguishes blocking `active_spec_leak` and `active_code_leak` findings from acknowledged historical references (`applied`/`rejected` SpecDeltas and `adopted`/`discarded` Explorations) and verifies zero dangling graph edges.

== Public Surface
* `AuditEngine(repo_root: Path, eidos_dir: Path | None = None)`
* `AuditEngine.audit_delta(delta_id_or_path: str, strict: bool = False) -> AuditReport`
* `AuditReport.to_dict() -> dict[str, Any]`, `AuditReport.to_json() -> str`

== Design Constraints & Operational Notes
* **Strictly Governed Boundary (`POL-001`)**: Scans only files governed by `eidos/` specifications (`indexed_files` in `index.db`), avoiding Git subprocesses and unowned repository directories.
