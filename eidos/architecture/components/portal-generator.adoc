= Component: PortalGenerator
:toc: left

== Responsibility
Synthesizes all 16 living specification types, AST-derived component and container dependency graphs, W3C DTCG design token hierarchies, and SpecDelta impact blast radii into the unified Web Portal payload (`generator.py`: `get_portal_data`) and auto-generated C4 Level 1–3 & UX Screen/Flow Mermaid diagrams (`mermaid.py`).

== Key Responsibilities & Collaborators
* **Living Architecture & Human-Readable Mermaid Synthesis (`generator.py`, `mermaid.py`, `DEC-PORTAL-HUMAN-FIRST-PRESENTATION`)**: Consumes validated specifications from `CMP-SPEC-VALIDATOR` and directed graph edges (`consumes_api`, `depends_on`, `part_of`, `realizes`) from `CMP-GRAPH-STORAGE` (performing structural-only dirty synchronization with `auto_semantic=False` so portal loads never block on ONNX semantic embedding generation), delegating C4 Level 1 System Context, Level 2 Container, Level 3 Component, and UX Screen/Flow Mermaid generation plus HTML-escaping and unsafe `%%{init:...}%%` / `click ... call` directive sanitization to leaf-acyclic `mermaid.py`. Emits clean human-readable node, subgraph, edge (formatting `rest_http` as `"REST HTTP"` and displaying `custom_protocol` when `protocol == "other"`), state, and participant labels while preserving stable internal Mermaid node IDs (including component-ID-derived `mod_<CMP_SLUG>` module IDs for exact DOM click and blast-radius binding).
* **Product, Contained Design Tokens, Screen Hydration, Enriched Invariants & Exploration Summaries**: Enforces `cand.resolve().is_relative_to(repo_root.resolve())` containment on `tokens.manifest` files, preserves Screen Specification AsciiDoc bodies for `"Inspect Screen Spec"`, enriches synthesized invariants with humanized `title` and owning entity `source_title` fields while preserving wire compatibility, extracts structured `exit_criteria` and `recommendation` summaries on `EXP-*` explorations, and builds `compute_delta_impact` Kanban/Timeline models.

== Public Surface
* `get_portal_data(eidos_dir: Path) -> dict[str, Any]`

== Design Constraints & Operational Notes
* **Archived SpecDelta Slimming**: Replaces verbose bodies on `applied` and `rejected` SpecDeltas in `data.specs` with concise motivation summaries to keep static portal payloads compact.
