== Responsibility
Documents Eidos's architectural foundations, execution pipeline, 16-schema glossary, SQLite/FTS5 knowledge graph, SpecDelta mutation lifecycle, polyglot test-bound invariants, discovery explorations, and W3C design systems (`docs/concepts/`).
