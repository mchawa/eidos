= Component: AstSymbolIndexer
:toc: left

== Responsibility
Extracts polyglot AST code symbols (`CodeSymbol`), cross-file import specifiers (`extract_imports`), declared namespaces (`extract_declared_namespaces`), and invariant test bindings across 17 supported languages using `ast-grep-py` (`SgRoot`), delegating static HTTP route extraction to `CMP-HTTP-TOPOLOGY-LINKER` and structural/design diff classification to `CMP-AST-DIFF-CLASSIFIER`.

== Key Responsibilities & Collaborators
* **Source Preprocessing, Models & Visibility Helpers (`ast_preprocess.py`)**: Defines `CodeSymbol`, `TestFunctionBinding`, exact `INV-*` / `POL-*` token regexes (`INV_OR_POL_TOKEN_RE`), PEP 695/696 Python AST parsing (`_parse_python_ast`), length-preserving C/C++ export macro blanking, Vue/Svelte SFC `<script>` extraction, commented-out code & preprocessor blanking (`_strip_commented_out_code_blocks`), and polyglot visibility evaluation (`_is_public_symbol`, `_is_component_surface_symbol`).
* **Polyglot Import, Namespace & Repo-Map Base (`ast_imports.py`)**: Implements `BaseAstIndexer` syntax-tree import extraction (`extract_imports`, including grouped Rust `use_list` expansion and bodyless `mod <name>;` declarations), declared C#/Java/Kotlin namespaces (`extract_declared_namespaces`), and token-budgeted structural repo-map formatting (`generate_repo_map`).
* **17-Language Structural AST & Test-Binding Extraction (`ast_indexer.py`)**: Implements `AstGrepIndexer` across Python, TS/TSX/MTS/CTS, JS/JSX/MJS/CJS, Go, Rust, Java, Kotlin, C, C++, C#, Ruby, PHP, Swift, Vue, and Svelte with exact `line_start`/`line_end` coordinates, C# properties/events/fields/records, interface/trait member signatures, polyglot test-binding extraction (`list_test_functions`, `extract_test_file_cache_payload`), delegation to `CMP-HTTP-TOPOLOGY-LINKER` (`extract_http_endpoints`, `extract_http_requests`), and lazy `__getattr__` backward-compatible resolution for symbols moved to `CMP-AST-DIFF-CLASSIFIER` and `CMP-HTTP-TOPOLOGY-LINKER`.
* **TypeScript & JavaScript Data Bindings**: Extracts module-level TypeScript and JavaScript variable bindings (`.ts`, `.tsx`, `.mts`, `.cts`, `.js`, `.jsx`, `.mjs`, `.cjs`) as non-callable `variable` symbols, covering ESM `export const`/`let`/`var`, multiple declarators, shallow object/array destructuring (including property aliases), local named exports (`export { ... }`), ambient `export declare const`, and CommonJS (`module.exports` / `exports.<name>`) exports while preserving callable `function` classification (including parenthesized callables) and keeping private or nested bindings non-public.

== Public Surface
* `CodeSymbol`, `TestFunctionBinding`, `BaseAstIndexer`, `AstGrepIndexer`, `get_ast_indexer() -> AstGrepIndexer`
* `AstGrepIndexer.extract_symbols(file_path: Path, content: str | None = None) -> list[CodeSymbol]`
* `AstGrepIndexer.extract_imports(file_path: Path, content: str | None = None) -> list[str]`
* `AstGrepIndexer.extract_http_endpoints(file_path: Path | str, content: str | None = None) -> list[CodeSymbol]`
* `AstGrepIndexer.extract_http_requests(file_path: Path | str, content: str | None = None) -> list[CodeSymbol]`
* `AstGrepIndexer.extract_declared_namespaces(file_path: Path | str, content: str | None = None) -> list[str]`
* `AstGrepIndexer.list_test_functions(file_path: Path | str, content: str | None = None) -> dict[str, str]`
* `extract_test_file_cache_payload(rel_path: str, content: str, ast_idx: Any = None) -> tuple[dict[str, list[str]], list[str], str, str]`

== Design Constraints & Operational Notes
* **Zero Regex False Positives on Supported Languages**: Ignores commented-out definitions, string literals, and nested local helper closures by walking the concrete `SgRoot` syntax tree after length-preserving C/C++ export macro blanking.
