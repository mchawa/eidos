= Component: AstSymbolIndexer
:toc: left

== Responsibility
Extracts polyglot AST code symbols (`CodeSymbol`), cross-file import specifiers (`extract_imports`), public boundary symbol diffs, and invariant test bindings across 17 supported languages using `ast-grep-py` (`SgRoot`).

== Key Responsibilities & Collaborators
* **17-Language Structural AST Extraction (`AstGrepIndexer`)**: Parses Python, TypeScript, TSX, JavaScript, JSX, Go, Rust, Java, Kotlin, C, C++, C#, Ruby, PHP, Swift, Vue, and Svelte source files into `CodeSymbol` records with exact `line_start`/`line_end` coordinates, decorator/attribute prefixes, and language-native visibility flags (`is_public`).
* **Boundary Symbol Diffing & Import Extraction**: Computes public/boundary symbol maps (`public_symbol_map`, `boundary_symbol_map`, `diff_public_symbols`) for `CMP-DRIFT-DETECTOR` and extracts syntax-tree import targets (`extract_imports`) for `CMP-INCREMENTAL-SYNC-ENGINE`.
* **Polyglot Test-Binding Resolution**: Identifies test functions, class-qualified test methods (`Class::method`), parameterized tests (`test.each`, `Deno.test`, Go `t.Run`, Rust `#[rstest]`/`#[tokio::test]`), and `eidos:fixture` exemptions (`extract_test_file_cache_payload`).

== Public Surface
* `CodeSymbol`, `AstGrepIndexer`, `get_ast_indexer() -> AstGrepIndexer`
* `AstGrepIndexer.extract_symbols(file_path: Path, content: str | None = None) -> list[CodeSymbol]`
* `AstGrepIndexer.extract_imports(file_path: Path, content: str | None = None) -> list[str]`
* `AstGrepIndexer.list_test_functions(file_path: Path, content: str | None = None) -> set[str]`
* `extract_test_file_cache_payload(ast_idx: Any, file_path: Path, content: str) -> tuple[dict[str, list[str]], list[str]]`

== Design Constraints & Operational Notes
* **Zero Regex False Positives on Supported Languages**: Ignores commented-out definitions, string literals, and nested local helper closures by walking the concrete `SgRoot` syntax tree.
