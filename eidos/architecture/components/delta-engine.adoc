= Component: DeltaEngine
:toc: left

== Responsibility
Manages the end-to-end SpecDelta (`DLT-*`) lifecycle across three cohesive submodules: CRUD & state-machine orchestration (`delta_engine.py`), stateless Git-baseline & declarative `expect:` verification (`delta_verifier.py`), and lossless two-tier archive partitioning (`archiver.py`).

== Key Responsibilities & Collaborators
* **Blueprint Authoring & Lifecycle State Machine (`delta_engine.py`)**: Allocates cross-branch collision-free `DLT-YYYY-NNN-<SLUG>-<4HEX>` identifiers (`generate_collision_free_delta_id`, inspecting local, archived, and Git branch refs alongside `slug_suffix`), scaffolds files (`create_delta`) with auto-detected `vcs.branch` / `vcs.base_commit`, enforces verify-gated transitions (`set_delta_status`, `apply_delta`) while rejecting vacuous empty `mutations: []` lists, and exposes backward-compatible facade exports for verifier and archiver functions.
* **Git-Baseline & Declarative Post-Condition Verification (`delta_verifier.py`)**: Evaluates non-empty `mutations[]` across all four composable operations (`add`, `modify`, `remove`, `deprecate`) against CRLF-normalized, shallow-clone-safe Git baseline blobs (`_resolve_git_baseline_sha`) and structured `expect.body` / `expect.frontmatter` assertions (`verify_delta_mutations`, supporting `{"dotted.key": null}` key-removal checks and exact `test_binding` matching), exposes `is_delta_ready_to_apply` (shared by `CMP-DRIFT-DETECTOR` and `CMP-CLI-DOCTOR-HOOKS` to enforce full `apply_delta` preconditions: active non-archived status, zero schema errors on the delta document, non-empty mutations, and 100% verified post-conditions), flags duplicate `DEC-*` authoring conflicts when a SpecDelta declares the same decision ID in both its own `decisions` frontmatter and a mutation's `expect.frontmatter.decisions.id` (`INV-DELTA-AUTHORING-GUARDRAILS`), and analyzes open non-terminal SpecDeltas (`proposed`, `in_review`, `approved`) for direct target collisions and 1-hop graph blast-radius overlaps via `detect_delta_conflicts` (`INV-DELTA-PARALLEL-CONFLICT-DETECTION`).
* **Lossless Two-Tier Archive Partitioning (`archiver.py`)**: Moves older terminal (`applied`/`rejected`) SpecDeltas and (`adopted`/`discarded`) Explorations into `eidos/deltas/archive/` and `eidos/explorations/archive/` (`archive_deltas`, `archive_explorations`), preserving full multi-line paragraph and `===` subsection content before unlinking archived explorations.

== Public Surface
* `generate_collision_free_delta_id(eidos_dir: Path, raw_id: str | None = None, title: str = "", slug_suffix: bool = False) -> str`
* `create_delta(eidos_dir: Path, raw_id: str = "auto", title: str = "Untitled SpecDelta", kind: str = "feature", slug_suffix: bool = False) -> Path`
* `verify_delta_mutations(eidos_dir: Path, delta_id_or_path: str, *, git_repo_root: Path | None = None, snapshot_root: Path | None = None, git_sub_prefix: str = "") -> tuple[bool, str, DeltaVerificationReport | None]`
* `is_delta_ready_to_apply(eidos_dir: Path, delta_id_or_path: str, *, delta_rel_path: str = "", delta_status: str = "proposed", schema_error_paths: list[str] | set[str] | tuple[str, ...] | None = None, git_repo_root: Path | None = None, snapshot_root: Path | None = None, git_sub_prefix: str = "") -> dict[str, Any] | None`
* `detect_delta_conflicts(eidos_dir: Path, *, include_blast_radius: bool = True) -> dict[str, Any]`
* `apply_delta(eidos_dir: Path, delta_id_or_path: str, verify: bool = True) -> tuple[bool, str, Path | None]`
* `set_delta_status(...)`, `list_deltas(...)`, `get_delta_status_summary(...)`, `delete_delta(...)`
* `archive_deltas(...)`, `archive_explorations(...)`, `normalize_delta_mutation(m: dict) -> dict`

== Design Constraints & Operational Notes
* **Stateless Git Baselines (`DEC-INDEX-STATELESS-DERIVED-CACHE`)**: Resolves pre-delta baselines strictly from Git commit history (`vcs.base_commit`) rather than local SQLite snapshot tables, including across isolated commit-range `eidos drift` snapshots.
* **Pre-Apply Document Validation**: `apply_delta` validates the updated SpecDelta via `CMP-SPEC-VALIDATOR` (`validate_document`) before marking a SpecDelta `applied`.
