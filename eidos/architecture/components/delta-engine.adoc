= Component: DeltaEngine
:toc: left

== Responsibility
Manages the end-to-end SpecDelta (`DLT-*`) lifecycle: collision-free `<SLUG>-<4HEX>` blueprint creation, composable `operation` + `target` mutation normalization, Git-baseline and declarative `expect` post-condition verification, verify-gated status transitions, atomic application, and two-tier archive slimming.

== Key Responsibilities & Collaborators
* **Blueprint Authoring & Lifecycle State Machine**: Scaffolds `DLT-YYYY-NNN-<SLUG>-<4HEX>` files (`create_delta`) with auto-detected `vcs.branch` / `vcs.base_commit`, lists and summarizes 5-state statuses (`proposed`, `in_review`, `approved`, `applied`, `rejected`), and enforces verify-gated transitions (`set_delta_status`, `apply_delta`).
* **Git-Baseline & Declarative Post-Condition Verification**: Evaluates `mutations[]` (`add`, `modify`, `remove`, `deprecate`) against Git baseline blobs (`_resolve_git_baseline_sha`) and structured `expect.body` / `expect.frontmatter` assertions (`verify_delta_mutations`).
* **Two-Tier Archive Partitioning**: Moves older terminal (`applied`/`rejected`) SpecDeltas and (`adopted`/`discarded`) Explorations into `eidos/deltas/archive/` and `eidos/explorations/archive/` (`archive_deltas`, `archive_explorations`) while slimming archived `.adoc` bodies.

== Public Surface
* `create_delta(eidos_dir: Path, raw_id: str, title: str, kind: str = "feature", slug: str | None = None) -> Path`
* `verify_delta_mutations(eidos_dir: Path, delta_id_or_path: str) -> tuple[bool, str, dict[str, Any]]`
* `apply_delta(eidos_dir: Path, delta_id_or_path: str, verify: bool = True) -> tuple[bool, str]`
* `set_delta_status(...)`, `list_deltas(...)`, `get_delta_status_summary(...)`, `delete_delta(...)`
* `archive_deltas(...)`, `archive_explorations(...)`, `normalize_delta_mutation(m: dict) -> dict`

== Design Constraints & Operational Notes
* **Stateless Git Baselines (`DEC-INDEX-STATELESS-DERIVED-CACHE`)**: Resolves pre-delta baselines strictly from Git commit history (`vcs.base_commit`) rather than local SQLite snapshot tables.
* **Pre-Commit Catalog Validation**: `apply_delta` runs `CMP-SPEC-VALIDATOR` across `eidos/` before marking a SpecDelta `applied`.
