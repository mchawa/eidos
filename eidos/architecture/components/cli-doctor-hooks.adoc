= Component: DoctorAndHookCommands
:toc: left

== Responsibility
Exposes `eidos doctor` for workspace environment, PyPI CLI release currency, Git, SQLite index, and agent plugin health diagnostics, and `eidos hook` for executing the stateless CLI-native agent `Stop` drift gate.

== Key Responsibilities & Collaborators
* **Workspace Diagnostics (`eidos doctor`)**: Resolves `--path` via `resolve_cli_eidos_dir(path)` (`CMP-CLI-APP`) across top-level repositories and monorepo sub-project directories, verifies Python runtime, non-blocking PyPI CLI release update status (`check_cli_update_status` in `CMP-PLUGIN-INSTALLER`), Git binary availability, `eidos/` specification validity (`CMP-SPEC-VALIDATOR`), SQLite index synchronization (`CMP-GRAPH-STORAGE`), and installed agent plugin currency at the enclosing Git monorepo root (`find_git_root(repo_root) or repo_root` via `CMP-PLUGIN-INSTALLER`).
* **Stateless Agent Hook Entrypoint (`eidos hook`)**: Invokes `CMP-HOOK-RUNNER` (`execute_hook`) at the end of an agent turn (`Stop`) and writes the JSON hook verdict to stdout.

== Public Surface
* `register(app: typer.Typer) -> None`
* `doctor_cmd(path: Path, json_output: bool) -> None`
* `hook_cmd(path: Path | None) -> None`

== Design Constraints & Operational Notes
* **Non-Blocking Hook Protocol (`DEC-PLUGIN-STATELESS-SINGLE-STOP-HOOK`)**: `eidos hook` always exits `0` with a valid JSON `decision` payload so agent harnesses never crash or enter retry loops.
