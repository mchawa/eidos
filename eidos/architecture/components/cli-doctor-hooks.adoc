= Component: DoctorAndHookCommands
:toc: left

== Responsibility
Exposes `eidos doctor` (including root `AGENTS.md` onboarding governance verification) for workspace environment, PyPI CLI release currency, Git, SQLite index, and agent plugin health diagnostics, and `eidos hook` for executing the session-scoped CLI-native agent `Stop` / `PreToolUse` (`attempt_completion`) drift gate.

== Key Responsibilities & Collaborators
* **Workspace & Onboarding Diagnostics (`eidos doctor`)**: Resolves `--path` via `resolve_cli_eidos_dir(path)` (`CMP-CLI-APP`), verifies Python runtime, non-blocking PyPI CLI release update status (`check_cli_update_status()`), Git binary availability, `eidos/` specification validity (`CMP-SPEC-VALIDATOR`), SQLite index synchronization (`CMP-GRAPH-STORAGE`), root `AGENTS.md` managed-block integrity (`checks.agents_md` via `read_managed_block`), and installed agent plugin currency and per-target hook health (`hooks_ok`, `hooks_status`, `target_hooks`, `hook_errors`).
* **Session-Scoped Agent Hook Entrypoint (`eidos hook`)**: Invokes `CMP-HOOK-RUNNER` (`execute_hook`) on `SessionStart` / `Stop` / Cline `PreToolUse` (`attempt_completion`) and writes the JSON hook verdict to stdout.

== Public Surface
* `register(app: typer.Typer) -> None`
* `doctor_cmd(path: Path | None, json_output: bool) -> None`
* `hook_cmd(path: Path | None) -> None`

== Design Constraints & Operational Notes
* **Non-Blocking Hook Protocol (`DEC-PLUGIN-STATELESS-SINGLE-STOP-HOOK`)**: `eidos hook` always exits `0` with a valid JSON `decision` payload so agent harnesses never crash or enter retry loops.
