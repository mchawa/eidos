= Component: DoctorAndHookCommands
:toc: left

== Responsibility
Exposes `eidos doctor` (including root `AGENTS.md` onboarding governance verification) for workspace environment, PyPI CLI release currency, Git, SQLite index, and agent plugin health diagnostics, and `eidos hook` for executing the session-scoped CLI-native agent `Stop` / `PreToolUse` (`attempt_completion`) drift gate.

== Key Responsibilities & Collaborators
* **Workspace & Onboarding Diagnostics (`eidos doctor`)**: Resolves `--path` via `resolve_cli_eidos_dir(path)` (`CMP-CLI-APP`), inspects optional `eidos/eidos.yaml` via `CMP-REPO-CONFIG` (`checks.repo_config`, reporting `absent` or `valid` as OK and `invalid` as a blocking exit code `1` failure), verifies Python runtime, non-blocking PyPI CLI release update status (`check_cli_update_status` honoring `plugin.updates_check` via `allow_network`), Git binary availability, `eidos/` specification validity (`CMP-SPEC-VALIDATOR`), SQLite index synchronization (`CMP-GRAPH-STORAGE`), root `AGENTS.md` managed-block integrity (`checks.agents_md` via `read_managed_block`), non-blocking open SpecDelta verification readiness (`checks.open_deltas`, delegating to `CMP-DELTA-ENGINE` `is_delta_ready_to_apply` with `SpecValidator` `schema_errors` exclusion to flag schema-valid open `proposed`/`in_review`/`approved` deltas whose mutations are already verified on disk as `ready_to_apply`), and installed agent plugin currency, per-target hook health (`hooks_ok`, `hooks_status`, `target_hooks`, `hook_errors`), and non-blocking advisory notices when concrete `plugin.targets` declared in `eidos/eidos.yaml` are missing (`configured_targets`, `missing_configured_targets`).
* **Session-Scoped Agent Hook Entrypoint (`eidos hook`)**: Invokes `CMP-HOOK-RUNNER` (`execute_hook`) on `SessionStart` / `Stop` / Cline `PreToolUse` (`attempt_completion`) and writes the JSON hook verdict to stdout.

== Public Surface
* `register(app: typer.Typer) -> None`
* `doctor_cmd(path: Path | None, json_output: bool) -> None`
* `hook_cmd(path: Path | None) -> None`

== Design Constraints & Operational Notes
* **Non-Blocking Hook Protocol (`DEC-PLUGIN-STATELESS-SINGLE-STOP-HOOK`)**: `eidos hook` always exits `0` with a valid JSON `decision` payload so agent harnesses never crash or enter retry loops.
