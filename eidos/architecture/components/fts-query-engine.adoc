= Component: FTSQueryEngine
:toc: left

== Responsibility
Full-text lexical search (execute_fts_query deriving source_path strictly from data_json['source_path'], build_fts_match_query with operator='AND'|'OR' support, two-tier multi-term AND coordination boost, English stop-word and single-character noise token filtering, full v1 entity prefix recognition derived from ENTITY_PREFIX_REGISTRY including SYS-*, ARCH-*, PER-* and underscore IDs, and exact entity ID plus CMP-*/DEC-* exact-ID boosting) and symbol/repo-map resolution (find_symbol_in_db querying unified all_mappings CTE over symbol_mappings and code_symbols with empty-query guard, length(s.symbol) ASC ordering, method location deduplication, and escaped SQL LIKE wildcards, resolve_symbol_locations_in_db, generate_repo_map_from_db) with positional column-weighted BM25 (title > rule/keywords/symbols > body; UNINDEXED entity_id placeholder weight first) across titles, rules/responsibilities/motivations, descriptions, embedded architectural decisions, keywords, projected AST code_symbols in specs_fts.symbols, and de-compounded camelCase/snake_case identifier sub-tokens using SQLite FTS5; indexes child INV-* invariants (across capabilities, policies, containers, and components) as first-class FTS rows (purged with their parent spec) and supports include/exclude entity-type filters applied before LIMIT with deterministic id tie-breaking.
