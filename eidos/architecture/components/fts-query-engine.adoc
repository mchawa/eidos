= Component: FTSQueryEngine
:toc: left

== Responsibility
Executes column-weighted SQLite FTS5 BM25 lexical search (`execute_fts_query`), reverse symbol lookup (`find_symbol_in_db`), and token-budgeted structural repository map generation (`generate_repo_map_from_db`) over the indexed knowledge graph.

== Key Responsibilities & Collaborators
* **Two-Tier Weighted FTS5 Search (`DEC-INDEX-FTS-RETRIEVAL-HYGIENE`)**: Prioritizes high-precision multi-term `AND` queries before `OR` fallback using positional BM25 column weights `(0, 4, 2, 1, 2, 2)` (`title` > `jtbd_or_rule`/`keywords`/`symbols` > `body_text`), identifier de-compounding, and exact `CMP-*`/`DEC-*` entity ID boosting.
* **Reverse Symbol & Repo Map Resolution**: Resolves AST symbol names (`find_symbol_in_db`, `resolve_symbol_locations_in_db`) across `code_symbols` and `symbol_mappings`, and formats token-budgeted structural outlines (`generate_repo_map_from_db`) from persisted primary `code_symbols` rows without re-parsing source files.

== Public Surface
* `execute_fts_query(conn: sqlite3.Connection, query: str, limit: int = 10, include_types: set[str] | None = None, exclude_types: set[str] | None = None) -> list[dict[str, Any]]`
* `build_fts_match_query(query: str, operator: str = "OR") -> str`
* `find_symbol_in_db(conn: sqlite3.Connection, query: str, limit: int = 20) -> list[dict[str, Any]]`
* `generate_repo_map_from_db(conn: sqlite3.Connection, max_tokens: int = 1500) -> dict[str, Any]`

== Design Constraints & Operational Notes
* **SQL-Scoped Type Filtering**: Applies `include_types` and `exclude_types` filters inside SQL *before* `LIMIT` so historical SpecDeltas and explorations never crowd out active architecture entities during `eidos context --task`.
