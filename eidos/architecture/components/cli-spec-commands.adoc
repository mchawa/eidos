= Component: SpecCommands
:toc: left

== Responsibility
Implements `eidos validate` and the `eidos spec` subcommand group (`list`, `show`, `schema`, `create`, `delete`) for inspecting, validating, scaffolding, and deleting living catalog specifications across all 15 non-delta specification types.

== Key Responsibilities & Collaborators
* **Root Validation (`eidos validate`)**: Invokes `CMP-SPEC-VALIDATOR` (`SpecValidator.validate_directory`) and renders Rich validation tables or `orjson` JSON reports (`--json`).
* **Living Catalog Management (`eidos spec`)**: Delegates `list`, `show`, `schema`, `create`, and `delete` operations to `CMP-LIFECYCLE-SCAFFOLDER` while enforcing a strict disjoint boundary from `eidos delta`.

== Public Surface
* `register(app: typer.Typer) -> None`, `spec_app: typer.Typer`
* `validate(path: Path, json_output: bool) -> None`
* `spec_list_cmd(...)`, `spec_show_cmd(...)`, `spec_schema_cmd(...)`, `spec_create_cmd(...)`, `spec_delete_cmd(...)`

== Design Constraints & Operational Notes
* **Disjoint Delta Rejection**: Rejects `delta/mutation` (`DLT-*`) in `eidos spec list --type delta`, `show`, `create`, and `delete`, directing callers to `eidos delta`.
