= Component: SpecParser
:toc: left

== Responsibility
Extracts and serializes YAML frontmatter and AsciiDoc body prose from `.adoc` specification files using Rust-backed `fastyaml-rs` (`fast_yaml`) and block-scalar-safe frontmatter splitting.

== Key Responsibilities & Collaborators
* **Fast YAML Deserialization & Dumping**: Wraps `fast_yaml` in safe loader/dumper helpers (`safe_load_yaml`, `safe_dump_yaml`) with consistent `YamlError` diagnostics.
* **Frontmatter & Body Separation**: Splits leading `---` YAML frontmatter blocks from AsciiDoc body content (`split_frontmatter_and_body`) without misinterpreting `---` horizontal rules inside multiline YAML block scalars or AsciiDoc prose.
* **SpecDocument Hydration**: Produces normalized `SpecDocument` instances (`parse_spec_file`, `dump_spec_document`) backed by `CMP-DOMAIN-MODELS`.

== Public Surface
* `parse_spec_file(file_path: Path) -> SpecDocument`
* `split_frontmatter_and_body(content: str) -> tuple[str | None, str]`
* `dump_spec_document(frontmatter: dict, body: str) -> str`
* `safe_load_yaml(stream_or_str) -> Any`, `safe_dump_yaml(data: Any) -> str`, `YamlError`

== Design Constraints & Operational Notes
* **Root `system.adoc` Placeholder Handling**: Scopes the 0-byte `SYS-UNINITIALIZED` placeholder exemption strictly to the root `eidos/system.adoc` file prior to initial authoring.
