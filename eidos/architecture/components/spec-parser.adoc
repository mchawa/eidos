= Component: SpecParser
:toc: left

== Responsibility
Extracts and serializes YAML frontmatter metadata and body text from AsciiDoc documents via Rust-backed fast_yaml helpers (YamlError, safe_load_yaml, safe_dump_yaml) and canonical file-start-anchored, block-scalar-safe split_frontmatter_and_body and dump_spec_document helpers, deriving schema_ref from type via canonical TYPE_TO_SCHEMA_NAME in models.py and normalizing document scalars (doc_type, doc_id, schema_ref, title) via SpecDocument.model (FrontmatterModel) while scoping the 0-byte SYS-UNINITIALIZED placeholder strictly to root system.adoc outside known spec subdirectories.

== Public Surface
Document exported language-level APIs (functions, classes, traits) provided to peer components.
