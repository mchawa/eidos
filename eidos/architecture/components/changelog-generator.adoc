= Component: ChangelogGenerator
:toc: left

== Responsibility
Compiles applied SpecDeltas (`eidos/deltas/` and `eidos/deltas/archive/`) and Git release tag history into a portable Keep a Changelog (`CHANGELOG.md`) ledger with categorized sections and inline code badges (`INV-DELTA-CHANGELOG-GENERATION`).

== Key Responsibilities & Collaborators
* **SpecDelta & Tag Ancestry Resolution**: Scans applied SpecDeltas (`status: applied`), extracts abbreviation- and SemVer-safe `intent.motivation` summaries, maps each delta to its earliest `status: applied` commit via batched `git log -G` queries, and groups entries by SemVer Git release tags or `[Unreleased]`.
* **Keep a Changelog Formatting**: Classifies SpecDeltas and conventional commits into `Added`, `Changed`, `Deprecated`, `Removed`, `Fixed`, and `Security` sections while deduplicating commits already covered by an applied SpecDelta.

== Public Surface
* `generate_changelog(eidos_dir: Path, output_path: Path | None = None) -> tuple[bool, str, str]`

== Design Constraints & Operational Notes
* **Deterministic Classification**: Categorizes SpecDeltas strictly from v1 `intent.kind` and composable `mutations[].operation` values, and maintains `docs/changelog.md` parity when writing the default root `CHANGELOG.md`.
