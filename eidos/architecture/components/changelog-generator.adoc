= Component: ChangelogGenerator
:toc: left

== Responsibility
Compiles applied SpecDeltas (`eidos/deltas/` and `eidos/deltas/archive/`) and Git release tag history into a portable Keep a Changelog (`CHANGELOG.md`) ledger with categorized sections and inline code badges (`INV-DELTA-CHANGELOG-GENERATION`).

== Key Responsibilities & Collaborators
* **Frontmatter-Verified SpecDelta & Tag Ancestry Resolution**: Scans applied SpecDeltas (`status: applied`), keys and deduplicates entries by full canonical delta ID (avoiding `short_id` prefix collisions), verifies `status: applied` transitions strictly inside parsed YAML frontmatter rather than prose code blocks, and groups entries by SemVer Git release tags or `[Unreleased]`.
* **Dynamic `SYS-*` Project Header & Keep a Changelog Formatting**: Resolves the project display name dynamically from the repository's `SYS-*` `product/system` specification (falling back to the repository directory name without hardcoded self-references) and classifies SpecDeltas and conventional commits into `Added`, `Changed`, `Deprecated`, `Removed`, `Fixed`, and `Security` sections.

== Public Surface
* `ChangelogGenerator(repo_root: Path | None = None, eidos_dir: Path | None = None, repo_url: str | None = None)`
* `ChangelogGenerator.generate_changelog(include_unreleased: bool = True) -> str`
* `ChangelogGenerator.update_changelog_files(output_file: Path | None = None, update_docs: bool = True, include_unreleased: bool = True) -> dict[str, Any]`

== Design Constraints & Operational Notes
* **Deterministic Classification**: Categorizes SpecDeltas strictly from v1 `intent.kind` and composable `mutations[].operation` values, and maintains `docs/changelog.md` parity when writing the default root `CHANGELOG.md`.
