= Component: PortalAssets
:toc: left

== Responsibility
Packages and lazily loads the pre-compiled single-file React 19, Tailwind v4, Asciidoctor.js, and Mermaid v12 SPA bundle (`assets/portal/bundle.html.gz` and `assets/portal/favicon.svg`) and owns the TypeScript frontend views and asset build verification scripts.

== Key Responsibilities & Collaborators
* **Lazy Gzip Asset Delivery (`assets.py`)**: Decompresses and caches `assets/portal/bundle.html.gz` and `assets/portal/favicon.svg` on first access (`get_portal_html_template`, `get_portal_favicon_svg`), plus `(raw_utf8_bytes, gzip_bytes)` in `_get_portal_html_bundle_bytes` for zero-copy HTTP root delivery in `CMP-PORTAL-SERVER` and `CMP-PORTAL-BUILDER`.
* **Human-First Presentation Layer (`frontend/src/lib/presentation.ts`, `DEC-PORTAL-HUMAN-FIRST-PRESENTATION`)**: Mounts `EntityLabelProvider` once in `App.tsx` backed by `buildEntityLabelIndex` and exposes `useEntityLabels`, `resolveEntityTitle`, `humanizeToken`, and curated enum/type/status/tab formatters (formatting canonical protocols including `"REST HTTP"`, `"Code Interface"`, `"WSDL"`, `"Avro"`, `"SQL DDL"`, `"tRPC"`, `"WebSocket"`, `"MCP"`, displaying `custom_protocol` whenever `protocol == "other"`, recognizing `MEM-*` / `agent/memory`, and sanitizing `memory_audit` freshness reasons via `formatMemoryCategory`, `formatMemoryFreshness`, and `formatMemoryFreshnessReason`) so every view, navigation rail, command palette, `SpecReader`, and `AsciiDocRenderer` cross-reference link renders human-readable titles and plain-language copy without raw Eidos ID slugs, schema type slugs, literal backticks, raw paths, or technical jargon while retaining canonical IDs strictly internally for hash routing, DOM/Mermaid click delegation, and hidden `searchText`.
* **Embedded AsciiDoc Mermaid Rendering & Unified Serialized Queue (`DEC-PORTAL-DOCUMENT-MERMAID-RENDERING`, `INV-PORTAL-DOCUMENT-MERMAID-RENDERING`)**: Extracts `[mermaid]` and `[source,mermaid]` blocks across `----`/`....` fences, case-insensitive styles, `dlist`/list/admonition/example/sidebar nesting, and recursive table head/body/foot inner documents into `RenderedAsciiDoc` (`mermaidBlocks`) inside `frontend/src/lib/asciidoc.ts` with CSPRNG per-parse nonced role tagging, untouched `DOMPurify` `SANITIZE_CONFIG`, unconditional passthrough slot stripping, and deterministic `.adoc-mermaid-slot` placeholders; serializes all Mermaid v12 renders for `ArchitectureView.tsx`, `MermaidDiagram.tsx`, and `DocumentMermaidBlock.tsx` through one module-level promise queue (`renderMermaidSvg` in `frontend/src/lib/mermaid.ts`) enforcing `sanitizeMermaidCode`, `securityLevel: "strict"`, theme-change-aware initialization, monotonic SVG IDs, and orphan `#d<id>` error DOM cleanup; observes document theme mutations via SSR-safe `useDarkMode` (`frontend/src/lib/theme.ts`); renders interactive embedded diagram cards in `DocumentMermaidBlock` (caption header, `View Source` / `View Diagram` toggle, `Copy`, modifier-wheel zoom, expand toggle, and single accessible `role="alert"` fallback with sanitized raw source) mounted post-DOMPurify via sibling React portals in `AsciiDocRenderer.tsx` with `.adoc-mermaid-slot` cascade resets in `frontend/src/theme/theme.css`.
* **Strict Sanitization, SSE Live Drift, Advisory Warnings, Governance Health Scorecard, Team Memory Surface & Interactive SPA Views (`frontend/src/`)**: Configures Mermaid with `securityLevel: "strict"` (`mermaid.ts`), enforces DOMPurify `SANITIZE_DOM: true`, `idprefix: "spec-"`, and protocol-relative `//` external link hardening (`asciidoc.ts`), honors `measure?: "prose" | "full"` in `AsciiDocRenderer.tsx`, supports `requestSpecNavigation` with `{ mode: "reader" }` in `specNav.ts` / `App.tsx` so **"Open in Full Reader"** launches `SpecReader` directly in `CatalogView`, renders uncramped full-height **Full Specification** prose (zero nested scroll traps or double-nested cards) for containers (`CNT-*`), focused internal components (`CMP-*`), and contracts (`CTR-*`) inside `ArchitectureView.tsx` (`#c4InspectorDrawer`), promotes `#c4DiagramContainer` in-place into a zoomed-in **Full Page** (`z-[45]`, `25%`–`400%` zoom) C4 stage (`#btnC4FullPage` / `#btnC4ExitFullPage`), unifies underscore-safe Mermaid v12 SVG node/edge/label connection highlighting and Blast Radius style restoration in `frontend/src/lib/c4Highlight.ts` (`#c4HighlightSelect`, `#btnC4FocusMode`, direction filter, floating Connection Summary Pill, and `"Highlight on Diagram"` drawer action), renders Mermaid errors via safe JSX text nodes, guards pan-drag C4 click misfires (`hasMovedRef.current`), binds C4 drill-down clicks via post-render DOM delegation using stable component-ID-derived Mermaid node IDs, normalizes schema-valid `$defs/state_entry` (`string | { name, description }`) component states/variants and polymorphic screen `slots` in `DesignView.tsx` alongside hydrating `screens` bodies for `"Inspect Screen Spec"`, surfaces Git-native team memories and non-blocking `memory_audit` hygiene highlights in `MemoryView.tsx` (`SCR-PORTAL-MEMORY`, `#/memory`) with category/freshness filters, zero-memory CLI quickstart empty state, `NavigationRail.tsx` Team Memory tab, `HomeView.tsx` Team Operational Memory health card, `CatalogView.tsx` Team Memory branch, IME-safe `CommandDialog` indexing, and inline `EntityMemoriesStrip.tsx` cross-links inside `ArchitectureView.tsx` and `BusinessView.tsx`, isolates tab-panel rendering behind an accessible `role="alert"` `ViewErrorBoundary` in `App.tsx`, subscribes to `/api/events` SSE + `/api/drift` (`SpecDriftStatus` in `frontend/src/types.ts`) for live workspace drift badges, renders non-blocking amber advisory validation `warnings` badges, a collapsible diagnostics list, and a Governance Health Scorecard card (`governance_health`, displaying component-scoped Public Surface coverage) alongside clickable repo-relative `schema_errors` (`App.tsx`, `HomeView.tsx`), and lazy-fetches externalized local `./specs/<id>.json` chunks (`specChunks.ts`).
* **Build & Wheel Hook Verification (`build_assets.py`, `hatch_build.py`)**: Compiles the Vite bundle (`<= 5 MiB` uncompressed), verifies zero remote URLs (`INV-PORTAL-AIR-GAPPED-BUNDLE`), and synchronizes bundle assets during Hatch wheel builds.

== Public Surface
* `get_portal_html_template() -> str`, `get_portal_favicon_svg() -> str`
* `PORTAL_HTML_TEMPLATE: str`, `PORTAL_FAVICON_SVG: str`

== Design Constraints & Operational Notes
* **Air-Gapped & Zero-Node Runtime (`INV-PORTAL-AIR-GAPPED-BUNDLE`, `INV-PORTAL-ZERO-NODE-DEP`)**: All fonts (`@fontsource` Geist / Geist Mono), Mermaid v12, and Asciidoctor.js are bundled inline; `build_assets.py --check` rejects any remote `http://` or `https://` subresource references.
