== Responsibility
Root command dispatcher (`--version` / `-V` callback and `eidos info` reporting across all 16 bundled v1 schemas), error code translation, shared CLI `eidos/` directory resolution (`resolve_cli_eidos_dir` and `has_eidos_markers` in `src/eidos/cli/_shared.py`), and formatted diagnostic table rendering without legacy command re-exports.
