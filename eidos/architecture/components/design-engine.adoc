= Component: DesignEngine
:toc: left

== Responsibility
Scaffolds schema-valid draft blueprints (`build_design_spec`) and baseline W3C DTCG `tokens.json` manifests for Multi-Design Systems (`DS-*`), UI components (`UIC-*`), screens (`SCR-*`), clients (`CLT-*`), and user flows (`FLOW-*`).

== Key Responsibilities & Collaborators
* **Design Blueprint Generation**: Renders frontmatter and `.template.adoc` prose via `CMP-ASSET-LOCATOR` for all 5 `design/*` specification types under `eidos/design/`.
* **W3C DTCG Token Bootstrapping**: Initializes a baseline W3C Design Tokens Community Group (`tokens.json`) manifest via `orjson` when scaffolding a new `design/system` specification without overwriting pre-existing token files.

== Public Surface
* `DESIGN_SPEC_KEYS: set[str]`
* `build_design_spec(eidos_dir: Path, canonical_key: str, doc_id: str, slug: str, title: str, heading: str, first_of_type_fn) -> tuple[Path, Path, dict[str, Any], str]`

== Design Constraints & Operational Notes
* **Idempotent Token Manifests**: Preserves existing `tokens.json` files when re-scaffolding a `design/system` blueprint.
