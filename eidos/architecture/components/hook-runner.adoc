= Component: HookRunner
:toc: left

== Responsibility
Executes the session-baseline-aware CLI-native `Stop` and Cline `PreToolUse` (`attempt_completion`) lifecycle hooks (`eidos hook`), short-circuiting zero-edit Q&A turns on pre-existing dirty worktrees and emitting client-aware 1-turn capped continuation feedback (`DEC-PLUGIN-TURN-SCOPED-STOP-GATE`, `DEC-PLUGIN-HOOK-CAPABLE-TARGETS`).

== Key Responsibilities & Collaborators
* **Session-Scoped Client-Aware Stop Gate Execution**: Resolves the nearest governing sub-project `repo_root` and `eidos/` directory (`find_workspace_root`), captures working-tree baselines (`git status --porcelain=v1 -z` + SHA-256 file digests) under gitignored `eidos/.cache/hook_baselines/` on `SessionStart` / `UserPromptSubmit` / `TaskStart`, and short-circuits drift blocking only when zero governed files (`code_files`, `spec_files`, `delta_files`, `test_files`, or `onboarding_files`) changed relative to the session baseline. Honors both snake_case `stop_hook_active` and camelCase `stopHookActive` retry flags (preventing GitHub Copilot `agentStop` infinite loops), immediately returns `{"cancel": false}` on Cline `PreToolUse` calls for tools other than `attempt_completion`, and invokes `CMP-DRIFT-DETECTOR` (`detect_drift(uncommitted=True)`) on the first completion attempt when governed edits exist.

== Public Surface
* `find_workspace_root(payload: dict[str, Any] | None = None) -> Path`
* `capture_session_baseline(payload: dict[str, Any], workspace_root: Path) -> dict[str, Any]`
* `handle_stop_hook(payload: dict[str, Any], workspace_root: Path, event: str | None = None) -> dict[str, Any]`
* `execute_hook(path: Path | None = None, repo_root: Path | None = None, stdin_data: str | None = None, event: str | None = None) -> int`

== Design Constraints & Operational Notes
* **Turn-Scoped Retry & Dirty-Worktree Safety (`DEC-PLUGIN-TURN-SCOPED-STOP-GATE`)**: Caps continuation prompts to 1 retry turn via client `stdin` flags (`executionNum`, `loop_count`, `stop_hook_active`, `stopHookActive`) plus state-digest tracking for Cline `attempt_completion`, and stores ephemeral session baselines strictly inside gitignored `eidos/.cache/hook_baselines/`.
