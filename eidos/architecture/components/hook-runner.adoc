= Component: HookRunner
:toc: left

== Responsibility
Executes the session-baseline-aware CLI-native `Stop` and Cline `PreToolUse` (`attempt_completion`) lifecycle hooks (`eidos hook`), short-circuiting zero-edit Q&A turns on pre-existing dirty worktrees and emitting client-aware 1-turn capped continuation feedback (`DEC-PLUGIN-TURN-SCOPED-STOP-GATE`, `DEC-PLUGIN-HOOK-CAPABLE-TARGETS`).

== Key Responsibilities & Collaborators
* **Session-Scoped Client-Aware Stop Gate Execution, Multi-Subproject Monorepo Evaluation & `eidos/eidos.yaml` Hook Overrides**: Resolves all governing `(repo_root, eidos_dir)` pairs (`find_workspace_root`, `_resolve_all_eidos_roots`) across single-project and monorepo workspaces (including root `eidos/` only when `_has_eidos_markers` is true—ignoring cache-only `<git_root>/eidos/.cache/`—plus every nested sub-project discovered via `discover_nested_subproject_roots`), loads each project's optional `<eidos_dir>/eidos.yaml` via `load_repo_config_with_errors` honoring `plugin.hooks.enabled` (default `true` runtime kill-switch), `plugin.hooks.baseline_ttl_seconds` (pruning stale baselines via `_prune_stale_baselines`), and nullable `plugin.hooks.strict` / `plugin.hooks.fail_on_warnings` (inheriting `drift.*` when omitted), captures a single shared Git worktree baseline (`git status --porcelain=v1 -z` + SHA-256 file digests) persisted under each active project's gitignored `eidos/.cache/hook_baselines/` on `SessionStart` / `UserPromptSubmit` / `TaskStart`, excludes nested child sub-project paths from parent/root baseline scoping (`_scope_paths_to_subproject`), and short-circuits drift blocking per project only when zero governed files (`code_files`, `spec_files`, `delta_files`, `test_files`, or `onboarding_files`) changed relative to the session baseline and no changed `eidos/eidos.yaml` fails schema validation. Honors both snake_case `stop_hook_active` and camelCase `stopHookActive` retry flags (preventing GitHub Copilot `agentStop` infinite loops), immediately returns `{"cancel": false}` on Cline `PreToolUse` calls for tools other than `attempt_completion`, invokes `CMP-DRIFT-DETECTOR` (`detect_drift(uncommitted=True, strict=...)`) for every modified project, and aggregates findings (with `-p <subproject>/eidos` remediation hints) into a single client-aware 1-turn continuation payload.

== Public Surface
* `find_workspace_root(payload: dict[str, Any] | None = None) -> Path`
* `capture_session_baseline(payload: dict[str, Any], workspace_root: Path) -> dict[str, Any]`
* `handle_stop_hook(payload: dict[str, Any], workspace_root: Path, event: str | None = None) -> dict[str, Any]`
* `execute_hook(path: Path | None = None, repo_root: Path | None = None, stdin_data: str | None = None, event: str | None = None) -> int`

== Design Constraints & Operational Notes
* **Turn-Scoped Retry & Dirty-Worktree Safety (`DEC-PLUGIN-TURN-SCOPED-STOP-GATE`)**: Caps continuation prompts to 1 retry turn via client `stdin` flags (`executionNum`, `loop_count`, `stop_hook_active`, `stopHookActive`) plus state-digest tracking for Cline `attempt_completion`, and stores ephemeral session baselines strictly inside gitignored `eidos/.cache/hook_baselines/`.
