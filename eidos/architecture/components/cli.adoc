= Component: Eidos Command-Line Interface (C4 Level 3 Whitebox)
:toc: left

== Architectural Boundary
This container represents the user-facing CLI under `src/eidos/cli/`. It provides terminal commands, structured exit codes (0 = Success, 1 = Failure), and Rich table formatting for software engineers and product managers.
