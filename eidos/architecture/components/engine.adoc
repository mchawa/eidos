= Component: Eidos Orchestration & Validation Engine (C4 Level 3 Whitebox)
:toc: left

== Architectural Boundary
This component represents the core Python codebase under `src/eidos/`. It parses AsciiDoc files with YAML frontmatter, validates metadata against JSON/YAML schemas, executes CLI commands, hosts an MCP stdio server, and coordinates autonomous agent execution harnesses.

== Arc42 Section 5.2 / C4 Level 3: Internal Building Blocks

[cols="1,2,2", options="header"]
|===
| Internal Module | Responsibility | Source Path
| **SpecParser** | Robust extraction of YAML frontmatters from AsciiDoc content | `src/eidos/core/parser.py`
| **SpecValidator** | Schema resolution via dynamic asset loading and Draft 2020-12 validation | `src/eidos/core/validator.py`
| **CliInterface** | Typer and Rich user interface, formatted diagnostic reporting, exit codes | `src/eidos/cli/main.py`
| **AgentHarness** | Abstract protocol for pluggable agent execution drivers | `src/eidos/agent/base.py`
| **VCSBridge** | Normalized contract across GitHub and GitLab VCS platforms | `src/eidos/vcs/bridge.py`
| **LifecycleScaffolder** | Scaffolding living specifications, reference safety, repository initialization, and delta lifecycles | `src/eidos/core/scaffolder.py`
| **DesignEngine** | Multi-Design Systems, W3C DTCG tokens, UI component contracts, and screen state machines | `src/eidos/core/scaffolder.py`
| **PluginManager** | Agent-plugins.org v1.0.0 and project-scoped MCP installer | `src/eidos/plugin/installer.py`
| **PluginValidator** | Validation of agent plugins and SemVer 2.0.0 synchronization | `src/eidos/plugin/validator.py`
| **AssetLocator** | Centralized locator for schemas and plugin reference in assets/ | `src/eidos/core/assets.py`
| **McpServer** | Standard JSON-RPC 2.0 Model Context Protocol (MCP) server | `src/eidos/mcp/server.py`
|===

== Operational Invariants & Quality Attributes
* **Stateless Operation**: The engine persists zero runtime state outside of the target Git repository.
* **Deterministic Validation**: Identical repository specifications must always produce identical validation reports across all environments.
