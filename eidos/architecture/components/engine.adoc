= Component: Eidos Orchestration & Validation Engine
:toc: left

== Architectural Boundary
This component represents the core Python codebase under `src/eidos/`. It is responsible for parsing AsciiDoc files with YAML frontmatter, validating metadata against JSON/YAML schemas, executing CLI commands, and bridging autonomous agent execution harnesses.

== Internal Package Anatomy

[cols="1,3", options="header"]
|===
| Module | Responsibility
| `src/eidos/core/parser.py` | Robust extraction of YAML frontmatters from AsciiDoc content.
| `src/eidos/core/validator.py` | Schema resolution via `importlib.resources` and JSON Schema Draft 2020-12 validation.
| `src/eidos/cli/main.py` | Typer and Rich user interface, formatted diagnostic reporting, exit codes.
| `src/eidos/agent/base.py` | Abstract protocol for pluggable agent execution drivers.
| `src/eidos/vcs/bridge.py` | Normalized contract across GitHub and GitLab VCS platforms.
|===
