= Component: Eidos Agent Plugin & Extension Manager (C4 Level 3 Whitebox)
:toc: left

== Architectural Boundary
This container represents the plugin distribution and validation system under `src/eidos/plugin/`. It packages living specification skills, MCP server definitions, and validation rules into standard bundles adhering to `agent-plugins.org v1.0.0`.

== Arc42 Section 5.2 / C4 Level 3: Internal Building Blocks

[cols="1,2,2", options="header"]
|===
| Internal Module | Responsibility | Source Path
| **PluginInstaller** | Manages installation and file synchronization into `.agents/plugins/eidos` | `src/eidos/plugin/installer.py`
| **PluginValidator** | Enforces JSON Schema conformance and SemVer 2.0.0 rules for plugins | `src/eidos/plugin/validator.py`
| **McpConfigSync** | Automatically configures client MCP entries in `.cursor/mcp.json` and `.claude/mcp.json` | `src/eidos/plugin/installer.py`
|===
