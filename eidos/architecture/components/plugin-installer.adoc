= Component: PluginInstaller
:toc: left

== Responsibility
Installs, updates, and safely uninstalls portable agent plugins and 4 cohesive workflow skills (`ACTIVE_EIDOS_SKILLS` across `eidos`, `eidos-spec`, `eidos-plan`, and `eidos-ops`, synchronized with streamlined v1 JSON Schema-validated YAML frontmatter templates deriving schema from type across `SYS-*`/`ARCH-*`/product/tech/design/delta specs, explicit `additionalProperties: false` frontmatter guardrails, `eidos spec schema` introspection, 4-parameter blueprint `eidos spec create`, `eidos context --json`, composable `operation`/`target` SpecDelta workflows with Implementation Plan prose guidance, and canonical `eidos/design/**` paths) via a declarative `TargetAdapter` registry (`TargetAdapter.install` and `TargetAdapter.uninstall` driving bundle copying via `_copy_plugin_tree` from `assets/plugin_reference` with `include_skills=(self.skills_subdir is None)` to avoid duplicating skills inside `plugin_subdir/skills` when flat skill projection is active, skill projection, instruction blocks including non-destructive append into existing `.github/copilot-instructions.md` when `COPILOT_START_MARKER` is absent, `orjson`-backed hook/JSONC merges, and manifest-only cleanup via `_uninstall_from_manifest`, with `PluginInstallTarget.PROJECT` scoped strictly to `.agents/plugins/eidos`, `Path`-typed `InstallResult.created_files` for Aider, and accurate fallback `plugin_dir` resolution in `check_plugin_version_status` alongside PEP 440 / SemVer normalization via `normalize_to_semver` and release-synchronized `get_bundled_plugin_version`) and manifest tracking (`.eidos-manifest.json` serialized via `orjson` after `post_install_hook` and flat skill projection, tracking pre-existing bundle files on `force=False` so uninstall remains complete) with SHA-256 digests, preserving existing manifest entries and user-owned files on `force=False`, enforcing ancestor-aware symlink protection (`_check_not_symlink`), and upgrading version-pinned `uvx` hook commands across `agent-plugins.org` v1.0.0, Claude Code, OpenAI Codex, OpenCode (`open-code`), Aider, Cline, Cursor, and GitHub Copilot.
