= Component: PluginInstaller
:toc: left

== Responsibility
Installs, updates, and safely uninstalls the Eidos Agent Plugin and its 4 workflow skills (`eidos`, `eidos-spec`, `eidos-plan`, `eidos-ops`) across 8 AI coding harnesses via a declarative `TargetAdapter` registry and SHA-256 `.eidos-manifest.json` tracking.

== Key Responsibilities & Collaborators
* **Declarative Multi-Harness Projection (`installer.py`)**: Projects `assets/plugin_reference/` (resolved via `CMP-ASSET-LOCATOR`) across `project` (`.agents/plugins/eidos`), GitHub Copilot, Claude Code, Cursor, Cline, OpenCode, OpenAI Codex, and Aider targets, merging `hooks.json` and instruction blocks non-destructively.
* **Manifest-Tracked Uninstall & Version Synchronization (`version.py`)**: Records installed file paths and SHA-256 digests in `.eidos-manifest.json`, removes only Eidos-managed files during `uninstall`, and normalizes package versions to SemVer 2.0.0 (`normalize_to_semver`, `get_bundled_plugin_version`).

== Public Surface
* `PluginInstallTarget`, `InstallResult`, `ACTIVE_EIDOS_SKILLS`
* `install_plugin(target: PluginInstallTarget, repo_root: Path, force: bool = False) -> list[InstallResult]`
* `uninstall_plugin(target: PluginInstallTarget, repo_root: Path) -> list[str]`
* `check_plugin_version_status(repo_root: Path) -> dict[str, Any]`
* `get_bundled_plugin_version() -> str`, `normalize_to_semver(version_str: str) -> str`

== Design Constraints & Operational Notes
* **Symlink & User-File Safety**: Rejects symlink traversal outside the repository (`_check_not_symlink`) and refuses to overwrite modified user-owned files when `force=False`.
