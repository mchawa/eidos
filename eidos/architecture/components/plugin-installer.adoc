= Component: PluginInstaller
:toc: left

== Responsibility
Installs, updates, and safely uninstalls the Eidos Agent Plugin and its 4 workflow skills (`eidos`, `eidos-spec`, `eidos-plan`, `eidos-ops`) across 8 AI coding harnesses via a declarative `TargetAdapter` registry and SHA-256 `.eidos-manifest.json` tracking.

== Key Responsibilities & Collaborators
* **Declarative Multi-Harness Projection (`installer.py`)**: Projects `assets/plugin_reference/` (resolved via `CMP-ASSET-LOCATOR`) across `project` (`.agents/plugins/eidos`), GitHub Copilot, Claude Code (`.claude/skills/` and `.claude/settings.json` `hooks.Stop` registration), Cursor, Cline, OpenCode, OpenAI Codex, and Aider targets, merging `hooks.json`, `.claude/settings.json`, and instruction blocks non-destructively.
* **Manifest-Tracked Uninstall & Version Synchronization (`version.py`)**: Records installed file paths and SHA-256 digests in `.eidos-manifest.json` (while excluding shared host `.claude/settings.json` from full-file unlinking), removes only Eidos-managed files during `uninstall`, resolves both `plugin.json` and `.eidos-manifest.json` in `_resolve_installed_plugin_manifest`, and normalizes package versions to SemVer 2.0.0 (`normalize_to_semver`, `get_bundled_plugin_version`).

== Public Surface
* `PluginInstallTarget`, `InstallResult`, `UninstallResult`, `ACTIVE_EIDOS_SKILLS`
* `install_plugin(target: PluginInstallTarget, project_dir: Path | None = None, dest_path: Path | None = None, force: bool = False, launcher: str = "eidos") -> list[InstallResult]`
* `uninstall_plugin(target: PluginInstallTarget, project_dir: Path | None = None, dest_path: Path | None = None) -> list[UninstallResult]`
* `update_plugin(target: PluginInstallTarget, project_dir: Path | None = None, dest_path: Path | None = None, launcher: str = "eidos") -> tuple[str | None, str, list[InstallResult]]`
* `check_plugin_version_status(project_dir: Path | None = None, dest_path: Path | None = None) -> dict[str, Any]`
* `get_bundled_plugin_version() -> str`, `normalize_to_semver(version: str) -> str | None`

== Design Constraints & Operational Notes
* **Symlink & User-File Safety**: Rejects symlink traversal outside the repository (`_check_not_symlink`) and refuses to overwrite modified user-owned files when `force=False`.
