= Component: TieredContextCompressor
:toc: left

== Responsibility
Extracts rank-ordered, token-budgeted architectural subgraph slices (`ArchitecturalContextSlice`) across `anchor` (`<=300` tokens), `guardrails` (`<=1000` tokens), and `deep` (`<=2500` tokens) tiers in both Markdown and `orjson` JSON formats for AI coding agents.

== Key Responsibilities & Collaborators
* **Multi-Entry & Brace-Glob Context Resolution (`context_globs.py`, `DEC-CONTEXT-GLOB-AND-GUARDRAIL-RETENTION`)**: Resolves context queries by file path, comma-separated file list, or quoted glob pattern (`--file`, expanding `*`, `?`, `[`, and `{a,b}` brace alternations via `expand_brace_globs` and `split_brace_aware_csv` across existing workspace files and planned paths under existing directories or `symbol_mappings` prefixes), entity ID (`--component`), or natural-language task (`--task`).
* **Calibrated Token Budgeting, Structural Entity Tie-Breaking, AST Test-Coupled Ranking & Guardrail-Preserving Compaction (`context_models.py`, `context.py`, `DEC-CONTEXT-GLOB-AND-GUARDRAIL-RETENTION`, `DEC-CONTEXT-AST-TEST-COUPLING-RANKING`, `INV-CONTEXT-GUARDRAIL-INVARIANT-RETENTION`, `INV-CONTEXT-TEAM-MEMORY-ATTACHMENT`)**: Models `ArchitecturalContextSlice` and `TieredContextSlice` in `context_models.py`, honors `context.default_tier`, `context.budgets` (`anchor`, `guardrails`, `deep` overriding `TIER_TOKEN_BUDGETS` via `tier_budgets`), and `context.semantic.enabled` from optional `<eidos_dir>/eidos.yaml` while preserving calibrated built-in constants when absent, estimates tokens using structure-aware calibration (`~3.0` chars/token for code/YAML/JSON vs. `~4.0` chars/token for prose), breaks 1-hop capability ties structurally by shared matched architectural links (containers/components/contracts) and declared invariant breadth ahead of alphabetical ID while ranking governing policies by severity (`blocking > warning > advisory`), top-capability affinity, and governed capability reach before alphabetical ID, ranks capability `INV-*` guardrails (after explicit `CMP-*.invariants`) by observed AST test-to-source import coupling (`code_symbols` `kind = 'import', is_test = 1`: direct import of an edited file > direct import of a primary `CMP-*` source file > uncoupled fallback) followed by lexical ID specificity precision (`focus_id_hits / max(len(id_core_toks), 1)`) and test-file stem fallback ahead of capability declaration order, runs Stage 0 memory-first pruning (drop untargeted globals -> compact memories -> pop tail anchored memories) before any architectural entity compression or eviction, and applies progressive Stage 1a prose compression (`_compact_prose` followed by `_compact_primary_decisions` tail `DEC-*` compaction, deferring `_compact_metadata` to Stage 3) plus guardrails Stage 1b secondary 1-hop component trimming and secondary decision compaction *before* evicting 1-hop capability `INV-*` guardrails below `min_len=3` while retaining compact primary `DEC-*` summaries.
* **Secondary Team Memory Freshness & Budgeted Attachment (`context_memories.py`, `DEC-INDEX-MEMORY-FRESHNESS-AND-SECONDARY-SLICING`, `INV-CONTEXT-TEAM-MEMORY-ATTACHMENT`)**: Evaluates deterministic `agent/memory` (`MEM-*`) freshness (`fresh`, `stale`, `expired`, `unverifiable`) backed by the non-blocking `HEAD`-keyed `memory_freshness_cache` (with `git merge-base --is-ancestor` shallow-clone/squash/rebase safety and `commit_drift_threshold: int | None = None` auto-resolving `memory.commit_drift_threshold` from `<eidos_dir>/eidos.yaml` with fallback to `DEFAULT_MEMORY_COMMIT_DRIFT_THRESHOLD = 5` so `CMP-MEMORY-ENGINE` and `CMP-GRAPH-TRAVERSAL-ENGINE` share identical thresholds), attaches active memories via a secondary pass across target paths/globs (`match_path_pattern`), entity anchors, bounded `include_types=("agent/memory",)` FTS queries, and tier-capped untargeted globals honoring `memory.tier_caps` overrides (defaults `anchor: <=2/0`, `guardrails: <=3/2`, `deep: <=5/3` with `guidance`/`why` sections extracted via `extract_memory_sections`), omits the `memories` section/key when empty, and preserves Honest Empty Slices when explicit queries match zero entities and zero anchored memories.

== Design Constraints & Operational Notes
* **Honest Empty Slices**: Returns an empty `ArchitecturalContextSlice` when an explicit file, glob, component, or task query matches zero entities rather than injecting unrelated alphabetical fallback specs.
* **Direct-Over-1-Hop Container Prioritization & Structured Epistemic Provenance (`DEC-INDEX-HYBRID-SEMANTIC-RRF`, `DEC-INDEX-HTTP-LINKING-AND-PROVENANCE`)**: Separates directly matched containers/components (`direct_cnt_ids`) from 1-hop domain/design-system and `ast_import`/`ast_http` dependency expansions (`expanded_cnt_ids`) so 1-hop expansions never crowd out direct FTS/Hybrid container hits or survive `_enforce_token_budget` ahead of direct matches, and surfaces structured `provenance_tags` (`provenance`, `confidence`, and `file:line` `evidence` across `observed`, `derived`, and `inferred` tiers) in `TieredContextSlice.to_dict()` and `to_markdown()` on `guardrails` (`<=1000` tokens) and `deep` (`<=2500` tokens) slices while omitting verbose provenance metadata from `anchor` (`<=300` tokens) to preserve `INV-CONTEXT-TOKEN-COMPRESSION`.
