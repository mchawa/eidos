= Component: IndexCommands
:toc: left

== Responsibility
Implements the `eidos index` subcommand group (`status`, `sync`, `search`, `blast-radius`, `repo-map`, `find-symbol`, `semantic`, `health`) for inspecting and querying the embedded SQLite knowledge graph, polyglot AST symbol index, optional Harrier ONNX semantic embedding index, and architecture governance health scorecard.

== Key Responsibilities & Collaborators
* **Knowledge Graph CLI Adapter**: Routes `--path` discovery across all `eidos index` subcommands through `require_cli_eidos_dir` (`CMP-CLI-APP`, preventing bogus empty `<git_root>/eidos/.cache/index.db` creation at rootless monorepos and failing closed with `discovered_subprojects` hints), auto-routes path-shaped `blast-radius` targets to their owning sub-project with sub-project-relative normalization, attaches `nested_subprojects` hints on root `search`, `find-symbol`, and `repo-map` queries in hybrid monorepos, resolves `context.semantic.enabled`, `context.repo_map_max_tokens`, and `context.semantic.variant` defaults from optional `eidos/eidos.yaml` via `resolve_param_from_config` (explicit CLI flags take precedence), delegates index synchronization (`index_sync_cmd` with `--force`, `--semantic/--no-semantic` allowing explicit CLI override of `context.semantic.enabled: false` while passing `auto_semantic=False` so foreground sync never spawns competing background ONNX workers, and `--json`) and status telemetry (including `edge_counts_by_provenance`) to `CMP-GRAPH-STORAGE` and `CMP-INCREMENTAL-SYNC-ENGINE`, BM25 lexical and Hybrid RRF search (`--semantic/--no-semantic`), symbol resolution, and repo-map generation (rendering epistemic `provenance` and `confidence`) to `CMP-FTS-QUERY-ENGINE` and `CMP-SEMANTIC-EMBEDDING-ENGINE`, and target-resolved recursive `k`-hop impact analysis (`resolve_blast_radius_targets`, `symbol_or_path`, and `--min-confidence` filtering across `inferred`, `derived`, and `observed`) plus deterministic governance health scorecards (`index_health_cmd` for `eidos index health [--path PATH] [--json]`, displaying component-scoped `== Public Surface` coverage alongside container counts) to `CMP-GRAPH-TRAVERSAL-ENGINE`.

== Public Surface
* `index_app: typer.Typer`
* `index_status_cmd(...)`, `index_sync_cmd(...)`, `index_search_cmd(...)`, `index_blast_radius_cmd(symbol_or_path: str, ...)`, `index_repo_map_cmd(...)`, `index_find_symbol_cmd(...)`, `index_semantic_cmd(...)`, `index_health_cmd(...)`

== Design Constraints & Operational Notes
* **Deterministic Agent Telemetry**: Supports `--json` (`orjson`) across `status`, `sync`, `search`, `blast-radius`, `repo-map`, and `find-symbol` (including `file:line` AST symbol coordinates).
