= Component: LifecycleScaffolder
:toc: left

== Responsibility
Scaffolds minimal, schema-valid draft blueprints across all 15 living specification types, introspects v1 JSON Schemas (`get_spec_schema_info`), deterministically scans polyglot repositories for brownfield onboarding (`discover_repository_blueprint`), resolves catalog entities, and performs reference-safe specification deletion.

== Key Responsibilities & Collaborators
* **Generic Catalog-Aware Blueprint Scaffolding**: Generates schema-valid `.adoc` blueprints (`create_spec`) using `CMP-ASSET-LOCATOR` templates (`*.template.adoc`) and `CMP-DESIGN-ENGINE` for `design/*` specs (requiring an explicit `client` argument for `screen` blueprints with no silent default so screens are placed under `eidos/design/clients/<client>/screens/`) while resolving parent domain/container/persona/design-system references strictly from live catalog entities (or omitting optional reference fields rather than injecting nonexistent placeholder IDs).
* **Dynamic Schema Introspection**: Flattens v1 JSON Schemas and `$defs` (`get_spec_schema_info`) to synthesize required/optional key metadata and valid YAML frontmatter examples for `eidos spec schema`.
* **Deterministic Brownfield Discovery (`DEC-CORE-DISCOVER-OPENAPI-DEDUP-AND-SERVICE-PRECEDENCE`, `INV-BROWNFIELD-DETERMINISTIC-DISCOVERY`, `INV-BROWNFIELD-REST-CONTROLLER-DISCOVERY`)**: Scans polyglot build/package manifests (`.csproj`/`.fsproj`, `pyproject.toml`, `package.json`, `go.mod`, `Cargo.toml`, `pom.xml`, `build.gradle`) with service-first `container_type` precedence (prioritizing web frameworks and discovered HTTP routes ahead of `[project.scripts]` / `package.json` `bin`), schema-first interface contract artifacts (OpenAPI/Swagger, AsyncAPI, Protobuf `.proto`, GraphQL `.graphql`/`.gql`, OpenRPC, WSDL `.wsdl` as `wsdl`, Avro `.avsc`/`.avdl` as `avro`, Prisma `.prisma` and canonical schema `.sql` files such as `schema.sql`/`ddl.sql`/`*schema*.sql` as `sql_ddl`, excluding numbered migration/seed `.sql` scripts), code-first modern REST controller/router roots (`protocol: "rest_http"` with `route_count` via `CMP-HTTP-TOPOLOGY-LINKER`, deduplicating containers already covered by active or co-located OpenAPI contracts, matching camelCase `Test`/`Tests` filenames case-sensitively, and honoring `DEC-CORE-MODERN-REST-PARITY-ONLY`), and test directories (`discover_repository_blueprint`) with zero AI calls, pruning `STANDARD_EXCLUDED_DIRS` and `.NET` `bin/`/`obj/` outputs and cross-referencing existing active `CNT-*`/`CMP-*`/`CTR-*` specs to report proposed containers, contracts, `already_mapped` status, and unmapped code roots.
* **Quote-Safe YAML Scalar Updates & Ambiguity-Checked Lookup**: Updates top-level YAML scalars via structure-aware `_set_frontmatter_scalar` without corrupting multiline quoted or block scalars, and resolves entities via `find_spec_by_id_or_path` (supporting `include_archived`, rejecting bare `DLT-YYYY` year-only prefixes, and raising explicit `ValueError` diagnostics when a prefix matches multiple colliding candidates) before deleting specifications (`delete_spec`).

== Public Surface
* `create_spec(eidos_dir: Path, doc_type_key: str, raw_id: str, title: str, *, client: str | None = None) -> Path`
* `delete_spec(eidos_dir: Path, target_id_or_path: str, force: bool = False) -> tuple[bool, str, list[str]]`
* `list_specs(eidos_dir: Path, type_filter: str | None, status_filter: str | None, include_archived: bool) -> list[dict]`
* `get_spec_schema_info(spec_type: str | None = None) -> dict[str, Any]`
* `discover_repository_blueprint(repo_root: Path, eidos_dir: Path | None = None) -> dict[str, Any]`
* `find_spec_by_id_or_path(eidos_dir: Path, target: str)`, `find_references_to_spec(eidos_dir: Path, doc_id: str, rel_path: str)`

== Design Constraints & Operational Notes
* **Disjoint SpecDelta Boundary**: `create_spec`, `delete_spec`, and `list_specs` explicitly reject `delta/mutation` (`DLT-*`), which is managed exclusively by `CMP-DELTA-ENGINE`.
