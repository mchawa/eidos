= Component: SpecValidator
:toc: left

== Responsibility
Validates all 17 living specification types (including team-scoped `agent/memory` schemas) against Draft 2020-12 JSON Schemas (`assets/schemas/v1/`), verifies `x-eidos-ref` graph cross-references, checks disk and AST `test_binding` existence, validates W3C DTCG design token manifests (`design_validation.py`), and orchestrates `CMP-MERMAID-VALIDATOR`, `CMP-CONTRACT-PARITY-VALIDATOR`, and `CMP-ARCHITECTURE-BOUNDARY-VALIDATOR`.

== Key Responsibilities & Collaborators
* **Schema, Embedded Mermaid Syntax, Repo-Relative Diagnostics & Design Token Containment (`validator.py`, `design_validation.py`)**: Resolves v1 schemas and shared `$defs` (`common/defs.yaml`), normalizes `ValidationReport.schema_errors` keys to repo-relative POSIX paths (preserving backward-compatible absolute/relative lookup), validates W3C DTCG token manifests and acyclic `extends` chains with `cand.resolve().is_relative_to(repo_root.resolve())` containment (`design_validation.py`), caches per-document schema verdicts via `CMP-GRAPH-STORAGE` (`spec_validation_cache`, invoking `validate_document(..., check_mermaid=False)` inside `validate_directory` to keep `spec_validation_cache` purely schema-scoped), runs a single post-load batch `CMP-MERMAID-VALIDATOR` pass (skipping historical `applied`/`rejected` SpecDeltas, hydrating/flushing `mermaid_validation_cache` non-blockingly, and emitting blocking diagnostics with lazily resolved `.adoc` line offsets), and batch-hydrates/flushes `public_surface_cache` without blocking on contended `index.db.lock` cache reads/writes (falling back to live disk parsing on contended reads and skipping contended cache persistence while keeping `evaluate_import_boundaries` strictly fresh).
* **Cross-Reference, Brace-Glob Path, Client-Scoped Screen Ownership, Advisory Memory Isolation & Active `test_binding` Integrity**: Verifies all schema-declared `x-eidos-ref` fields (emitting non-blocking advisory `warnings` whenever an active living specification references a `deprecated` or `retired` catalog entity per `INV-LIFECYCLE-AND-TIER-GUARDRAIL-WARNINGS`, while exempting `agent/memory` frontmatter from `_check_dict_references` and `_warn_if_deprecated_dependency` per `DEC-CORE-AGENT-MEMORY-SCHEMA-ISOLATION` so stale memory anchors never enter `broken_references` or `ValidationReport.warnings`), `{a,b}` brace-glob `source_path` targets (`_resolve_source_path`), SpecDelta `mutations[].target` references, global `CMP-*` / `INV-*` / `DEC-*` ID uniqueness (enriching duplicate `DEC-*` diagnostics involving a `delta/mutation` SpecDelta with an authoring remediation hint per `INV-DELTA-AUTHORING-GUARDRAILS`), centralized component placement (`INV-COMPONENT-CENTRALIZATION-MANDATE`, `INV-COMPONENT-CONTAINER-AFFINITY`), client-scoped `design/screen` placement (`eidos/design/clients/<client>/screens/<screen>.adoc`) and active `design/screen` ownership by at least one `design/client` (`CLT-*.screens`, `INV-DESIGN-SCREEN-CLIENT-OWNERSHIP`), and rejects empty, `N/A`, `TBD`, `NONE`, and bare symbol-less `test_binding` values on `status: active` specifications (including `UIC-*`).
* **Delegation to Specialized Conformance Validators (`DEC-ARCH-MODULAR-COMPONENT-COHESION`, `DEC-CORE-ADVISORY-VALIDATION-WARNINGS`, `DEC-CORE-CANONICAL-CONTRACT-PROTOCOL-ENUM`, `DEC-CORE-EXTENDED-CONTRACT-PROTOCOLS`)**: Delegates bidirectional multi-protocol `CTR-*` verification to `CMP-CONTRACT-PARITY-VALIDATOR` (passing uncollapsed multi-file glob/brace-glob and directory `specification_file` targets across the canonical multi-target protocol set: `rest_http`, `cli_args`, `code_interface`, `sql_ddl`, `trpc`, `websocket`, and `mcp`) and delegates scoped `== Public Surface` AST parity, advisory `ValidationReport.warnings` collection (over-scoped and overlapping `CMP-*.source_path` entries and 2-tier lazy prose symbol drift), and declarative `import_boundaries` / `ratchet_baseline` evaluation to `CMP-ARCHITECTURE-BOUNDARY-VALIDATOR`, preserving `SpecValidator` and `evaluate_import_boundaries` facade entrypoints.

== Public Surface
* `SpecValidator.validate_directory(root_dir: Path, *, check_import_boundaries: bool = True) -> ValidationReport`
* `SpecValidator.validate_document(doc: SpecDocument, root_dir: Path | None = None, *, check_mermaid: bool = True) -> list[str]`
* `evaluate_import_boundaries(eidos_dir: Path, *, repo_root: Path | None = None, documents: list[SpecDocument] | None = None) -> tuple[list[dict[str, Any]], list[dict[str, Any]]]`

== Design Constraints & Operational Notes
* **Cache Isolation**: Cross-reference errors depend on catalog-wide state and are never persisted into per-file `spec_validation_cache` entries.
* **Static-Only Verification**: Verifies test symbol existence and contract signatures via static AST inspection without importing or executing user code.
