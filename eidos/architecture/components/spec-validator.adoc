= Component: SpecValidator
:toc: left

== Responsibility
Validates all 16 living specification types against Draft 2020-12 JSON Schemas (`assets/schemas/v1/`), verifies `x-eidos-ref` graph cross-references, checks disk and AST `test_binding` existence, validates W3C DTCG token manifests, verifies static `== Public Surface` AST symbols in active `CMP-*` / `CNT-*` specifications, and enforces bidirectional multi-protocol `CTR-*` contract parity.

== Key Responsibilities & Collaborators
* **Schema, Repo-Relative Diagnostics & Token Containment Validation**: Resolves v1 schemas and shared `$defs` (`common/defs.yaml`), normalizes `ValidationReport.schema_errors` keys to repo-relative POSIX paths (preserving backward-compatible absolute/relative lookup), enforces `cand.resolve().is_relative_to(repo_root.resolve())` path containment on `tokens.manifest` files, and caches per-document schema verdicts via `CMP-GRAPH-STORAGE` (`spec_validation_cache`).
* **Cross-Reference, Brace-Glob Path & Graph Integrity**: Verifies all schema-declared `x-eidos-ref` fields, `{a,b}` brace-glob `source_path` targets (`_resolve_source_path`), SpecDelta `mutations[].target` references, global `CMP-*` / `INV-*` / `DEC-*` ID uniqueness, and centralized component placement (`INV-COMPONENT-CENTRALIZATION-MANDATE`, `INV-COMPONENT-CONTAINER-AFFINITY`).
* **Active `test_binding`, `== Public Surface` & Multi-Protocol Contract Parity**: Rejects empty, `N/A`, `TBD`, `NONE`, and bare symbol-less `test_binding` values on `status: active` specifications (including `UIC-*`), verifies `::`-qualified, generic (`<T>`, `[T]`), multi-keyword, Go-receiver, and per-class `== Public Surface` AST symbols on disk, and enforces bidirectional `CTR-*` parity across `cli_args` (including Click/argparse alongside Typer helpers and imported `add_typer` sub-apps), `python_protocol`, left-bounded `openapi` HTTP routes, backtick-scoped `protobuf` (`rpc`, `service`, `message`, `enum`), `graphql`, and `json_schema`.

== Public Surface
* `SpecValidator.validate_directory(eidos_dir: Path) -> ValidationReport`
* `SpecValidator.validate_document(doc: SpecDocument) -> list[str]`

== Design Constraints & Operational Notes
* **Cache Isolation**: Cross-reference errors depend on catalog-wide state and are never persisted into per-file `spec_validation_cache` entries.
* **Static-Only Verification**: Verifies test symbol existence and contract signatures via static AST inspection without importing or executing user code.
