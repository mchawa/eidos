:toc: left

== Responsibility
Resolves bundled JSON/YAML schemas via a deterministic path-qualified _schema_cache (keyed strictly by relative path under assets/schemas/v1/, deriving schema paths from type via TYPE_TO_SCHEMA_NAME and ENTITY_ID_PREFIXES in models.py and merging shared reusable $defs from assets/schemas/v1/common/defs.yaml across all 16 v1 schemas for lifecycle_status, delta_status, exploration_status, semver, invariant, decision, and canonical x-eidos-ref definitions, requiring top-level status and allowing optional semver version across all 16 schemas, enforcing structured mutations[].expect schema validation with body/frontmatter blocks and composable mutations[].operation/target validation in delta.schema.yaml, and dynamically extracting entity ID prefixes including INV-* via _extract_prefixes_from_schema), performs cached per-document schema and architectural-invariant validation via unified 'spec_validation_cache' helpers in storage.py without duplicate inline DDL (persisting deduplicated _validate_architectural_invariants errors directly inside 'doc_json' via 'orjson' without a duplicate 'schema_errors_json' column, sharing cached SpecDocument records via get_cached_spec_document without leaking cross-reference errors into cached schema error lists, consuming typed FrontmatterModel properties via doc.model, and keying relative to repo_root via resolve_spec_and_repo_roots across standard, custom --path, and subdirectory roots while seeding catalog_ids/entity_types from spec_root on subdirectory validation, scoping the 0-byte empty-file exemption strictly to root system.adoc), verifies recursive #/$defs/* schema-driven x-eidos-ref cross-references and _check_dict_references across all 16 schemas including .adoc path target_types verification and composable SpecDelta mutations[].target references via infer_entity_type_from_path and resolve_entity_prefix_meta (exempting tombstone/expect and add/remove/deprecate or closed delta .adoc paths in _check_dict_references, enforcing catalog existence on modify/deprecate mutations and prefix/type integrity across all operations including SYS-* targets and deprecate across all 14 lifecycle-status specification types, with strict container vs. component target type enforcement and 'graduated_from'), validates container and component source_path, optional contract specification_file, UI component invariants[].test_binding, and invariant test_binding (file::func, rejecting empty symbols after trailing '::') file and AST-backed polyglot test symbol existence on disk across both src/ and non-src/ polyglot layouts via get_ast_indexer().list_test_functions and extract_symbols in _test_symbol_exists (scoping Python class methods to their immediate class body while indexing leaf method names for unqualified bindings, with per-file SHA-256 _TEST_SYMBOL_CACHE caching and comment-stripped fallback only for unsupported file extensions, rejecting comment and string-literal false positives), and design/system W3C DTCG tokens.manifest structure (including leaf/scalar token checks) and acyclic DS-* inheritance via top-level extends, enforces global 'CMP-*', 'INV-*', and 'DEC-*' ID uniqueness, dispatches bidirectional multi-protocol CTR-* parity checks through a pluggable protocol verifier registry (_CONTRACT_PROTOCOL_VERIFIERS supporting cli_args, python_protocol, rest_openapi/openapi, json_schema with non-list required guard, grpc_proto/protobuf, and graphql with deduplicated symbols and comment-stripped bodies, scoping Python Typer/Click/argparse CLI contract parity checks to AST-verified Typer instances with positional/keyword/constructor add_typer names, async def commands, nested Click groups and add_command, functional app.command(...)(fn) calls, and delegated *_commands.register(app) modules), and enforces repo-relative centralized component invariants (INV-COMPONENT-CENTRALIZATION-MANDATE, INV-COMPONENT-CONTAINER-AFFINITY, INV-INTERFACE-BOUNDARY-GOVERNANCE).
