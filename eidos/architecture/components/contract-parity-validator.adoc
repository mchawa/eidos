= Component: ContractParityValidator
:toc: left

== Responsibility
Verifies bidirectional parity between `CTR-*` living interface contract specifications and their declared `specification_file` code or schema artifacts across all 16 verifiable canonical contract protocols (`cli_args`, `python_protocol`, `openapi`, `rest_http`, `protobuf`, `graphql`, `json_schema`, `asyncapi`, `json_rpc_stdio`, `code_interface`, `wsdl`, `avro`, `sql_ddl`, `trpc`, `websocket`, and `mcp`), treating `protocol: other` (with required `custom_protocol`) as explicitly custom.

== Key Responsibilities & Collaborators
* **CLI Interface AST & Polyglot Parity (`cli_contract_parity.py`, `source_contract_parity.py`)**: Parses Python Typer (including imported `add_typer` sub-apps and decorator helpers), Click, and `argparse` command/option/positional trees via `_parse_python_ast` (`verify_cli_contract_commands`) for single `.py` files and safely dispatches directory, multi-file, or polyglot CLI targets (Go `cobra`, Rust `clap`, Node/TS `commander`/`yargs`, C# `System.CommandLine`) via `verify_polyglot_cli_contract` without calling `.read_text()` on directories.
* **Schema & IDL Parity Leaf (`schema_contract_parity.py`)**: Provides shared comment-stripping, interface-section scoping, and directory/glob source collection (`collect_protocol_source_files`) alongside stdlib-only bidirectional parity verifiers for XML `wsdl` 1.1/2.0 (rejecting DTD/ENTITY declarations), `avro` (`.avsc`/`.avdl`), and `sql_ddl` (`.sql`/`.prisma`).
* **Source-Backed Parity Leaf (`source_contract_parity.py`)**: Implements zero-symbol-safe static bidirectional parity across polyglot `code_interface` (TypeScript, C#, Go, Rust, Java/Kotlin), TypeScript `trpc` routers, `websocket` (ASP.NET Core SignalR hubs with opt-in contradiction-only `[Authorize]`/`[AllowAnonymous]` parity, NestJS `@SubscribeMessage`, Socket.IO/WS events), transport-agnostic `mcp` (manifests + Python/TS tools, resources, prompts), and polyglot `cli_args`.
* **Multi-Protocol Bidirectional Parity Facade (`contract_parity.py`, `DEC-CORE-MODERN-REST-PARITY-ONLY`, `DEC-CORE-CANONICAL-CONTRACT-PROTOCOL-ENUM`, `DEC-CORE-EXTENDED-CONTRACT-PROTOCOLS`, `INV-CONTRACT-ASYNCAPI-AND-JSONRPC-PARITY`, `INV-CONTRACT-EXTENDED-PROTOCOLS-PARITY`, `INV-CONTRACT-CLI-OPENAPI-JSONSCHEMA-PARITY`)**: Dispatches `CTR-*` protocol verification via `ContractParityValidator._CONTRACT_PROTOCOL_VERIFIERS` strictly on canonical protocol enum values across Python `Protocol`/ABC signatures, left-bounded `openapi` HTTP routes plus OpenAPI 3.1 `webhooks`, modern `rest_http` source-backed HTTP contracts (`_verify_rest_http_contract`, resolving single-file, directory, or glob/brace-glob `specification_file` targets via `CMP-HTTP-TOPOLOGY-LINKER` with cross-file ASP.NET Core base-controller `[Route]`/`[Authorize]` inheritance plus opt-in polyglot authorization verification across ASP.NET Core, Spring, NestJS, and FastAPI per `INV-CONTRACT-POLYGLOT-AUTH-PARITY`), backtick-scoped `protobuf`, `graphql` SDL, bidirectional `json_schema` (including `$defs`/`definitions` and recursive bare-identifier reverse phantom parity), AsyncAPI 2.x/3.x, OpenRPC/JSON-RPC/MCP stdio (`_verify_json_rpc_stdio_contract`), and all 7 extended protocols, while treating `protocol: other` (`custom_protocol`) as an intentional no-op.

== Design Constraints & Operational Notes
* **Static-Only Inspection**: Verifies Typer/Click/`argparse` ASTs, Python protocols, OpenAPI YAML/JSON, Protobuf, and GraphQL definitions strictly via static parsing without importing or executing user application code.
