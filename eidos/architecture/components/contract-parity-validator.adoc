= Component: ContractParityValidator
:toc: left

== Responsibility
Verifies bidirectional parity between `CTR-*` living interface contract specifications and their declared `specification_file` code or schema artifacts across all 9 canonical contract protocols (`cli_args`, `python_protocol`, `openapi`, `rest_http`, `protobuf`, `graphql`, `json_schema`, `asyncapi`, and `json_rpc_stdio`), treating `protocol: other` (with required `custom_protocol`) as explicitly custom.

== Key Responsibilities & Collaborators
* **CLI Interface AST Parity (`cli_contract_parity.py`)**: Parses Python Typer (including imported `add_typer` sub-apps and decorator helpers), Click, and `argparse` command/option/positional trees via `_parse_python_ast` and verifies bidirectional parity (`verify_cli_contract_commands`) against AsciiDoc CLI contract command tables after stripping AsciiDoc comments (`strip_asciidoc_comments`).
* **Multi-Protocol Bidirectional Parity (`contract_parity.py`, `DEC-CORE-MODERN-REST-PARITY-ONLY`, `DEC-CORE-CANONICAL-CONTRACT-PROTOCOL-ENUM`, `INV-CONTRACT-ASYNCAPI-AND-JSONRPC-PARITY`)**: Dispatches `CTR-*` protocol verification via `ContractParityValidator` strictly on canonical protocol enum values across Python `Protocol`/ABC signatures, left-bounded `openapi` HTTP routes (scoping reverse checks away from boundary/out-of-scope sections and contrastive prose clauses), modern `rest_http` source-backed HTTP contracts (`_verify_rest_http_contract`, resolving single-file, directory, or glob/brace-glob `specification_file` targets via `CMP-HTTP-TOPOLOGY-LINKER` with cross-file ASP.NET Core base-controller `[Route]`/`[Authorize]` inheritance to enforce bidirectional `(METHOD, normalized_path)` parity with a zero-route fallback for custom/stdlib servers plus opt-in contradiction-only authorization verification across ASP.NET Core (`[Authorize]` / `Roles` / `Policy` / `[AllowAnonymous]`), Java/Kotlin Spring (`@PreAuthorize`, `@Secured`, `@RolesAllowed`, `@PermitAll`), TypeScript NestJS (`@UseGuards`, `@Roles`, `@Public`), and Python FastAPI (`Security`, `Depends`) per `INV-CONTRACT-POLYGLOT-AUTH-PARITY`), backtick-scoped `protobuf` verification (`rpc`, `service`, and top-level `message`/`enum`), `graphql` SDL queries/mutations/subscriptions, `json_schema` definitions, AsyncAPI 2.x/3.x channels and operations (`_verify_asyncapi_contract`), and OpenRPC/JSON-RPC/MCP stdio manifests and handler sources (`_verify_json_rpc_stdio_contract`), while treating `protocol: other` (`custom_protocol`) as an intentional no-op.

== Public Surface
* `ContractParityValidator`
* `verify_cli_contract_commands(doc: SpecDocument, cli_file: Path, report: ValidationReport) -> None`
* `strip_asciidoc_comments(body: str) -> str`

== Design Constraints & Operational Notes
* **Static-Only Inspection**: Verifies Typer/Click/`argparse` ASTs, Python protocols, OpenAPI YAML/JSON, Protobuf, and GraphQL definitions strictly via static parsing without importing or executing user application code.
