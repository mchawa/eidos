= Component: GraphTraversalEngine
:toc: left

== Responsibility
Executes recursive Common Table Expression (CTE) `k`-hop blast-radius traversals (`execute_k_hop_traversal`), multi-target blast-radius symbol/path resolution (`resolve_blast_radius_targets`), incoming reference lookups, file/symbol-to-entity resolution, indexed catalog reconstruction (`query_spec_catalog_in_db`), SpecDelta impact analysis (`compute_delta_impact_in_db`), and architecture governance health scorecard computation (`compute_governance_health`) from its dedicated disjoint module (`traversal.py`).

== Key Responsibilities & Collaborators
* **Hub-Scoped & Confidence-Filtered Recursive CTE Blast Radius**: Resolves entity IDs, specification paths, source file paths, and AST code symbols (`kind NOT IN ('import', 'namespace')`) to seed entity IDs (`resolve_blast_radius_targets`, filtering to `CMP-*` seeds when component matches resolve), filters edges by `min_confidence` (`observed > derived > inferred`), and traverses forward and reverse architectural edges up to `max_depth` hops while projecting bottleneck hop `provenance`, `confidence`, `via_rel_type`, and `evidence` on both `execute_k_hop_traversal` and `execute_incoming_references` and suppressing hop >= 2 sibling fan-out through organizational hub nodes (`DOM-*`, `DS-*`, `PER-*`, `ARCH-*`, `SYS-*`, `DLT-*`, `EXP-*`).
* **Indexed Catalog, SpecDelta Impact & Governance Health (`INV-INDEX-GOVERNANCE-HEALTH-SCORECARD`)**: Reconstructs `(specs_by_id, invariant_map)` directly from `entities` (`query_spec_catalog_in_db`) for `CMP-LIFECYCLE-SCAFFOLDER`, computes direct `affects` and transitive `blast_radius` sets (`compute_delta_impact_in_db`) for `CMP-PORTAL-GENERATOR` and `eidos delta`, and computes deterministic governance health metrics (`compute_governance_health`: source file ownership %, unowned files, Public Surface coverage, verified contract `specification_file` coverage, capability bound-invariant coverage, validation warning counts, and `ratchet_baseline` debt totals).

== Public Surface
* `resolve_blast_radius_targets(conn: sqlite3.Connection, symbol_or_path: str) -> list[str]`
* `execute_k_hop_traversal(conn: sqlite3.Connection, entity_id: str | Sequence[str], max_depth: int = 2, min_confidence: str = "inferred") -> list[dict[str, Any]]`
* `execute_incoming_references(conn: sqlite3.Connection, target_id_or_path: str) -> list[dict[str, Any]]`
* `resolve_symbol_or_path_in_db(conn: sqlite3.Connection, query: str) -> list[dict[str, Any]]`
* `query_spec_catalog_in_db(conn: sqlite3.Connection, eidos_dir: Path, repo_root: Path | None = None)`
* `compute_delta_impact_in_db(conn: sqlite3.Connection, mutations: list[dict[str, Any]]) -> tuple[dict[str, list[str]], dict[str, list[str]]]`
* `compute_governance_health(conn: sqlite3.Connection, repo_root: Path, eidos_dir: Path, *, validation_report: Any = None) -> dict[str, Any]`

== Design Constraints & Operational Notes
* **Sub-2ms Traversal Latency**: All graph neighborhood and catalog queries run entirely against indexed SQLite tables without disk scans.
