= Component: RepositoryInitializer
:toc: left

== Responsibility
Bootstraps greenfield and brownfield repositories with an Eidos living specification directory skeleton (`eidos/`), self-contained `eidos/.gitignore`, root `system.adoc` descriptor, and immediate schema validation.

== Key Responsibilities & Collaborators
* **Skeleton Provisioning**: Creates the complete 12-directory Eidos hierarchy with `.gitkeep` markers.
* **System Context & Cache Isolation**: Renders `eidos/system.adoc` (`product/system`) when `--title` is provided (or a 0-byte placeholder otherwise), writes `eidos/.gitignore` via `_ensure_eidos_gitignore` to exclude `.cache/`, and validates the initialized tree via `CMP-SPEC-VALIDATOR`.

== Public Surface
* `init_repository(project_dir: Path, title: str | None = None, eidos_dir_name: str = "eidos", force: bool = False) -> tuple[bool, str, list[Path]]`

== Design Constraints & Operational Notes
* **Non-Destructive Re-Initialization**: Refuses to overwrite a non-empty `eidos/` directory unless `force=True` is passed, treats an `eidos/` directory containing only `.cache/` and `.gitignore` (such as a shared Git-root semantic model cache provisioned before root initialization) as uninitialized without requiring `--force`, preserves an already authored `system.adoc` when `--force` is invoked without `--title`, and normalizes `project_dir` when it already ends with `eidos_dir_name` to prevent nested `eidos/eidos/` directories.
