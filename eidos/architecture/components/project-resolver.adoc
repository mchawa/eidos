= Component: ProjectResolver
:toc: left

== Responsibility
Discovers repository, monorepo sub-project, and living specification roots (`eidos/`), locates the enclosing `.git` worktree root (`find_git_root`), evaluates glob-based `source_path` ownership specificity, classifies polyglot test suites, and enumerates Git-tracked non-vendored workspace files while isolating nested child sub-projects (`discover_nested_subproject_roots`).

== Key Responsibilities & Collaborators
* **Workspace, Sub-Project & Cached Git Root Discovery**: Locates the nearest governing specification root and sub-project `repo_root` (`find_repo_root`, `resolve_spec_and_repo_roots`) across nested subdirectories, loads optional `<eidos_dir>/eidos.yaml` into `ProjectConfig.repo_config` (prepending `drift.base_ref` ahead of `base_ref_candidates`), evaluates `.agents` exclusions strictly relative to `repo_root` (never breaking checkouts cloned under `~/.agents/...`), resolves the enclosing `.git` worktree root (`find_git_root`), and caches `.gitignore`-pruned child sub-project boundaries honoring `workspace.subprojects_exclude` (`discover_nested_subproject_roots`).
* **Brace-Glob Path Ownership, Relative Path Normalization & Specificity**: Exposes canonical dotfile-safe POSIX path normalization (`normalize_rel_path`, shared across `CMP-DRIFT-DETECTOR`, `CMP-INCREMENTAL-SYNC-ENGINE`, and `CMP-HTTP-TOPOLOGY-LINKER`), expands `{a,b}` brace alternations in `_glob_to_anchored_regex` (`expand_brace_globs`), and scores literal directory-prefix specificity ahead of wildcards (`match_path_pattern`, `extract_entity_paths`) so `CMP-INCREMENTAL-SYNC-ENGINE` and `CMP-DRIFT-DETECTOR` bind source files deterministically to their most specific `CMP-*` or `CNT-*` owner.
* **Git-Tracked Preservation, Config Exclusions & Polyglot Test / Build Filtering**: Preserves explicitly Git-tracked files returned by `git ls-files` even when an internal directory segment matches `STANDARD_EXCLUDED_DIRS` (`target`, `build`, `site`, `out`, `obj`, `dist`, `vendor`), filters `workspace.exclude` patterns via `is_excluded_by_config` across Git and non-Git scans, excludes untracked `STANDARD_EXCLUDED_DIRS` (`obj`), `.NET` `bin/` build outputs (`is_dotnet_bin_dir`), nested child sub-project roots, and `linguist-generated` / `linguist-vendored` `.gitattributes` entries, and classifies polyglot test suites honoring `workspace.tests.exclude` before `workspace.tests.include` before built-in heuristics (including `.NET` `*.Tests` / `*Tests.cs`) in `is_polyglot_test_file`.

== Public Surface
* `ProjectConfig`
* `find_git_root(start_dir: Path | None = None) -> Path | None`, `find_repo_root(start_dir: Path | None = None) -> Path`
* `resolve_spec_and_repo_roots(root_dir: Path, doc_path: Path | None = None) -> tuple[Path, Path]`, `discover_nested_subproject_roots(repo_root: Path, *, repo_config: EidosConfig | None = None) -> list[Path]`
* `load_project(start_dir: Path | None = None, eidos_dir: Path | None = None, repo_root: Path | None = None) -> ProjectConfig`
* `normalize_rel_path(raw: str, *, strip_leading_slash: bool = True, strip_trailing_slash: bool = True) -> str`
* `match_path_pattern(rel_path: str, pattern: str) -> int`, `extract_entity_paths(frontmatter: dict) -> list[str]`, `is_excluded_by_config(rel_path: str, patterns: Sequence[str]) -> bool`
* `is_polyglot_test_file(rel_path: str, *, repo_root: Path | None = None, eidos_dir: Path | None = None, package_paths: Iterable[str] | None = None, repo_config: EidosConfig | None = None) -> bool`, `is_dotnet_bin_dir(dir_path: Path) -> bool`, `is_generated_or_vendored(repo_root: Path, rel_paths: Iterable[str]) -> set[str]`, `get_tracked_files(repo_root: Path, *, eidos_dir: Path | None = None, repo_config: EidosConfig | None = None) -> set[str]`

== Design Constraints & Operational Notes
* **Deterministic Ownership Precedence**: Literal file and directory prefixes always outrank broad glob patterns, and dotfile path segments (e.g., `.github/`) are preserved during normalization.
* **Monorepo Sub-Project Isolation (`DEC-CORE-MONOREPO-ISOLATED-SUBPROJECTS`)**: Prioritizes the nearest ancestor directory containing a valid `eidos/` specification catalog ahead of the enclosing `.git` root, ignores cache-only `<git_root>/eidos/` directories containing only `.cache/` and `.gitignore`, and loads each sub-project's optional `eidos/eidos.yaml` strictly from its own `eidos/` directory.
