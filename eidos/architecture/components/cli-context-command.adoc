= Component: ContextCommand
:toc: left

== Responsibility
Exposes the `eidos context` CLI command for extracting token-budgeted 3-tier architectural subgraph slices (`anchor`, `guardrails`, `deep`) by file path, comma-separated paths, or quoted glob pattern, component/container ID, or natural-language task prompt.

== Key Responsibilities & Collaborators
* **Brace-Aware, Monorepo-Aware & Git-Diff Context Slice CLI Adapter (`INV-CONTEXT-GIT-DIFF-SLICING`, `INV-MONOREPO-ROOT-CLI-AND-HOOK-ROUTING`)**: Parses `--file` (`-f`, splitting comma-separated values only outside `{...}` brace groups via `split_brace_aware_csv` so patterns such as `'src/**/*.{ts,tsx}'` remain intact, preserving repo-root-relative globs, and failing closed with `discovered_subprojects` when `-f` spans multiple monorepo sub-projects), `--component`, `--task`, `--uncommitted` (`-u`), `--base` (`-b`), `--head`, `--tier`, `--semantic/--no-semantic`, `--json`, and `--path` options via `resolve_cli_target_files_and_workspace` and `require_cli_eidos_dir`, auto-routes `--uncommitted`/`--base` to a single dirty monorepo sub-project (failing closed with `discovered_subprojects` when multiple sub-projects are dirty), collects Git working-tree or branch-diff modified files via `CMP-GIT-DIFF-INSPECTOR` (`get_git_diff_files`), and delegates deduplicated subgraph extraction to `CMP-TIERED-CONTEXT-COMPRESSOR`.

== Public Surface
* `register(app: typer.Typer) -> None`
* `resolve_cli_target_files_and_workspace(files: list[str] | None, path: Path | None, *, json_output: bool = False) -> tuple[Path, Path, list[str] | None]`
* `context_cmd(files: list[str] | None, component: str | None, task: str | None, uncommitted: bool, base: str | None, head: str, tier: str, semantic: bool, json_output: bool, path: Path | None) -> None`

== Design Constraints & Operational Notes
* **Dual Markdown / JSON Output**: Emits token-budgeted Markdown by default or `orjson`-serialized JSON when `--json` is passed.
