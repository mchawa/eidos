= Component: Eidos Living Web Portal (C4 Level 3 Whitebox)
:toc: left

== Architectural Boundary
This container represents the graphical web interface under `src/eidos/portal/`. It enables non-IDE stakeholders (product managers, architects, designers, and compliance officers) to visually navigate the living architecture, inspect C4 topologies, monitor SpecDelta lifecycles, and explore multi-design system tokens.

== Arc42 Section 5.2 / C4 Level 3: Internal Building Blocks

[cols="1,2,2", options="header"]
|===
| Internal Module | Responsibility | Source Path
| **PortalServer** | Multi-threaded HTTP daemon hosting the portal UI and REST endpoints | `src/eidos/portal/server.py`
| **PortalGenerator** | Synthesizes specs, C4 Mermaid graphs, and SpecDelta Kanban state | `src/eidos/portal/generator.py`
| **StaticSiteBuilder** | Exports zero-dependency static documentation sites for GitHub/GitLab Pages | `src/eidos/portal/builder.py`
| **PortalAssets** | Single-page HTML5/CSS3/ES-modules responsive interface with Mermaid.js | `src/eidos/portal/assets.py`
|===

== Operational Invariants & Quality Attributes
* **Zero-Node.js Dependency**: Runs entirely using standard Python without requiring Node.js, npm, or build step compilation.
* **Offline Resiliency**: Injects serialized JSON directly into static exports for offline execution and zero-CORS file system viewing.
