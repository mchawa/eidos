= Component: PluginValidator
:toc: left

== Responsibility
Validates Eidos Agent Skills packages (`skills/*/SKILL.md` and `hooks.json`) against the `agentskills.io` specification and SemVer 2.0.0 versioning rules (`INV-PLUGIN-SCHEMA-CONFORMANCE`).

== Key Responsibilities & Collaborators
* **Skill Frontmatter & Naming Parity Validation**: Extracts line-anchored YAML frontmatter from `SKILL.md` files (`safe_load_yaml`), verifies required `name` and `description` attributes, validates identifier format (`PLUGIN_NAME_PATTERN`), and enforces skill directory naming parity.

== Public Surface
* `validate_plugin_package(plugin_dir: Path, version: str | None = None) -> PluginValidationReport`
* `PluginValidationReport`

== Design Constraints & Operational Notes
* **Strict SemVer 2.0.0 Enforcement**: Rejects non-SemVer version strings so downstream agent harnesses and version sync checks operate deterministically.
