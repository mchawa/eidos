= Component: DriftDetector
:toc: left

== Responsibility
Orchestrates specification-to-code and design drift detection across Git commit ranges and uncommitted working trees (`detect_drift`), isolates `--head` commit-tree snapshots and onboarding governance checks (`snapshot.py`), evaluates 1-hop structural and sibling-relocation coverage (`structural.py`), resolves non-blocking advisory untouched sibling consumers across polyglot reverse imports and re-export barrels (`consumers.py`), delegates Git diff plumbing to `CMP-GIT-DIFF-INSPECTOR` and invariant verification to `CMP-INVARIANT-TRACEABILITY-VERIFIER`, and generates actionable remediation prompts and CI Markdown reports (`report.py`).

== Key Responsibilities & Collaborators
* **Isolated `--head` Commit-Tree Snapshot, `eidos/eidos.yaml` Isolation & Onboarding Integrity (`snapshot.py`, `DEC-VCS-UNIFIED-TEST-BINDING-SEMANTICS`, `INV-DRIFT-SHALLOW-AND-COMMIT-TREE-FIDELITY`)**: Materializes `--head` Git commit trees into isolated `eval_root` temporary snapshots (`_materialize_head_snapshot`, resetting copied `indexed_files.mtime = -1.0` so snapshot sync never reuses stale working-tree couplings), loads optional `<eidos_dir>/eidos.yaml` strictly from `--head` via `git show` prior to `base_ref` resolution (`_load_head_commit_config`) and from `eval_eidos / "eidos.yaml"` inside the materialized `eval_root` tree so working-tree edits never alter commit-range verdicts, remaps snapshot diagnostics (including `warnings`) to repo-relative paths (`_remap_validation_report`), and validates modified onboarding artifacts (`AGENTS.md`, `CLAUDE.md`, `.aider.conf.yml`, `SKILL.md`) via `_validate_onboarding_governance`.
* **Structural Coverage, Sibling Relocation Awareness, `drift.checks` & Boundary Ratchet Enforcement (`structural.py`, `drift.py`, `DEC-VCS-STRICT-UI-CONTRACT-DESIGN-DRIFT`, `DEC-VCS-EXECUTABLE-IMPORT-RATCHET`)**: Threads `EidosConfig` into `detect_drift` (honoring `drift.base_ref`, `drift.strict`, `drift.ignore_paths`, and `drift.checks`—including explicitly gating `evaluate_import_boundaries` via `drift.checks.import_boundaries` across `error | warn | off` with explicit arguments taking precedence), consumes Git diffs from `CMP-GIT-DIFF-INSPECTOR`, invariant traces from `CMP-INVARIANT-TRACEABILITY-VERIFIER`, structural/design symbol diffs from `CMP-AST-DIFF-CLASSIFIER`, and import-boundary evaluations from `CMP-ARCHITECTURE-BOUNDARY-VALIDATOR`; executes `verify_delta_mutations` and `_spec_coverage_verdict` on newly applied SpecDeltas without planned-mode bypasses; filters intra-component symbol relocations across sibling `source_path` files owned by the same component out of `stale_removed_symbol` (`_filter_sibling_relocated_symbols`, `INV-DRIFT-DIFF-AWARE-COVERAGE`); fails closed (`is_clean=False`, `drift_detected=True`) on blocking `boundary_violations` while emitting non-blocking `ratchet_shrink_candidates`; and enforces bound `CLT-*`/`DS-*` design subgraph updates on `token` and `ui_contract` frontend changes.
* **Untouched Sibling Consumer Discovery (`consumers.py`, `DEC-VCS-UNTOUCHED-CONSUMERS-ADVISORY`, `INV-DRIFT-UNTOUCHED-CONSUMERS`)**: Intersects modified, removed, and body-changed AST symbols (plus module-scope constants while excluding Python dunder metadata like `__all__`, and deleted targets) with SQLite `code_symbols` reverse imports (including Python, JS/TS, Go `go.mod` package directories, Rust `crate::`/`super::`/`self::`/workspace crates, `.cs`/`.java`/`.kt` namespaces, and 1-hop re-export barrels/facades) and `file_tokens_fts` via `find_untouched_consumers(...)`, exposing deterministic severity-sorted non-blocking `DriftCheckResult.untouched_consumers`.
* **Diagnostic & CI Markdown Reporting (`report.py`, `drift.py`)**: Exposes the resolved evaluation configuration and fail-closed config diagnostics on `DriftCheckResult.eval_config` / `DriftCheckResult.eval_config_errors` (so CLI exit-code handling honors `--head` config and never allows `warn_only` to mask invalid config), non-blocking `DriftCheckResult.validation_warnings` (forwarded from `ValidationReport.warnings` without affecting `is_clean`), diff-scoped `DriftCheckResult.ready_to_apply_deltas` (detecting diff-touched and spec-overlapping open `proposed`/`in_review`/`approved` SpecDeltas whose declared mutations are already 100% verified on disk), and advisory `DriftCheckResult.untouched_consumers`, and formats CLI remediation prompts (`generate_remediation_prompt`) and PR Markdown summaries (`build_drift_remediation_and_summary`, including `boundary_violations`, advisory `ratchet_shrink_candidates`, advisory specification validation warnings, advisory `ready_to_apply_deltas`, and advisory `untouched_consumers` review hints).

== Design Constraints & Operational Notes
* **Fail-Closed Git Ref Resolution (`INV-DRIFT-FAIL-CLOSED-ON-GIT-ERROR`)**: Raises `GitResolutionError` immediately when an explicit or shallow-clone `--base` Git reference cannot be resolved.
* **Deterministic Spec Diff & AST Inspection**: Evaluates baseline/head blob versions (`_get_files_versions_batch` and `_SpecDiffInspector`) purely from resolved version tuples without test-mocking sentinel heuristics; whitespace-only, comment-only, or identity (`old == new`) edits do not satisfy structural code or design token drift.
