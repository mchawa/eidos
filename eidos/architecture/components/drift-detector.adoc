= Component: DriftDetector
:toc: left

== Responsibility
Detects specification-to-code and design drift across Git commit ranges and uncommitted working trees (`detect_drift`), verifies static polyglot `INV-*` test bindings (`POL-002`), evaluates 1-hop knowledge graph neighborhoods, and generates actionable remediation prompts and CI Markdown reports.

== Key Responsibilities & Collaborators
* **Shallow-Safe Git Diff, `-z` Porcelain Parsing & File Classification (`diff.py`)**: Detects shallow clones across standard checkouts and linked Git worktrees via `git rev-parse --is-shallow-repository` (failing closed instead of diffing `HEAD..HEAD` on `fetch-depth: 1` single-commit pushes), collects uncommitted paths via NUL-delimited `git status --porcelain=v1 -z -uall`, restricts `docs/` exemptions in `classify_changed_files` to static/prose extensions so executable code under `docs/` is governed as `code_files`, tracks onboarding artifacts (`AGENTS.md`, `CLAUDE.md`, `.aider.conf.yml`, `.agents/skills/**/SKILL.md`) for integrity verification, and batch-reads historical blobs via `git cat-file --batch`.
* **Commit-Tree Isolation, Planned-Mode Mutation Enforcement & Structural Reconciliation (`structural.py`, `drift.py`, `DEC-VCS-UNIFIED-TEST-BINDING-SEMANTICS`)**: Evaluates specs, ownership, and invariants from an isolated `--head` Git-tree snapshot when `--base`/`--head` are passed without `--uncommitted`, executes `verify_delta_mutations` and `_spec_coverage_verdict` on newly applied SpecDeltas without planned-mode bypasses, normalizes overloaded AST symbol keys, and enforces bound `CLT-*`/`DS-*` design subgraph updates on `token` and `ui_contract` frontend changes (`DEC-VCS-STRICT-UI-CONTRACT-DESIGN-DRIFT`).
* **Static Invariant Traceability Across `design/` & Reporting (`invariants.py`, `report.py`)**: Scans `policies/`, `domains/`, `architecture/`, and `design/` (`UIC-*`) roots to verify exact-bounded `INV-*` `test_binding` (`file::func` or `file::Class::method`) coverage against non-skipped test symbols, and formats CLI remediation prompts (`generate_remediation_prompt`) and PR Markdown summaries (`build_drift_remediation_and_summary`).

== Public Surface
* `detect_drift(repo_root: Path, base_ref: str | None = None, head_ref: str = "HEAD", eidos_dir: Path | None = None, uncommitted: bool = False, strict: bool = False) -> DriftCheckResult`
* `DriftCheckResult`, `GitResolutionError`, `recommend_invariants_for_unbound_tests(...) -> dict[str, list[dict[str, Any]]]`
* `generate_remediation_prompt(result: DriftCheckResult) -> str`, `build_drift_remediation_and_summary(...) -> tuple[list[str], str]`

== Design Constraints & Operational Notes
* **Fail-Closed Git Ref Resolution (`INV-DRIFT-FAIL-CLOSED-ON-GIT-ERROR`)**: Raises `GitResolutionError` immediately when an explicit or shallow-clone `--base` Git reference cannot be resolved.
* **Deterministic Spec Diff & AST Inspection**: Evaluates baseline/head blob versions (`_get_files_versions_batch` and `_SpecDiffInspector`) purely from resolved version tuples without test-mocking sentinel heuristics; whitespace-only, comment-only, or identity (`old == new`) edits do not satisfy structural code or design token drift.
