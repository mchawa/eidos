= Component: DriftDetector
:toc: left

== Responsibility
Orchestrates specification-to-code and design drift detection across Git commit ranges and uncommitted working trees (`detect_drift`), isolates `--head` commit-tree snapshots and onboarding governance checks (`snapshot.py`), evaluates 1-hop structural and sibling-relocation coverage (`structural.py`), delegates Git diff plumbing to `CMP-GIT-DIFF-INSPECTOR` and invariant verification to `CMP-INVARIANT-TRACEABILITY-VERIFIER`, and generates actionable remediation prompts and CI Markdown reports (`report.py`).

== Key Responsibilities & Collaborators
* **Isolated `--head` Commit-Tree Snapshot & Onboarding Integrity (`snapshot.py`, `DEC-VCS-UNIFIED-TEST-BINDING-SEMANTICS`)**: Materializes `--head` Git commit trees into isolated temporary snapshots (`_materialize_head_snapshot`, resetting copied `indexed_files.mtime = -1.0` so snapshot sync never reuses stale working-tree couplings), remaps snapshot diagnostics to repo-relative paths (`_remap_validation_report`), and validates modified onboarding artifacts (`AGENTS.md`, `CLAUDE.md`, `.aider.conf.yml`, `SKILL.md`) via `_validate_onboarding_governance`.
* **Structural Coverage, Sibling Relocation Awareness, Boundary Ratchet & Planned-Mode Enforcement (`structural.py`, `drift.py`, `DEC-VCS-STRICT-UI-CONTRACT-DESIGN-DRIFT`, `DEC-VCS-EXECUTABLE-IMPORT-RATCHET`)**: Consumes Git diffs from `CMP-GIT-DIFF-INSPECTOR`, invariant traces from `CMP-INVARIANT-TRACEABILITY-VERIFIER`, structural/design symbol diffs from `CMP-AST-DIFF-CLASSIFIER`, and import-boundary evaluations from `CMP-ARCHITECTURE-BOUNDARY-VALIDATOR`; executes `verify_delta_mutations` and `_spec_coverage_verdict` on newly applied SpecDeltas without planned-mode bypasses; filters intra-component symbol relocations across sibling `source_path` files owned by the same component out of `stale_removed_symbol` (`_filter_sibling_relocated_symbols`, `INV-DRIFT-DIFF-AWARE-COVERAGE`); fails closed (`is_clean=False`, `drift_detected=True`) on `boundary_violations` while emitting non-blocking `ratchet_shrink_candidates`; and enforces bound `CLT-*`/`DS-*` design subgraph updates on `token` and `ui_contract` frontend changes.
* **Diagnostic & CI Markdown Reporting (`report.py`)**: Formats CLI remediation prompts (`generate_remediation_prompt`) and PR Markdown summaries (`build_drift_remediation_and_summary`, including `boundary_violations` and advisory `ratchet_shrink_candidates`).

== Public Surface
* `detect_drift(repo_root: Path, base_ref: str | None = None, head_ref: str = "HEAD", eidos_dir: Path | None = None, uncommitted: bool = False, strict: bool = False) -> DriftCheckResult`
* `DriftCheckResult`
* `generate_remediation_prompt(result: DriftCheckResult) -> str`, `build_drift_remediation_and_summary(...) -> tuple[list[str], str]`

== Design Constraints & Operational Notes
* **Fail-Closed Git Ref Resolution (`INV-DRIFT-FAIL-CLOSED-ON-GIT-ERROR`)**: Raises `GitResolutionError` immediately when an explicit or shallow-clone `--base` Git reference cannot be resolved.
* **Deterministic Spec Diff & AST Inspection**: Evaluates baseline/head blob versions (`_get_files_versions_batch` and `_SpecDiffInspector`) purely from resolved version tuples without test-mocking sentinel heuristics; whitespace-only, comment-only, or identity (`old == new`) edits do not satisfy structural code or design token drift.
