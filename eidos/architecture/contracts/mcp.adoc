= Contract: Eidos MCP stdio Interface
:toc: left

== Protocol Specification
The Eidos MCP server implements the Model Context Protocol (MCP) specification (protocol version `2024-11-05`) over JSON-RPC 2.0 stdio transport.

=== Supported Methods
* `initialize`: Negotiates protocol version, server identity, and tool execution capabilities.
* `notifications/initialized`: Handshake confirmation notification.
* `tools/list`: Returns the complete catalog of callable tools with their JSON Schema parameters.
* `tools/call`: Dispatches and executes an MCP tool with structured input arguments and returns typed content blocks.
