= Contract: Eidos Living Web Portal HTTP Interface
:toc: left

== Architectural Boundary
This contract defines the local loopback HTTP and Server-Sent Events (SSE) endpoints exposed by the Eidos Living Web Portal server (`CNT-EIDOS-PORTAL`). All endpoints enforce `Host` header validation against the bound `host:port` (mitigating DNS rebinding), reject `Sec-Fetch-Site: cross-site` API/event requests, and emit `Cross-Origin-Resource-Policy: same-origin`, `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, and `Content-Security-Policy: frame-ancestors 'none'` headers with zero wildcard CORS headers.

== Endpoints

[cols="1,1,2,2", options="header"]
|===
| Method | Path | Response Type | Description
| `GET` | `/` | `text/html` | Serves the interactive single-page web portal application (`/index.html` alias supported).
| `GET` | `/api/data` | `application/json` | Returns the complete unified living specification data graph.
| `GET` | `/api/overview` | `application/json` | Returns aggregate statistics and document counts.
| `GET`, `POST` | `/api/validate` | `application/json` | Executes dynamic specification validation (`GET` over catalog or `POST` for an inline YAML/AsciiDoc draft payload up to 5 MiB) with repo-relative `schema_errors` keys and returns the report.
| `GET` | `/api/version` | `application/json` | Returns lightweight repository file mtime snapshot (`count`, `max_mtime_ns`, `total_size`) across `eidos/`, governed `src/`, and `tests/`.
| `GET` | `/api/drift` | `application/json` | Executes cached, fail-closed uncommitted drift detection (`detect_drift`) and returns live governance health status.
| `GET` | `/api/events` | `text/event-stream` | Streams real-time Server-Sent Events (`event: status`) carrying `version` and cached `drift` payloads whenever `eidos/`, governed `src/`, or `tests/` change (`?once=1` / `?max_events=N` supported).
| `GET` | `/health` | `application/json` | Health check endpoint returning server availability status (`/api/health` alias supported).
| `GET` | `/favicon.svg` | `image/svg+xml` | Serves the official Eidos Form brand mark vector favicon (`/favicon.ico` alias supported).
|===
