= Contract: Eidos Living Web Portal HTTP Interface
:toc: left

== Architectural Boundary
This contract defines the HTTP endpoints exposed by the Eidos Living Web Portal server (`CNT-EIDOS-PORTAL`).

== Endpoints

[cols="1,1,2,2", options="header"]
|===
| Method | Path | Response Type | Description
| `GET` | `/` | `text/html` | Serves the interactive single-page web portal application.
| `GET` | `/api/data` | `application/json` | Returns the complete unified living specification data graph.
| `GET` | `/api/overview` | `application/json` | Returns aggregate statistics and document counts.
| `GET` | `/api/validate` | `application/json` | Executes dynamic specification validation and returns the report.
| `GET` | `/health` | `application/json` | Health check endpoint returning server availability status.
| `GET` | `/favicon.svg` | `image/svg+xml` | Serves the official Eidos Form brand mark vector favicon.
|===
