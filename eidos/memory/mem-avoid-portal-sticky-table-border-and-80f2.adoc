= Memory: Avoid portal sticky, table-border, and dialog Escape traps
:toc: left

== Guidance

In the portal SPA: (1) keep App.tsx <main> free of unbounded overflow-y-auto (min-h-screen without h-screen silently breaks position:sticky headers/sidebars/TOCs and SpecReader scroll-spy); (2) style .table-wrapper borders on th/td rather than thead/tbody/tr because border-collapse: separate ignores row borders; (3) mount native <dialog> modals as Fragment siblings outside pan/zoom containers and guard Sheet Escape with !document.querySelector('dialog[open]').

== Why

All three cause silent UX regressions that unit tests do not catch visually: unbounded overflow-y-auto creates a non-scrolling container for sticky/scroll-spy descendants, CSS 2.2 suppresses row/thead borders under border-collapse: separate, and Sheet's window Escape listener closes drawers behind an open top-layer <dialog>.
