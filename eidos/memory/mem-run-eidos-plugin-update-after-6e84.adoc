= Memory: Sync installed Agent Skills via plugin update after template edits
:toc: left

== Guidance

After modifying assets/plugin_reference/skills/*/SKILL.md or assets/plugin_reference/agents-md/block.md, run uv run eidos plugin update antigravity to refresh .agents/skills/, .agents/.eidos-manifest.json, and root AGENTS.md, then run uv run pytest tests/test_plugin.py -k test_bundled_skill_size_ceilings.

== Why

Bundled plugin assets and repository-installed .agents/skills/ copies are tracked separately; skipping eidos plugin update leaves AGENTS.md and .agents/.eidos-manifest.json stale relative to bundled templates.
