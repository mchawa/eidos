= Memory: Use generic fixture IDs in portal frontend tests
:toc: left

== Guidance

Use generic dummy IDs (e.g., CNT-DEMO-PORTAL, CMP-DEMO-*, SYS-ACME-001) in src/eidos/portal/frontend/tests/*.test.ts and run pytest tests/test_scaffolder.py -k test_engine_genericity_zero_self_references after editing portal frontend files or tests.

== Why

tests/test_scaffolder.py::test_engine_genericity_zero_self_references scans all .ts/.tsx files under src/eidos/ (excluding dist and node_modules), which includes src/eidos/portal/frontend/tests/, and fails CI on Eidos-self IDs such as CNT-EIDOS-* or CLT-WEB-PORTAL.
