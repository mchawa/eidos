= Memory: Avoid nested flag tokens inside quoted bash examples in docs
:toc: left

== Guidance

In docs/**/*.md bash code blocks containing eidos invocations, avoid embedding unrelated --flag tokens inside quoted string arguments because test_documented_cli_flags_match_live_command_tree splits lines on whitespace and checks every --token against the eidos subcommand.

== Why

test_docs_sync.py uses whitespace tokenization rather than shell quote parsing when scanning bash fences, causing false invalid-flag failures when a quoted argument contains a double-dash flag.
