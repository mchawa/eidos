= Memory: Compile portal bundle.html.gz via pnpm on frontend changes
:toc: left

== Guidance

After modifying TypeScript, React, or CSS files under src/eidos/portal/frontend/src/, run pnpm exec tsc --noEmit, pnpm test, and pnpm build inside src/eidos/portal/frontend (using pnpm rather than npm) so assets/portal/bundle.html.gz stays synchronized.

== Why

Python packaging and eidos portal serve/build serve the precompiled assets/portal/bundle.html.gz artifact; editing frontend sources without running pnpm build leaves the shipped bundle stale.
