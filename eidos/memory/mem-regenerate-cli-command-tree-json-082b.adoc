= Memory: Regenerate cli_command_tree.json after Typer option or help edits
:toc: left

== Guidance

Whenever adding, removing, or renaming a Typer command, option, default, or help string under src/eidos/cli/, regenerate tests/fixtures/cli_command_tree.json from _walk_command_tree(typer.main.get_command(app), []) and run uv run pytest tests/test_cli_json.py -k test_cli_command_tree_unchanged.

== Why

test_cli_command_tree_unchanged asserts exact equality on every Typer parameter name, flag, default, and help string, so even a minor help-text edit breaks CI until the snapshot fixture is updated.
