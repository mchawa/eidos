= SpecDelta DLT-2026-099: Deduplicate test_binding_cache Schema and Unify AST Test Function Extraction
:toc: left

== Context & Motivation
`test_binding_cache` previously stored both `functions_json` (`fname -> {tokens, fixture_invs}`) and `bindings_json` (`[{identifier, invariants, policies}]`), requiring `_build_cached_test_file_entry` in `src/eidos/vcs/invariants.py` to execute two full AST passes (`list_test_functions` and `extract_test_bindings`) per test file even though `bindings_json` is 100% derivable from `functions_json` and `file_path`. In addition, `AstGrepIndexer.list_test_functions` and `AstGrepIndexer.extract_test_bindings` in `src/eidos/core/index/ast_indexer.py` duplicated ~100 lines of `SgRoot` test-function traversal.

== Architectural Changes
1. **`CMP-GRAPH-STORAGE` (`src/eidos/core/index/storage.py`)**:
   * Bumped `SCHEMA_VERSION` from `"2.8.0"` to `"2.9.0"` and removed the redundant `bindings_json` column from `test_binding_cache` (`load_test_binding_cache` and `save_test_binding_cache`).
2. **`CMP-DRIFT-DETECTOR` (`src/eidos/vcs/invariants.py`)**:
   * Updated `_build_cached_test_file_entry`, `detect_orphan_invariants`, and `extract_invariants_and_verify` to derive invariant and policy test bindings directly from `functions_json` (`tokens` and `fixture_invs`) in a single `list_test_functions` AST pass.
3. **`CMP-AST-SYMBOL-INDEXER` (`src/eidos/core/index/ast_indexer.py`)**:
   * Extracted shared `_iter_test_function_spans` helper used by both `list_test_functions` and `extract_test_bindings`.
