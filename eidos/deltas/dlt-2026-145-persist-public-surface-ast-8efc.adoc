= SpecDelta: Persist Public Surface AST Symbol Cache in SQLite Index
:toc: left

== Problem Statement
`SpecValidator` persists schema verdicts (`spec_validation_cache`) and test AST symbols (`test_binding_cache`) in `eidos/.cache/index.db`, but `PublicSurfaceValidator._PUBLIC_SURFACE_SYMBOL_CACHE` lives strictly in process memory. Every cold `eidos validate` CLI run therefore re-parses all active `CNT-*` and `CMP-*` source files from scratch, adding unnecessary latency on large polyglot solutions (>1,000 files).

== Proposed Specification Changes
* **`CMP-GRAPH-STORAGE` (`src/eidos/core/index/storage.py`) & `CNT-EIDOS-INDEX`**: Add a stateless, disposable `public_surface_cache` table keyed by `(file_path, mtime_ns, st_size, extractor_version)` storing `orjson`-serialized public and component-scoped symbol tuples, bump `SCHEMA_VERSION`, and expose strictly non-blocking `load_public_surface_cache` (`allow_ddl=False`) and `save_public_surface_cache` (`non_blocking=True` advisory lock + short busy timeout). Record `DEC-INDEX-PERSISTENT-PUBLIC-SURFACE-CACHE` (`graduated_from: DLT-2026-145-PERSIST-PUBLIC-SURFACE-AST-8EFC`, rejecting blocking cache writes and rejecting skipping `mtime_ns`/`st_size` invalidation).
* **`CMP-ARCHITECTURE-BOUNDARY-VALIDATOR` (`src/eidos/core/spec/surface_validator.py`) & `CMP-SPEC-VALIDATOR` (`src/eidos/core/spec/validator.py`)**: Batch-hydrate `_PUBLIC_SURFACE_SYMBOL_CACHE` from `public_surface_cache` once per `validate_directory` call and flush newly parsed files non-blockingly at the end, immediately invalidating any entry whose `(mtime_ns, st_size, extractor_version)` changed and never reading stale data.
* **`CMP-DOCS-CORE-CONCEPTS` & `CAP-AGENT-002`**: Sync table counts and `SCHEMA_VERSION` in `docs/concepts/how-eidos-works.md` and `docs/concepts/architectural-index.md`, and bind `INV-INDEX-PUBLIC-SURFACE-CACHE`.

== Implementation Plan
1. **Storage Schema & Non-Blocking Helpers (`CMP-GRAPH-STORAGE`, `CNT-EIDOS-INDEX`)**: Add `public_surface_cache` DDL, bump `SCHEMA_VERSION`, and implement `load_public_surface_cache` / `save_public_surface_cache` in `src/eidos/core/index/storage.py`.
2. **Validator Integration (`CMP-ARCHITECTURE-BOUNDARY-VALIDATOR`, `CMP-SPEC-VALIDATOR`)**: Wire batch load/flush in `src/eidos/core/spec/surface_validator.py` and `src/eidos/core/spec/validator.py` (`CNT-EIDOS-CORE` covered via `CMP-SPEC-VALIDATOR` and `CMP-ARCHITECTURE-BOUNDARY-VALIDATOR`), preserving exact LRU bounds and zero blocking under lock contention.
3. **Docs, Living Specs & Tests (`POL-005-STATEMENT-TEST-COVERAGE`)**: Update `docs/concepts/how-eidos-works.md`, `docs/concepts/architectural-index.md`, `docs/guides/cli.md` (if `SCHEMA_VERSION` appears there — check `INV-DOCS-SYNCHRONIZATION`), all declared component/container/capability specs, and add `tests/test_validator.py::test_persistent_public_surface_symbol_cache_hit_invalidation_and_nonblocking_fallback`.
