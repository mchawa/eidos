= SpecDelta: Extend Opt-In REST HTTP Authorization Parity to Spring, NestJS, and FastAPI
:toc: left

== Problem Statement
`DLT-2026-142` introduced `HttpEndpointMeta` (`auth_mode`, `auth_policies`, `auth_roles`) and opt-in contradiction-only authorization verification in `_verify_rest_http_contract`, currently populated only for C# ASP.NET Core. Modern Java/Kotlin Spring, TypeScript NestJS, and Python FastAPI services already have static route extraction in `ast_http.py`, but their authorization annotations (`@PreAuthorize`, `@Secured`, `@RolesAllowed`, `@PermitAll`, `@UseGuards`, `@Public`, `Security(...)`/`Depends(...)`) are not yet extracted or checked against `CTR-*` contracts.

== Proposed Specification Changes
* **`CMP-HTTP-TOPOLOGY-LINKER` (`src/eidos/core/index/ast_http.py`)**: Populate `HttpEndpointMeta` auth fields deterministically for:
  - **Spring (Java/Kotlin)**: `@PreAuthorize(...)`, `@Secured(...)`, `@RolesAllowed(...)`, and `@PermitAll` with controller-to-method inheritance and method-level overrides.
  - **NestJS (TypeScript/JavaScript)**: `@UseGuards(...)` and `@Public()` with controller-to-handler inheritance and handler-level overrides.
  - **FastAPI (Python)**: `Security(...)` and `Depends(...)` auth/guard dependencies on `APIRouter(dependencies=[...])`, route decorator `dependencies=[...]`, or handler parameter defaults.
* **`CMP-CONTRACT-PARITY-VALIDATOR` (`src/eidos/core/spec/contract_parity.py`)**: Recognize Spring/NestJS/FastAPI auth tokens alongside ASP.NET Core tokens and `Auth` table columns in `_parse_doc_auth_expectation`, preserving opt-in contradiction-only semantics (plain route tables without auth declarations remain unaffected).
* **`CNT-EIDOS-CORE`, `CMP-DOCS-CORE-CONCEPTS` & `CAP-PROD-001`**: Synchronize docs and bind `INV-CONTRACT-POLYGLOT-AUTH-PARITY`.

== Implementation Plan
1. **Polyglot Auth Metadata Extraction (`CMP-HTTP-TOPOLOGY-LINKER`)**: Extend `src/eidos/core/index/ast_http.py` (`CNT-EIDOS-INDEX` covered via `CMP-HTTP-TOPOLOGY-LINKER`) to populate `auth_mode`, `auth_policies`, and `auth_roles` across Spring, NestJS, and FastAPI without affecting existing route extraction.
2. **Polyglot Opt-In Auth Verification (`CMP-CONTRACT-PARITY-VALIDATOR`)**: Extend `_parse_doc_auth_expectation` and contradiction messages in `src/eidos/core/spec/contract_parity.py`.
3. **Docs, Living Specs & Tests (`POL-005-STATEMENT-TEST-COVERAGE`)**: Update `docs/concepts/how-eidos-works.md`, all declared specs, and add `tests/test_contract_parity.py::test_polyglot_rest_http_authorization_parity_spring_nestjs_fastapi` verifying clean parity, role/policy/guard contradictions, and `>90.0%` per-file statement coverage.
4. **Verification**: Run `pytest`, `eidos delta verify DLT-2026-148 --json`, `eidos delta apply DLT-2026-148`, and `eidos drift --uncommitted --json`.
