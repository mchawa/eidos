= SpecDelta: Preserve Spec Embeddings Across Schema Version Migrations
:toc: left

== Problem Statement
Currently, `_apply_cache_schema_ddl()` in `src/eidos/core/index/storage.py` drops **every** table in `_MANAGED_TABLES` (including `spec_embeddings` and `metadata`) using non-transactional `with conn:` DDL and `conn.executescript(_CACHE_SCHEMA_DDL)` whenever `SCHEMA_VERSION` changes. Even though `sync_index(force=True)` and incremental cache-version keys (`test_binding_cache_ver`, `code_symbol_cache_ver`) intentionally preserve `spec_embeddings`, any unrelated `SCHEMA_VERSION` bump that adds a new cache table (such as `2.21.0` `public_surface_cache`, `2.22.0` `mermaid_validation_cache`, or `2.23.0` `memory_freshness_cache`) wipes all precomputed Harrier ONNX embeddings, forcing a 90–220 second CPU re-embedding rebuild on persistent workstations, CI caches, and remote devboxes.

Naively excluding `spec_embeddings` from `DROP TABLE` during `SCHEMA_VERSION` migrations is unsafe without five explicit guards:
1. **Atomic DDL Transactions**: Python `sqlite3`'s `with conn:` does not begin a transaction for DDL, and `conn.executescript()` implicitly commits outside transaction control—risking mid-migration data loss or torn WAL visibility for concurrent readers and background semantic workers holding `semantic_sync.lock`.
2. **Complete State-Machine Coverage (Including Partial Tables & Extra Tables)**: Checking only `user_tables == set(_MANAGED_TABLES)` and `user_tables > set(_MANAGED_TABLES)` leaves a bypass when `user_tables < set(_MANAGED_TABLES)` (or when both missing managed tables and extra retired tables occur together), which would silently stamp the new `EMBEDDING_SCHEMA_VERSION` over mismatched `spec_embeddings`.
3. **Full Schema & Embedding Contract Verification**: `query_semantic_embeddings()` checks only vector byte length (`len(blob)`), and `INSERT OR REPLACE` requires `PRIMARY KEY` on `entity_id`. Preserving `spec_embeddings` requires an independent `EMBEDDING_SCHEMA_VERSION`, full `PRAGMA table_info(spec_embeddings)` validation of `(name, type, notnull, pk)`, and a cross-component bump contract in `CMP-SEMANTIC-EMBEDDING-ENGINE`.
4. **Completeness Gate Integrity (`INV-SEMANTIC-COMPLETE-RRF-GATE`)**: Dropping `metadata` without restoring a `.strip()`-normalized `metadata['semantic_sync_complete']` turns an interrupted partial sync marker (`'0'`) into `None`, allowing `is_semantic_index_complete(conn)`'s ratio fallback (`total_embeddable >= 10`, `missing <= 4`, `>= 85%`) to falsely treat an incomplete run as complete.
5. **Fail-Closed Legacy & Corruption Boundaries**: Unversioned legacy `SCHEMA_VERSION` migrations (`embedding_schema_ver` missing or ancient `metadata` schema) and empty-string markers must fail closed, and genuine SQLite corruption (`SQLITE_CORRUPT` / `SQLITE_NOTADB`) must propagate untouched to `open_cache_connection`'s unlink-and-rebuild recovery.

== Proposed Specification Changes
1. **`CMP-GRAPH-STORAGE` (`src/eidos/core/index/storage.py`)**:
   * Export `EMBEDDING_SCHEMA_VERSION: str = "1"` in `storage.py` (intentionally kept `storage.py`-only rather than re-exported on `ArchitecturalIndex`; `SCHEMA_VERSION` remains `"2.23.0"` because the 15-table DDL is unchanged), alongside internal constants `_EMBEDDING_SCHEMA_VERSION_KEY = "embedding_schema_ver"`, `_SEMANTIC_SYNC_COMPLETE_KEY = "semantic_sync_complete"`, `_SPEC_EMBEDDINGS_SCHEMA = (("entity_id", "TEXT", 0, 1), ("content_sha256", "TEXT", 1, 0), ("model_id", "TEXT", 1, 0), ("embedding", "BLOB", 1, 0))`, `_SPEC_EMBEDDINGS_DDL`, and `_CACHE_SCHEMA_STATEMENTS: tuple[str, ...]` (explicit per-statement tuple referencing `_SPEC_EMBEDDINGS_DDL`, with `_CACHE_SCHEMA_DDL` derived from it so comments with semicolons cannot split SQL).
   * Add `_has_compatible_spec_embeddings_schema(conn)` validating `(name, type.upper(), int(notnull), int(pk))` in exact column order via `PRAGMA table_info(spec_embeddings)` without swallowing `sqlite3.DatabaseError` / corruption, `_read_metadata_value_safe(conn, key)` returning `None` strictly on non-corrupt missing-column/missing-table `sqlite3.OperationalError` (propagating `database is locked`, `database schema has changed`, and corruption), and `_normalize_semantic_sync_complete(raw)` (`.strip()`-normalizing to `'1'` only for `'1'`, `'0'` for `'0'` or any other non-empty marker, and `None` when absent/blank).
   * Extend `_is_schema_current(conn)` to require `metadata['embedding_schema_ver'] == EMBEDDING_SCHEMA_VERSION` and `_has_compatible_spec_embeddings_schema(conn)`.
   * Update `_apply_cache_schema_ddl(conn)` so **every** DDL and metadata mutation executes atomically inside a single `_immediate_write_transaction(conn)` using `conn.execute(...)` (never `conn.executescript(...)`):
     ** **Path 1 — Exact 15 managed tables on current `SCHEMA_VERSION`**: Check `needs_tbc`, `needs_csc`, and `needs_emb` (`stored_emb_ver != EMBEDDING_SCHEMA_VERSION or not spec_embeddings_compatible`). When `needs_emb` is `True`: if `stored_emb_ver is None` (strict `is None`, never adopting `""`), `spec_embeddings_compatible` is `True`, and `EMBEDDING_SCHEMA_VERSION == _INITIAL_EMBEDDING_SCHEMA_VERSION` (`"1"`), stamp `metadata['embedding_schema_ver'] = EMBEDDING_SCHEMA_VERSION` non-destructively without touching `spec_embeddings` or `semantic_sync_complete`; otherwise `DROP TABLE IF EXISTS spec_embeddings`, `conn.execute(_SPEC_EMBEDDINGS_DDL)`, `DELETE FROM metadata WHERE key = 'semantic_sync_complete'`, and stamp `EMBEDDING_SCHEMA_VERSION` while keeping the other 14 tables intact.
     ** **Path 2 — Fresh DB, `SCHEMA_VERSION` mismatch, extra unmanaged tables (`bool(user_tables - set(_MANAGED_TABLES))`), or partial managed-table subset (`user_tables < set(_MANAGED_TABLES)`)**: Compute `preserve_embeddings = (spec_embeddings_compatible and stored_emb_ver == EMBEDDING_SCHEMA_VERSION)` before DDL (failing closed whenever `embedding_schema_ver` is absent on a `SCHEMA_VERSION` mismatch or partial subset). On `full_rebuild` (`bool(user_tables) and (stored_version != SCHEMA_VERSION or bool(extra_tables))`), drop all managed + quoted extra tables **except** `spec_embeddings` iff `preserve_embeddings` is `True`. On partial subsets (`not full_rebuild`) when `not preserve_embeddings`, drop `spec_embeddings` if present and delete stale `metadata['semantic_sync_complete']` if `metadata` exists. Execute every statement in `_CACHE_SCHEMA_STATEMENTS`, stamp `schema_version`, `test_binding_cache_ver`, `code_symbol_cache_ver`, and `embedding_schema_ver`, and whenever `preserve_embeddings` is `True` write normalized `metadata['semantic_sync_complete']` (or clear blank markers on partial subsets).
     ** **Corruption recovery (`open_cache_connection`)**: Unchanged—genuine `SQLITE_CORRUPT` / `SQLITE_NOTADB` still unlinks `index.db`, `-wal`, and `-shm` completely under `_advisory_db_lock`.
   * Keep `storage.py` free of `semantic.py` imports; downstream orphan pruning in `CMP-INCREMENTAL-SYNC-ENGINE` (`src/eidos/core/index/sync.py`, no edits required) and `entities` joins in `CMP-SEMANTIC-EMBEDDING-ENGINE` remain unchanged.
