= SpecDelta: Fix SQLite Sync Concurrency, Polyglot .NET Indexing, Public Surface Visibility and LRU Caching, and Semantic Sync CLI Controls
:toc: left

== Problem Statement
Six interrelated defects degrade multi-agent concurrency, .NET/C# polyglot support, validation precision, and semantic indexing performance:
1. Concurrent CLI calls (`eidos context`, `eidos index search`, `eidos index sync`) race in `sync_index()` because `_advisory_db_lock` only wraps DDL in `storage.py`, allowing deferred SQLite transactions to collide with `sqlite3.IntegrityError: UNIQUE constraint failed: entities.id`.
2. `.NET` test projects (`*.Tests`, `*.UnitTests`, `*Tests.cs`, `*_Tests.cs`, `*Test.cs`) and parameterized/DisplayName xUnit/NUnit/MSTest attributes (`[Fact(...)]`, `[TestCase(...)]`, `[TestMethod]`) are misclassified as production source or skipped by AST binding extraction.
3. C# `using` imports and `.csproj` `<ProjectReference>` links produce zero `consumes_api`/`depends_on` edges because `module_to_file` only maps file stems rather than declared namespaces.
4. `== Public Surface` rejects C# properties and `:` base-class inheritance while ignoring `sym.is_public` and failing on `[Attribute(...)]`-decorated C# types.
5. Over-broad backtick and directory scanning flags `.cs`/`.dll`/`.svc`/`.rdlc` filenames, bare prose tokens (`SOAP`, `POST`), `bin/`/`obj/` outputs, and out-of-scope OpenAPI routes in narrative boundary sections.
6. `_PUBLIC_SURFACE_SYMBOL_CACHE` clears all 512 entries at once after eagerly hashing every file, and `eidos index sync` triggers competing background and foreground ONNX sessions while lacking `--no-semantic` and `--json`.

== Proposed Specification Changes
* Coordinate `sync_index()` and opportunistic `check_index_dirty()` writes under re-entrant `_advisory_db_lock` + `BEGIN IMMEDIATE`, refreshing `is_dirty()` on contention or `PRAGMA data_version` changes (`DEC-INDEX-SERIALIZED-SYNC-AND-CSHARP-NAMESPACES`).
* Recognize `.NET` test project directories and `.cs` test suffixes across `CMP-PROJECT-RESOLVER`, `CMP-DRIFT-DETECTOR`, `CMP-INCREMENTAL-SYNC-ENGINE`, and `CMP-AST-SYMBOL-INDEXER`, including attribute-aware C# test spans (`INV-DOTNET-POLYGLOT-PARITY`).
* Index declared C#/Java/Kotlin namespaces (`kind = 'namespace'`) and parse `.csproj` `<ProjectReference>` links to materialize cross-component `consumes_api` and cross-container `depends_on` edges without false self-namespace edges.
* Extract C# properties, events, indexers, and record primary-constructor properties with normalized signatures, fix C# `[Attribute]` visibility stripping, enforce strict public (`CNT-*`) vs component-scoped (`CMP-*`) `== Public Surface` visibility, extract polyglot inheritance (`:` / `implements`), switch `_PUBLIC_SURFACE_SYMBOL_CACHE` to an 8,192-entry `mtime_ns`/`st_size` LRU cache with pruned `os.walk` enumeration, skip prose-context tokens and artifact extensions, and scope OpenAPI reverse route scanning (`DEC-CORE-SCOPED-PUBLIC-SURFACE-AND-LRU-CACHE`).
* Add `--no-semantic` and `--json` to `eidos index sync` (`CTR-EIDOS-CLI` `1.6.0`), prevent duplicate background ONNX subprocess spawning (`auto_semantic=False`), and lock + re-check `spec_embeddings` in `sync_spec_embeddings()` (`INV-INDEX-SYNC-CLI-CONTROLS`).

2. Update `src/eidos/core/workspace/project.py` and `src/eidos/vcs/diff.py` for `"obj"`, `is_dotnet_bin_dir`, `.NET` test directory suffixes, and `.cs` test filename patterns.

4. Update `src/eidos/core/index/semantic.py` and `src/eidos/cli/index_commands.py` for serialized `semantic_sync.lock` re-verification and `eidos index sync --no-semantic --json`.
