= SpecDelta: Incremental SQLite Caching for Specification Validation and Static Invariant Verification
:toc: left

== Problem Statement

Every time `eidos drift` or `eidos hook drift` (`PostInvocation` and `Stop` hooks) runs, [`detect_drift()`](file:///home/MTS/marwan.chawa/WS/eidos/src/eidos/vcs/drift.py#L848) performs two full $O(N)$ repository crawls from scratch:
1. `validate_directory(eidos_dir)` parses every `.adoc` file in `eidos/` and runs Draft 2020-12 JSON Schema validation against YAML schemas on disk.
2. `extract_invariants_and_verify()` and `detect_orphan_invariants()` crawl all test files (`tests/**/*test*.py`, `*.spec.ts`, `*_test.go`, etc.) via `rglob`, read every test file from disk, and run `ASTIndexer.list_test_functions()` + `extract_test_bindings()` on every file.

In repositories with hundreds of specifications and thousands of test files, running this uncached on every agent turn (`PostInvocation`) introduces multi-second latency.

== Architectural & Behavioral Mutations

1. **SQLite Test Binding & Function Cache (`test_binding_cache`)**:
   * Create `test_binding_cache (file_path TEXT PRIMARY KEY, mtime_ns INTEGER, sha256 TEXT, functions_json TEXT, bindings_json TEXT)` in `eidos/.cache/index.db`.
   * During `extract_invariants_and_verify()` and `detect_orphan_invariants()`, check each discovered test file's `st_mtime_ns`. If it matches `test_binding_cache.mtime_ns`, load `list_test_functions()` and `extract_test_bindings()` directly from SQLite without reading or AST-parsing the file.
   * Prune deleted test files from `test_binding_cache` automatically.
2. **Incremental Spec Validation Cache (`spec_validation_cache`)**:
   * Create `spec_validation_cache (file_path TEXT PRIMARY KEY, mtime_ns INTEGER, sha256 TEXT, schema_hash TEXT, doc_json TEXT, schema_errors_json TEXT)` in `eidos/.cache/index.db`.
   * When `SpecValidator.validate_directory()` runs, reuse cached `SpecDocument` frontmatter and per-file JSON Schema validation results for any `.adoc` file whose `mtime_ns` and `schema_hash` are unchanged, then run the cross-document catalog reference check (`_validate_semantic_references`) across the assembled catalog in memory.

== Verification Criteria

* A warm invocation of `eidos drift` when zero `.adoc` or test files have changed executes zero `ASTIndexer.list_test_functions()` calls and zero redundant JSON Schema validations.
* Modifying a test file or `.adoc` specification immediately invalidates its cache entry via `mtime_ns` / `sha256` and produces identical validation and invariant coverage results to a cold run.
