== Problem Statement

Auditing `CNT-EIDOS-VCS` (`src/eidos/vcs/`), `CMP-SPEC-VALIDATOR` (`src/eidos/core/spec/validator.py`), and `CMP-AST-SYMBOL-INDEXER` (`src/eidos/core/index/ast_indexer.py`) revealed critical silent-pass paths in `eidos drift` and contradictions in static invariant verification:

1. **Shallow CI Clone (`fetch-depth: 1`) Silent Zero-Diff Pass & Worktree Blindness (`src/eidos/vcs/diff.py`)**:
   * On push to `main` in a `fetch-depth: 1` CI checkout (`diff.py:135-145`), `cand_sha == head_sha`, `git rev-parse HEAD~1` fails (`returncode != 0`, so `L144` does not `continue`), `git merge-base` returns `HEAD`, and `eidos drift` diffs `HEAD..HEAD` (`0` files -> `is_clean: True`) without ever reaching the shallow-clone error at `L188-199`.
   * Furthermore, `(git_root / ".git" / "shallow").exists()` (`L189`) fails inside linked Git worktrees where `.git` is a pointer file rather than a directory.
2. **Planned-Mode SpecDelta Bypass & Commit-Range Dirty-Worktree Contamination (`src/eidos/vcs/drift.py`)**:
   * Any `proposed` SpecDelta—or a newly created `applied` SpecDelta where `old_dc is None`—naming `CNT-*`/`CMP-*` in `mutations` hits `continue` at `drift.py:406, 446`, bypassing `_spec_coverage_verdict` (`trivial_spec_diff`, `missing_anchor`, `stale_removed_symbol`) and never invoking `DeltaEngine.verify_delta_mutations`.
   * When `--base A --head B` is supplied without `--uncommitted` (`drift.py:243-248`), `detect_drift` diffs Git blobs for code changes but validates specifications, ownership, and invariants from the **dirty working tree on disk** (`L551-563`).
3. **Unquoted Porcelain Spaces & Blanket `docs/` Code Exemption (`src/eidos/vcs/diff.py`)**:
   * `git status --porcelain` without `-z` (`diff.py:310-325`) wraps paths containing spaces in double quotes (`"src/my mod.py"`), turning `Path(f).suffix` into `'.py"'` -> `other_files` and bypassing uncommitted drift.
   * `parts[0] == "docs"` (`diff.py:545-578`) classifies executable `.py`/`.ts`/`.tsx` files under `docs/` as `doc_files`.
4. **Omitted `UIC-*` Invariants, `test_binding: N/A` Contradiction, & Token/Skip Bugs (`invariants.py`, `validator.py`, `ast_indexer.py`)**:
   * `scan_roots` (`src/eidos/vcs/invariants.py:440-444`) scans `policies`, `domains`, and `architecture`, omitting `design`. Consequently, `UIC-*` (`design/ui-component`) invariants are never verified, and tests referencing `# INV-UIC-*` fail `eidos drift` as **orphan invariants**.
   * `eidos-plan/SKILL.md:173` and `delta.schema.yaml:175` list `N/A` alongside `TBD`, `validator.py:1087-1114` silently skips `N/A`, `TBD`, `NONE`, empty strings, and bare file paths without `::symbol` even on `status: active` specs, and `_verify_single_invariant` (`invariants.py:230-238`) then flags `N/A` under `Uncovered Invariants` (`report.py:139-143`).
   * `INV_OR_POL_TOKEN_RE` (`ast_indexer.py:24`) greedily consumes lowercase prose suffixes (`INV-AUTH-001-compliant` fails to match `INV-AUTH-001`), `\b{iid}\b` (`invariants.py:280, 310`) falsely matches `INV-AUTH-1-EXTENDED`, and `_extract_ts_test_call_title` (`ast_indexer.py:692-701`) accepts `test.skip`, `test.todo`, `test.fixme`, and suite-level `describe(...)` calls as valid invariant test symbols.

== Proposed Specification Changes

* **Worktree-Safe Shallow Detection, `-z` Porcelain Parsing & `docs/` Code Classification (`CMP-DRIFT-DETECTOR`, `INV-DRIFT-SHALLOW-AND-COMMIT-TREE-FIDELITY`)**:
  1. Replace `(git_root / ".git" / "shallow").exists()` with `git rev-parse --is-shallow-repository` in `diff.py`, and when `cand_sha == head_sha` and `HEAD~1` is unresolvable in a shallow clone, fail closed (`DriftError`) with actionable `fetch-depth: 0` guidance instead of diffing `HEAD..HEAD`.
  2. Switch uncommitted status collection in `diff.py` to `git status --porcelain=v1 -z` (`\0`-delimited, handling rename pairs properly).
  3. Restrict `docs/` `doc_files` classification in `classify_changed_files` to documentation/static extensions (`.md`, `.adoc`, `.rst`, `.txt`, `.png`, `.svg`, `.yml`/`.toml` site configs) so executable code under `docs/` is classified as `code_files`.
* **Planned-Mode Mutation Verification & `--head` Commit-Tree Isolation (`CMP-DRIFT-DETECTOR`, `CNT-EIDOS-VCS`, `DEC-VCS-UNIFIED-TEST-BINDING-SEMANTICS`)**:
  1. Remove the `continue` short-circuit in `drift.py` for `status: applied` SpecDeltas: automatically run `DeltaEngine.verify_delta_mutations` on deltas applied in the changeset and enforce `_spec_coverage_verdict` (`trivial_spec_diff`, `missing_anchor`, `stale_removed_symbol`) across touched components.
  2. When `--base` / `--head` are supplied (`uncommitted=False`), materialize `--head`'s `eidos/` and referenced `source_path`/`test_binding` blobs into an ephemeral snapshot (or Git-tree reader) so uncommitted local edits never pollute commit-range CI checks.
* **`UIC-*` Invariants, Unified `test_binding` Rules & Token/Skip Hardening (`CMP-DRIFT-DETECTOR`, `CMP-SPEC-VALIDATOR`, `CMP-AST-SYMBOL-INDEXER`, `POL-002-INVARIANT-TEST-ENFORCEMENT`, `CNT-EIDOS-PLUGIN`, `INV-DRIFT-UIC-AND-SKIPPED-TEST-GUARD`)**:
  1. Add `spec_root / "design"` to `scan_roots` in `invariants.py`.
  2. Enforce concrete `file::symbol` `test_binding` values on all `status: active` specs across `validator.py` and `invariants.py` (allowing `TBD` strictly on `draft | planned` specs and `proposed | in_review | approved` SpecDeltas, and removing `N/A` from `assets/schemas/v1/delta/delta.schema.yaml` and `assets/plugin_reference/skills/eidos-plan/SKILL.md` while keeping skill word counts below `INV-PLUGIN-SKILL-SIZE-CEILING`).
  3. Update `INV_OR_POL_TOKEN_RE` in `ast_indexer.py` and invariant boundary checks in `invariants.py` to match `(?<![A-Z0-9_-])((?:INV|POL)-[A-Z0-9]+(?:-[A-Z0-9]+)*)(?![A-Z0-9_]|-[A-Z0-9])` (allowing trailing lowercase prose like `-compliant` while rejecting `-EXTENDED`), and exclude `.skip`, `.todo`, `.fixme`, `xit`, `xtest`, and non-test `describe(...)` wrappers in `_extract_ts_test_call_title` (preserving `DEC-VCS-STATIC-INVARIANT-TRACEABILITY` with zero AST `assert` inspection).
