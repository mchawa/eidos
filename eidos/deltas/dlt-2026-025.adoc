== Problem Statement

`src/eidos/vcs/bridge.py` contained stubbed `VCSBridge`, `VCSIssue`, and `VCSPullRequest` classes that returned placeholder URLs (`https://github.com/org/repo/issues/1`) without making real API calls, while living specifications claimed bidirectional GitHub/GitLab issue and PR comment synchronization.

== Architectural & Behavioral Mutations

1. Delete `src/eidos/vcs/bridge.py` and clean up `src/eidos/vcs/__init__.py`.
2. Rename `eidos/domains/vcs-lifecycle/capabilities/github-gitlab-bridge.adoc` to `eidos/domains/vcs-lifecycle/capabilities/drift-detection.adoc` (`CAP-VCS-001`).
3. Remove `INV-VCS-PARITY` and update `eidos/system.adoc`, `eidos/domains/vcs-lifecycle/domain.adoc`, and `eidos/personas/product-lead.adoc` to reflect local Git-native verification and CI/CD gating.
