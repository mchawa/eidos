= SpecDelta: Preserve Test-to-Invariant Assertion Edges in Knowledge Graph Sync
:toc: left

== Problem Statement

During `GraphIndex.sync()` (`src/eidos/core/graph_index.py`), Eidos extracts test bindings (`file.py::test_func`) and inserts relational edges `(binding.identifier, inv_id, "asserts")` into the `edges` table (lines 1063–1070 and 1162–1169). However, `binding.identifier` is never inserted into the `entities` table. Immediately before `conn.commit()`, the orphan edge cleanup query (`DELETE FROM edges WHERE source_id NOT IN (SELECT id FROM entities)` at lines 1222–1226) deletes every single `asserts` edge that was just created. As a result:

1. `get_index_status()["test_invariant_assertions"]` always returns `0`.
2. Graph queries and k-hop neighborhood traversals cannot traverse from test functions to the invariants (`INV-*`) they verify.

== Architectural & Behavioral Mutations

1. **First-Class Test Binding Persistence in `eidos/.cache/index.db`**:
   * Register discovered test bindings (`path/to/test_file.py::test_func`) as `type = "test_binding"` entities in the `entities` table (with `file_path` set to the test file path), or explicitly preserve valid `relation = 'asserts'` edges during orphan-edge pruning while cleaning up stale bindings for deleted test files.
2. **Accurate Index Telemetry & Graph Traversal**:
   * Ensure `get_index_status()["test_invariant_assertions"]` accurately reflects the count of persisted `asserts` edges after `GraphIndex.sync(force=True)` and incremental syncs.
   * Enable `get_k_hop_neighborhood()` and `get_incoming_references()` on `INV-*` entities to return their bound `file::func` test assertions.

== Verification Criteria

* Running `eidos index sync --force` followed by `eidos index status --json` reports `test_invariant_assertions > 0` matching the repository's bound invariants.
* Unit test in `tests/test_graph_index.py` verifies that `SELECT COUNT(*) FROM edges WHERE relation = 'asserts'` is non-zero after `sync()` and updates cleanly when a test file is modified or removed.
