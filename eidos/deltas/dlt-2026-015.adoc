= SpecDelta: Modernize Living Web Portal with React 19, Tailwind CSS v4, and Material Design 3 (MD3)
:toc: left

== 1. Intent & Strategic Rationale

Graduating from empirical spike link:../explorations/EXP-2026-003.adoc[EXP-2026-003], this SpecDelta modernizes the Living Web Portal (`CLT-WEB-PORTAL`, implemented by `CNT-EIDOS-PORTAL`).

Today, `src/eidos/portal/assets.py` contains a handcrafted 4,300+ line HTML/JS template. While functional, it poses maintainability challenges for rich developer interactions like spotlight search, pan-zoom diagrams, and accessible drawers.

By compiling the modern frontend (`src/eidos/portal/frontend`) using Vite and `vite-plugin-singlefile` at build time, the resulting single-file HTML bundle is only **95.89 KB gzipped** (336.74 KB raw) and requires **zero Node.js or npm dependencies at runtime**.
