= SpecDelta: Centralized Hybrid C4 Level 3 Component Manifests
:toc: left
:icons: font

== 1. Context & Motivation

Following architectural discovery under *EXP-2026-004*, this SpecDelta formalizes the **Centralized Hybrid C4 Level 3 Architecture** across Eidos.

Previously, all C4 Level 3 components were declared strictly inline within Level 2 container manifests (`eidos/architecture/containers/*.adoc`). While compact, inline declarations prevent complex modules from documenting internal state machines, granular in-process API signatures, and component-level invariants without bloating container manifests.

This delta establishes a centralized hybrid approach:
* **Inline Default (80%)**: Simple internal modules remain inline in `CNT-*.adoc` manifests.
* **Centralized Promoted Specs (20%)**: Architecturally complex modules receive dedicated `type: tech/component` specifications residing centrally in `eidos/architecture/components/<component>.adoc`, linked via `ref:` in the parent container manifest and pointing to code via `package_path`.
* **Zero Code Pollution**: Eidos specifications must **NEVER touch or reside within source code directories** (`src/`, `packages/`). Implementation code remains 100% pure source code.
* **Initialization Guardrail**: `eidos init` provisions `eidos/architecture/components/` tracked by `.gitkeep` even if no promoted components exist initially.

== 2. Delivered Invariants

1. **`INV-COMPONENT-CENTRALIZATION-MANDATE`**:
   Every dedicated `tech/component` specification MUST reside centrally within `eidos/architecture/components/`. Storing specification `.adoc` files inside source code directories (`src/`, `packages/`) triggers immediate validation failure.
2. **`INV-COMPONENT-CONTAINER-AFFINITY`**:
   Every dedicated `CMP-*` specification must declare a `container: CNT-*` property binding it to an existing Level 2 container.
3. **`INV-INTERFACE-BOUNDARY-GOVERNANCE`**:
   Boundary Protocol Contracts (`CTR-*`) must be owned by Containers (`CNT-*`). In-process components declare local language-level interfaces via `interfaces.provides`.
