= SpecDelta: Collision-Free Schema Cache Keying, 16-Schema eidos info, and Functional Typer Root CLI Contract Parity
:toc: left

== Problem Statement

`CMP-SPEC-VALIDATOR` (`src/eidos/core/spec/validator.py`) and `CMP-CLI-APP` (`src/eidos/cli/main.py`) have two validation defects:

1. **Basename Collision on `system.schema.yaml`, Non-Deterministic `_schema_hash`, and `eidos info` Reporting 15 Instead of 16 Schemas (`src/eidos/core/spec/validator.py`, lines 217-265 & `src/eidos/cli/main.py`, line 125)**:
   * Both `assets/schemas/v1/product/system.schema.yaml` and `assets/schemas/v1/design/system.schema.yaml` have `schema_path.name == "system.schema.yaml"`.
   * `_load_bundled_schemas` iterates over unsorted `self.schemas_dir.rglob("*.schema.*")`, hashes files in filesystem order (making `self._schema_hash` non-deterministic for `spec_validation_cache`), and overwrites `self._schema_cache["system.schema.yaml"]`.
   * `eidos info` filters `[k for k in validator._schema_cache if "/" not in k]`, displaying only 15 schemas instead of all 16.
2. **Missing Root CLI Commands in `_verify_cli_contract_commands` (`src/eidos/core/spec/validator.py`, lines 978-1055)**:
   * Only inspects `@app.command()` decorators and `app.add_typer(...)` calls. Because `src/eidos/cli/main.py` registers root commands via functional calls (`app.command(...)(validate)`, `app.command(...)(drift)`, `app.command(...)(init)`, `app.command(...)(context)`, `app.command(...)(doctor)`) inside `*_commands.register(app)` helpers, none of the 7 root CLI commands (`version`, `info`, `validate`, `context`, `drift`, `init`, `doctor`) are checked for parity against `CTR-EIDOS-CLI`.

== Proposed Specification Changes

1. **Deterministic Relative-Keyed Schema Cache & 16-Schema `eidos info` (`src/eidos/core/spec/validator.py`, `src/eidos/cli/main.py`)**:
   * Sort `rglob("*.schema.*")` paths before computing `_schema_hash` and loading schemas.
   * Store relative schema paths (`v1/<category>/<name>.schema.yaml` and `<category>/<name>.schema.yaml`) as primary keys, only registering bare `schema_path.name` when unambiguous across categories, and update `eidos info` to list all 16 canonical `<category>/<name>.schema.yaml` entries.
2. **Discover Functional `app.command(...)(fn)` & Delegated `register(app)` Calls (`src/eidos/core/spec/validator.py`)**:
   * Extend `_verify_cli_contract_commands` to detect functional `app.command(...)(fn)` call expressions and follow `<module>.register(app)` calls into sibling CLI modules.
