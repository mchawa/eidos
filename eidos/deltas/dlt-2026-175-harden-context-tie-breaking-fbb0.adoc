= SpecDelta: Harden Context Tie-Breaking, CLI Help AST Diffing, Schema Genericity, and Doctor Open-Delta Diagnostics
:toc: left

== Problem Statement
Five follow-up issues surfaced after migrating living specifications from numbered IDs to semantic names (`DLT-2026-174`):
1. Tied 1-hop capabilities and governing policies in `eidos context` fell back to raw alphabetical ID order before guardrails budget truncation.
2. Editing prose-only `help=` strings inside Typer/Click `Argument`/`Option`/`command` signatures was classified as a structural code change by `CMP-AST-DIFF-CLASSIFIER`.
3. `INV-ENGINE-GENERICITY` did not scan `assets/schemas/`, allowing Eidos-self IDs to slip into generic schema descriptions.
4. `DLT-2026-170` remained at `status: proposed` after its code/spec changes landed, and `eidos doctor` had no advisory diagnostic flagging already-verified open SpecDeltas.
5. `tests/test_validator.py::test_pol_statement_test_coverage` read pre-existing stale `coverage.json` mid-run during `pytest --cov`.

== Proposed Specification Changes
* **`CMP-TIERED-CONTEXT-COMPRESSOR`**: Add structural capability tie-breaking (`-shared_links`, `-inv_count`) and policy ranking (`severity`, top-capability affinity, `-len(pol_cap_refs)`, plus severity-ordered fallback query) in `src/eidos/core/index/context.py`.
* **`CMP-AST-DIFF-CLASSIFIER`**: Add Python AST-based `_normalize_signature_for_diff` in `src/eidos/core/index/ast_diff.py` stripping prose-only `help`/`rich_help_panel`/`short_help`/`epilog` string literals inside Typer/Click descriptors while preserving all flag, default, type, and non-CLI signature diffs.
* **`CMP-CLI-DOCTOR-HOOKS`, `CTR-EIDOS-CLI` (`1.10.0`), `CMP-DOCS-USER-GUIDES`**: Add non-blocking `checks.open_deltas` (`clean` | `in_progress` | `ready_to_apply`) in `src/eidos/cli/doctor_hook_commands.py` and document it in `CTR-EIDOS-CLI` and `docs/guides/cli.md`.
* **`CAP-LIVING-SPEC-ENGINE` / `INV-ENGINE-GENERICITY`**: Extend `test_engine_genericity_zero_self_references` to scan `assets/schemas/` in addition to `src/eidos/` and `assets/plugin_reference/skills/`.
* **Operational Hygiene**: Apply already-verified `DLT-2026-170` (`13/13` verified) and guard live `coverage.json` verification inside `test_pol_statement_test_coverage` when `--cov` is actively running.
