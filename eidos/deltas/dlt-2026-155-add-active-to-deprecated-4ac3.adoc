= SpecDelta: Add Active-to-Deprecated Dependency and Undeclared Tier Guardrail Warnings
:toc: left

== Problem Statement
1. **Rotting references to retired/deprecated entities**: When a container, component, contract, design system, or client transitions to `status: deprecated` or `status: retired`, `status: active` specs that still reference it continue to pass `eidos validate` silently with zero warning.
2. **Silent `tier_rules` bypass on typos**: `ARCH-*.import_boundaries.tier_rules` evaluates rules by matching each `CNT-*.tier` string. If a container mistypes `tier: cor` instead of `tier: core`, `validate_import_boundary_declarations` does not flag the undeclared tier slug, silently exempting that container from tier rules.

== Proposed Specification Changes
* **`CMP-SPEC-VALIDATOR` (`src/eidos/core/spec/validator.py`)**: During cross-reference validation, emit a non-blocking `ValidationReport.warnings` entry whenever a `status: active` living specification (excluding `delta/mutation` and `product/exploration` historical records) references an entity whose `status` is `deprecated` or `retired`.
* **`CMP-ARCHITECTURE-BOUNDARY-VALIDATOR` (`src/eidos/core/spec/boundary_validator.py`)**: When `ARCH-*.import_boundaries.tier_rules` is non-empty, compute the set of known tier slugs (all `tier_rules` keys plus all `allow`/`deny` targets) and emit a `ValidationReport.warnings` entry for any `status: active` `CNT-*` declaring a `tier` not in that set.
* **`CNT-EIDOS-CORE` & `CAP-PROD-001`**: Update living specs and bind `INV-LIFECYCLE-AND-TIER-GUARDRAIL-WARNINGS`.

== Implementation Plan
1. **Lifecycle Dependency Warning (`CMP-SPEC-VALIDATOR`)**: Add active-to-deprecated/retired `x-eidos-ref` warning check in `src/eidos/core/spec/validator.py` (preserving zero warnings on Eidos's own catalog).
2. **Undeclared Tier Check (`CMP-ARCHITECTURE-BOUNDARY-VALIDATOR`)**: Add tier-slug warning check in `validate_import_boundary_declarations` (`src/eidos/core/spec/boundary_validator.py`).
3. **Living Specs, Tests & Coverage (`POL-005-STATEMENT-TEST-COVERAGE`)**: Update all declared specs and add `tests/test_validator.py::test_active_to_deprecated_and_undeclared_tier_warnings` verifying non-blocking `warnings`, zero false warnings on Eidos's catalog, and `>90.0%` coverage.
4. **Verification**: Run `pytest`, `eidos delta verify DLT-2026-155 --json`, `eidos delta apply DLT-2026-155`, and `eidos drift --uncommitted --json`.
