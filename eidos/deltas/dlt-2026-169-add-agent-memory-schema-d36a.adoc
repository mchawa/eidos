= SpecDelta: Add Agent Memory Schema, Validation & Drift Isolation (Phase 1)
:toc: left

== Problem Statement

`EXP-2026-012` validated a Git-native, team-scoped auto-memory architecture (`type: agent/memory`, stored as one `.adoc` file per memory under `eidos/memory/`). Before building indexing, CLI commands, skills, or Portal screens in Phases 2–4, Spike 1 empirically proved three foundational engine gaps that must be closed first:

1. **Missing Canonical Schema & Registry Entry**: `agent/memory` (`MEM-*`) is unregistered in `assets/schemas/v1/`, `ENTITY_PREFIX_REGISTRY`, `infer_entity_type_from_path`, and `_TEMPLATE_PATHS_BY_TYPE`, and `assets/schemas/v1/common/defs.yaml` (`decision.graduated_from`) currently rejects `MEM-*`.
2. **Blocking Validator Leakage**: `SpecValidator._check_dict_references()` recursively flags any missing `.adoc` path in frontmatter as a blocking `broken_references` error (failing CI if a memory's `targets.paths` points to a deleted `.adoc` file), and `_warn_if_deprecated_dependency()` would emit `ValidationReport.warnings` (breaking `--fail-on-warnings` under `INV-VALIDATION-WARNINGS-PORTAL-AND-CI-ESCALATION`).
3. **Drift & `Stop` Hook Classification Leakage**: `classify_changed_files()` currently routes every non-delta `eidos/*.adoc` file into `classification.spec_files`, polluting `DriftCheckResult` and defeating `CMP-HOOK-RUNNER`'s zero-edit Q&A short-circuit (`INV-AGENT-DRIFT-HOOK`) whenever an agent saves a team memory without editing code.

== Proposed Specification Changes

* **`CNT-EIDOS-CORE` (`eidos/architecture/containers/core.adoc`)**: Add `assets/schemas/v1/agent/memory.schema.yaml` + `memory.template.adoc`, extend `assets/schemas/v1/common/defs.yaml` (`decision.graduated_from` accepting `MEM-*`), and record `DEC-CORE-AGENT-MEMORY-SCHEMA-ISOLATION` (`graduated_from: EXP-2026-012`) documenting why team memories exclude personal `user` preferences, isolate staleness from `ValidationReport.warnings`, and reject `eidos spec create memory`.
* **`CMP-DOMAIN-MODELS` (`eidos/architecture/components/domain-models.adoc`)**: Register `"MEM-": ("memory", "agent/memory", "agent/memory.schema.yaml")` in `ENTITY_PREFIX_REGISTRY` (17 v1 document types) and resolve `eidos/memory/**` via parent-first `infer_entity_type_from_path`.
* **`CMP-ASSET-LOCATOR` (`eidos/architecture/components/asset-locator.adoc`)**: Register `agent/memory` and `memory` template paths (`agent/memory.template.adoc`) in `_TEMPLATE_PATHS_BY_TYPE`.
* **`CMP-SPEC-VALIDATOR` (`eidos/architecture/components/spec-validator.adoc`)**: Validate all 17 living specification types while exempting `agent/memory` `targets` and `promoted_to` from `_check_dict_references()` and exempting `agent/memory` from `_warn_if_deprecated_dependency()`.
* **`CMP-LIFECYCLE-SCAFFOLDER` (`eidos/architecture/components/lifecycle-scaffolder.adoc`)**: Reject `memory` / `agent/memory` in `create_spec()` with a `ValueError` pointing callers to `eidos memory add` (mirroring `delta/mutation`), while exposing all 17 schemas in `get_spec_schema_info()`.
* **`CMP-GIT-DIFF-INSPECTOR` (`eidos/architecture/components/git-diff-inspector.adoc`)**: Add `ChangedFilesClassification.memory_files` and route `eidos/memory/**` files into `memory_files` (excluded from `spec_files` and `delta_files`, and excluded from `total_changed` governance triggers that gate `CMP-HOOK-RUNNER`).
* **`CMP-DOCS-CORE-CONCEPTS` (`eidos/architecture/components/docs-core-concepts.adoc`)**: Document `agent/memory` (`MEM-*`) in `docs/concepts/schema-glossary.md` (17-schema glossary).
* **`CAP-PROD-001` (`1.21.0`)**: Update `INV-SPEC-VALIDATION` and `INV-DOCS-SYNCHRONIZATION` to 17 schemas and add `INV-AGENT-MEMORY-SCHEMA-ISOLATION`.
* **`CAP-VCS-001` (`1.15.0`)**: Add `INV-DRIFT-MEMORY-FILE-ISOLATION`.
