= SpecDelta: Tool-Only Installation, CLI-Native Agent Hooks, and Block-Once Stop Gate
:toc: left

== Problem Statement

Previously, Eidos documentation mixed `uv add eidos-ai` with `uv tool install`, and the bundled plugin hooks (`hooks.json`) invoked copied Python scripts (`python3 .agents/plugins/eidos/scripts/lint_docs.py` and `check_drift.py`) that failed with `ModuleNotFoundError: No module named 'eidos'` in non-Python repositories or isolated virtual environments. Furthermore, the `Stop` hook only emitted a passive `systemMessage` without blocking an agent from finishing a turn with drifted specifications.

== Architectural & Behavioral Mutations

1. **Tool-Only Installation**:
   * Standardize installation exclusively around `uv tool install eidos-ai`, `pipx install eidos-ai`, and ephemeral `uvx eidos-ai`.
   * Expose both `eidos` and `eidos-ai` script entry points in `pyproject.toml`.
2. **CLI-Native Hooks (`eidos hook lint`, `eidos hook drift`) & `eidos doctor`**:
   * Implement `src/eidos/plugin/hooks.py` and wire `eidos hook lint` and `eidos hook drift` in `src/eidos/cli/main.py`.
   * Keep lightweight forwarding shims in `scripts/lint_docs.py` and `scripts/check_drift.py` that delegate to `eidos hook` (falling back to `uvx --from eidos-ai eidos hook`).
3. **Block-Once Stop Gate**:
   * On `Stop`, if specification validation or drift fails, compute a SHA-256 fingerprint of the failure state and store it in `eidos/.cache/stop-gate.json`.
   * First `Stop` with a new fingerprint returns `{"decision": "continue", "reason": ...}` to block turn completion and instruct the agent to reconcile specs.
   * If the agent attempts to stop a second time with the identical failure fingerprint, clear `eidos/.cache/stop-gate.json` and return `{"decision": "allow", "systemMessage": ...}` to prevent infinite loops.
