= SpecDelta: Add Parallel SpecDelta Target and Blast-Radius Conflict Detection
:toc: left

== Problem Statement
In multi-agent and team workflows, several `proposed`, `in_review`, or `approved` SpecDeltas frequently exist at the same time. Today there is no command to detect when two open SpecDeltas mutate the same `CNT-*`/`CMP-*`/`CTR-*` target, attempt incompatible operations (`remove`/`deprecate` vs. `modify`), or share overlapping 1-hop architectural blast radii.

== Proposed Specification Changes
* **`CMP-DELTA-ENGINE` (`src/eidos/core/lifecycle/delta_verifier.py`)**: Implement deterministic `detect_delta_conflicts` classifying pairwise overlaps across non-terminal SpecDeltas into `direct_target_conflicts` (severity `high` when one removes/deprecates while the other modifies, `medium` for concurrent modifies) and `blast_radius_overlaps` (severity `info`, derived from `ArchitecturalIndex.compute_delta_impact`).
* **`CMP-CLI-DELTA-COMMANDS` (`src/eidos/cli/delta_commands.py`), `CTR-EIDOS-CLI` & `CMP-DOCS-USER-GUIDES`**: Expose `eidos delta conflicts [--path PATH] [--blast-radius/--no-blast-radius] [--strict] [--json]`, update `tests/fixtures/cli_command_tree.json` and `docs/guides/cli.md`.
* **`CAP-PROD-002`**: Add and bind `INV-DELTA-PARALLEL-CONFLICT-DETECTION`.

== Implementation Plan
1. **Conflict Analyzer (`CMP-DELTA-ENGINE`)**: Implement `detect_delta_conflicts` in `src/eidos/core/lifecycle/delta_verifier.py` (`CNT-EIDOS-CORE` covered via `CMP-DELTA-ENGINE`), excluding terminal (`applied`, `rejected`) and archived deltas.
2. **CLI Command & Contract (`CMP-CLI-DELTA-COMMANDS`, `CTR-EIDOS-CLI`, `CMP-DOCS-USER-GUIDES`)**: Add `conflicts` subcommand to `delta_app` in `src/eidos/cli/delta_commands.py` (`CNT-EIDOS-CLI` covered via `CMP-CLI-DELTA-COMMANDS` and `CTR-EIDOS-CLI`), update `tests/fixtures/cli_command_tree.json` and `docs/guides/cli.md`.
