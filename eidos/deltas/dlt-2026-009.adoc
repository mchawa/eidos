= SpecDelta: Eidos Living Web Portal & Interactive Architecture Visualizer
:toc: left

== Problem Statement
Product managers, architects, designers, and non-engineering stakeholders lack an interactive graphical interface to explore living specifications without opening an IDE or reading raw text in terminal. Furthermore, sharing architecture topologies, C4 diagrams, multi-design system tokens, and in-flight SpecDelta lifecycles requires manual documentation exports that quickly drift out of date.

== Proposed Specification Changes
1. Author container manifest `CMP-EIDOS-PORTAL` (`src/eidos/portal/`) providing:
   - Zero-external-dependency local HTTP web server (`server.py`).
   - Dynamic API endpoints (`/api/overview`, `/api/specs`, `/api/components`, `/api/c4-model`, `/api/deltas`, `/api/design`, `/api/invariants`).
   - Static documentation site exporter (`builder.py`) for hosting on GitHub Pages and GitLab Pages.
   - Interactive single-page web application featuring C4 Mermaid diagrams, SpecDelta Kanban board, W3C design tokens studio, and search.
2. Define interface contract `CTR-EIDOS-PORTAL` under `eidos/architecture/contracts/portal.adoc`.
3. Update `ARCH-EIDOS-001` container topology to register `CMP-EIDOS-PORTAL`.
4. Expose `eidos serve` and `eidos build-site` subcommands in `CTR-EIDOS-CLI`.
5. Add invariant `INV-LIVING-PORTAL-VISUALIZATION` to `CAP-PROD-001`.
