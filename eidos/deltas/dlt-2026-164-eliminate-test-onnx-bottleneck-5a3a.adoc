= SpecDelta: Eliminate Test ONNX Bottleneck, Vite 8 Deprecation, and Spec Hygiene Warnings
:toc: left

== Problem Statement
Three accumulated developer-experience and hygiene issues were observed during full-suite verification:

1. **Test Suite ONNX Bottleneck**: `tests/test_context.py::test_cli_index_commands` invokes `eidos index sync` without `--no-semantic` against Eidos's live repo, triggering a multi-minute CPU ONNX embedding pass whenever `eidos/.cache/models/harrier-oss-v1-0.6b` is provisioned locally (even though semantic sync has dedicated mocked unit tests).
2. **Vite 8 Config Deprecation**: `src/eidos/portal/frontend/vite.config.ts` uses `__dirname` on lines 56 and 74, emitting a Vite 8 `configLoader: 'native'` deprecation warning on every `pnpm build:assets` run.
3. **Asciidoctor List Warnings**: `src/eidos/portal/frontend/tests/asciidoc.test.ts` emits 7 `asciidoctor: WARNING: list item index: expected N, got M` diagnostics caused by nested `1.` ordered lists (instead of AsciiDoc `..` nested syntax) in `eidos/deltas/dlt-2026-119-publish-official-9237.adoc`.

== Proposed Specification Changes
* **`CNT-EIDOS-PORTAL` (`src/eidos/portal/frontend/vite.config.ts`, `src/eidos/portal/frontend/tests/asciidoc.test.ts`, `eidos/architecture/containers/portal.adoc`)**:
  * Replace `__dirname` with `import.meta.dirname` in `vite.config.ts` for clean Vite 8 builds.
  * Assert zero Asciidoctor `MemoryLogger` warnings when converting repository `.adoc` bodies in `src/eidos/portal/frontend/tests/asciidoc.test.ts`.
* **`CAP-PROD-001` (`eidos/domains/spec-engine/capabilities/living-spec-engine.adoc`)**:
  * Bind `INV-ASCIIDOC-ZERO-WARNING-HYGIENE` to `tests/test_docs_sync.py::test_repo_specs_zero_asciidoc_list_warnings_and_fast_index_cli_test`.

== Implementation Plan
1. **Vite 8 & Vitest Zero-Warning Gate (`CNT-EIDOS-PORTAL`)**: Replace `__dirname` with `import.meta.dirname` in `src/eidos/portal/frontend/vite.config.ts` and assert zero Asciidoctor list-index warnings in `src/eidos/portal/frontend/tests/asciidoc.test.ts`; update `eidos/architecture/containers/portal.adoc`.
2. **Fast Deterministic Index CLI Test (test-only; no spec mutation)**: Pass `--no-semantic` to `eidos index sync` inside `tests/test_context.py::test_cli_index_commands` so full `pytest` never stalls on local CPU ONNX runs.
3. **AsciiDoc List Syntax & `CAP-PROD-001` Invariant Binding**: Convert nested `1.` sublists to canonical AsciiDoc `..` syntax in `eidos/deltas/dlt-2026-119-publish-official-9237.adoc` (SpecDelta AsciiDoc formatting cleanup; no target mutation), and add `INV-ASCIIDOC-ZERO-WARNING-HYGIENE` in `eidos/domains/spec-engine/capabilities/living-spec-engine.adoc`.
