= SpecDelta: Surface Ready-to-Apply SpecDeltas in Eidos Drift and Fail-On-Warnings
:toc: left

== Problem Statement
`eidos doctor` (`checks.open_deltas`) reports already-verified open SpecDeltas across the repository, but developers, AI coding agents, and CI pipelines execute `eidos drift`—not `eidos doctor`—at completion and merge time. As a result, finished Planned Mode SpecDeltas can be committed and merged at `status: proposed` (omitting them from `eidos delta changelog` and leaving stale active deltas in conflict checks) while `eidos drift --fail-on-warnings` exits `0`.

== Proposed Specification Changes
* **`CMP-DRIFT-DETECTOR`**: Add `DriftCheckResult.ready_to_apply_deltas`, verify diff-touched and spec-overlapping open non-archived SpecDeltas (`proposed` / `in_review` / `approved` with non-empty mutations) via the shared snapshot-aware verification helper without flipping `is_clean` or `drift_detected`, and emit an advisory section in `build_drift_remediation_and_summary` (`report.py`).
* **`CMP-CLI-DRIFT-COMMANDS` & `CTR-EIDOS-CLI` (`1.11.0`)**: Emit `"ready_to_apply_deltas"` in `eidos drift --json`, display yellow advisory lines in Rich output, and escalate **all** non-empty `ready_to_apply_deltas` alongside `validation_warnings` to exit code `1` when `--fail-on-warnings` is supplied (unless `--warn-only` is set).
* **`CAP-DRIFT-DETECTION` / `INV-DRIFT-READY-TO-APPLY-DELTAS`**: Bind the invariant to `tests/test_drift.py::test_drift_ready_to_apply_deltas_and_fail_on_warnings`.
* **`CMP-DOCS-USER-GUIDES`**: Sync `docs/guides/cli.md` and `eidos/architecture/components/docs-user-guides.adoc`.

== Implementation Plan
1. Update `src/eidos/vcs/drift.py`, `src/eidos/vcs/report.py`, and `src/eidos/cli/drift_commands.py`.
2. Co-evolve `drift-detector.adoc`, `cli-drift-commands.adoc`, `cli.adoc` (`1.11.0`), `drift-detection.adoc`, `docs-user-guides.adoc`, and `docs/guides/cli.md`.
3. Add comprehensive tests in `tests/test_drift.py` (`test_drift_ready_to_apply_deltas_and_fail_on_warnings`) and update `tests/test_cli_json.py`.
4. Verify with `ruff`, parallel `pytest --cov=src/eidos`, `eidos delta verify/apply DLT-2026-176`, and `eidos drift --uncommitted --fail-on-warnings --json`.
