= SpecDelta: AI Plugin Lifecycle Hooks for Automated Documentation Linting
:toc: left

== Problem Statement
When autonomous AI agents make code and documentation modifications in Eidos-governed repositories, mistakes such as malformed YAML frontmatters, broken cross-references, or missing required schema properties can occur. Without immediate feedback, an agent might conclude its session leaving invalid specifications.

== Proposed Specification Changes
1. Provide an AI plugin lifecycle hook configuration (`hooks.json`) and executable hook runner (`scripts/lint_docs.py`) bundled within `assets/plugin_reference` and installed to `.agents/plugins/eidos/`.
2. Hook into agent lifecycle events:
   - `PreToolUse`: Intercepts `write_to_file` and `replace_file_content` targeting `.adoc` specifications, denying writes if YAML frontmatter syntax is malformed.
   - `PostInvocation`: Injects diagnostic ephemeral messages into the conversation if specifications fail validation.
   - `Stop`: Blocks agent completion (`decision: continue`) if living specifications in `eidos/` fail schema or reference validation.
3. Expose standalone execution support in `scripts/lint_docs.py` and CLI alias `eidos lint` under `CTR-EIDOS-CLI`.
4. Add invariant `INV-AGENT-LINT-HOOK` under `CAP-AGENT-001`.
5. Update `CMP-EIDOS-PLUGIN` validator to verify `hooks.json` structure and script references.
