= SpecDelta: Support Nested Dot-Path and Partial Object Matching in SpecDelta expect.frontmatter
:toc: left

== Problem Statement
In `src/eidos/core/lifecycle/delta_engine.py`, `_evaluate_declarative_postcondition` currently resolves `expect.frontmatter` keys via a shallow 1-level lookup (`actual = target_dict.get(k)`) and falls back to strict full-dictionary equality (`actual != exp_v`). Consequently:

1. **Nested dictionaries cannot be queried by path**: Assertions on `contracts.provides` (`CNT-*`), `technical.containers` (`CAP-*`), or `tokens.manifest` (`DS-*`) require matching the entire parent dictionary (`contracts`, `technical`, `tokens`) key-for-key, because `target_dict.get("contracts.provides")` returns `None`.
2. **Arrays of structured objects require verbatim duplication**: Asserting that a specific `DEC-*` decision or inline `CMP-*` component was added to `decisions:` or `components:` fails `item not in actual` unless the author duplicates the entire multi-line dictionary (including `rationale` and `rejected_alternatives`) inside `expect.frontmatter`.

== Proposed Specification & Engine Changes
1. **Dot-Path Key Resolution (`_resolve_frontmatter_path`)**:
   * When a key `k` in `expect.frontmatter` (or `expect.frontmatter.custom`) is not an exact top-level key in `target_dict` and contains `.`, traverse nested dictionaries segment-by-segment (e.g., `"contracts.provides"` -> `target_dict["contracts"]["provides"]`, `"technical.containers"` -> `target_dict["technical"]["containers"]`).
2. **Recursive Dict-Subset & Object-List Matching (`_matches_expected_value`)**:
   * When `exp_v` is a `dict` and `actual` is a `dict`, recursively verify that every `(sub_k, sub_v)` declared in `exp_v` is satisfied in `actual` (allowing partial dictionary assertions without specifying unrelated sibling keys).
   * When `exp_v` is a `list` (or single `dict`) and `actual` is a `list` of dicts (e.g., `decisions`, `components`, `invariants`), consider an expected dict item matched if at least one element in `actual` satisfies recursive dict-subset matching (for example, `decisions: [{ id: "DEC-VCS-STATIC-INVARIANT-TRACEABILITY" }]`).
