= SpecDelta: Remove Unschematized Ghost Frontmatter Key Lookups Across Engine
:toc: left

== Problem Statement
Several engine modules (`src/eidos/core/workspace/project.py`, `src/eidos/core/lifecycle/changelog.py`, `src/eidos/core/index/graph_index.py`, `src/eidos/core/index/query.py`, `src/eidos/core/index/context.py`, `src/eidos/vcs/structural.py`, and `src/eidos/portal/generator.py`) still contained fallback reads for legacy or non-existent YAML frontmatter keys (`owned_path`, `tokens_path`, `name` on `product/system`, `arch/system`, `responsibility`/`summary` on `tech/container`, `mission`/`capabilities` in `product/domain` frontmatter, `summary` and `technical.decisions` in `product/capability` frontmatter, `role`/`archetype` in `product/persona` frontmatter, `brand_name` on `design/system`, `blast_radius` and `feature_addition` on `delta/mutation`, top-level `hypothesis`/`findings`/`recommendation`/`outcome`/`resulting_deltas`/`exit_criteria` in `product/exploration` frontmatter, `c4_context` on `product/system`, and top-level `description`/`details`/`rationale` in `TieredContextSlice._compress_verbose_fields_in_place`) that are forbidden by `additionalProperties: false` across all 16 bundled v1 schemas.

== Proposed Specification Changes
1. **`CMP-PROJECT-RESOLVER` & `CMP-DRIFT-DETECTOR` (`CNT-EIDOS-CORE`, `CNT-EIDOS-VCS`, `CAP-VCS-001`)**:
   * Remove `"owned_path"` from `extract_entity_paths` (`project.py`), `_OWNERSHIP_KEYS`, `_declared_source_patterns`, and `_collect_1hop_spec_targets` (`structural.py`), and remove `"name"` fallback on `system.adoc` (`project.py`).
   * Remove `"tokens_path"` from `_collect_1hop_spec_targets` and `_collect_design_subgraph` (`structural.py`), relying strictly on `tokens.manifest`.
2. **`CMP-GRAPH-STORAGE`, `CMP-GRAPH-TRAVERSAL-ENGINE` & `CMP-TIERED-CONTEXT-COMPRESSOR` (`CNT-EIDOS-INDEX`)**:
   * Remove `raw_blast_radius` from `ArchitecturalIndex.compute_delta_impact` (`graph_index.py`) and `compute_delta_impact_in_db` (`query.py`).
   * Remove dead top-level `description`, `details`, and `rationale` compression loops in `TieredContextSlice._compress_verbose_fields_in_place` (`context.py`), compressing only schematized `responsibility`.
3. **`CMP-PORTAL-GENERATOR` (`CNT-EIDOS-PORTAL`) & `CMP-CHANGELOG-GENERATOR` (`CNT-EIDOS-CORE`)**:
   * Remove unschematized frontmatter reads in `get_portal_data` and `_extract_design_systems` (`generator.py`) while preserving all derived output dictionary keys (`mission`, `capabilities`, `summary`, `role`, `archetype`, `hypothesis`, `findings`, `resulting_deltas`, `brand_name`) populated from AsciiDoc prose sections, graph edges, and `decision.*`.
   * Default `delta_item["kind"]` to `"feature"` instead of `"feature_addition"`, and remove legacy `intent.kind` aliases from `changelog.py`.

== Implementation Plan
1. Clean up ghost frontmatter key lookups in `project.py`, `changelog.py`, `graph_index.py`, `query.py`, `context.py`, `structural.py`, `report.py`, and `generator.py`.
2. Update affected living specifications (`core.adoc`, `index.adoc`, `vcs.adoc`, `portal.adoc`, `drift-detection.adoc`) and test fixtures (`test_graph_index.py`, `test_portal.py`, `test_context.py`).
3. Verify and apply `DLT-2026-111-REMOVE-UNSCHEMATIZED-AD72`, run `pytest`, `eidos validate`, and `eidos drift --uncommitted`.
