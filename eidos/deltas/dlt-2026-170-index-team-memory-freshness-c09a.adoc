= SpecDelta: Index Team Memory, Freshness Cache & Context Attachment (Phase 2)
:toc: left

== Problem Statement

Phase 1 (`DLT-2026-169-ADD-AGENT-MEMORY-SCHEMA-D36A`) introduced the canonical `agent/memory` (`MEM-*`) v1 schema, validation exemptions, and drift isolation. However, the embedded SQLite knowledge graph (`CNT-EIDOS-INDEX`) does not yet project `agent/memory` documents selectively into `specs_fts` (active-only) or materialize `anchors_entity` / `promoted_to` edges, does not persist a `HEAD`-keyed `memory_freshness_cache` to avoid linear `git rev-list` latency (`608 ms` at `N = 100` in `EXP-2026-012` Spike 2), and `CMP-TIERED-CONTEXT-COMPRESSOR` (`eidos context`) does not yet attach relevant team operational memories to `TieredContextSlice` with Stage 0 memory-first budget pruning.

== Proposed Specification Changes

* **SQLite Schema & Non-Blocking Freshness Cache (`CNT-EIDOS-INDEX`, `CMP-GRAPH-STORAGE`)**:
  ** Bump `SCHEMA_VERSION` from `"2.22.0"` to `"2.23.0"` (15 managed tables) adding `memory_freshness_cache (memory_id TEXT PRIMARY KEY, head_sha TEXT NOT NULL, mem_sha256 TEXT NOT NULL, freshness TEXT NOT NULL, reason TEXT NOT NULL, checked_at TEXT NOT NULL)`.
  ** Expose non-blocking `load_memory_freshness_cache` (`allow_ddl=False`) and `save_memory_freshness_cache` (`_advisory_db_lock(..., non_blocking=True)`) helpers in `src/eidos/core/index/storage.py`.
  ** Record `DEC-INDEX-MEMORY-FRESHNESS-AND-SECONDARY-SLICING` (`graduated_from: EXP-2026-012`) in `CNT-EIDOS-INDEX.decisions`.
* **Incremental Indexing & Graph Edges (`CMP-INCREMENTAL-SYNC-ENGINE`, `CAP-AGENT-002`)**:
  ** Keep all `agent/memory` files in `entities` (active, draft, promoted, archived) for audit and portal visibility, while inserting ONLY `status == "active"` non-archived (`eidos/memory/archive/` excluded) entries into `specs_fts` (which automatically scopes `spec_embeddings` in `CMP-SEMANTIC-EMBEDDING-ENGINE` — unchanged; no edits needed in `semantic.py` or `fts_query.py`).
  ** Materialize `anchors_entity` (`targets.entities`) and `promoted_to` (`promoted_to`) edges in `spec_edges.py` while retaining `promoted_to` edges targeting embedded `DEC-*` IDs during orphan pruning.
  ** Evict `memory_freshness_cache` rows on memory update, deletion, spec/code deletion, or `sync --force`.
  ** Add `INV-INDEX-MEMORY-GRAPH-AND-FRESHNESS-CACHE` on `CAP-AGENT-002`.
* **Secondary Budgeted Context Attachment & Stage 0 Pruning (`CMP-TIERED-CONTEXT-COMPRESSOR`, `CAP-AGENT-001`, `CTR-EIDOS-CLI`)**:
  ** Add cohesive leaf module `src/eidos/core/index/context_memories.py` owned by `CMP-TIERED-CONTEXT-COMPRESSOR` implementing `evaluate_memory_freshness`, `resolve_memory_freshness_batch`, `extract_memory_sections`, and `attach_context_memories`.
  ** Match active memories by anchored entity ID (`targets.entities`), normalized file/brace-glob path (`targets.paths` via `match_path_pattern`), and bounded secondary `execute_fts_query(..., include_types=("agent/memory",))` without displacing `TASK_SLICE_ENTITY_TYPES`, plus tier-capped untargeted global memories (`anchor: <=2/0`, `guardrails: <=3/2`, `deep: <=5/3`).
  ** Preserve Honest Empty Slices (never attach untargeted global memories when an explicit query matches zero architectural entities and zero anchored/task memories) and omit `memories` from `to_dict()` / `to_markdown()` when empty (0-token overhead when unused).
  ** Run Stage 0 memory-first pruning in `TieredContextSlice._enforce_token_budget` (drop global memories -> compact memories -> pop tail anchored memories) before any architectural entity compression or eviction.
  ** Add `INV-CONTEXT-TEAM-MEMORY-ATTACHMENT` on `CAP-AGENT-001` and bump `CTR-EIDOS-CLI` to `1.8.1`.
* **Documentation Sync (`CMP-DOCS-CORE-CONCEPTS`, `CMP-DOCS-USER-GUIDES`, `CAP-PROD-001`)**:
  ** Sync `docs/concepts/how-eidos-works.md`, `docs/concepts/architectural-index.md`, and `docs/guides/cli.md` to 15 tables, `SCHEMA_VERSION` `2.23.0`, `memory_freshness_cache`, `context_memories.py`, and optional `memories` on `eidos context` (`CNT-EIDOS-DOCS` parent unchanged; `CMP-FTS-QUERY-ENGINE` and `CMP-SEMANTIC-EMBEDDING-ENGINE` unchanged).
