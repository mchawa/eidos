= SpecDelta: Add 90% Per-File Statement Test Coverage Policy (POL-005)
:toc: left

== Problem Statement
While aggregate statement coverage across `src/eidos/` is 91%, individual modules could dip to 82%–90% without violating a per-file governance policy. Additionally, passing `<repo>/eidos` to `eidos init` created a nested `<repo>/eidos/eidos/` directory.

== Proposed Specification Changes
* Introduce `POL-005-STATEMENT-TEST-COVERAGE` (`eidos/policies/pol-005-statement-test-coverage.adoc`) and `INV-POL-005-STATEMENT-TEST-COVERAGE` bound to `tests/test_validator.py::test_pol_005_statement_test_coverage`.
* Configure `[tool.coverage.run]` and `[tool.coverage.report]` in `pyproject.toml`.
* Update `CMP-CLI-INIT-COMMAND` and `CMP-REPO-INITIALIZER` to normalize explicit `<repo>/eidos` target paths.

== Implementation Plan
1. **Policy & Coverage Configuration**: Author `POL-005-STATEMENT-TEST-COVERAGE` and configure `[tool.coverage]` in `pyproject.toml`.
2. **Initializer Path Normalization**: Normalize explicit `<repo>/eidos` paths in `src/eidos/core/lifecycle/initializer.py` and `src/eidos/cli/init_command.py`.
3. **Per-File >90% Statement Coverage Suite**: Add `test_pol_005_statement_test_coverage` and unit tests in `tests/test_validator.py` and `tests/test_scaffolder.py` so every file under `src/eidos/` exceeds 90% statement coverage.
