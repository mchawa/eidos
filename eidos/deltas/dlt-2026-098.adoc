= SpecDelta DLT-2026-098: Replace PyYAML with Rust-Backed fastyaml-rs (fast_yaml)
:toc: left

== Context & Motivation
`PyYAML` was previously used across Eidos for YAML frontmatter extraction, JSON/YAML schema loading, and specification serialization. Replacing `pyyaml` with `fastyaml-rs` (`import fast_yaml`, powered by Rust `saphyr` and PyO3 `cp310-abi3` wheels) provides ~4.3x faster frontmatter parsing and ~12x faster YAML serialization while shipping prebuilt `abi3` binary wheels across Python 3.11–3.15+.

== Architectural Changes
1. **`CMP-SPEC-PARSER` (`src/eidos/core/spec/parser.py`)**:
   * Introduced `YamlError`, `safe_load_yaml`, and `safe_dump_yaml` backed by `fast_yaml.safe_load`, `fast_yaml.safe_load_all`, and `fast_yaml.safe_dump`.
   * Updated `split_frontmatter_and_body`, `dump_spec_document`, and `extract_frontmatter` to use `safe_load_yaml` and `safe_dump_yaml`.
2. **Unified YAML Helpers Across Consumers**:
   * Replaced `import yaml` across `src/eidos/core/lifecycle/catalog.py`, `src/eidos/core/spec/validator.py`, `src/eidos/plugin/installer.py`, `src/eidos/plugin/validator.py`, `src/eidos/vcs/structural.py`, and tests with `safe_load_yaml`, `safe_dump_yaml`, and `YamlError`.

== Verification & Invariants
* `INV-SPEC-VALIDATION`: Verified via `tests/test_validator.py::test_validate_eidos_specifications`.
