= SpecDelta: Unquoted Git Path Resolution, Container-Level Invariant Verification, Single-Pass Test Cache Loading, and reconcile_specs Graph API Fix
:toc: left

== Problem Statement

`CMP-DRIFT-DETECTOR` (`src/eidos/vcs/diff.py`, `src/eidos/vcs/invariants.py`, and `src/eidos/vcs/drift.py`) contains five defects:

1. **Git C-Style Quoted/Octal Paths (`src/eidos/vcs/diff.py`, lines 255-290 & 309-318)**:
   * `get_git_diff_files` and `get_tracked_files` run `git diff --name-only`, `git status --porcelain`, and `git ls-files` without `-c core.quotePath=false`. Git wraps filenames containing spaces or non-ASCII characters in double quotes with octal escapes (`"src/my file.py"`), breaking path resolution on disk.
2. **Dropped Top-Level Container Invariants (`src/eidos/vcs/invariants.py`, lines 549-555)**:
   * `extract_invariants_and_verify` extracts `components[].invariants` from `tech/container` specs and then sets `inv_list = []`, silently ignoring top-level container `invariants:` (`fm.get("invariants")`) and legacy `c4_internal_components` (which *are* indexed by `sync.py` and rendered by `context.py`).
3. **Redundant Double `os.walk` + SQLite Query on Every `eidos drift` (`src/eidos/vcs/invariants.py`, lines 148-159 & `src/eidos/vcs/drift.py`, lines 477-483)**:
   * `detect_drift` calls `extract_invariants_and_verify` and then `detect_orphan_invariants` without sharing the loaded `_CachedTestFile` map, causing `_load_or_update_test_binding_cache` to walk the entire repository with `os.walk(root)` and query SQLite twice per run.
4. **Unchanged `status: applied` SpecDeltas Treated as Active (`src/eidos/vcs/drift.py`, lines 251-257)**:
   * When a touched delta file has `status == "applied"` and `old_dc == new_dc` (e.g. file mode change or synthetic diff), `if old_dc is not None and new_dc is not None and old_dc != new_dc:` evaluates to `False`, so the already-applied delta is not skipped and wrongly activates Planned Mode.
5. **Runtime `TypeError` in `reconcile_specs` (`src/eidos/vcs/drift.py`, lines 580-588)**:
   * Calls `idx.get_k_hop_neighborhood(cid, max_hops=1)` and reads `n.get("data", {}).get("file_path")`, whereas `ArchitecturalIndex.get_k_hop_neighborhood` takes `max_depth: int = 2` and returns flat entity dictionaries.

== Proposed Specification Changes

1. **Unquoted Git Paths in `src/eidos/vcs/diff.py`**:
   * Pass `-c core.quotePath=false` to Git subprocess calls in `get_git_diff_files` and `get_tracked_files`, and slice `git status --porcelain` lines prior to stripping leading status spaces (`splitlines()` on raw stdout).
2. **Container-Level Invariants & Single-Pass Cache Reuse in `src/eidos/vcs/invariants.py` and `src/eidos/vcs/drift.py`**:
   * Extract top-level `fm.get("invariants", [])` as well as `components` and `c4_internal_components` for `tech/container` specs in `extract_invariants_and_verify`.
   * Allow passing pre-loaded `cached_tests` into `detect_orphan_invariants` so `detect_drift` loads the test binding cache only once per invocation.
3. **Skip Unchanged Applied Deltas & Fix `reconcile_specs` (`src/eidos/vcs/drift.py`)**:
   * Check `if old_dc is not None:` (without requiring `old_dc != new_dc`) when skipping pre-existing `status: applied` deltas.
   * Update `reconcile_specs` to call `idx.get_k_hop_neighborhood(cid, max_depth=1)` and look up neighbor `file_path` via `idx.get_entity(nid)`.
