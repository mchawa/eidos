= SpecDelta: Refine Governance Health Scorecard Ownership Filtering and Public Surface Breakdown
:toc: left

== Problem Statement
Running `eidos index health --json` on Eidos's own repository surfaced two metric precision issues:

1. `src/eidos/_version.py` (an auto-generated, gitignored `hatch-vcs` build file) is reported as the sole entry in `source_ownership.unowned_files` (`107/108 = 99.1%`), creating false unowned-file noise in any `hatch-vcs`, `setuptools-scm`, or codegen repository.
2. `public_surface` combines active C4 Level 3 components (`CMP-*`, where `== Public Surface` is the standard AST-checked section: `47/47`) with C4 Level 2 containers (`CNT-*`, which typically use `== Architectural Boundary` and `== Internal Structure`: `0/7`), artificially capping `public_surface.coverage_pct` at `87.0%`.

== Proposed Specification Changes
* **`CMP-GRAPH-TRAVERSAL-ENGINE` (`src/eidos/core/index/traversal.py`)**:
  * Filter `source_ownership` candidates using Git-tracked / non-ignored and `is_generated_or_vendored` exclusions (falling back cleanly in non-Git test directories) so gitignored build outputs and `linguist-generated` files never appear in `unowned_files`.
  * Compute `public_surface` with explicit component and container fields (`total_components`, `documented_components`, `total_containers`, `documented_containers`, plus backward-compatible `total_entities` and `documented_entities`), basing `public_surface.coverage_pct` on active `CMP-*` components (falling back to `total_entities` only when zero active `CMP-*` components exist).
* **`CMP-CLI-INDEX-COMMANDS` (`src/eidos/cli/index_commands.py`) & `CMP-PORTAL-ASSETS` (`types.ts`, `HomeView.tsx`, `assets/portal/bundle.html.gz`)**:
  * Render `documented_components / total_components` as the primary Public Surface coverage score in `eidos index health` and the Portal Governance Health Scorecard card.
* **`CAP-AGENT-002` (`eidos/domains/agent-intelligence/capabilities/cap-agent-002.adoc`)**:
  * Add and bind `INV-INDEX-HEALTH-GENERATED-AND-COMPONENT-SCOPE` to `tests/test_graph_index.py::test_index_governance_health_excludes_generated_files_and_splits_surface`.
