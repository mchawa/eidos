= SpecDelta: Lossless C4 Component Promotion/Inlining and Word-Bounded Specification Reference & Scalar Mutations
:toc: left

== Problem Statement

`CMP-LIFECYCLE-SCAFFOLDER` (`src/eidos/core/lifecycle/scaffolder.py` and `src/eidos/core/lifecycle/catalog.py`) has four implementation defects affecting C4 component promotion/inlining, reference checks, and in-place YAML scalar updates:

1. **Raw f-String YAML Injection in `promote_component` / `inline_component` (`scaffolder.py`, lines 575-619 & 649-693)**:
   * Both functions interpolate `comp_source` and `comp_resp` into raw YAML via f-strings (`f'source_path: "{comp_source}"'`). When `source_path` is a `list[str]` (permitted by `container.schema.yaml` and `component.schema.yaml`), Python formats the list as a literal string `"['src/a.py', 'src/b.py']"`. Quotes or newlines in `responsibility` or `name` produce invalid YAML.
2. **Silent Loss of `invariants`, `decisions`, and `interfaces` (`scaffolder.py`, lines 575-607 & 649-685)**:
   * `promote_component` only copies `id`, `name`, `responsibility`, and `source_path` to the promoted `tech/component` document, dropping any inline `invariants` or `decisions` (`DEC-*`).
   * `inline_component` deletes the dedicated `CMP-*` file while writing only `id`, `name`, `responsibility`, and `source_path` back into the parent container, permanently discarding component-level `invariants`, `decisions`, and `interfaces`.
3. **Substring False Positives & Symlink Duplication in `find_references_to_spec` (`catalog.py`, lines 243-261)**:
   * Uses raw substring checks (`target_id in content or target_id_lower in content.lower()`) without word boundaries (`\b`), causing `CNT-CORE` to falsely match `CNT-CORE-API` or `DLT-2026-001` to match `DLT-2026-0010` and blocking `eidos spec delete`.
   * Iterates `eidos_dir.rglob("*.adoc")` without skipping `deltas/by-status/` symlinks, reporting duplicate references from symlinked delta views.
4. **Unescaped YAML Scalar Writes in `_set_frontmatter_scalar` (`catalog.py`, lines 89-100)**:
   * Splices `f"{m.group(1)}{value}{m.group(3) or ''}"` directly into raw YAML without quoting or escaping, corrupting frontmatter when `value` contains `:`, `#`, quotes, or newlines.

== Proposed Specification Changes

1. **Lossless YAML Serialization in `promote_component` and `inline_component` (`src/eidos/core/lifecycle/scaffolder.py`)**:
   * Construct promoted `tech/component` frontmatter dictionaries and inline component entries using `yaml.safe_dump(..., sort_keys=False)`, preserving `source_path` (`str` or `list[str]`), `invariants`, `decisions`, `interfaces`, and `quality_attributes` across both promotion and inlining.
2. **Word-Bounded Reference Discovery & Safe Scalar Formatting (`src/eidos/core/lifecycle/catalog.py`)**:
   * Skip symlinked files and `deltas/by-status/` directories in `find_references_to_spec`, and match `target_id` using a case-insensitive word-bounded regular expression (`rf"\b{re.escape(target_id)}\b"`).
   * Format scalar values in `_set_frontmatter_scalar` via `yaml.safe_dump` single-line scalar serialization when the value contains special YAML characters (`:`, `#`, quotes, leading/trailing whitespace).
