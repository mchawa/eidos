= SpecDelta: Portal Docs-Style Reader, De-Carded Views, and Full-Screen Flow Viewer
:toc: left

== Problem Statement
Across the Living Web Portal, users currently navigate walls of cards with 1–2 line truncated excerpts and read specifications inside popup modals that double-box the header, prose, and TOC inside nested cards. In addition, User Flows & Journeys in `DesignView` only offer inline height expansion rather than a true full-screen flow viewer.

== Proposed Specification Changes
1. **Phase 1 — Docs-Style Split Reader & Reader Typography (`UIC-PORTAL-READER`, `SCR-PORTAL-CATALOG`)**:
   - Make `CatalogView` open directly into a 3-pane documentation layout: collapsible left spec tree sidebar, borderless center `SpecReader` reading canvas with breadcrumbs and Prev/Next navigation, and borderless sticky right "On This Page" TOC.
   - Flatten `SpecReader` and `AsciiDocRenderer` default surfaces (eliminating nested cards), deduplicate repeated document titles, and constrain narrative prose blocks (`p`, `ul`, `ol`, `dl`, blockquotes, admonitions) to `90ch` while allowing wide tables, code blocks, and Mermaid diagrams to expand up to `max-w-4xl xl:max-w-5xl`.
2. **Phase 2 — De-Carded Content Views (`SCR-PORTAL-BUSINESS`, `SCR-PORTAL-DELTAS`, `SCR-PORTAL-EXPLORATIONS`, `SCR-PORTAL-MEMORY`)**:
   - Replace dense card grids with clean editorial divided sections, scannable list rows, and a semantic sticky-header responsive Rules table in `BusinessView`.
   - Default `DeltasView` to the chronological Timeline list (retaining Kanban Board toggle).
   - Flatten entity drawers with compact metadata strips and native `<details>` disclosures so full AsciiDoc prose leads immediately, paired with `"Open in Full Reader"` escalation.
3. **Full-Screen Flow & Diagram Expansion (`SCR-PORTAL-DESIGN`, `MermaidDiagram`)**:
   - Add a **"Full Screen"** button on every client and cross-client flow in `DesignView` and in the `MermaidDiagram` toolbar, opening a native `<dialog>` top-layer modal (`showModal()`, `Esc` + click-outside dismissal, `overscroll-behavior: contain`) with full-viewport interactive Mermaid pan/zoom/fit and a toggleable journey steps panel.

== Implementation Plan
1. Update `theme.css`, `AsciiDocRenderer.tsx`, `SpecReader.tsx`, `CatalogView.tsx`, and `App.tsx` (Phase 1).
2. Update `BusinessView.tsx`, `DeltasView.tsx`, `ExplorationsView.tsx`, `MemoryView.tsx`, `MermaidDiagram.tsx`, and `DesignView.tsx` (Phase 2 + Full-Screen Flows).
3. Update Vitest suites, rebuild `assets/portal/bundle.html.gz` via `pnpm build:assets`, add Python invariant test `test_portal_docs_reader_decarded_views_and_flow_fullscreen`, co-evolve living specs, verify and apply `DLT-2026-186`, and run full verification.
