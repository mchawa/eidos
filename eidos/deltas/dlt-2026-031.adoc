= SpecDelta: Enforce Static Invariant Verification Across C4 Level 3 Component Specifications
:toc: left

== Problem Statement

Both `assets/schemas/v1/tech/component.schema.yaml` (lines 96–114) and `src/eidos/core/graph_index.py` (lines 736–751) explicitly support technical `invariants` (`id: INV-*`, `rule`, `test_binding`) on `tech/component` specifications (`eidos/architecture/components/*.adoc`). However, `extract_invariants_and_verify()` in `src/eidos/vcs/drift.py` (lines 541–638) only iterates over `domains/` (`product/capability`) and `policies/` (`product/policy`). As a result:

1. Uncovered or broken `test_binding` declarations on `tech/component` invariants silently bypass `eidos drift` and `POL-002-INVARIANT-TEST-ENFORCEMENT`.
2. Any test function referencing a component-level `INV-*` token is falsely flagged as an `orphan_invariant` by `detect_orphan_invariants()` because the component invariant ID was never collected into `declared_invariants`.

== Architectural & Behavioral Mutations

1. **Component Invariant Extraction (`extract_invariants_and_verify`)**:
   * Scan `eidos/architecture/components/*.adoc` (`doc.doc_type == "tech/component"`) for top-level `invariants` arrays and verify their `test_binding` (`file::func`) via `_verify_ast_invariant_bindings()`.
   * Also inspect inline `components[].invariants` declared inside `eidos/architecture/containers/*.adoc` (`doc.doc_type == "tech/container"`).
2. **Unified Orphan Invariant Resolution (`detect_orphan_invariants`)**:
   * Include all component-declared `INV-*` IDs in the authoritative `declared_invariants` set so tests asserting component invariants are recognized as valid bindings rather than orphans.

== Verification Criteria

* Declaring an invariant `INV-CMP-EXAMPLE-001` in a `tech/component` spec under `eidos/architecture/components/` with a missing or invalid `test_binding` causes `eidos drift` to fail with an `uncovered_invariants` violation.
* Declaring a valid `test_binding: tests/test_foo.py::test_bar` referencing `# INV-CMP-EXAMPLE-001` passes `eidos drift` with zero uncovered and zero orphan invariants.
