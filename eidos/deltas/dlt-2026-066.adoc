= SpecDelta: Parameterized Repository Initialization (--name, --title) and Scoped Empty system.adoc Parser & Validator Exemption
:toc: left

== Problem Statement

1. **Ignored `name` and `title` Parameters in `init_repository` (`src/eidos/core/lifecycle/initializer.py`, lines 10-82)**:
   * `init_repository` accepts `name: str | None`, `title: str | None`, and `with_plugin: bool` (and `eidos init` exposes `--name` and `--title` CLI options in `src/eidos/cli/init_command.py`), but line 31 explicitly discards all three (`_ = (name, title, with_plugin)`) and always writes an empty 0-byte `eidos/system.adoc`.
2. **Global 0-Byte Validation Loophole in `extract_frontmatter` and `SpecValidator._load_or_validate` (`src/eidos/core/spec/parser.py`, lines 16-24 & `src/eidos/core/spec/validator.py`, lines 377-378, 405-406)**:
   * To allow an unedited 0-byte `eidos/system.adoc` to pass `eidos validate` immediately after `eidos init`, `extract_frontmatter` returns synthetic valid `arch/system` frontmatter whenever *any* input string is empty (`if not content.strip(): return {"type": "arch/system", "id": "SYS-UNINITIALIZED", ...}`), and `SpecValidator._load_or_validate` returns `None` whenever `not doc.raw_content.strip()`.
   * As a result, any accidentally truncated 0-byte or whitespace-only `.adoc` file anywhere under `eidos/domains/`, `eidos/architecture/`, `eidos/policies/`, or `eidos/deltas/` silently passes `eidos validate`.

== Proposed Specification Changes

1. **Honor `name` and `title` in `CMP-REPO-INITIALIZER` (`src/eidos/core/lifecycle/initializer.py`)**:
   * When `name` or `title` is passed to `init_repository`, populate `eidos/system.adoc` with valid `arch/system` YAML frontmatter using `yaml.safe_dump` and the normalized `SYS-*` identifier and title; retain the empty `system.adoc` skeleton when neither is specified.
2. **Scope Empty-File Exemption Strictly to `system.adoc` in `CMP-SPEC-PARSER` and `CMP-SPEC-VALIDATOR` (`src/eidos/core/spec/parser.py`, `src/eidos/core/spec/validator.py`)**:
   * In `parse_spec_file(file_path)` (`parser.py`) and `_load_or_validate(file_path)` (`validator.py`), only apply the empty-file `SYS-UNINITIALIZED` exemption when `file_path.name.lower() == "system.adoc"`. For any other 0-byte or whitespace-only `.adoc` file, report a missing frontmatter validation error.
