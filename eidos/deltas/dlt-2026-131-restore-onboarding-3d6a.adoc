= SpecDelta: Restore Onboarding Governance, Harden Skill Installer, and Scope Stop Hooks to Session Edits
:toc: left
:icons: font
:sectnums:

== Problem Statement

Auditing Eidos's dogfooded workspace and `CNT-EIDOS-PLUGIN` (`src/eidos/plugin/`), `CMP-CLI-DOCTOR-HOOKS` (`src/eidos/cli/doctor_hook_commands.py`), and `CMP-DRIFT-DETECTOR` (`src/eidos/vcs/diff.py`) uncovered live onboarding regressions and concrete installer/hook bugs:

1. **Live Dogfooding Regressions Undetected by `validate`, `drift`, and `doctor`**:
   * Commit `429202a` overwrote the root `AGENTS.md` `<!-- eidos:begin agents-md ... -->` ... `<!-- eidos:end agents-md -->` managed block (`src/eidos/plugin/managed_block.py:85-91`) with the 8-byte string `project\n`. Because `classify_changed_files` (`src/eidos/vcs/diff.py:545-578`) classifies `AGENTS.md` as a generic `doc_file` and `doctor_cmd` (`src/eidos/cli/doctor_hook_commands.py:36-185`) never calls `read_managed_block(root / "AGENTS.md", "agents-md")`, all three governance gates reported green while every AI coding assistant lost its Eidos workspace rules.
2. **Silent Stale-Skill Version Lie & Fragile Installer Edge Cases (`src/eidos/plugin/installer.py`)**:
   * **False `"up_to_date"` on non-force upgrade**: `_copy_skills_flat` (`installer.py:249-252`) skips modified `SKILL.md` files when `force=False`, yet `_write_installation_manifest` (`installer.py:189-193`, invoked at `L1023`) unconditionally writes `bundled_ver` into `.eidos-manifest.json`. Consequently, `check_plugin_version_status()` (`version.py`) and `eidos doctor` falsely report `"up_to_date"` while stale skills remain on disk.
   * **YAML comment destruction in `.aider.conf.yml`**: `_update_project_aider_conf` (`installer.py:388-413`) round-trips `.aider.conf.yml` through `safe_load_yaml` + `safe_dump_yaml`, wiping all user comments and formatting.
   * **Symlinked `.agents/skills` aborts `install all` / `update all`**: When `.agents/skills` is a symlink (such as Eidos's own `.agents/skills -> ../assets/plugin_reference/skills`), `dest_skills_root.is_symlink()` raises `FileExistsError` at `installer.py:229`, aborting `install_plugin(ALL)` (`L1405-1413`) and `update_plugin(ALL)` (`L1460-1475`) before remaining targets (`claude`, `aider`, etc.) are processed.
   * **Dangling pointers on `uninstall_plugin`**: `uninstall_plugin` (`installer.py:1240-1263`) deletes `.agents/skills`, `.claude/skills`, or `.aider/skills` while leaving dangling target references inside `AGENTS.md`, `CLAUDE.md` (`@AGENTS.md`), and `.aider.conf.yml` (`read: [AGENTS.md]`).
3. **Stop Hook Infinite Loops, Non-Blocking Cline Hook, & Dirty-Worktree Q&A Hijacking (`src/eidos/plugin/hooks.py`)**:
   * **GitHub Copilot `agentStop` infinite loop**: Copilot passes camelCase `"stopHookActive": true` alongside `"cwd"`. `_detect_hook_client` (`hooks.py:22`) classifies it as `"standard"`, and `_is_retry_or_non_normal_stop` (`hooks.py:49`) checks only snake_case `payload.get("stop_hook_active")`, so the 1-turn circuit-breaker never trips.
   * **Cline `TaskComplete` cannot block completion**: Cline's `TaskComplete` hook (`installer.py:726-736`, `hooks.py:20, 48, 59`) is a post-completion notification rather than a cancellable gate; gating premature task completion in Cline requires `.clinerules/hooks/PreToolUse` targeting `preToolUse.tool == "attempt_completion"` with a retry guard.
   * **Read-only Q&A hijacking on dirty worktrees**: `handle_stop_hook` (`hooks.py:82-135`) runs `detect_drift(uncommitted=True)` unconditionally even when the agent made zero file edits during the turn, trapping conversational Q&A turns whenever the developer already has uncommitted WIP on disk.
4. **Stale Editable Version in `eidos doctor` (`doctor_hook_commands.py`, `src/eidos/__init__.py`)**:
   * Editable installs read a stale generated `_version.py` (`0.21.2.dev2`) when new Git tags (`v0.23.0`) have been created without reinstalling the editable package.

== Proposed Specification Changes

* **Restore Repository Dogfooding & Enforce Onboarding Health (`CMP-CLI-DOCTOR-HOOKS`, `CMP-DRIFT-DETECTOR`, `INV-DOCTOR-ONBOARDING-INTEGRITY`)**:
  1. Re-project the canonical `agents-md` managed block into Eidos's root `AGENTS.md` (`antigravity:.agents/skills`, keeping `AGENTS.md` template `<= 250` words and rendered block `<= 320` words per `INV-PLUGIN-SKILL-SIZE-CEILING`).
  2. Teach `eidos doctor` (`doctor_cmd`) to verify root `AGENTS.md` managed block integrity via `read_managed_block` (unless opted out with `<!-- eidos:agents-md off -->`) and resolve live Git tag versions in editable checkouts (`src/eidos/__init__.py` / `src/eidos/plugin/version.py`).
  3. Update `classify_changed_files` in `src/eidos/vcs/diff.py` (`CMP-DRIFT-DETECTOR`) and drift/doctor checks so wiping a managed `AGENTS.md` block or editing installed `.agents/skills/**/SKILL.md` in an Eidos-enabled repository triggers governance verification instead of silently passing as `doc_files`.
* **Harden `CMP-PLUGIN-INSTALLER` (`INV-PLUGIN-INSTALL-TRUTHFULNESS`)**:
  1. Record `skipped_files` (and actual on-disk SHA-256 digests) in `.eidos-manifest.json` when `_copy_skills_flat(..., force=False)` skips locally modified `SKILL.md` files, and make `check_plugin_version_status()` report `status: "modified"` (not `"up_to_date"`) until reconciled via `eidos plugin install <target> --force`.
  2. Replace destructive YAML re-serialization in `_update_project_aider_conf` (and add `_remove_project_aider_conf`) with comment-preserving text/line editing on `.aider.conf.yml`.
  3. In `_copy_skills_flat`, `install_plugin`, and `update_plugin`, treat a symlinked `dest_skills_root` whose resolved target equals `source_skills_dir.resolve()` (self-hosted Eidos repository) as valid and in-sync, and isolate per-target exceptions in `install all` / `update all` so remaining targets still execute before raising aggregated errors.
  4. Update `uninstall_plugin` to prune the uninstalled target from `AGENTS.md` (`targets=...`, removing the managed block completely when zero targets remain), remove the `claude-import` block from `CLAUDE.md` when uninstalling `claude`, and remove `AGENTS.md` from `.aider.conf.yml` when uninstalling `aider` (if no other Eidos targets remain).
* **Turn-Aware Stop Hooks, Copilot `stopHookActive`, & Cline `PreToolUse` (`CMP-HOOK-RUNNER`, `CMP-HOOK-MANAGER`, `CNT-EIDOS-PLUGIN`, `DEC-PLUGIN-TURN-SCOPED-STOP-GATE`)**:
  1. Check `bool(payload.get("stop_hook_active") or payload.get("stopHookActive"))` in `_is_retry_or_non_normal_stop` and `_detect_hook_client` (`hooks.py`).
  2. Migrate Cline's opt-in `--hooks` wiring from `.clinerules/hooks/TaskComplete` to `.clinerules/hooks/PreToolUse` (`TARGET_HOOK_PATHS["cline"] = ".clinerules/hooks/PreToolUse"`): inspect `payload.get("preToolUse", {}).get("toolName") or payload.get("tool")` and immediately return `{"cancel": False}` when the tool is not `"attempt_completion"`, gating only `attempt_completion` with a 1-turn retry guard.
  3. Implement ephemeral session baseline snapshots in `eidos/.cache/hook_baselines/<session_id>.json` (populated on `SessionStart` / `UserPromptSubmit` or client modified-file metadata, with automatic TTL cleanup) so `handle_stop_hook` immediately allows completion when the current agent session modified zero governed files since turn start.
