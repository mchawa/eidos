= SpecDelta: Word-Bounded Multi-Term Reference Matching, Polyglot Test Classification, Archive Exclusion, and Fail-Loud Graph Checks in DeltaAuditor
:toc: left

== Problem Statement

`AuditEngine` (`CMP-DELTA-AUDITOR` in `src/eidos/core/lifecycle/audit.py`) has five defects when auditing reverse-dependency blast radius for deleted or deprecated entities:

1. **Unbounded Substring Matching (`_scan_and_classify_references`, line 326)**:
   * Line 326 checks `if term in line:` using raw substring containment rather than word-bounded token matching.
   * Auditing `CAP-PROD-001`, `CMP-CLI`, or a short `search_tokens` identifier falsely matches longer identifiers such as `CAP-PROD-0010` or `CMP-CLI-APP`.
2. **Early `break` Skips Co-Occurring Removed Terms on the Same Line (`_scan_and_classify_references`, lines 325-340)**:
   * `for term in target_terms:` ends with `break` after the first matched term on a line. If `term_1` is exempted by a path/pattern rule in `allowed_reasons` while `term_2` on the same line is an unexempted active leak, `term_2` is never inspected.
3. **Compressed `.gz` Bundles Scanned During Deletion Audit (`SKIP_EXTENSIONS`, lines 98-115)**:
   * `SKIP_EXTENSIONS` omits `.gz`, causing `_collect_scannable_files` to read `assets/portal/bundle.html.gz` on every `eidos delta audit`.
4. **Hardcoded `tests/` Prefix in Negative-Test Classification (`_classify_occurrence`, line 420)**:
   * Line 420 checks `if rel_str.startswith("tests/"):`, ignoring `test/` directories and co-located polyglot test files (`src/**/*.test.ts`, `*_test.go`, `*_test.rs`, `*Test.java`, `*Test.kt`) as well as JS/TS/Go/Rust negative assertion patterns (`expect(...).toThrow`, `assert.False`, `#[should_panic]`).
5. **Silent Exception Swallowing on Graph Foreign-Key Check (`_check_graph_integrity`, lines 278-280)**:
   * `_check_graph_integrity` catches `(OSError, RuntimeError)` and `pass`es silently, returning `[]` (`0 graph_violations`) even if the SQLite index failed to open or sync.

== Proposed Specification Changes

1. **Word-Bounded Multi-Term Token Matching & `.gz` Exclusion (`src/eidos/core/lifecycle/audit.py`)**:
   * Add `".gz"` to `SKIP_EXTENSIONS`.
   * Pre-compile word-bounded regexes (`re.compile(rf"(?<![A-Za-z0-9_-]){re.escape(term)}(?![A-Za-z0-9_-])")`) for entity IDs and `re.compile(rf"\b{re.escape(term)}\b")` for general search tokens in `_scan_and_classify_references`, and evaluate all target terms on a line without breaking after the first match.
2. **Polyglot Negative-Test Classification**:
   * Replace `if rel_str.startswith("tests/"):` in `_classify_occurrence` with `is_test_code_path(rel_str)` from `src/eidos/core/index/sync.py`, and expand `negative_patterns` to include polyglot negative assertions (`toThrow`, `rejects`, `should_panic`, `assertFalse`, `assertNil`).
3. **Fail-Loud Graph Foreign-Key Verification**:
   * Surface index errors from `_check_graph_integrity` into `DeltaAuditResult` (`status="ERROR"`, `is_clean=False`, `error_message=...`) rather than silently ignoring them.
