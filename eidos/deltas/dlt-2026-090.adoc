= SpecDelta: Simplify SpecDelta Schema & Engine, AST Fallback Indexer, Context Slicer, and Delta Catalog

== Architectural Summary

1. **Composable-Only SpecDelta Schema (`delta.schema.yaml`)**: Retired the legacy 44-verb `action` enum and 15 `target_*` properties, establishing composable `(operation, target, parent)` as the sole SpecDelta mutation contract across validation, verification, auditing, changelog synthesis, drift detection, index synchronization, and the web portal.
2. **Declarative `eidos delta apply`**: Removed mechanical YAML string-splicing spec execution (`execute_delta_mutations`, `_MutationTransaction`, and `--execute` / `-e`) so `apply_delta` performs declarative post-condition verification, a pre-commit `SpecValidator` check, and atomic `status: applied` transition.
3. **AST-Grep Delegation in `FallbackIndexer`**: Delegated core `ast-grep` languages (`.ts`, `.tsx`, `.js`, `.jsx`, `.rs`, `.go`, `.java`, `.kt`, `.kts`) in `FallbackIndexer` to `AstGrepIndexer()`, keeping regex fallback strictly for secondary languages.
4. **Unified Context Slicing (`CMP-TIERED-CONTEXT-COMPRESSOR`)**: Removed dead `reconcile_specs` and consolidated `src/eidos/core/workspace/context.py` (`CMP-CONTEXT-SLICER`) into `src/eidos/core/index/context.py` (`CMP-TIERED-CONTEXT-COMPRESSOR`).
5. **Flat `eidos/deltas/` Catalog**: Removed `eidos/deltas/by-status/` symlink views and the `eidos delta sync-views` CLI command.
