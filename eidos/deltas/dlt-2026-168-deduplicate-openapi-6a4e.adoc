= SpecDelta: Deduplicate OpenAPI vs rest_http Discovery, Prioritize Service Container Types, and Harden FastAPI Route Scanning
:toc: left

== Problem Statement

Field usage of `eidos spec discover` on multi-service OpenAPI-first FastAPI repositories surfaced three deterministic heuristic defects:

1. **Duplicate OpenAPI / `rest_http` Proposals**: When a container already maps an active `protocol: openapi` contract (or contains a co-located OpenAPI file), `discover_repository_blueprint` still emits a sibling `protocol: rest_http` candidate as `already_mapped: false`, generating false-positive unmapped contract noise.
2. **Web Services Misclassified as `cli`**: `_inspect_manifest_container` checks `[project.scripts]` / `[tool.poetry.scripts]` (and `package.json` `bin`) *before* web service frameworks (`fastapi`, `uvicorn`, `express`, `@nestjs/core`, etc.), misclassifying Python/Node HTTP services that expose launcher entrypoints as `container_type: "cli"`.
3. **FastAPI Route Scanning Blind Spots**: `_extract_polyglot_http_endpoints` in `ast_http.py` and `_has_modern_http_route_hint` / `_is_test_source_filename` in `scaffolder.py` miss valid FastAPI/Starlette services using `@router.api_route(...)`, dotted targets (`@self.router.get(...)`), keyword `path="..."` arguments, f-string/constant concatenation paths, imperative `.add_api_route()`/`.add_route()` or `Route(...)` calls, or non-test filenames ending in lowercase `test` (such as `latest.py` or `attest.py`).

== Proposed Specification Changes

=== 1. OpenAPI ↔ `rest_http` Deduplication & Service-First Container Inference (`CMP-LIFECYCLE-SCAFFOLDER`)

* **Decision Capture (`DEC-CORE-DISCOVER-OPENAPI-DEDUP-AND-SERVICE-PRECEDENCE`)**: Record `DEC-CORE-DISCOVER-OPENAPI-DEDUP-AND-SERVICE-PRECEDENCE` on `CMP-LIFECYCLE-SCAFFOLDER` explaining why `rest_http` candidates inside OpenAPI-covered containers are suppressed (unless already mapped by an active `rest_http` contract) and why web-service frameworks + discovered HTTP routes take precedence over `[project.scripts]` / `bin`.
* **OpenAPI Coverage Resolution (`src/eidos/core/lifecycle/scaffolder.py`)**:
  * While reading live `eidos/` specs, resolve every active `protocol: openapi` `CTR-*` contract's owning `CNT-*`/`CMP-*` entities (via both `CTR-*.provider` and `CNT-*/CMP-*.contracts.provides`) and collect their `source_path` patterns into `openapi_covered_source_patterns`.
  * Also treat any discovered `openapi` file located inside a non-root container's manifest directory as covering that container's `source_path`.
  * Suppress redundant `rest_http` candidates whose `spec_target` / `member_files` are covered by `openapi_covered_source_patterns` (unless already explicitly mapped by an active `rest_http` `CTR-*`).
* **Service-First `container_type` Inference**:
  * In `pyproject.toml`, check web frameworks (`fastapi`, `flask`, `django`, `uvicorn`, `litestar`, `starlette`, `aiohttp`, `sanic`, `tornado`, `gunicorn`, `hypercorn`) *before* `[project.scripts]` / `[tool.poetry.scripts]`.
  * In `package.json`, check backend web frameworks (`express`, `@nestjs/core`, `fastify`, `koa`, `hono`) *before* `bin` (retaining `webapp` first).
  * After scanning HTTP routes, promote any discovered `"cli"` or `"library"` container with non-root `source_path` containing discovered HTTP routes to `"service"`.
* **Pre-Filter & Case-Sensitive Test Filename Filter**:
  * Expand `.py` pre-filter hints in `_has_modern_http_route_hint` to include `.options(`, `.head(`, `.add_api_route(`, `.add_route(`, and `Route(`.
  * Restrict `Test`/`Tests` suffix matching in `_is_test_source_filename` to case-sensitive camelCase `raw_stem.endswith(("Test", "Tests"))` while keeping `_test`/`_tests`/`.test`/`.spec`/`test_*` case-insensitive so files like `latest.py` or `attest.py` are never skipped.

=== 2. Comprehensive FastAPI / Starlette Route Extraction (`CMP-HTTP-TOPOLOGY-LINKER`)

* Update `_extract_polyglot_http_endpoints` in `src/eidos/core/index/ast_http.py` (Python branch) to:
  * Match `@<dotted_obj>.(get|post|put|patch|delete|options|head|route|api_route)(...)`, resolving `router_prefixes` by full target or trailing attribute name.
  * Support keyword `path=...` arguments alongside positional arguments, evaluating expressions through `_eval_url_expr` (literals, f-strings, constants, and `+` concatenations).
  * Support `methods=` specified as lists, tuples, or sets (`[...]`, `(...)`, `{...}`).
  * Extract imperative `<obj>.add_api_route(...)` and `<obj>.add_route(...)` registrations.

=== 3. Capability Invariants (`CAP-PROD-001`)

* Bump `CAP-PROD-001` from `1.19.0` to `1.20.0`, updating `INV-BROWNFIELD-DETERMINISTIC-DISCOVERY` and `INV-BROWNFIELD-REST-CONTROLLER-DISCOVERY` to cover service-first container classification, OpenAPI-vs-`rest_http` deduplication, and expanded FastAPI route discovery.
