= SpecDelta: Gate Hybrid RRF Retrieval on Complete Semantic Embedding Sync
:toc: left

== Problem Statement
`sync_spec_embeddings` in `src/eidos/core/index/semantic.py` commits `spec_embeddings` batch-by-batch so progress is persisted across batches. However, `execute_fts_query` in `src/eidos/core/index/fts_query.py` currently checks only `SELECT 1 FROM spec_embeddings LIMIT 1` to decide whether to activate Hybrid RRF. If an ONNX sync is interrupted mid-run (e.g., Ctrl+C or cancelled background subprocess), `spec_embeddings` holds a partial subset of entities and Hybrid RRF silently boosts embedded specs while demoting unembedded specs.

== Proposed Specification Changes
* **`CMP-SEMANTIC-EMBEDDING-ENGINE` (`src/eidos/core/index/semantic.py`)**:
  * Use the existing SQLite `metadata` key-value table (no `SCHEMA_VERSION` change required) to set `semantic_sync_complete = "0"` before batch encoding when pending entities exist and flip it to `"1"` only after all batches and orphan pruning finish cleanly.
  * Export `is_semantic_index_complete(conn: sqlite3.Connection) -> bool`, returning `False` when `spec_embeddings` is empty, `semantic_sync_complete == "0"`, or embedded coverage drops below an interrupted-sync threshold relative to sliceable entities (while still allowing small 1–4 incremental spec edits that `_refresh_stale_embeddings_for_query` refreshes on the fly).
  * Surface `is_complete` in `get_semantic_index_status`.
* **`CMP-FTS-QUERY-ENGINE` (`src/eidos/core/index/fts_query.py`)**:
  * Gate Hybrid RRF activation in `execute_fts_query` on `is_semantic_index_complete(conn)` (unless an explicit `query_embedding` test override is passed with complete rows), falling back cleanly to deterministic FTS5 BM25 (`provenance: "fts_bm25"`) whenever `spec_embeddings` is incomplete.
* **`CAP-AGENT-001` (`eidos/domains/agent-intelligence/capabilities/agent-adapter.adoc`)**:
  * Add and bind `INV-SEMANTIC-COMPLETE-RRF-GATE` to `tests/test_graph_index.py::test_partial_semantic_embeddings_fall_back_to_bm25`.

== Implementation Plan

2. **FTS Hybrid RRF Gate (`CMP-FTS-QUERY-ENGINE`)**: Gate semantic fusion in `src/eidos/core/index/fts_query.py` on `is_semantic_index_complete(conn)` (`CNT-EIDOS-INDEX` covered via `CMP-FTS-QUERY-ENGINE`).
