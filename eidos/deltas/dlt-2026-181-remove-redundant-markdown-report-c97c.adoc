= SpecDelta: Remove Redundant --markdown Report Flag and summary_markdown Renderer from eidos drift
:toc: left

== Problem Statement
`eidos drift` previously maintained three parallel output renderers: structured `--json`, Rich terminal diagnostics, and a standalone `--markdown FILE` summary table (`DriftCheckResult.summary_markdown` built in `src/eidos/vcs/report.py`). In practice, CI drift checks are invoked by AI coding agents or automated gates that consume `--json` or standard CLI logs—not a bespoke Markdown file—turning `summary_markdown` into ~125 lines of redundant presentation code duplicated across every new drift signal.

== Proposed Specification Changes
* **`CTR-EIDOS-CLI` (`2.0.0`)**: Remove `[--markdown FILE]` / `-m` from `eidos drift` (SemVer major bump for breaking CLI option removal).
* **`CMP-CLI-DRIFT-COMMANDS`**: Remove `markdown_out` from `drift_cmd` and reference `build_drift_remediation`.
* **`CMP-DRIFT-DETECTOR` & `CNT-EIDOS-VCS`**: Replace `build_drift_remediation_and_summary(...) -> tuple[list[str], str]` with `build_drift_remediation(...) -> list[str]`, drop `DriftCheckResult.summary_markdown`, and record `DEC-VCS-DROP-DRIFT-MARKDOWN-REPORT`.
* **`CAP-DRIFT-DETECTION` (`1.18.0`), `INV-DRIFT-READY-TO-APPLY-DELTAS`, `INV-DRIFT-UNTOUCHED-CONSUMERS`**: Scope advisory reporting strictly to JSON and Rich terminal outputs.
* **`CMP-REPO-INITIALIZER`**: Drop `--markdown "$GITHUB_STEP_SUMMARY"` from the scaffolded GitHub Actions CI template so it matches GitLab CI.

== Implementation Plan
1. **CLI & VCS Core**:
   * Remove `markdown_out` (`--markdown`, `-m`) and file writing from `src/eidos/cli/drift_commands.py`.
   * Replace `build_drift_remediation_and_summary` with `build_drift_remediation` in `src/eidos/vcs/report.py` (deleting the Markdown table builder) and remove `summary_markdown` from `DriftCheckResult` in `src/eidos/vcs/drift.py`.
   * Remove `--markdown "$GITHUB_STEP_SUMMARY"` from `_GITHUB_CI_WORKFLOW_TEMPLATE` in `src/eidos/core/lifecycle/initializer.py`.
   * Remove unused `"summary_markdown"` key from `/api/drift` in `src/eidos/portal/server.py` (body-only; no spec mutation) and `summary_markdown?: string;` from `SpecDriftStatus` in `src/eidos/portal/frontend/src/types.ts` (covered by `CMP-PORTAL-ASSETS`).
