= SpecDelta: Add Deterministic Brownfield Discovery Command eidos spec discover
:toc: left

== Problem Statement
When onboarding an existing polyglot repository onto Eidos, engineers and AI agents must manually enumerate deployable projects (`.csproj`, `package.json`, `pyproject.toml`, `go.mod`, `Cargo.toml`, `pom.xml`), locate OpenAPI/`.proto`/GraphQL/AsyncAPI files, and identify which source directories are not yet claimed by any `CNT-*` or `CMP-*` `source_path`.

== Proposed Specification Changes
* **`CMP-LIFECYCLE-SCAFFOLDER` (`src/eidos/core/lifecycle/scaffolder.py`)**: Add 100% deterministic (`POL-004`), read-only `discover_repository_blueprint(repo_root, eidos_dir)` scanning standard build/package manifests, interface contract files, and existing `eidos/` ownership to emit structured container candidates (`suggested_id`, `runtime`, `container_type`, `source_path`, `already_mapped`), contract candidates (`protocol`, `specification_file`), and unowned top-level code roots.
* **`CMP-CLI-SPEC-COMMANDS` (`src/eidos/cli/spec_commands.py`), `CTR-EIDOS-CLI` & `CMP-DOCS-USER-GUIDES`**: Expose `eidos spec discover [--path PATH] [--json]` and update `tests/fixtures/cli_command_tree.json` and `docs/guides/cli.md`.
* **`CNT-EIDOS-PLUGIN` (`assets/plugin_reference/skills/eidos-ops/SKILL.md`) & `CAP-PROD-001`**: Point the brownfield extraction guide to `eidos spec discover --json` and bind `INV-BROWNFIELD-DETERMINISTIC-DISCOVERY`.

== Implementation Plan
1. **Discovery Engine (`CMP-LIFECYCLE-SCAFFOLDER`)**: Implement `discover_repository_blueprint` (`CNT-EIDOS-CORE` covered via `CMP-LIFECYCLE-SCAFFOLDER`), pruning `STANDARD_EXCLUDED_DIRS` and `.NET` `bin/`/`obj/` directories while honoring `INV-ENGINE-GENERICITY`.
2. **CLI & Skill Integration (`CMP-CLI-SPEC-COMMANDS`, `CTR-EIDOS-CLI`, `CNT-EIDOS-PLUGIN`, `CMP-DOCS-USER-GUIDES`)**: Wire `eidos spec discover` in `src/eidos/cli/spec_commands.py` (`CNT-EIDOS-CLI` covered via `CMP-CLI-SPEC-COMMANDS` and `CTR-EIDOS-CLI`), update `tests/fixtures/cli_command_tree.json`, `assets/plugin_reference/skills/eidos-ops/SKILL.md`, and `docs/guides/cli.md`.
3. **Living Specs, Tests & Coverage (`POL-005-STATEMENT-TEST-COVERAGE`)**: Update all declared specs and add `tests/test_scaffolder.py::test_spec_discover_polyglot_brownfield_blueprint` covering `.NET`, Python, TypeScript, Go, Rust, and OpenAPI/Protobuf discovery plus `>90.0%` coverage.
