= SpecDelta: Add Git-Aware Uncommitted and Base Diff Slicing to eidos context
:toc: left

== Problem Statement
Before editing or reviewing a PR, developers and AI agents want the deduplicated architectural guardrails (`CNT-*`, `CMP-*`, `CTR-*`, `CAP-*`, `INV-*`, `DEC-*`, `POL-*`) governing every modified file in the current Git working tree or branch diff. Today, `eidos context` only accepts explicit `-f/--file`, `-c/--component`, or `-t/--task` arguments, forcing extra shell turns to enumerate changed paths via `git status` or `git diff`.

== Proposed Specification Changes
* **`CMP-CLI-CONTEXT-COMMAND` (`src/eidos/cli/context_command.py`) & `CTR-EIDOS-CLI`**: Add `--uncommitted` (`-u`), `--base` (`-b REF`), and `--head REF` (default `HEAD`) to `eidos context`, reusing `CMP-GIT-DIFF-INSPECTOR` (`src/eidos/vcs/diff.py`, read-only reuse; no mutation required) to collect modified code/spec files (respecting monorepo sub-project scoping and fail-closed `--base` ref resolution) and feed them into the existing deduplicated `extract_context` pipeline. Emit a clean empty-diff response (exit code `0`) when zero files changed.
* **`CMP-DOCS-USER-GUIDES` & `CAP-AGENT-001`**: Synchronize `docs/guides/cli.md`, update `tests/fixtures/cli_command_tree.json`, and bind `INV-CONTEXT-GIT-DIFF-SLICING`.

== Implementation Plan
1. **CLI Diff Slicing (`CMP-CLI-CONTEXT-COMMAND`, `CTR-EIDOS-CLI`)**: Wire `--uncommitted`, `--base`, and `--head` in `src/eidos/cli/context_command.py` (`CNT-EIDOS-CLI` covered via `CMP-CLI-CONTEXT-COMMAND` and `CTR-EIDOS-CLI`) reusing `CMP-GIT-DIFF-INSPECTOR` (`get_changed_files`, body-only reuse), and update `tests/fixtures/cli_command_tree.json`.
2. **Docs, Living Specs & Tests (`POL-005-STATEMENT-TEST-COVERAGE`, `INV-DOCS-SYNCHRONIZATION`)**: Update `docs/guides/cli.md`, all declared living specs, and add `tests/test_context.py::test_context_uncommitted_and_base_diff_slicing` covering `--uncommitted`, `--base`, empty working trees, invalid base refs, and `>90.0%` statement coverage.
3. **Verification**: Run `pytest`, `eidos delta verify DLT-2026-152 --json`, `eidos delta apply DLT-2026-152`, and `eidos drift --uncommitted --json`.
