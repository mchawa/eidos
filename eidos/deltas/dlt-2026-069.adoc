= SpecDelta: HTML-Safe </script> JSON Serialization in Static Web Portal Builder
:toc: left

== Problem Statement

`CMP-PORTAL-BUILDER` (`src/eidos/portal/builder.py`, lines 24-28) embeds the serialized portal payload directly into an inline `<script>` block inside `index.html`:

[source,python]
----
script_injection = f"<script>window.__EIDOS_STATIC_DATA__ = {json.dumps(data)};</script>"
html_content = PORTAL_HTML.replace("</head>", f"{script_injection}\n</head>", 1)
----

Because standard `json.dumps(data)` does not escape forward slashes in `</script>`, any living specification or SpecDelta whose AsciiDoc body or frontmatter contains the literal substring `</script>` prematurely closes the `<script>` tag in the generated `index.html`, corrupting the static portal page and enabling DOM injection.

== Proposed Specification Changes

1. **HTML-Safe Inline JSON Escaping in `CMP-PORTAL-BUILDER` (`src/eidos/portal/builder.py`)**:
   * Sanitize the serialized JSON string by replacing `</` with `<\/`, `\u2028` with `\\u2028`, and `\u2029` with `\\u2029` before interpolating into `<script>window.__EIDOS_STATIC_DATA__ = ...;</script>`.

== Verification Plan

* `uv run pytest tests/test_portal.py` — Add a unit test verifying `build_static_portal` produces valid HTML without premature `</script>` termination when a specification body contains `<script>alert(1)</script>`.
