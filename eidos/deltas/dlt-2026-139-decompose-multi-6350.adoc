= SpecDelta: Decompose Multi-Responsibility Modules into Cohesive C4 Components and Acyclic Submodules
:toc: left

== Problem Statement
Rapid feature delivery across specification governance, polyglot AST indexing, static HTTP auto-linking, executable import boundaries, multi-harness Agent Skills, and Git drift verification accumulated distinct architectural responsibilities inside a handful of multi-concern modules and created two C4 Level 3 `source_path` ownership collisions:

1. **Validation Layer Conflation (`CNT-EIDOS-CORE`)**: `src/eidos/core/spec/validator.py` (`3,901` LOC) combines Draft 2020-12 JSON Schema & `x-eidos-ref` graph validation, 6-protocol bidirectional `CTR-*` interface contract parity (`cli_args`, `python_protocol`, `openapi`, `protobuf`, `graphql`, `json_schema`), scoped `== Public Surface` polyglot AST verification, and `import_boundaries` / `ratchet_baseline` evaluation inside one class. Similarly, `src/eidos/core/lifecycle/delta_engine.py` (`1,822` LOC) mixes SpecDelta CRUD/state transitions with Git-baseline `expect:` verification and two-tier archive partitioning.
2. **Knowledge Graph Tangles & Shared-File Collision (`CNT-EIDOS-INDEX`)**: Both `CMP-FTS-QUERY-ENGINE` and `CMP-GRAPH-TRAVERSAL-ENGINE` point to `src/eidos/core/index/query.py` (`1,340` LOC), which also participates in a mutual import cycle with `sync.py` (`3,052` LOC). Meanwhile, `src/eidos/core/index/ast_indexer.py` (`3,827` LOC) mixes 17-language AST extraction with VCS structural/design diff classification and static HTTP route extraction, while `src/eidos/core/index/context.py` (`2,410` LOC) mixes `--file` brace-glob expansion, token-budgeted slice models, and graph retrieval assembly.
3. **Plugin Hook Collision, Opaque VCS Whitebox & Portal Diagram Coupling (`CNT-EIDOS-PLUGIN`, `CNT-EIDOS-VCS`, `CNT-EIDOS-PORTAL`)**: Both `CMP-HOOK-MANAGER` and `CMP-PLUGIN-VALIDATOR` claim `src/eidos/plugin/validator.py` while `835` lines of multi-harness hook wiring and health checks sit inside `src/eidos/plugin/installer.py` (`1,843` LOC); `CNT-EIDOS-VCS` lumps all 5 VCS modules (`3,924` LOC) into a single `CMP-DRIFT-DETECTOR` component; and `src/eidos/portal/generator.py` (`1,626` LOC) couples JSON payload hydration with C4/UX Mermaid diagram compilation.

== Proposed Specification Changes
Apply a **Hybrid C4 Level 3 Decomposition (`DEC-ARCH-MODULAR-COMPONENT-COHESION`)** driven strictly by architectural responsibility rather than arbitrary line-count caps:
