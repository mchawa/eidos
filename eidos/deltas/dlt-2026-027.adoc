= SpecDelta: Strict Static-Only Invariant-to-Test Function Verification
:toc: left

== Problem Statement

Previously, `extract_invariants_and_verify()` in `src/eidos/vcs/drift.py` contained a fallback (`if not matching and tb and (repo_root / tb.split("::")[0]).exists(): matching = [tb_file]`) that marked any invariant as covered if its test file merely existed on disk—even when the `::test_func` did not exist or never mentioned the invariant ID. It also used substring matching (`iid in content`) and did not gate `DriftCheckResult.is_clean` on uncovered invariants.

== Architectural & Behavioral Mutations

1. **Strict Static-Only Verification (No Test Execution)**:
   * Eidos never runs test suites or parses JUnit XML; verification is 100% static and instantaneous.
   * When `test_binding: path/to/test_file.py::test_func` is declared, both the file AND `test_func` must exist in the AST (`list_test_functions`), and `test_func` (including its preceding comments and decorators) must contain the exact word-boundary token `\bINV-...\b`.
2. **Orphan Invariant Detection**:
   * `detect_orphan_invariants()` reports `INV-*` tokens referenced in test functions that do not exist in any capability or policy specification (supporting `# eidos:fixture` opt-out for synthetic test fixtures).
3. **Default Gate Enforcement**:
   * `DriftCheckResult.is_clean` requires zero uncovered invariants and zero orphan invariant references (`eidos drift --warn-only` downgrades to advisory mode).
