= SpecDelta: CLI Spec Document Lifecycle Management and Plugin Multi-Skill Expansion
:toc: left

== Problem Statement
While Eidos already validates specifications, scans components, runs an MCP server, and installs agent plugins, developers and AI agents need first-class CLI commands to scaffold new specifications (capabilities, domains, policies, contracts, components, deltas), safely delete old specifications with reference checking, and transition SpecDeltas from proposed to applied. Furthermore, AI agents require distinct, focused skills for delta authoring, architectural modeling, and invariant testing rather than a single monolithic skill.

== Proposed Specification Changes
1. Expand CTR-EIDOS-CLI contract with:
   - `eidos spec list [--type] [--status]`
   - `eidos spec show <id_or_path>`
   - `eidos spec create <type> <id> --title <title> ...`
   - `eidos spec delete <id_or_path> [--force]`
   - `eidos delta create <id> --title <title> --kind <kind> --motivation <motivation>`
   - `eidos delta list [--status]`
   - `eidos delta apply <id>`
   - `eidos delta delete <id> [--force]`
   - Convenient top-level shortcuts: `eidos create`, `eidos delete`, `eidos list`.
2. Expand Agent Plugin bundle with 4 specialized skills:
   - `skills/eidos/SKILL.md` (Master orchestrator)
   - `skills/eidos-delta/SKILL.md` (SpecDelta mutation authoring & reconciliation)
   - `skills/eidos-architecture/SKILL.md` (Arc42 building blocks & C4 Level 1-3 modeling)
   - `skills/eidos-invariants/SKILL.md` (Policy guardrails & invariant-test traceability)
