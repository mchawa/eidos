= SpecDelta: Remove CLI Shortcuts and Duplicate Aliases, Nest Component Under Spec
:toc: left

== Problem Statement
The Eidos CLI previously exposed root-level convenience shortcuts (`eidos install`, `eidos serve`, `eidos build-site`, `eidos create`, `eidos delete`, `eidos list`, `eidos containers`, `eidos components`, `eidos lint`, `eidos repo-map`, `eidos find-symbol`, `eidos changelog`), intra-group command aliases (`eidos plugin remove`, `eidos plugin upgrade`, `eidos index update`, `eidos portal build-site`, `eidos spec containers`, `eidos spec components`), a top-level `eidos component` group (`list`, `promote`, `inline`), and a redundant `eidos reconcile` / `eidos sync` command. This created multiple overlapping ways to invoke the same operation and cluttered `eidos --help`.

== Proposed Specification Changes
1. **Single Canonical CLI Command Path (`CTR-EIDOS-CLI`, `CNT-EIDOS-CLI`)**:
   - Remove all root-level shortcuts (`install`, `uninstall`, `create`, `delete`, `list`, `containers`, `components`, `lint`, `serve`, `build-site`, `repo-map`, `find-symbol`, `changelog`) and remove `reconcile` / `sync`.
   - Remove intra-group duplicate aliases (`plugin remove`, `plugin upgrade`, `index update`, `portal build-site`, `spec containers`, `spec components`).
   - Nest `component` under `eidos spec` as `eidos spec component` with `promote` and `inline` subcommands (removing `component list`).
2. **Unified Spec & Component Catalog Listing (`CNT-EIDOS-CORE`)**:
   - Enhance `list_specs()` in `src/eidos/core/lifecycle/scaffolder.py` to normalize short/canonical `--type` filters via `VALID_SPEC_TYPES` and include inline C4 Level 3 components (`CMP-*`) declared inside container manifests so `eidos spec list` (and `eidos spec list --type component` / `--type container`) covers all containers and components.
3. **Skills & Documentation Alignment (`CNT-EIDOS-PLUGIN`, `CNT-EIDOS-DOCS`)**:
   - Update bundled and installed Agent Skills (`eidos`, `eidos-ops`, `eidos-plan`, `eidos-spec`) and `docs/` guides to reference only canonical CLI commands.
