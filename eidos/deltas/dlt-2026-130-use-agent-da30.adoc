= SpecDelta: Use Agent Skills Across All Clients and Remove agent-plugins.org Bundles
:toc: left
:icons: font
:sectnums:

== Problem Statement

Eidos previously split its 9 supported AI coding harnesses across two distinct packaging standards:

1. **Dual Packaging Overhead (`.agents/plugins/eidos/` vs. `.agents/skills/`)**:
   * Four targets (`antigravity`, `cursor`, `copilot`, `codex`) installed an `agent-plugins.org v1.0.0` bundle under `.agents/plugins/eidos/` (`plugin.json` + `skills/`), while three targets (`cline`, `kilocode`, `open-code`) installed the exact same 4 skills (`eidos`, `eidos-spec`, `eidos-plan`, `eidos-ops`) under `.agents/skills/<skill>/SKILL.md`.
   * Installing both a target from the first group (e.g., `antigravity` or `cursor`) and a target from the second group (e.g., `cline` or `kilocode`) or running `eidos plugin install all` duplicated all 4 skill directories inside `.agents/` (`.agents/plugins/eidos/skills/` and `.agents/skills/`).
2. **Native `.agents/skills/` & `.agents/hooks.json` Support Across All Cross-Agent Clients**:
   * Google Antigravity, Cursor, GitHub Copilot, OpenAI Codex, Cline, Kilo Code, and OpenCode all natively discover workspace skills at `.agents/skills/<skill>/SKILL.md` (`agentskills.io` format) and read the root `AGENTS.md` instruction block.
   * Furthermore, Google Antigravity natively discovers workspace lifecycle hooks at `.agents/hooks.json` (under top-level named hook key `"eidos-drift-gate": {"Stop": [...]}`), just as Cursor uses `.cursor/hooks.json`, Copilot uses `.github/hooks/hooks.json`, Codex uses `.codex/hooks.json`, Cline uses `.clinerules/hooks/TaskComplete`, and Claude Code uses `.claude/settings.json`.
3. **Unnecessary `plugin.json` and `assets/schemas/agent_plugins/` Artifacts**:
   * Once no client uses `agent-plugins.org` bundles, `assets/plugin_reference/plugin.json` and `assets/schemas/agent_plugins/` (`plugin.schema.json` and `mcp.schema.json`, plus `get_agent_plugins_schemas_dir()`) are dead weight that require manual version synchronization and extra schema plumbing.

== Proposed Specification Changes

* **Unify All 9 Targets on Agent Skills (`CMP-PLUGIN-INSTALLER`, `CNT-EIDOS-PLUGIN`, `CAP-AGENT-001`)**:
  1. **Three Canonical Skill Directories Across 9 Harnesses (`DEC-PLUGIN-SKILLS-ONLY-ALL-TARGETS`)**:
     - **`.agents/skills/<skill>/SKILL.md`** (tracked in `.agents/.eidos-manifest.json` via `_make_agents_skills_adapter`): Shared by 7 targets—`antigravity`, `cursor`, `copilot`, `codex`, `cline`, `kilocode`, and `open-code`. All 7 project `targets=<target>:.agents/skills` in the root `AGENTS.md` managed block.
     - **`.claude/skills/<skill>/SKILL.md`** (tracked in `.claude/.eidos-manifest.json`): Used by `claude`, alongside root `CLAUDE.md` (`@AGENTS.md`) and `AGENTS.md` (`targets=claude:.claude/skills`).
     - **`.aider/skills/<skill>/SKILL.md`** (tracked in `.aider/.eidos-manifest.json`): Used by `aider`, alongside `.aider.conf.yml` (`read: [AGENTS.md]`) and `AGENTS.md` (`targets=aider:.aider/skills`).
  2. **Native Opt-In `--hooks` Lifecycle Wiring Across All 6 Hook-Capable Clients**:
     - `antigravity`: `.agents/hooks.json` (`eidos-drift-gate.Stop` invoking `<launcher> hook`, non-destructively merged and cleaned up via `_antigravity_configure_hooks`, `_update_project_antigravity_hooks`, and `_remove_project_antigravity_hooks`, with `"hooks.json"` included in `SHARED_USER_FILES`).
     - `claude`: `.claude/settings.json` (`hooks.Stop` nested matcher array).
     - `cursor`: `.cursor/hooks.json` (`version: 1`, `hooks.stop` with `loop_limit: 1`).
     - `cline`: `.clinerules/hooks/TaskComplete` (executable `0o755` script).
     - `copilot`: `.github/hooks/hooks.json` (`version: 1`, `hooks.agentStop`).
     - `codex`: `.codex/hooks.json` (`hooks.Stop`).
  3. **Retire `.agents/plugins/eidos/` Projection & Version Fallbacks**:
     - Update `locate_plugin_bundle()` in `src/eidos/plugin/installer.py` to check `(ref_dir / "skills").is_dir()` instead of `(ref_dir / "plugin.json").exists()`.
     - Remove `_make_project_adapter`, `_copy_plugin_tree`, `_rewrite_hook_command_for_target_root`, and legacy `.claude/plugins/eidos` cleanup from `src/eidos/plugin/installer.py`.
     - Update `get_bundled_plugin_version()` in `src/eidos/plugin/version.py` to return `normalize_to_semver(__version__)` directly without reading `plugin.json`.
     - Update `_resolve_installed_plugin_manifest()` and `check_plugin_version_status()` in `src/eidos/plugin/version.py` to resolve installed state strictly from `.agents/.eidos-manifest.json`, `.claude/.eidos-manifest.json`, and `.aider/.eidos-manifest.json`.
* **Remove `plugin.json` and `assets/schemas/agent_plugins/` & Validate Bundled Skills Directly (`CMP-ASSET-LOCATOR`, `CMP-PLUGIN-VALIDATOR`, `CMP-HOOK-MANAGER`, `CMP-CLI-PLUGIN-COMMANDS`, `CMP-CLI-APP`)**:
  - Delete `assets/plugin_reference/plugin.json` and `assets/schemas/agent_plugins/` (`plugin.schema.json`, `mcp.schema.json`).
  - Remove `get_agent_plugins_schemas_dir()` from `src/eidos/core/workspace/assets.py`.
  - Update `validate_plugin_package()` in `src/eidos/plugin/validator.py` (`CMP-PLUGIN-VALIDATOR` / `CMP-HOOK-MANAGER`) to validate the bundled skill package (`skills/*/SKILL.md` frontmatter against `agentskills.io` rules, skill directory naming parity, SemVer 2.0.0 version normalization of `get_bundled_plugin_version()`, and `hooks.json` Stop-scoped CLI-native hook rules) without `plugin.json` or `plugin.schema.json`.
  - Update `eidos plugin validate` and `eidos plugin info` in `src/eidos/cli/plugin_commands.py` (`CMP-CLI-PLUGIN-COMMANDS`) to display and validate the bundled Agent Skills package metadata (`eidos-agent-skills`, `get_bundled_plugin_version()`, skills list, and `hooks.json` Stop hook events), and update `eidos info` in `src/eidos/cli/main.py` (`CMP-CLI-APP`) to display `agentskills.io (Agent Skills)` and all 9 targets.
* **Update Contracts & Documentation (`CTR-EIDOS-CLI`, `CNT-EIDOS-CORE`, `CMP-DOCS-USER-GUIDES`, `CMP-DOCS-CORE-CONCEPTS`)**:
  - Bump `CTR-EIDOS-CLI` to `1.4.0` and `CAP-AGENT-001` to `1.14.0`.
  - Update `docs/guides/agent-plugin.md`, `docs/guides/cli.md`, `docs/concepts/how-eidos-works.md`, `README.md`, `docs/index.md`, and `assets/plugin_reference/README.md` to reflect `.agents/skills/` and `.agents/hooks.json`.
