= SpecDelta: Consolidate Agent Lifecycle Hooks into a Single Stateless Stop Hook
:toc: left

== Problem Statement
`src/eidos/plugin/hooks.py` grew to **820 lines** due to four layers of accumulated redundancy and over-engineering:

1. **100% Redundant `lint` vs. `drift` Hook Split**:
   * `assets/plugin_reference/hooks.json` defined two separate hooks (`eidos-doc-linter` -> `eidos hook lint` and `eidos-drift-gate` -> `eidos hook drift`), both running on `Stop`.
   * However, `detect_drift()` in `src/eidos/vcs/drift.py` **already runs `SpecValidator().validate_directory()`** and verifies all `INV-*` test bindings in addition to checking code-to-spec drift—making `eidos hook lint` on `Stop` completely redundant.
2. **Custom 100-Line SQLite Snapshot Cache (`last_stop_validation`)**:
   * Because both `eidos hook lint` and `eidos hook drift` ran back-to-back on `Stop`, `hooks.py` implemented `_compute_adoc_snapshot`, `_save_stop_validation_snapshot`, and `_load_stop_validation_snapshot` (~100 lines of raw `sqlite3` queries against `eidos/.cache/index.db`) just to pass `ValidationReport` from the first `Stop` hook to the second `Stop` hook.
3. **Per-Edit `PreToolUse` & `PostToolUse` Interception + In-Memory Edit Simulation (~250 lines)**:
   * `eidos-doc-linter` intercepted every `write_to_file` / `replace_file_content` tool call (`PreToolUse` and `PostToolUse`), probing ~15 payload keys across 6 harnesses and simulating find-and-replace chunk edits in memory (`_extract_tool_edit_request`).
4. **Stateful SHA-256 Fingerprinting & `stop-gate.json` (~200 lines)**:
   * To avoid trapping agents in infinite loops when returning `"decision": "continue"`, `hooks.py` hashed all tracked files (`_hash_files`), built tagged item sets, evaluated subset inclusion (`cur_items.issubset(prev_items)`), and persisted TTL/session-scoped state in `eidos/.cache/stop-gate.json`.

== Proposed Specification Changes

=== 1. Single Hook in `hooks.json` & Single CLI Command `eidos hook [--path PATH]` (`CMP-HOOK-MANAGER`, `CMP-CLI-APP`, `CMP-CLI-DOCTOR-HOOKS`, `CTR-EIDOS-CLI`)
* **`assets/plugin_reference/hooks.json`**:
  * Remove `eidos-doc-linter` and all `PreToolUse` / `PostToolUse` matchers.
  * Retain a single `Stop` hook under `eidos-drift-gate`:
    ```json
    {
      "eidos-drift-gate": {
        "Stop": [
          {
            "type": "command",
            "command": "eidos hook",
            "timeout": 30
          }
        ]
      }
    }
    ```
* **`eidos hook [--path PATH]` (`src/eidos/cli/doctor_hook_commands.py`, `src/eidos/cli/main.py`)**:
  * Replace the `hook_app` subcommand group (`eidos hook lint` / `eidos hook drift` and `--event`) with a single flat command `eidos hook [--path PATH]` mounted in `PANEL_PLUGINS`.

=== 2. Stateless ~65-Line Implementation in `src/eidos/plugin/hooks.py` (`CMP-HOOK-RUNNER`, `CMP-DRIFT-DETECTOR`)
* Delete all `sqlite3` snapshot caching (`_compute_adoc_snapshot`, `_save_stop_validation_snapshot`, `_load_stop_validation_snapshot`), all `hashlib` / `stop-gate.json` state (`_check_and_record_stop_gate`, `_clear_stop_gate`, `_hash_files`, `_extract_session_id`), all `PreToolUse` / `PostToolUse` simulation (`_extract_tool_edit_request`, `is_eidos_doc`, `_validate_doc_content`, `handle_lint_pre_tool_use`, `handle_lint_post_tool_use`), and `_infer_event`.
* Remove the unused `validation_report` parameter from `detect_drift()` in `src/eidos/vcs/drift.py`.
* Implement `handle_stop_hook(payload, workspace_root)` and `execute_hook(path, repo_root, stdin_data)`:
  * Run `detect_drift(repo_root=ws_root, eidos_dir=eidos_dir, uncommitted=True)` once.
  * When `drift_res.is_clean` is `True`: return `{"decision": "allow"}`.
  * When validation errors, broken references, uncovered/orphan invariants, or code-to-spec drift are detected (or on internal exception): return `{"decision": "allow", "systemMessage": "⚠️ [Eidos Stop Hook] ..."}` with the concise cause and remediation summary.

=== 3. Capability Invariant & Documentation Consolidation (`CAP-AGENT-001`, `CNT-EIDOS-DOCS`)
* In `CAP-AGENT-001` (`eidos/domains/agent-intelligence/capabilities/agent-adapter.adoc`, version `1.6.0`):
  * Update `INV-AGENT-DRIFT-HOOK` to cover the unified stateless `Stop` hook (`eidos hook`).
  * Remove the 3 redundant hook invariants (`INV-AGENT-LINT-HOOK`, `INV-HOOK-BLOCK-ONCE`, `INV-HOOK-FAIL-LOUD`).
* Update `docs/guides/agent-plugin.md`, `docs/guides/cli.md`, `docs/concepts/how-eidos-works.md`, and `assets/plugin_reference/README.md`.
