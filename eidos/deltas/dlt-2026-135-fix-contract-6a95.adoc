= SpecDelta: Fix Contract and Public Surface Parity, YAML and Workspace Edge Cases, and SpecDelta Lifecycle Verification
:toc: left
:icons: font
:sectnums:

== Problem Statement

Deep inspection of `CNT-EIDOS-CORE` (`src/eidos/core/`), `CMP-CLI-CONTEXT-COMMAND`, and `CMP-TIERED-CONTEXT-COMPRESSOR` surfaced parser, validator, workspace, and SpecDelta lifecycle bugs:

1. **Contract & `== Public Surface` Parity False Positives / False Passes (`src/eidos/core/spec/validator.py`)**:
   * **gRPC / Protobuf (`L2334-2397`)**: `(?:`|\b)(?:rpc|service)\s+([A-Za-z_][A-Za-z0-9_]*)\b` matches plain English words (`"service layer"`, `"rpc retries"`), while `protocol: protobuf` ignores `message` and `enum` definitions completely.
   * **OpenAPI routes (`L2268-2285`)**: Forward route matching lacks a left boundary (`` `GET /v2/users` `` false-passes undocumented `/users`), while reverse route matching flags any backticked slash path (`` `/etc/eidos/config` ``) as an undocumented endpoint.
   * **`== Public Surface` AST parity (`L2552-2590`)**: Stops at the first `:` of Rust/C++ `::` (`crate::parser::parse()` looks up `crate`; `RenderGraph::DoesNotExist()` false-passes if `RenderGraph` exists), skips generics (`parse<T>()`, `def first[T]()`) and multi-keyword headers (`pub fn`, `export async function`, `export class`, Go `func (s *Server) Start()`), and pools `defined_classes` and `defined_methods` flatly across all files so `ClassA.method_from_ClassB` false-passes.
   * **`cli_args` parity (`L1406-1663`)**: Importing helpers from `typer` without instantiating `typer.Typer()` hits `if not typer_app_vars: return` (`L1447`), skipping Click/argparse checks; `add_typer(sub_mod.app, name="sub")` (`L1619, 1663`) initializes an empty `subcommands_by_group["sub"] = set()` without resolving `sub_mod.app`.
2. **YAML Frontmatter Surgery, Parser Edge Cases & Entity Path Collisions (`catalog.py`, `parser.py`, `models.py`)**:
   * `_set_frontmatter_scalar` (`src/eidos/core/lifecycle/catalog.py:110-152`) regex-replaces raw lines without tracking YAML scalar context, corrupting multiline quoted strings containing `status:` at column 0.
   * `safe_load_yaml` (`src/eidos/core/spec/parser.py:33-40`) rejects single-document YAML files ending with a trailing `---` marker (`safe_load_all` yields `[doc, None]`), and `parse_spec_file` (`L117-119`) raises uncaught `UnicodeDecodeError` (`ValueError`), crashing `load_project()`.
   * `infer_entity_type_from_path` (`src/eidos/core/spec/models.py:80-101`) checks `resolve_entity_prefix_meta(stem_upper)` before parent directories, misclassifying `eidos/architecture/components/flow-engine.adoc` (`CMP-FLOW-ENGINE`) as `('FLOW-', 'design/flow', 'FLOW-ENGINE')`.
3. **SpecDelta Lifecycle, Archive Data Loss, Audit Schema Mismatch, Changelog & Scaffolder Bugs (`src/eidos/core/lifecycle/`)**:
   * `generate_collision_free_delta_id` (`delta_engine.py:248-310`) ignores `slug_suffix` (`_ = slug_suffix`) and allocates sequence numbers from local files only; when branch collisions occur (`DLT-2026-119-*`), `find_spec_by_id_or_path` (`catalog.py:219-224`) returns `None` (`"not found"`) instead of reporting ambiguity, while `eidos delta delete DLT-2026` dangerously matches if only one `2026` delta is unarchived.
   * Empty `mutations: []` (`delta_engine.py:1150-1152`) verifies vacuously as `True` on `verify` and `apply`.
   * Shallow clones (`fetch-depth: 1`) fall back to `HEAD` in `_compute_fallback_revs` (`delta_engine.py:515-605`), falsely failing `cur_sha == base_sha` (`UNMODIFIED`), while Windows `core.autocrlf=true` (`LF` in `git show` vs `CRLF` in `read_bytes()`) false-passes untouched files.
   * `expect:` is ignored on `remove`/`deprecate` (`delta_engine.py:942-969`), `{"technical.components": null}` fails on deleted dotted keys (`L837`), and `test_binding` is listed in `_PROSE_EXPECT_FIELDS` (`L642`), substring-matching `test_a` against `test_a_other`.
   * `archive_explorations` (`delta_engine.py:1306-1352`) uses `([^=\n][^\n]+)` to capture at most **one line** of Hypothesis and Findings (and `""` before `===`) before `p.unlink()` permanently deletes the exploration.
   * `audit.py:583-615` reads `tombstone.allowed_reasons[].pattern`, which `assets/schemas/v1/delta/delta.schema.yaml:204-216` forbids via `additionalProperties: false`.
   * `changelog.py` (`L147, 353, 408`) matches `status: applied` inside prose code blocks, drops colliding `short_id` siblings, and hardcodes `"All notable changes to Eidos are documented in this file."` into external user repositories; `scaffolder.py` (`L109-287`) injects nonexistent `PER-USER`, `DOM-CORE`, `CNT-CORE`, and `DS-CORE` IDs.
4. **Workspace Filtering & Brace-Glob Blind Spots (`src/eidos/core/workspace/project.py`)**:
   * `STANDARD_EXCLUDED_DIRS` (`project.py:437`) drops Git-tracked files whose path contains `target`, `build`, `site`, `out`, `dist`, or `vendor` (e.g. `src/compiler/target/x86.rs` or `packages/site/src/App.tsx`); `_is_inside_plugin_or_assets` (`L108-118`) checks `".agents"` on absolute `path.parts` (breaking repos cloned under `~/.agents/...`); `discover_nested_subproject_roots` (`L146-162`) runs uncached `os.walk` ignoring `.gitignore`; and `{a,b}` brace globs fail in `_glob_to_anchored_regex` (`project.py:605-652`), `_resolve_source_path` (`validator.py:844`), and `context_command.py:58`.

== Proposed Specification Changes

* **Accurate Multi-Protocol Contract & `== Public Surface` Parity (`CMP-SPEC-VALIDATOR`, `INV-SPEC-GRAPH-INTEGRITY`)**:
  1. Require backticks for gRPC `rpc`/`service` prose extraction and validate `message`/`enum` symbols for `protocol: protobuf`; anchor OpenAPI forward route regexes on the left and require HTTP method verbs (or route-table context) for reverse route checks; parse `::`, `<T>`/`[T]`, multi-keyword modifiers, Go receivers, and per-class method maps (`dict[str, set[str]]`) in `== Public Surface`; keep Click/argparse active alongside `typer` utility imports and resolve imported `add_typer(sub_mod.app, name=...)` AST targets.
* **Resilient YAML/UTF-8 Parsing, Parent-First Path Inference & Brace-Glob Workspace Discovery (`CMP-SPEC-PARSER`, `CMP-DOMAIN-MODELS`, `CMP-PROJECT-RESOLVER`, `CMP-CLI-CONTEXT-COMMAND`, `CMP-TIERED-CONTEXT-COMPRESSOR`)**:
  1. Strip trailing `None` documents in `safe_load_yaml`, catch `UnicodeDecodeError` into `SpecDocument.parse_errors`, check canonical parent directories ahead of stem prefixes in `infer_entity_type_from_path`, preserve `git ls-files` tracked paths in `project.py`, evaluate `.agents` relative to `repo_root`, cache `.gitignore`-filtered `discover_nested_subproject_roots`, and expand `{a,b}` brace globs across `project.py`, `validator.py`, `context.py`, and brace-aware `-f` splitting in `context_command.py`.
* **Hardened SpecDelta Lifecycle, Lossless Exploration Archiving, Schema-Aligned Tombstones & Generic Scaffolder/Changelog (`CMP-DELTA-ENGINE`, `CMP-LIFECYCLE-SCAFFOLDER`, `CMP-DELTA-AUDITOR`, `CMP-CHANGELOG-GENERATOR`, `CNT-EIDOS-CORE`)**:
  1. Parse YAML structure safely in `_set_frontmatter_scalar`, raise explicit ambiguity errors and reject bare `DLT-YYYY` prefixes in `find_spec_by_id_or_path`, consult Git branch refs + `slug_suffix` in `generate_collision_free_delta_id`, reject empty `mutations: []` on `verify`/`apply`, normalize CRLF digests and handle shallow clones in `delta_engine.py`, evaluate `expect:` on `remove`/`deprecate` with `null` key deletion and exact `test_binding` comparison, preserve full multi-line sections in `archive_explorations`, allow `tombstone.allowed_reasons[].pattern` in `delta.schema.yaml`, verify frontmatter `status: applied` + dynamic `SYS-*` project titles in `changelog.py`, and populate valid catalog references in `scaffolder.py`.
