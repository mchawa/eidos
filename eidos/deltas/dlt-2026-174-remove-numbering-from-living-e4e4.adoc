= SpecDelta: Remove Numbering from Living Specification IDs and Align Semantic Naming Conventions
:toc: left

== Problem Statement
Living specifications across `eidos/` mixed representative semantic names (`CNT-*`, `CMP-*`, `CTR-*`, `DOM-*`, `PER-*`, `DS-*`, `UIC-*`, `CLT-*`, `SCR-*`, `FLOW-*`) with arbitrary numeric identifiers and filenames (`SYS-EIDOS-001`, `ARCH-EIDOS-001`, `CAP-*-00N`, `cap-agent-002.adoc`, `POL-00N-*`, `POL-001-*.adoc`..`pol-005-*.adoc`, `INV-POL-00N-*`, `DEC-POL-002-*`). Bundled v1 schemas, `create_spec` filename generation, `_synthesize_example_value`, CLI help text, bundled Agent Skills, and user documentation also recommended numbered living-spec patterns (`CAP-<DOMAIN>-<NUMBER>`, `POL-<NUMBER>-<NAME>`, `*-EXAMPLE-001`).

== Proposed Specification Changes
* **Living Specs (`eidos/`)**:
  * Rename `SYS-EIDOS-001` -> `SYS-EIDOS` (`eidos/system.adoc`) and `ARCH-EIDOS-001` -> `ARCH-EIDOS` (`eidos/architecture/system-architecture.adoc`).
  * Rename all 8 capability IDs (`CAP-AGENT-001` -> `CAP-AGENT-ADAPTER`, `CAP-AGENT-002` / `cap-agent-002.adoc` -> `CAP-AST-CODE-GRAPH` / `ast-code-graph.adoc`, `CAP-EXP-001` -> `CAP-LIVING-WEB-PORTAL`, `CAP-EXP-002` -> `CAP-MULTI-DESIGN-SYSTEMS`, `CAP-PROD-001` -> `CAP-LIVING-SPEC-ENGINE`, `CAP-PROD-002` -> `CAP-SPEC-DELTA-MUTATIONS`, `CAP-PROD-003` -> `CAP-EXPLORATION-DISCOVERY`, `CAP-VCS-001` -> `CAP-DRIFT-DETECTION`).
  * Rename all 5 policy IDs, filenames, invariants, and embedded policy decision (`POL-001-GIT-SOURCE-OF-TRUTH` -> `POL-GIT-SOURCE-OF-TRUTH` / `git-source-of-truth.adoc`, `POL-002-INVARIANT-TEST-ENFORCEMENT` -> `POL-INVARIANT-TEST-ENFORCEMENT` / `invariant-test-enforcement.adoc` + `DEC-POL-STATIC-TRACEABILITY-BOUNDARY`, `POL-003-CONTINUOUS-DOCUMENTATION-SYNC` -> `POL-CONTINUOUS-DOCUMENTATION-SYNC` / `continuous-documentation-sync.adoc`, `POL-004-ZERO-AI-CALL-DEPENDENCY` -> `POL-ZERO-AI-CALL-DEPENDENCY` / `zero-ai-call-dependency.adoc`, `POL-005-STATEMENT-TEST-COVERAGE` -> `POL-STATEMENT-TEST-COVERAGE` / `statement-test-coverage.adoc`) and their `INV-POL-*` IDs.
  * Keep chronological `EXP-2026-*` explorations, `DLT-2026-*` SpecDeltas, and historical applied/archived `eidos/deltas/` files unchanged.
* **Eidos Conventions (`assets/schemas/v1/`, `CMP-LIFECYCLE-SCAFFOLDER`, `CMP-CLI-SPEC-COMMANDS`, `CNT-EIDOS-PLUGIN`, `CNT-EIDOS-DOCS`)**:
  * Update v1 schema `id` descriptions to recommend non-numbered semantic conventions (`SYS-<NAME>`, `ARCH-<NAME>`, `CAP-<NAME>`, `POL-<NAME>`) and remove Eidos-self `(POL-001)` parentheticals from generic schema descriptions.
  * Update `create_spec` in `src/eidos/core/lifecycle/scaffolder.py` to strip redundant type prefixes (`cap-`, `pol-`, `cnt-`, `ctr-`, `per-`) when the remaining stem is non-numeric, and update `_synthesize_example_value` to synthesize non-numbered `<PREFIX>EXAMPLE` IDs for living specs (retaining `DLT-2026-001`, `EXP-2026-001`, and `MEM-EXAMPLE-A1B2`).
  * Align `eidos spec create` help examples (`src/eidos/cli/spec_commands.py` + `tests/fixtures/cli_command_tree.json`), bundled skills (`assets/plugin_reference/skills/`), docs (`docs/`), `README.md`, and `.github/workflows/ci.yml`.
