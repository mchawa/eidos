= SpecDelta: Core Module Decomposition, Build-Time Portal Asset Bundling, CI Pinning, and Progressive Eidos Lite Profile
:toc: left

== Problem Statement
1. **Monolithic Modules & Logic Duplication**:
   - Core subsystems have grown into multi-thousand-line modules mixing persistence, domain logic, and presentation: `graph_index.py` (2,587 LOC), `drift.py` (2,085 LOC), `installer.py` (1,414 LOC), `ast_indexer.py` (1,061 LOC), and `delta_engine.py` (1,028 LOC).
   - `ContextSlice.to_markdown` is duplicated across `src/eidos/core/workspace/context.py` and `src/eidos/core/index/graph_index.py`, and `installer.py` repeats ~10 near-identical per-agent install/uninstall branches.
2. **Unused Pydantic Dependency & Unfactored Schema Blocks**:
   - `pydantic>=2.7.0` is declared as a core dependency in `pyproject.toml` but never imported in `src/eidos/`, while `SpecDocument.frontmatter` remains an untyped `dict[str, Any]`.
   - The `decisions:` schema definition is duplicated across 5 YAML schema files in `assets/schemas/v1/`.
3. **4.7 MB Generated Portal String in Git & Unpinned CI**:
   - `src/eidos/portal/assets.py` commits a 4.7 MB minified JS/HTML string directly into Git, and `.github/workflows/ci.yml` neither runs frontend `vitest` suites nor uses `uv sync --frozen`, allowing `ruff` version drift (`SIM117`, `I001`) on `main`.
   - `.agents/plugins/eidos/` duplicates `assets/plugin_reference/` as tracked files rather than a symlink or build artifact.
4. **High Onboarding Taxonomy Weight**:
   - With 18 ID prefixes, 16 document types, and 47 delta actions, small and medium repositories face steep initial ceremony.

== Proposed Specification & Engine Changes
1. **Modular Package Decomposition & Declarative Installer Registry**:
   - Split `graph_index.py` and `drift.py` into focused internal submodules while preserving public imports, and refactor `installer.py` to use a declarative `TargetAdapter` table.
2. **Typed Frontmatter Models & Shared Schema `$defs`**:
   - Validate parsed frontmatter into typed Pydantic models in `CMP-DOMAIN-MODELS` and factor shared schema definitions (`decisions`, `invariants`) into reusable `$defs`.
3. **Build-Time Portal Bundling & Locked CI**:
   - Generate `src/eidos/portal/assets.py` via a Hatch build hook during wheel/sdist build, add a frontend `pnpm test` (`vitest`) step and `--frozen` lock enforcement to `.github/workflows/ci.yml`, and fix all `ruff` lint violations.
4. **Progressive "Eidos Lite" Profile & Delta Compaction**:
   - Add an `eidos init --lite` mode scaffolding only the essential baseline (`system.adoc`, `containers/`, `capabilities/` with `INV-*`) and provide delta archiving once applied deltas are compiled into `CHANGELOG.md`.
