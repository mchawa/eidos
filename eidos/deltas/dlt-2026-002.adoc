= SpecDelta: Relocate Schemas and Plugin Reference to Assets Directory
:toc: left

== Problem Statement
Previously, JSON and YAML schemas (`src/eidos/schemas/`) as well as a duplicate copy of the plugin reference (`src/eidos/plugin_bundle/`) were stored directly inside the Python source tree (`src/eidos/`). This cluttered Python source code with non-code assets and created redundant, potentially divergent plugin copies.

== Proposed Specification Changes
1. Relocate all JSON and YAML schemas from `src/eidos/schemas/` to root `assets/schemas/`.
2. Relocate the canonical Eidos Agent Plugin reference from `src/eidos/plugin_bundle/` to root `assets/plugin_reference/`.
3. Introduce `src/eidos/core/assets.py` providing unified runtime asset location across development checkouts and installed wheels.
4. Configure Hatchling wheel target in `pyproject.toml` with `force-include` to package `assets/` into `eidos/assets/` during distribution.
5. Update `CMP-EIDOS-ENGINE` architecture manifest to document `AssetLocator` internal building block.
