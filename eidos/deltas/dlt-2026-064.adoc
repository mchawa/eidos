= SpecDelta: Validate Design System W3C DTCG Token Manifests and Acyclic Inheritance in SpecValidator
:toc: left

== Problem Statement

`CMP-DESIGN-ENGINE` (`src/eidos/core/lifecycle/design_engine.py`, lines 33-75) scaffolds `design/system` (`DS-*`) specifications with `tokens: {spec_format: w3c_design_tokens, manifest: tokens.json}` and optional `inheritance: {extends: DS-*}`.

However, `SpecValidator` (`src/eidos/core/spec/validator.py`) currently performs no validation on the referenced `tokens.manifest` file or the `inheritance.extends` graph:

1. **Missing or Malformed `tokens.json` Uncaught**: If `tokens.manifest` points to a missing file, invalid JSON, or non-DTCG objects lacking `$value`, `eidos validate` still passes.
2. **Circular `inheritance.extends` Chains Uncaught**: If `DS-BRAND-A` extends `DS-BRAND-B` and `DS-BRAND-B` extends `DS-BRAND-A`, `eidos validate` does not report a cycle error.

== Proposed Specification Changes

1. **W3C DTCG Manifest & Inheritance Validation in `CMP-SPEC-VALIDATOR` (`src/eidos/core/spec/validator.py`)**:
   * For every active `design/system` document:
     ** Resolve `tokens.manifest` relative to `doc.file_path.parent` (and `repo_root` / `root_dir`). Report a broken reference in `report.broken_references` if the manifest file does not exist on disk.
     ** Parse the manifest JSON and verify that when `tokens.spec_format == "w3c_design_tokens"`, every leaf token object defines a `$value` property (recording schema errors in `report.schema_errors[doc.file_path]` if malformed).
     ** Traverse `inheritance.extends` across `design/system` documents and report a broken reference / cycle error if any `DS-*` inheritance chain contains a cycle.

* `uv run eidos validate eidos && uv run eidos drift --uncommitted --json`
