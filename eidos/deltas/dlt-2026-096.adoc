= SpecDelta: Retire FallbackIndexer Regex Fallback in Favor of Unified AstGrepIndexer and AST Import Extraction
:toc: left

== Problem Statement
1. `ast-grep-py>=0.50.0` is a required core dependency of Eidos, yet `src/eidos/core/index/ast_indexer.py` retained a legacy 700-LOC `FallbackIndexer` regex engine, a separate Python `stdlib ast` dual path, `is_ast_grep_available()` / `AST_GREP_AVAILABLE` flags, and regex-based `extract_imports()` patterns that matched fake imports inside docstrings and comments.
2. `src/eidos/plugin/version.py` rejected PEP 440 `.devN` / pre-release versions against strict 3-part SemVer and fell back to `0.2.0`, while `assets/plugin_reference/plugin.json` remained at `0.8.0`.

== Proposed Specification Changes
* **Unified `AstGrepIndexer` (`CNT-EIDOS-INDEX`, `CAP-AGENT-002`, `CAP-VCS-001`)**: Route all 17 supported languages (including Python `.py`, C/C++ `.c`/`.cpp`/`.h`/`.hpp`, C# `.cs`, Ruby `.rb`, PHP `.php`, Swift `.swift`, and `.vue`/`.svelte` `<script>` blocks) through `SgRoot` in `AstGrepIndexer`. Replace regex `extract_imports` with syntax-tree import extraction, slice declaration headers up to `body.range().start`, handle Rust lifetime single quotes in `_find_body_brace_outside_parens`, and remove `FallbackIndexer`, `stdlib ast`, `AST_GREP_AVAILABLE`, and `is_ast_grep_available()`.
* **PEP 440 SemVer Normalization (`CNT-EIDOS-PLUGIN`)**: Add `normalize_to_semver()` in `src/eidos/plugin/version.py` and synchronize `assets/plugin_reference/plugin.json` to `0.12.0`.
