= SpecDelta: Pluggable Contract Protocol Verifier Registry for Multi-Protocol CTR-* Specifications
:toc: left

== Problem Statement

`assets/schemas/v1/tech/contract.schema.yaml` defines seven supported interface contract protocols for `CTR-*` documents: `rest_openapi`, `grpc_proto`, `graphql`, `asyncapi_event`, `cli_args`, `python_protocol`, and `json_schema`.

However, `SpecValidator._validate_source_and_contract_paths` (`src/eidos/core/spec/validator.py`, lines 892-903) and `_verify_cli_contract_commands` (lines 904-1055) only verify contract-to-code parity when:

* `protocol == "cli_args"`,
* `specification_file` ends in `.py`, and
* `"typer" in source.lower()`.

For every other protocol (`python_protocol`, `rest_openapi`, `json_schema`, `grpc_proto`, `graphql`, `asyncapi_event`), `eidos validate` only checks that `specification_file` exists on disk. An OpenAPI specification, Protobuf definition, JSON Schema, or Python `Protocol` class can diverge from its owning `CTR-*` document without triggering any validation error.

== Proposed Specification Changes

1. **Pluggable Protocol Verifier Registry in `CMP-SPEC-VALIDATOR` (`src/eidos/core/spec/validator.py`)**:
   * Replace the hardcoded `elif str(fm.get("protocol", "")).strip().lower() == "cli_args"` branch in `_validate_source_and_contract_paths` with a protocol verifier dispatch table (`_CONTRACT_PROTOCOL_VERIFIERS`) keyed by normalized `protocol`:
     ** `cli_args`: Existing AST-verified Typer command parity verifier (`_verify_cli_contract_commands`).
     ** `python_protocol`: Use `ASTCodeIndexer` / `ast` to verify that the Python `Protocol` or `ABC` classes and public method names declared in `specification_file` are documented in the `CTR-*` specification.
     ** `rest_openapi` / `json_schema`: Parse the referenced YAML/JSON specification file and verify structural validity plus parity of declared endpoint paths (`paths:` in OpenAPI) or top-level schema `$id` / `title` / required properties against the `CTR-*` body/frontmatter.
     ** `grpc_proto` / `graphql`: Verify that `service` and `rpc` declarations (for `.proto`) or root `type Query` / `type Mutation` definitions (for `.graphql` / `.gql`) in `specification_file` are documented in the `CTR-*` specification.

== Verification Plan
