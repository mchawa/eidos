= SpecDelta: Fix Component Spec Scaffolding, Add Client/Flow Scaffolding, and Enforce Safe YAML Serialization
:toc: left

== Problem Statement

1. **Broken `component` Scaffolding**: In `src/eidos/core/scaffolder.py` (lines 159–160 and 341–351), both `"component"` and `"tech/component"` map to `canonical_key = "container"`, generating a `type: tech/container` file in `eidos/architecture/containers/` instead of a `type: tech/component` file in `eidos/architecture/components/`.
2. **Missing `client` and `flow` Scaffolders**: `design/client` (`CLT-*`) and `design/flow` (`FLOW-*`) have schemas in `assets/schemas/v1/design/` and validation rules in `validator.py`, but are missing from `VALID_SPEC_TYPES` and `create_spec()` in `scaffolder.py`.
3. **Unsafe f-String YAML Interpolation**: `create_spec()` constructs YAML frontmatter via Python f-strings (`title: "{title}"`, `motivation: "{motivation}"`). Any title or motivation containing double quotes (`"`), colons, or newlines produces invalid YAML or risks YAML injection.
4. **Stale Co-Location References**: `assets/schemas/v1/tech/container.schema.yaml` (lines 42–43) still instructs users to create co-located component specs in `src/` (e.g., `src/eidos/core/validator.adoc`), contradicting `INV-COMPONENT-CENTRALIZATION-MANDATE` enforced by `validator.py` (lines 361–375).

== Architectural & Behavioral Mutations

1. **Dedicated `tech/component`, `design/client`, and `design/flow` Templates**:
   * Route `"component"` and `"tech/component"` to `eidos/architecture/components/<slug>.adoc` with `type: tech/component`, `schema: schemas/v1/tech/component.schema.yaml`, and required `container: CNT-*` affinity.
   * Add `"client"` / `"design/client"` (`eidos/design/clients/<slug>/client.adoc`) and `"flow"` / `"design/flow"` (`eidos/design/flows/<slug>.adoc` or client flow path) to `VALID_SPEC_TYPES` and `create_spec()`.
2. **Deterministic `yaml.safe_dump` Frontmatter Serialization**:
   * Build frontmatter as structured Python `dict` objects and serialize via `yaml.safe_dump(frontmatter, sort_keys=False, allow_unicode=True)` before wrapping in `---\n...\n---` delimiters.
3. **Schema & Validator Centralization Alignment**:
   * Update `container.schema.yaml` descriptions and `validator.py` comments to reference `eidos/architecture/components/*.adoc` exclusively.

== Verification Criteria

* `eidos spec create component CMP-TEST-001 --title ' Quote: "Test" ' --container CNT-EIDOS-CORE` creates `eidos/architecture/components/cmp-test-001.adoc` and passes `eidos validate` cleanly.
* `eidos spec create client CLT-WEB --title "Web App"` and `eidos spec create flow FLOW-LOGIN --title "Login Flow"` generate schema-valid specifications.
