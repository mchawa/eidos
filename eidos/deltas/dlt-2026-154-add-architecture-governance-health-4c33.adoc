= SpecDelta: Add Architecture Governance Health Scorecard to Index CLI and Portal
:toc: left

== Problem Statement
While `eidos index status` reports SQLite table counts and `eidos validate` checks individual rules, teams lack a single deterministic governance health scorecard showing what fraction of their codebase is actually covered by living specs (source file ownership `%`, `== Public Surface` adoption, verified `CTR-*` contracts, invariant-backed capabilities, advisory warnings, and `ratchet_baseline` debt).

== Proposed Specification Changes
* **`CMP-GRAPH-TRAVERSAL-ENGINE` (`src/eidos/core/index/traversal.py`) & `ArchitecturalIndex`**: Compute deterministic governance metrics directly from the synced SQLite knowledge graph (`entities`, `indexed_files`, `symbol_mappings`, `code_couplings`) and validation report.
* **`CMP-CLI-INDEX-COMMANDS` (`src/eidos/cli/index_commands.py`), `CTR-EIDOS-CLI` & `CMP-DOCS-USER-GUIDES`**: Expose `eidos index health [--path PATH] [--json]`, update `tests/fixtures/cli_command_tree.json` and `docs/guides/cli.md`.
* **`CMP-PORTAL-GENERATOR` (`src/eidos/portal/generator.py`) & `CMP-PORTAL-ASSETS`**: Export `governance_health` in the portal data graph and render a clean scorecard card on the Portal Home view.
* **`CAP-AGENT-002`**: Add and bind `INV-INDEX-GOVERNANCE-HEALTH-SCORECARD`.

== Implementation Plan
1. **Health Metrics Query & Facade (`CMP-GRAPH-TRAVERSAL-ENGINE`, `CMP-GRAPH-STORAGE`)**: Implement `compute_governance_health` in `src/eidos/core/index/traversal.py` and expose `get_governance_health` on `ArchitecturalIndex` in `src/eidos/core/index/graph_index.py` (`CNT-EIDOS-INDEX` covered via `CMP-GRAPH-TRAVERSAL-ENGINE` and `CMP-GRAPH-STORAGE`).
2. **CLI & Portal Surfacing (`CMP-CLI-INDEX-COMMANDS`, `CTR-EIDOS-CLI`, `CMP-PORTAL-GENERATOR`, `CMP-PORTAL-ASSETS`, `SCR-PORTAL-HOME`)**: Add `eidos index health` in `src/eidos/cli/index_commands.py`, include `governance_health` in `src/eidos/portal/generator.py`, render in `src/eidos/portal/frontend/src/views/HomeView.tsx`, update `eidos/design/clients/web-portal/screens/portal-home.adoc`, rebuild `assets/portal/bundle.html.gz`, and update `tests/fixtures/cli_command_tree.json`.
3. **Docs, Living Specs & Tests (`POL-005-STATEMENT-TEST-COVERAGE`, `INV-DOCS-SYNCHRONIZATION`)**: Update `docs/guides/cli.md`, all declared specs, and add `tests/test_graph_index.py::test_index_governance_health_scorecard_cli_and_portal`.
