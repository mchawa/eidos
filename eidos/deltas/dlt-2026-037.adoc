= SpecDelta: Consolidate 14 Fragmented Agent Skills into 4 Cohesive Workflow Skills
:toc: left

== Problem Statement

Currently, `assets/plugin_reference/skills/` defines 14 separate skills (`eidos`, `eidos-architecture`, `eidos-context`, `eidos-delta`, `eidos-design`, `eidos-drift`, `eidos-explore`, `eidos-extract`, `eidos-init`, `eidos-invariants`, `eidos-portal`, `eidos-product`, `eidos-reconcile`, `eidos-review`). In practice:
1. **System Prompt Bloat**: Every host IDE injects all 14 skill names and descriptions into every conversation's system prompt.
2. **Multi-Hop Context Thrashing**: A single engineering task in Planned Mode forces the agent to read 4–5 separate `SKILL.md` files sequentially (`eidos` -> `eidos-context` -> `eidos-delta` -> `eidos-architecture` -> `eidos-invariants` -> `eidos-drift`), repeating overlapping governance rules (`NO ADRs`, `POL-001`–`POL-004`, CLI syntax) in each file.

== Architectural & Behavioral Mutations

=== 1. Four Cohesive Workflow Skills (`assets/plugin_reference/skills/`)
* **`eidos` (Core Orchestrator, Context, Drift & Reconcile)**: Master workflow router (Direct vs. Planned Mode), token-budgeted context slicing (`eidos context`), continuous drift detection (`eidos drift`), and Direct Mode git-diff reconciliation (`eidos reconcile`). Absorbs `eidos-context`, `eidos-drift`, and `eidos-reconcile`.
* **`eidos-spec` (Living Specification & Invariant Authoring)**: Unified authoring reference for Product (`DOM-*`, `CAP-*`, `PER-*`), C4 Architecture (`CNT-*`, `CMP-*`, `CTR-*`, embedded `decisions` from `DLT-2026-036`), Multi-Design Systems (`DS-*`, `CLT-*`, `SCR-*`, `UIC-*`, `FLOW-*`), and Policies/Invariants (`POL-*`, `INV-*` with `file::func` test bindings). Absorbs `eidos-product`, `eidos-architecture`, `eidos-design`, and `eidos-invariants`.
* **`eidos-plan` (Explorations, SpecDeltas & Architectural Review)**: Technical discovery spikes (`EXP-*`), SpecDelta mutation lifecycle (`DLT-*`, `create`, `verify`, `audit`, `apply`, `changelog`), and Staff Systems Architect 5-dimension review checklists. Absorbs `eidos-explore`, `eidos-delta`, and `eidos-review`.
* **`eidos-ops` (Bootstrap, Brownfield Extraction & Web Portal)**: Repository initialization (`eidos init`), systematic reverse-engineering of existing codebases into living specs, and Living Web Portal operations (`eidos serve`, `eidos build-site`). Absorbs `eidos-init`, `eidos-extract`, and `eidos-portal`.
* All 4 `SKILL.md` files must strictly adhere to `INV-ENGINE-GENERICITY` (zero hardcoded Eidos-self entity IDs or author filesystem paths).

=== 2. Automated Legacy Skill Cleanup & Template Updates (`CMP-PLUGIN-INSTALLER` in `src/eidos/plugin/installer.py`)
* Define `RETIRED_EIDOS_SKILLS` for the 13 retired skill directory names (`eidos-architecture`, `eidos-context`, `eidos-delta`, `eidos-design`, `eidos-drift`, `eidos-explore`, `eidos-extract`, `eidos-init`, `eidos-invariants`, `eidos-portal`, `eidos-product`, `eidos-reconcile`, `eidos-review`).
* Update `_copy_plugin_tree()` and `_copy_skills_flat()` so `install_plugin()` and `update_plugin()` automatically remove retired skill directories from `.agents/plugins/eidos/skills/`, `.claude/plugins/eidos/skills/`, `.claude/skills/`, `.cursor/skills/`, `.github/plugin/skills/`, `.github/skills/`, `.cline/plugins/eidos/skills/`, `.cline/skills/`, `.opencode/plugins/eidos/skills/`, `.opencode/skills/`, `.codex/skills/`, and `.aider/skills/`.
* Update `_remove_skills_flat()` so `uninstall_plugin()` removes both the 4 active skills and any remaining `RETIRED_EIDOS_SKILLS` directories.
* Update `_write_aider_conventions()`, `_write_copilot_instructions()`, and `InstallResult.message` strings to reference the 4 consolidated skills.

=== 3. Documentation & Test Suite Synchronization (`CNT-EIDOS-DOCS`, `tests/`)
* Update `docs/guides/agent-plugin.md` and `docs/concepts/architectural-index.md` to document the 4 consolidated skills.
* Update `tests/test_docs_sync.py`, `tests/test_scaffolder.py::test_all_skills_in_bundle`, and `tests/test_plugin.py` to verify the 4 consolidated skills and test that `update_plugin()` prunes legacy skill directories.

== Coordination & Sequencing

== Verification Criteria

* `assets/plugin_reference/skills/` contains exactly the 4 consolidated skills (`eidos`, `eidos-spec`, `eidos-plan`, `eidos-ops`) and passes `eidos plugin validate` and `test_engine_genericity_zero_self_references` (`INV-ENGINE-GENERICITY`).
* Running `eidos plugin update` (or `install_plugin`) in a workspace containing the legacy 14 skills cleanly removes the 13 retired skill directories across both plugin-tree and flat skill targets while preserving unrelated user skills.
* `tests/test_docs_sync.py`, `tests/test_plugin.py`, and `tests/test_scaffolder.py` pass (`INV-DOCS-SYNCHRONIZATION`).
* `eidos validate eidos && eidos drift --uncommitted` exits 0.
