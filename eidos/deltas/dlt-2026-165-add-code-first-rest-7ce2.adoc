= SpecDelta: Add Code-First REST Controller Discovery to eidos spec discover
:toc: left

== Problem Statement
Many production services define HTTP endpoints code-first (ASP.NET Core `[ApiController]` / Minimal APIs, FastAPI `@app.get`/`APIRouter`, NestJS `@Controller`, Express/Hono routers, Spring `@RestController`) without committing a static OpenAPI YAML/JSON file. Currently `discover_repository_blueprint` (`eidos spec discover`) discovers schema-first contracts (`openapi`, `asyncapi`, `protobuf`, `graphql`, `json_rpc_stdio`) but misses code-first REST controller roots, forcing onboarding teams to manually hunt for `rest_http` `specification_file` targets.

== Proposed Specification Changes
* **`CMP-LIFECYCLE-SCAFFOLDER` (`src/eidos/core/lifecycle/scaffolder.py`)**:
  * During `discover_repository_blueprint(repo_root, eidos_dir)`, inspect non-test polyglot source files (`.cs`, `.py`, `.ts`, `.js`, `.java`, `.kt`, `.go`) via `CMP-HTTP-TOPOLOGY-LINKER` (`extract_http_endpoints_with_metadata`, respecting `ARCH-EIDOS-001` `core` tier boundaries) and group files with `>= 1` discovered modern HTTP route by their enclosing controller/router directory (or single file when standalone).
  * Emit deterministic `protocol: "rest_http"` entries in `blueprint["contracts"]` carrying `suggested_id` (`CTR-*-HTTP`), `protocol: "rest_http"`, `specification_file` (directory or file path), `route_count`, and `already_mapped` (matching active `CTR-*` `specification_file` paths/globs), skipping test roots and directories already covered by a discovered `rest_http` contract.
  * Honor `DEC-CORE-MODERN-REST-PARITY-ONLY` (zero legacy SOAP/WCF or .NET Framework Web API 2 heuristics).
* **`CTR-EIDOS-CLI` (`eidos/architecture/contracts/cli.adoc`) & `CMP-DOCS-USER-GUIDES` (`docs/guides/cli.md`)**:
  * Document code-first `rest_http` controller root detection under `eidos spec discover`.
* **`CAP-PROD-001` (`eidos/domains/spec-engine/capabilities/living-spec-engine.adoc`)**:
  * Add and bind `INV-BROWNFIELD-REST-CONTROLLER-DISCOVERY` to `tests/test_scaffolder.py::test_spec_discover_code_first_rest_http_controllers`.

== Implementation Plan
1. **Code-First REST Discovery (`CMP-LIFECYCLE-SCAFFOLDER`)**: Extend `discover_repository_blueprint` in `src/eidos/core/lifecycle/scaffolder.py` (`CNT-EIDOS-CORE` covered via `CMP-LIFECYCLE-SCAFFOLDER`) to reuse `extract_http_endpoints_with_metadata` from `CMP-HTTP-TOPOLOGY-LINKER` (`src/eidos/core/index/ast_http.py`, read-only caller; no mutation needed) and emit grouped `rest_http` contract candidates. Note: `src/eidos/cli/spec_commands.py` already renders all `blueprint["contracts"]` rows (`CNT-EIDOS-CLI` unchanged).
