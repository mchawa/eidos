= SpecDelta: Add Earlier SpecDelta Authoring Guardrails for Changelog Hygiene and Duplicate Decision Hints
:toc: left

== Problem Statement
Dogfooding Planned Mode across multi-delta features exposed two avoidable late-feedback authoring pitfalls:
1. **Changelog AsciiDoc link leakage**: Including a raw AsciiDoc filename inside a SpecDelta's `intent.motivation` passes `eidos validate` and `eidos delta apply`, only to fail `INV-DELTA-CHANGELOG-GENERATION` later when `ChangelogGenerator` compiles `CHANGELOG.md`.
2. **Cryptic duplicate `DEC-*` collisions**: Recording a planned `DEC-*` inside both a SpecDelta's top-level `decisions:` block and a target container's `mutations[].expect.frontmatter.decisions.id` triggers a global duplicate `DEC-*` error once the container is updated, without immediately flagging the conflict during `eidos delta verify` or hinting that planned decisions belong strictly on the owning `CNT-*`/`CMP-*` spec.

== Proposed Specification Changes
* **`CMP-CHANGELOG-GENERATOR` (`src/eidos/core/lifecycle/changelog.py`)**: Deterministically sanitize raw AsciiDoc path extensions in rendered SpecDelta changelog motivation lines while preserving clean backticked entity badges.
* **`CMP-DELTA-ENGINE` (`src/eidos/core/lifecycle/delta_verifier.py`) & `CMP-SPEC-VALIDATOR` (`src/eidos/core/spec/validator.py`)**: Detect overlapping `DEC-*` IDs declared in both `DLT-*.decisions` and `mutations[].expect.frontmatter.decisions.id` in `verify_delta_mutations` and enrich `SpecValidator` duplicate `DEC-*` diagnostics involving a `delta/mutation` with a clear remediation hint.
* **`CAP-PROD-002`**: Add and bind `INV-DELTA-AUTHORING-GUARDRAILS`.

== Implementation Plan
1. **Changelog Sanitization (`CMP-CHANGELOG-GENERATOR`)**: Sanitize raw AsciiDoc file references in `src/eidos/core/lifecycle/changelog.py` (`CNT-EIDOS-CORE` covered via `CMP-CHANGELOG-GENERATOR`, `CMP-DELTA-ENGINE`, and `CMP-SPEC-VALIDATOR`).
2. **Duplicate `DEC-*` Authoring Hints (`CMP-DELTA-ENGINE`, `CMP-SPEC-VALIDATOR`)**: Add overlap detection in `src/eidos/core/lifecycle/delta_verifier.py` and targeted remediation messaging in `src/eidos/core/spec/validator.py`.
3. **Living Specs, Tests & Coverage (`POL-005-STATEMENT-TEST-COVERAGE`)**: Update all declared living specs and add `tests/test_delta_engine.py::test_delta_authoring_guardrails_changelog_hygiene_and_duplicate_dec_hint`.
4. **Verification**: Run `pytest`, `eidos delta verify DLT-2026-150 --json`, `eidos delta apply DLT-2026-150`, and `eidos drift --uncommitted --json`.
