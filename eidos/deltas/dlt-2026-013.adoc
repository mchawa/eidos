= SpecDelta: Remove Deprecated PRCheckResult Backwards Compatibility Alias
:toc: left

== 1. Problem Statement
In earlier iterations of the VCS drift governance engine, the result data structure for pull request drift checks was named `PRCheckResult`. When the engine was unified around `DriftCheckResult` to provide a consolidated model for both local workspace drift detection (`eidos drift`) and CI/CD PR verification (`check_pr_drift`), a backwards compatibility alias was preserved:

[source,python]
----
# Backwards compatibility alias
PRCheckResult = DriftCheckResult
----

This alias is exported in `src/eidos/vcs/drift.py` and re-exported via `src/eidos/vcs/__init__.py`.

An audit of the codebase confirms:
* All CLI commands (`eidos drift`, `eidos reconcile`) use `DriftCheckResult` directly.
* All MCP tools (`eidos_detect_drift`) use `DriftCheckResult` directly.
* All automated tests in `tests/test_drift.py` verify `DriftCheckResult` attributes without referencing `PRCheckResult`.
* No living specifications or interface contracts depend on `PRCheckResult`.

Retaining this obsolete alias creates dead code, introduces cognitive ambiguity for developers and autonomous agents inspecting the `eidos.vcs` exports, and provides no continued architectural value.

== 2. Proposed Specification & Code Mutations

=== 2.1 Component Mutation: `CMP-EIDOS-CORE`
1. **`src/eidos/vcs/drift.py`**:
   - Delete the assignment `PRCheckResult = DriftCheckResult` (and associated comment).
2. **`src/eidos/vcs/__init__.py`**:
   - Remove `PRCheckResult` from the imported symbols from `eidos.vcs.drift`.
   - Remove `"PRCheckResult"` from the `__all__` exported symbols list.

=== 2.2 Capability Synchronization: `CAP-VCS-001`
- Confirm that `CAP-VCS-001` (Git-Native Drift Detection & GitHub/GitLab Bridge) specifies `DriftCheckResult` as the canonical return contract for drift analysis.

== 3. Blast Radius & Invariant Verification
* **Component Blast Radius:** `CMP-EIDOS-CORE` (`src/eidos/vcs/drift.py`, `src/eidos/vcs/__init__.py`).
* **Persona Impact:** `PER-SOFTWARE-ARCHITECT`, `PER-SOFTWARE-ENGINEER`, `PER-AUTONOMOUS-AGENT` benefit from a clean, unambiguous public API surface.
* **Invariants to Enforce:**
  - `INV-DRIFT-DETECTION-ACCURACY`: Run `tests/test_drift.py` to confirm that drift detection, pull request gate evaluation, and classification continue to function with 100% test pass rate.
  - `INV-SPEC-VALIDATION`: Run `eidos validate eidos` to ensure all living specifications conform to their schemas.
