= SpecDelta: Add Team Memory CLI, Sanitizer, Dedup & eidos-memory Skill (Phase 3)
:toc: left

== Problem Statement

Phases 1 and 2 (`DLT-2026-169`, `DLT-2026-170`) established the `agent/memory` (`MEM-*`) schema, validation/drift isolation, unified SQLite indexing, `HEAD`-keyed `memory_freshness_cache`, and secondary `eidos context` attachment. However, developers and AI coding agents have no CLI workflow to create, list, search, inspect, re-verify, archive, audit, or promote team memories—nor a bundled skill instructing agents when to save automatically, disclose the `MEM-*` file in their replies, avoid personal preferences, and promote proven lessons into formal specs.

== Proposed Specification Changes

* **Team Memory Lifecycle Engine (`CMP-MEMORY-ENGINE`, `CNT-EIDOS-CORE`, `CAP-PROD-001`)**:
  ** Add `src/eidos/core/lifecycle/memory_engine.py` under new disjoint component `CMP-MEMORY-ENGINE`.
  ** Implement word-boundary collision-resistant `generate_memory_id` (`MEM-<SLUG>-<4HEX>` with on-disk re-roll across active and archive dirs), zero-warning `sanitize_memory_asciidoc_body` (Markdown code fences, `include::` neutralization, `---` dividers, ATX/AsciiDoc heading demotion, safe nested bullet normalization), calibrated overlap detection (`detect_memory_overlaps`: BM25 `13.5`/`26.0` and pre-computed `spec_embeddings` Harrier `0.56`/`0.59` without ever re-embedding the corpus on the fly), standalone + embedded `DEC-*`/`INV-*`/`POL-*` `resolve_promotion_target`, and CRUD/audit functions (`add_memory`, `list_memories`, `search_memories`, `show_memory`, `verify_memory`, `archive_memory`, `promote_memory`, `audit_memories`).
  ** Record `DEC-CORE-MEMORY-ENGINE-SANITIZER-AND-OVERLAP` in `CNT-EIDOS-CORE` and bind `INV-MEMORY-LIFECYCLE-AND-SANITIZER` on `CAP-PROD-001`.
* **Team Memory CLI (`CMP-CLI-MEMORY-COMMANDS`, `CMP-CLI-APP`, `CNT-EIDOS-CLI`, `CTR-EIDOS-CLI`)**:
  ** Add `src/eidos/cli/memory_commands.py` (`memory_app`) and mount under `PANEL_KNOWLEDGE` in `src/eidos/cli/main.py`.
  ** Expose 8 subcommands: `add`, `list`, `search`, `show`, `verify`, `archive`, `audit` (strictly non-blocking exit code `0`), and `promote`, all supporting Rich tables/panels and `--json`.
  ** Bump `CTR-EIDOS-CLI` to `1.9.0`.
* **5th Bundled Agent Skill & `AGENTS.md` Trigger (`CNT-EIDOS-PLUGIN`, `CMP-PLUGIN-INSTALLER`, `CAP-AGENT-001`)**:
  ** Add `assets/plugin_reference/skills/eidos-memory/SKILL.md` (`<= 450`-word ceiling), register `"eidos-memory"` in `ACTIVE_EIDOS_SKILLS` (`src/eidos/plugin/installer.py`), add a 1-line `eidos-memory` companion pointer in `assets/plugin_reference/skills/eidos/SKILL.md` (tightening filler words to stay `<= 2,050` words), and add the concise team-memory capture/disclosure trigger to `assets/plugin_reference/agents-md/block.md` (`<= 250` template / `<= 320` rendered words).
  ** Record `DEC-PLUGIN-DEDICATED-MEMORY-SKILL` in `CNT-EIDOS-PLUGIN` and bind `INV-MEMORY-CLI-AND-SKILL-PARITY` on `CAP-AGENT-001`.
* **Documentation Sync (`CMP-DOCS-USER-GUIDES`, `CNT-EIDOS-DOCS` parent unchanged)**:
  ** Document `eidos memory` in `docs/guides/cli.md` and the 5th `eidos-memory` skill across `docs/guides/agent-plugin.md` and `assets/plugin_reference/README.md`.
