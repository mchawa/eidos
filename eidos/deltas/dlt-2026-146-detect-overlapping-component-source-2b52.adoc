= SpecDelta: Detect Overlapping Component Source Paths and ASP.NET Core Base Controller Inheritance
:toc: left

== Problem Statement
1. **Overlapping `CMP-*.source_path` declarations**: While Eidos tests its own components for disjointness (`INV-CORE-MODULAR-COMPONENT-COHESION`), `eidos validate` does not warn external/brownfield repos when two active `CMP-*` specs declare overlapping directories or files, silently distorting AST ownership and `consumes_api` edges.
2. **Cross-file ASP.NET Core base controller inheritance**: Many modern `.NET` APIs define a shared base class (e.g., `abstract class BaseApiController : ControllerBase` with `[Route("api/v1/[controller]")]` and `[Authorize]`) in one file and derive controllers (`OrdersController : BaseApiController`) in other files. Single-file extraction misses the inherited route prefix and authorization state.

== Proposed Specification Changes
* **`CMP-ARCHITECTURE-BOUNDARY-VALIDATOR` (`src/eidos/core/spec/surface_validator.py`) & `CMP-SPEC-VALIDATOR` (`src/eidos/core/spec/validator.py`)**: Map resolved AST code files per active `CMP-*` during validation and emit a non-blocking `ValidationReport.warnings` entry whenever two active components claim overlapping `source_path` targets (zero warnings on disjoint repos like Eidos itself).
* **`CMP-HTTP-TOPOLOGY-LINKER` (`src/eidos/core/index/ast_http.py`) & `CMP-CONTRACT-PARITY-VALIDATOR` (`src/eidos/core/spec/contract_parity.py`)**: Extract C# controller class base-type chains and pre-collect controller class `[Route]`/`[Authorize]`/`[AllowAnonymous]` metadata across all C# files in the `specification_file` target set before extracting endpoints, resolving inherited `[Route("api/v1/[controller]")]` (substituting the concrete derived controller's slug!) and inherited `[Authorize]`/`[AllowAnonymous]` cleanly.
* **`CNT-EIDOS-CORE` & `CAP-PROD-001`**: Update living specs and bind `INV-OVERLAPPING-SOURCE-PATH-AND-BASE-CONTROLLER-PARITY`.

== Implementation Plan
1. **Overlapping `CMP-*.source_path` Warning (`CMP-ARCHITECTURE-BOUNDARY-VALIDATOR`, `CMP-SPEC-VALIDATOR`)**: Implement deterministic file/directory overlap detection in `src/eidos/core/spec/surface_validator.py` and invoke from `src/eidos/core/spec/validator.py`.
2. **Cross-File ASP.NET Core Base Controller Inheritance (`CMP-HTTP-TOPOLOGY-LINKER`, `CMP-CONTRACT-PARITY-VALIDATOR`)**: Add a two-pass base-class table builder in `src/eidos/core/index/ast_http.py` (`CNT-EIDOS-INDEX` covered via `CMP-HTTP-TOPOLOGY-LINKER`) and wire multi-file C# target sets in `src/eidos/core/spec/contract_parity.py`.
3. **Living Specs, Tests & Coverage (`POL-005-STATEMENT-TEST-COVERAGE`)**: Update all declared specs and add `tests/test_contract_parity.py::test_overlapping_component_source_paths_and_base_controller_inheritance` covering overlapping directory/file warnings, multi-level base controller `[Route]` + `[Authorize]` inheritance with action `[AllowAnonymous]` override, and `>90.0%` per-file statement coverage.
