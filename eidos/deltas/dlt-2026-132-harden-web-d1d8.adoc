= SpecDelta: Harden Web Portal XSS and Token Path Containment, Repair C4 and UI Views, and Add SSE Live Drift with Chunked Export
:toc: left
:icons: font
:sectnums:

== Problem Statement

Deep inspection of `CNT-EIDOS-PORTAL` (`src/eidos/portal/`) and `CMP-SPEC-VALIDATOR` (`src/eidos/core/spec/validator.py`) surfaced security vulnerabilities, broken UI views, and static bundle scalability limits:

1. **Stored / Reflected DOM XSS, DOM Clobbering & Script-Data Breakage (`HIGH`)**:
   * `buildMermaidConfig` (`src/eidos/portal/frontend/src/lib/mermaid.ts:19-46`) sets `securityLevel: "loose"` (`L26`), disabling Mermaid's internal DOMPurify sanitizer while `MermaidDiagram.tsx:154` and `ArchitectureView.tsx:450` assign SVG output directly to `.innerHTML`.
   * `_extract_or_generate_flow_mermaid` (`src/eidos/portal/generator.py:1332-1381`) embeds raw `[mermaid]` blocks verbatim and interpolates unescaped `client`, `title`, `action`, and `screen` strings into HTML node labels (`L1357-1380`).
   * `ArchitectureView.tsx:463-465` writes unescaped `String(err)` into `diagramRef.current.innerHTML` on Mermaid parse failure.
   * `renderAsciiDoc` (`src/eidos/portal/frontend/src/lib/asciidoc.ts:41, 56, 155`) sets `idprefix: ""` and `SANITIZE_DOM: false` (allowing spec headings or passthrough blocks to clobber global DOM IDs) and checks only `/^https?:\/\//i` for external links, missing protocol-relative `//...` URLs.
   * `build_static_portal` (`src/eidos/portal/builder.py:98-104`) escapes `</` inside inline `<script>` JSON (`safe_json`) but omits `<!--`, which breaks HTML script-data state parsing (`SyntaxError` / blank-page DoS) when spec prose contains `<!--` + `<script>`.
2. **Arbitrary JSON File Disclosure via `tokens.manifest` Path Traversal (`HIGH`)**:
   * `_extract_design_systems` (`src/eidos/portal/generator.py:598-610`) and `_validate_design_systems` (`src/eidos/core/spec/validator.py:1188`) resolve `tokens.manifest` via path joining without checking `cand.resolve().is_relative_to(repo_root.resolve())` (and `assets/schemas/v1/design/system.schema.yaml:54-56` accepts arbitrary strings), allowing `../../...` or absolute paths in a PR to bundle runner host JSON files into published `index.html` and `data.json`.
3. **Cross-Origin Private Spec Exfiltration (`CORS: *`) & DNS Rebinding (`MEDIUM-HIGH`)**:
   * `EidosPortalHandler._send_json` (`src/eidos/portal/server.py:243`) sends `Access-Control-Allow-Origin: *` on every JSON endpoint (`/api/data`, `/api/drift`, `/api/validate`) with zero `Host` header validation, allowing any untrusted browser tab to exfiltrate private specs and uncommitted drift from `http://127.0.0.1:3000`.
4. **Broken C4 Level 1 Diagram, Dead UI Sections & Disconnected Live Drift**:
   * `_generate_c4_context_mermaid` (`generator.py:748-756`) calls `html.escape(str(ext))` on `{name, role, protocol}` objects (`architecture.schema.yaml:51-65`), rendering raw Python dict `repr` strings in C4 Level 1 diagrams.
   * `screens` omit `body` (`generator.py:707-719` and `hydratePortalData` in `App.tsx:24-46`), so `"Inspect Screen Spec"` in `DesignView.tsx:951` never renders; `explorations` hardcode `exit_criteria: {}` and `recommendation: ""` (`generator.py:443-445`); `ValidationReport.schema_errors` (`validator.py:321`) uses `str(file_path)` absolute keys, breaking `HomeView.tsx:282` -> `specNav.ts:30` click navigation; and `ArchitectureView.tsx:374` omits `if (hasMovedRef.current) return;`, firing C4 drill-down on pan-drag release.
   * `_compute_eidos_mtime_snapshot` (`server.py:21-41`) ignores `src/` and `tests/`, `_get_cached_drift` (`server.py:115-128`) fails open (`is_clean: True`), and the React frontend never fetches `/api/drift` despite `SCR-PORTAL-HOME` (`portal-home.adoc:30`) specifying live drift visibility.
5. **Monolithic Static Portal Payload (`6.73 MB` `index.html`)**:
   * `build_static_portal` (`builder.py:83-115`) combines a `4.74 MB` single-file JS/CSS bundle (`assets/portal/bundle.html.gz`) with `1.99 MB` of inlined JSON (`580 KB` of `.adoc` bodies across 231 specs) plus a duplicate `data.json`, which balloons past `25+ MB` at 2,000 specs.

== Proposed Specification Changes

* **Eliminate Portal XSS, DOM Clobbering & Path Traversal (`CMP-PORTAL-ASSETS`, `CMP-PORTAL-GENERATOR`, `CMP-PORTAL-BUILDER`, `CMP-SPEC-VALIDATOR`, `DS-CORE`, `INV-PORTAL-XSS-AND-SERVER-ISOLATION`, `INV-W3C-DTCG-COMPLIANCE`)**:
  1. Switch `buildMermaidConfig` (`mermaid.ts`) to `securityLevel: "strict"` and attach C4 node click drill-down handlers via post-render DOM event delegation on `[id*="CNT-"], [id*="CMP-"], [id*="SYS-"]` SVG groups rather than Mermaid inline JS callbacks.
  2. HTML-escape all interpolated fields (`client`, `title`, `action`, `screen`) and strip `%%{init:...}%%` / `click ... call` directives in `_extract_or_generate_flow_mermaid` (`generator.py`), render Mermaid syntax errors via React text nodes (never `.innerHTML`) in `ArchitectureView.tsx`, set `idprefix: "spec-"` and `SANITIZE_DOM: true` plus `^(?:https?:)?//` external link `rel="noopener noreferrer"` hardening in `asciidoc.ts`, and escape `<!--` as `\u003c!--` in `builder.py`.
  3. Enforce `cand.resolve().is_relative_to(repo_root.resolve())` (rejecting symlinks or `..` escaping `repo_root`) in `_extract_design_systems` (`generator.py`) and `_validate_design_systems` (`validator.py`), and disallow absolute/parent traversal patterns on `tokens.manifest` in `assets/schemas/v1/design/system.schema.yaml`.
* **Harden `eidos portal serve` & Stream Real-Time SSE Drift (`CMP-PORTAL-SERVER`, `CTR-EIDOS-PORTAL`, `SCR-PORTAL-HOME`, `INV-PORTAL-LIVE-DRIFT-SSE`)**:
  1. Remove `Access-Control-Allow-Origin: *` from `EidosPortalHandler._send_json` and validate the HTTP `Host` header against the server's bound `host:port` (plus `localhost`/`127.0.0.1`/`[::1]` equivalents when bound to loopback), returning `403 Forbidden` on mismatch.
  2. Include governed `src/` (`source_path`) and `tests/` directories in `_compute_eidos_mtime_snapshot`, fail closed (`is_clean: False`, `drift_detected: True`, `error: ...`) on exceptions in `_get_cached_drift`, expose `GET /api/events` (`text/event-stream` SSE) pushing version and drift invalidation events, and wire `/api/events` + `/api/drift` into `App.tsx` and `HomeView.tsx`.
* **Repair C4 Context, Screen Reader, Explorations, Schema Error Links, Pan-Drag & C4 Blast-Radius Highlighting (`CMP-PORTAL-GENERATOR`, `CMP-PORTAL-ASSETS`, `SCR-PORTAL-ARCHITECTURE`, `SCR-PORTAL-DESIGN`, `SCR-PORTAL-EXPLORATIONS`)**:
  1. Format `{name, role, protocol}` dicts in `_generate_c4_context_mermaid` (`generator.py`) into clean Mermaid C4 labels/edges; hydrate `screen.body` from `data.specs` in `hydratePortalData` (`App.tsx`); extract `exit_criteria` bullets/prose and `decision.outcome` recommendations in `generator.py`; emit repo-relative keys in `ValidationReport.schema_errors` (`validator.py`); guard `handleDiagramClick` in `ArchitectureView.tsx` with `if (hasMovedRef.current) return;`; and apply interactive CSS/SVG highlight classes (`1-hop`, `2-hop`, `dimmed`) directly onto C4 diagram nodes when the Blast Radius Simulator is active.
* **Chunked Local Static Export (`CMP-PORTAL-BUILDER`, `CMP-CLI-PORTAL-COMMANDS`, `CTR-EIDOS-CLI`, `INV-PORTAL-STATIC-SCALABILITY`)**:
  1. Default `eidos portal build` to emit a lean `<400 KB` `index.html`, code-split local `./assets/*.js` / `./assets/*.css` chunks (lazy-loading Mermaid and Asciidoctor from local relative files with zero remote URLs, preserving `INV-PORTAL-AIR-GAPPED-BUNDLE`), compact `data.json` index metadata, and lazy per-spec `./specs/<id>.json` body chunks fetched on SpecReader open, while providing `eidos portal build --single-file` (and keeping `assets/portal/bundle.html.gz` `<= 5 MiB` uncompressed) for single-file `file://` portability.
