= Capability: Git-Native Drift Detection & Reconciliation Gate
:toc: left

== Intent
Ensures that source code and living specifications never diverge. Through local Git diff analysis and automated CI/CD gating, Eidos continuously verifies that code modifications are paired with living specification updates, preserving system documentation integrity with zero manual overhead.

== Key Responsibilities
* Inspecting working trees and commits for unmapped architectural changes.
* Enforcing the Single Source of Truth policy (`POL-001`) during CI/CD checks.
* Generating human-readable and machine-verifiable drift summaries.
