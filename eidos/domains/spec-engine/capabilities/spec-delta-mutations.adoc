= Capability: SpecDelta Semantic Mutation Engine
:toc: left

== Intent
Replaces traditional essay-style RFCs with declarative, machine-executable mutations. When a feature is added, changed, or removed, a `SpecDelta` specifies the precise mutations and impacted invariants. Upon PR merge, the mutations are applied to update the living baseline documents automatically.

== Key Responsibilities
* **Transactional Mutation Execution & Pre-Commit Validation (`eidos delta apply --execute`)**: Performs copy-on-write transactional snapshotting of targeted living specifications before executing mutations, handles all 44 schema `mutations[].action` values (explicitly rejecting unsupported actions), verifies target specification `type:` before unlinking on `remove_*` mutations, validates all mutated specifications and the `status: applied` SpecDelta via `SpecValidator` prior to committing to disk, and rolls back all disk changes on any verification or validation failure (`INV-MUTATION-REVERSIBILITY`).
* **Modification-Evidence Verification (`eidos delta verify`)**: Verifies `modify_*`, `extend_*`, and `patch_*` mutations only on positive evidence of change to the targeted entity (a satisfied declarative `expect:` post-condition or a canonical content digest differing from the recorded SQLite baseline, with automatic `vcs.base_commit` and Git-history fallback via `_resolve_git_baseline_sha` on uncommitted branches, fresh clones, and CI cache misses), with action-aware target extraction, component-entry digest granularity for inline `CMP-*` targets, and parent/sub-target membership treated strictly as a precondition (`INV-DELTA-VERIFY-MODIFICATION-EVIDENCE`).
