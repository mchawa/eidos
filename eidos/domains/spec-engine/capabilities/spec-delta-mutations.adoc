= Capability: SpecDelta Semantic Mutation Engine
:toc: left

== Intent
Replaces traditional essay-style RFCs with declarative, machine-executable mutations. When a feature is added, changed, or removed, a `SpecDelta` specifies the precise mutations and impacted invariants. Upon PR merge, the mutations are applied to update the living baseline documents automatically.

== Key Responsibilities
* **Modification-Evidence Verification (`eidos delta verify`)**: Verifies `modify_*`, `extend_*`, and `patch_*` mutations only on positive evidence of change to the targeted entity (a satisfied declarative `expect:` post-condition or a canonical content digest differing from the recorded SQLite baseline), with action-aware target extraction, component-entry digest granularity for inline `CMP-*` targets, and parent/sub-target membership treated strictly as a precondition (`INV-DELTA-VERIFY-MODIFICATION-EVIDENCE`).
