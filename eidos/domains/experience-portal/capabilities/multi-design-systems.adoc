= Capability: Multi-Design Systems, W3C Tokens & Client Surface Management
:toc: left

== Intent
Visual design systems, component state machines, and client runtimes frequently suffer from token drift and undocumented edge cases. This capability elevates frontend design into a first-class living specification pillar, enabling multi-client applications (`CLT-*`), canonical UI component contracts (`UIC-*`), screen state machines (`SCR-*`), and interaction flows (`FLOW-*`) directly inside Git.

== Key Responsibilities
* Cataloging base and branded design systems using standard W3C DTCG tokens.
* Mapping client targets (web, mobile, desktop, CLI) to their bound design systems and C4 containers.
* Formalizing multi-step user interaction flows with visual state-transition diagrams.
