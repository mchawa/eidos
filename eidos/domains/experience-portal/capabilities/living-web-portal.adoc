= Capability: Interactive Living Web Portal & Visual Documentation Engine
:toc: left

== Intent
Technical specifications and architecture models are often trapped in raw text files or separate wikis. This capability provides a local, zero-dependency embedded HTTP server (`eidos serve`) and static site builder (`eidos build-site`) that turns living AsciiDoc files into an interactive single-page application.

== Key Responsibilities
* Real-time inspection and clickable hierarchical exploration of C4 Level 1 (Context), Level 2 (Containers), and Level 3 (Component Whitebox) models using client-side Mermaid rendering.
* Slide-over component inspection drawer revealing module responsibilities, source paths, bound contracts, and catalog specifications.
* Interactive SpecDelta Kanban dashboard tracking proposed, in-review, and applied mutations.
* Full-text fuzzy search and real-time schema filtering across all catalog entities.
