= Capability: Polyglot AST Code Graph & Structural Repo Map Intelligence
:toc: left
:icons: font

== 1. Intent & Purpose

This capability bridges the semantic chasm between **C4 Level 3 (Living Specifications)** and **C4 Level 4 (Code & Syntax Trees)**. It provides autonomous coding agents (Google Antigravity `agy`, Claude Code, Cursor, Copilot, Aider) with instant, token-compressed structural codebase intelligence (`eidos index repo-map` and `eidos index find-symbol`) directly from local SQLite storage (`eidos/.cache/index.db`), eliminating hallucinated symbol names and context window exhaustion.

In strict compliance with *POL-004-ZERO-AI-CALL-DEPENDENCY*, all AST extraction, repo map synthesis, and symbol indexing execute 100% deterministically on local CPU using `ast-grep-py` (with standard library `ast` fallback) with zero calls to remote AI or embedding APIs.

== 2. Key Responsibilities

1. **Token-Budgeted AI Repo Map (`eidos index repo-map`)**:
   Synthesizes a compact structural outline of classes, public methods, function signatures, and file coordinates across polyglot source trees (Python, TypeScript, Go, Rust, Java), achieving $\ge 85\%$ token compression compared to raw code ingestion.
2. **Sub-Millisecond Symbol Discovery (`eidos index find-symbol`)**:
   Exposes machine-readable (`--json`) lookup of symbol declarations, line numbers, docstrings, and owning C4 components for agent tool calling.
3. **Vertical Grounding**:
   Links code symbols directly to C4 containers (`CNT-*`), components (`CMP-*`), capability requirements (`CAP-*`), and invariant tests (`INV-*`) in a unified relational knowledge graph.
4. **Syntax-Aware Invariant Traceability**:
   Resolves exact test functions (`def test_*`, `it(...)`, `func Test*`, `#[test] fn`) enforcing capability invariants, replacing naive whole-file substring matching in drift detection.
5. **Continuous Code-Aware AST Indexing**:
   Monitors filesystem `mtime` across tracked source code files and automated test suites, detecting code modifications in sub-5ms and triggering transparent JIT re-indexing before query execution.
6. **AST Engine & Invariant Telemetry (`eidos index status`)**:
   Exposes deterministic telemetry regarding the active AST parsing engine (`ast-grep` vs `python-ast`), symbol counts by syntax kind (classes, functions, methods, test bindings), and exact test-to-invariant assertion metrics with full `--json` support.
