= Capability: Polyglot AST Code Graph & Structural Repo Map Intelligence
:toc: left
:icons: font

== Job To Be Done (JTBD)
Empower AI coding agents and human engineers with token-budgeted structural repo maps, sub-millisecond symbol discovery, and syntax-aware invariant test traceability without relying on cloud vector databases or remote AI dependencies.

== 1. Intent & Purpose

This capability bridges the semantic chasm between **C4 Level 3 (Living Specifications)** and **C4 Level 4 (Code & Syntax Trees)**. It provides autonomous coding agents (Google Antigravity `agy`, Claude Code, Cursor, Copilot, Aider) with instant, token-compressed structural codebase intelligence (`eidos context`, `eidos index repo-map`, and `eidos index find-symbol`) directly from local SQLite storage (`eidos/.cache/index.db`), eliminating hallucinated symbol names and context window exhaustion.

In strict compliance with *POL-004-ZERO-AI-CALL-DEPENDENCY*, all AST extraction, repo map synthesis, and symbol indexing execute 100% deterministically on local CPU using `ast-grep-py` (`SgRoot`) across all 17 supported languages with zero calls to remote AI or embedding APIs.

== 2. Key Responsibilities

1. **Token-Budgeted AI Repo Map (`eidos index repo-map`) & Context Slicing (`eidos context`, `INV-CONTEXT-GUARDRAIL-INVARIANT-RETENTION`)**:
   Synthesizes a compact structural outline of classes, public methods, `interface` and trait member signatures, overload-disambiguated function/method declarations, and file coordinates across polyglot source trees (Python, TypeScript/JS, Go, Rust, Java, Kotlin, C/C++ with length-preserving `*_API` / `*_EXPORT` macro normalization, C#, Ruby, PHP, Swift, Vue, Svelte), achieving $\ge 85\%$ token compression compared to raw code ingestion, enforces strict tier token budgets (`anchor`, `guardrails`, `deep`) across both Markdown and JSON (`--json`) context slices—weighting invariant ID token matches above incidental `test_binding` substrings and compacting primary-component `DEC-*` narratives plus trimming secondary 1-hop components before evicting 1-hop capability `INV-*` guardrails below `min_len=3` while retaining compact primary `DEC-*` summaries—and returns honest empty slices when explicit queries match zero entities.
2. **Sub-Millisecond Symbol & Test Discovery (`eidos index find-symbol`)**:
   Exposes machine-readable (`--json`) lookup of symbol declarations, exported TypeScript and JavaScript variable bindings, class methods, and automated test symbols (`is_test = 1`, e.g. `test_*`), line numbers, docstrings, and owning C4 components for agent tool calling.
3. **Vertical Grounding**:
   Links code symbols directly to C4 containers (`CNT-*`), components (`CMP-*`), capability requirements (`CAP-*`), and invariant tests (`INV-*`) in a unified relational knowledge graph.
4. **Syntax-Aware Invariant Traceability**:
   Resolves exact test functions (`def test_*`, `Class::test_*`, `it(...)`, `func Test*`, `#[test] fn`, `@Test fun`) enforcing capability invariants, preserving qualified `Class::method` keys so identical method names across test classes never overwrite each other.
5. **Concurrent WAL-Safe AST Indexing, Persistent Public Surface Cache, Strict Freshness & Lock-Wait Diagnostics (`INV-INDEX-CONCURRENT-WAL-SAFETY`, `INV-INDEX-SYNC-CLI-CONTROLS`, `INV-INDEX-FRESHNESS-AND-LOCK-DIAGNOSTICS`, `INV-INDEX-PUBLIC-SURFACE-CACHE`, `INV-DOTNET-POLYGLOT-PARITY`)**:
   Coordinates SQLite DDL, corruption recovery, and full `sync_index` write transactions via a re-entrant advisory lockfile (`index.db.lock`, storing holder PID metadata and emitting `sys.stderr` lock-wait notices on contention before kernel-blocking wait) and `BEGIN IMMEDIATE` transactions without `PRAGMA mmap_size`, keeps opportunistic cache reads/writes (`spec_validation_cache`, `test_binding_cache`, `public_surface_cache`) strictly non-blocking (falling back to live disk parsing on mid-DDL reads and skipping contended cache persistence without freshness loss), isolates SQLite connections per thread via `threading.local()`, debounces in-process `_ensure_synced` checks via `_last_synced_check` with `PRAGMA data_version` handoff, batches `>1,000` spec-edge rebuilds without hitting `SQLITE_MAX_EXPR_DEPTH`, indexes `.NET` test suites (`*.Tests`, `*Tests.cs`) and C# namespace/`.csproj` dependency edges, and exposes `eidos index sync --no-semantic --json` without competing background ONNX subprocess races.
6. **AST Engine, Epistemic Provenance, Governance Health Scorecard & Invariant Telemetry (`eidos index status`, `eidos index health`, `INV-INDEX-EPISTEMIC-PROVENANCE`, `INV-INDEX-GOVERNANCE-HEALTH-SCORECARD`, `INV-INDEX-HEALTH-GENERATED-AND-COMPONENT-SCOPE`)**:
   Exposes deterministic telemetry regarding the active AST parsing engine (`AstGrepIndexer`), `edge_counts_by_provenance` across `SCHEMA_VERSION` `2.22.0` `edges.provenance` tags (`declared_spec`, `ast_import`, `ast_http`, `ast_symbol`, `inferred_ownership`), `--min-confidence` (`observed`, `derived`, `inferred`) blast-radius traversal filtering, symbol counts by syntax kind, exact test-to-invariant assertion metrics, and repository-wide architecture governance health scorecards (source ownership % excluding gitignored and `linguist-generated`/`linguist-vendored` files, component-scoped Public Surface coverage alongside container counts, contract verification %, capability invariant coverage, advisory warnings, and `ratchet_baseline` debt) surfaced in both CLI (`--json` / Rich) and Living Web Portal (`governance_health`).
7. **Polyglot Static Frontend-to-Backend HTTP Auto-Linking & Structural Diff Classification (`CMP-HTTP-TOPOLOGY-LINKER`, `CMP-AST-DIFF-CLASSIFIER`, `INV-INDEX-STATIC-HTTP-AUTOLINK`)**:
   Extracts server `http_endpoint` routes and non-test client `http_request` calls across polyglot web frameworks and HTTP clients with zero runtime LLM calls (`POL-004`), normalizes dynamic route parameters to `{*}`, and links client components/containers to backend endpoints and OpenAPI/`rest_http` `CTR-*` contracts via `ast_http` edges and `code_couplings` rows with `file:line` evidence.
