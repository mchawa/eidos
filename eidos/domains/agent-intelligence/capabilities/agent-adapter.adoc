= Capability: Universal Agent Adapter & Context Slicing Layer
:toc: left

== Job To Be Done (JTBD)
Enable the team to use any state-of-the-art coding agent (Antigravity agy, Claude Code, Cursor, Cline, Codex, Aider) interchangeably without rewriting project workflows.

== Intent
Avoids vendor lock-in and eliminates context window bloat. External AI coding assistants—including Google Antigravity `agy`, Claude Code, Cursor, Cline, OpenAI Codex, GitHub Copilot, and Aider—query the deterministic Eidos CLI to retrieve token-budgeted, graph-indexed architectural slices (`eidos context --json`) and verify invariant compliance before committing changes.

In strict adherence to *POL-004*, Eidos never initiates AI/LLM calls itself. Instead, it provides the authoritative, noise-free substrate (C4 topology, interface contracts, governing policies, and test-bound invariants) that grounds external agents and prevents architectural drift.

== Key Responsibilities
* **Deterministic Substrate for Coding Agents**: Exposing machine-readable JSON envelopes across CLI inspection commands.
* **Tiered Architectural Context Slicing**: Dynamically extracting token-compressed architectural subgraphs matching task requirements.
* **Hybrid Lexical-Relational Retrieval**: Combining FTS5 BM25 search with graph-neighborhood traversals to resolve engineering prompts to architectural entities.
* **Architectural Blast-Radius Analysis**: Recursive CTE impact mapping allowing agents to assess blast radius before proposing code changes.
* **Stateless Stop Lifecycle Hook**: Single unified `Stop` hook (`eidos hook`) verifying specification schemas, cross-references, invariant test bindings, and spec-to-code synchronization via `detect_drift` and emitting non-blocking `systemMessage` warnings when drift or validation errors are detected.
* **Non-Destructive Plugin Ecosystem Management**: Installing and removing agent plugins via `eidos plugin` (including project-native Claude Code `.claude/skills/` and `.claude/settings.json` `hooks.Stop` registration) with deterministic `.eidos-manifest.json` tracking (preventing destruction of shared parent directories and shared host settings files), non-destructive `force=False` overwrite semantics, symlink guards, and version-pinned `uvx` hook execution.

== Tiered Context Slicing Architecture

Eidos implements a three-tier context compression model:

[cols="1,2,3", options="header"]
|===
| Tier | Approximate Size | Contents Included
| `anchor` | ~140 tokens | Owning container (`CNT-*`) and internal component (`CMP-*`), runtime, `source_path`, bound domain, compact `DEC-*` architectural decisions (`title`, `decision`, and rejected option names), and direct interface contract (`CTR-*`) signatures.
| `guardrails` | ~300–900 tokens | Everything in `anchor`, plus bounded `DEC-*` rationale and `rejected_alternatives`, domain capabilities (`CAP-*`), active invariants (`INV-*`) with `test_binding`, and governing policies (`POL-*`).
| `deep` | ~500–1,500 tokens | Comprehensive architectural audit slice: C4 Level 3 internal building blocks, full contract schemas, full policy texts, full `DEC-*` trade-off records, and downstream dependents.
|===

== Hybrid Retrieval & Freshness Invariant
* **FTS5 BM25 Lexical Ranking & Opt-In Harrier Hybrid RRF (`CMP-SEMANTIC-EMBEDDING-ENGINE`)**: Translates natural language engineering tasks into exact architectural IDs using two-tier multi-term `AND` coordination boosting over `OR` prefix matches, direct-over-1-hop container prioritization, and optional gated Harrier-OSS-v1-0.6B ONNX Reciprocal Rank Fusion (`spec_embeddings` over living specifications with automatic refresh on `.adoc` updates, `HARRIER_DOC_MAX_LENGTH = 4096`, $\tau_{\min} = 0.50$, $w_{\text{sem}} = 0.50$) with 100% deterministic fallback to FTS5 BM25 (`INV-AGENT-HYBRID-SEMANTIC-FALLBACK`).
* **Calibrated Token Budget Estimation**: `TieredContextSlice._estimate_tokens` weights structural syntax characters (`{}[]:,"'|`) at ~3.0 characters per token and natural-language prose at ~4.0 characters per token so `anchor`, `guardrails`, and `deep` slices honor strict token budgets across both Markdown and JSON outputs.
* **Zero-Drift Freshness (`INV-AGENT-GRAPH-INDEX-FRESHNESS`)**: Every CLI query lazily checks dirty status via SHA-256 and mtime hashing, synchronizing modified specs in sub-5ms so agents never operate on stale architecture.
* **Non-Destructive Plugin Management (`INV-PLUGIN-SCHEMA-CONFORMANCE`)**: The `eidos plugin` ecosystem ensures non-destructive installation, manifest-tracked uninstallation (`.eidos-manifest.json`), `force=False` overwrite protection, symlink traversal prevention, and version-pinned `uvx` hook commands.
* **Stateless Stop Hook (`INV-AGENT-DRIFT-HOOK`)**: The stateless `eidos hook` command runs `detect_drift(uncommitted=True)` once on `Stop` and returns `{"decision": "allow"}` when clean or `{"decision": "allow", "systemMessage": "..."}` when specification validation, invariant, or drift issues exist.
