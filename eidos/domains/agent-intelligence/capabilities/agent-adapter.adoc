= Capability: Universal Agent Adapter & Context Slicing Layer
:toc: left

== Intent
Avoids vendor lock-in and eliminates context window bloat. External AI coding assistants—including Google Antigravity `agy`, Claude Code, Cursor, Cline, OpenAI Codex, GitHub Copilot, and Aider—query the deterministic Eidos CLI to retrieve token-budgeted, graph-indexed architectural slices (`eidos context --format json`) and verify invariant compliance before committing changes.

In strict adherence to *POL-004*, Eidos never initiates AI/LLM calls itself. Instead, it provides the authoritative, noise-free substrate (C4 topology, interface contracts, governing policies, and test-bound invariants) that grounds external agents and prevents architectural drift.

== Key Responsibilities
* **Deterministic Substrate for Coding Agents**: Exposing machine-readable JSON envelopes across CLI inspection commands.
* **Tiered Architectural Context Slicing**: Dynamically extracting token-compressed architectural subgraphs matching task requirements.
* **Hybrid Lexical-Relational Retrieval**: Combining FTS5 BM25 search with graph-neighborhood traversals to resolve engineering prompts to architectural entities.
* **Architectural Blast-Radius Analysis**: Recursive CTE impact mapping allowing agents to assess blast radius before proposing code changes.
* **Lifecycle Linting & Safety Hooks**: Pre-completion hooks enforcing specification schemas, valid cross-references, frontmatter syntax integrity, and dedicated spec-to-code synchronization drift gates.

== Tiered Context Slicing Architecture

Eidos implements a three-tier context compression model:

[cols="1,2,3", options="header"]
|===
| Tier | Approximate Size | Contents Included
| `anchor` | ~1,500 tokens | Owning container (`CMP-*`), internal module responsibility, compact `DEC-*` architectural decisions (`title`, `decision`, and rejected option names), primary interface contracts (`CTR-*`), governing policies (`POL-*`), and immediate capability invariants (`INV-*`).
| `guardrails` | ~3,500 tokens | Everything in `anchor`, plus full `DEC-*` rationale and `rejected_alternatives`, 1-hop upstream and downstream peer containers, related domain capabilities, and test bindings. Reduces token payload by >=60% compared to raw file loading.
| `deep` | ~8,000 tokens | Comprehensive architectural audit slice: recursive CTE blast-radius traversal of all downstream dependents, cross-boundary contracts, full policy texts, full `DEC-*` trade-off records, and complete invariant test suites.
|===

== Hybrid Retrieval & Freshness Invariant
* **FTS5 BM25 Lexical Ranking**: Translates natural language engineering tasks (e.g. "update auth token expiration") into exact architectural IDs.
* **Zero-Drift Freshness (`INV-AGENT-GRAPH-INDEX-FRESHNESS`)**: Every CLI query lazily checks dirty status via SHA-256 and mtime hashing, synchronizing modified specs in sub-5ms so agents never operate on stale architecture.
