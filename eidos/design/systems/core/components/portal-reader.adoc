= UI Component: Portal Living Specification Reader
:toc: left

== 1. Component Purpose & Reading Ergonomics
The Portal Living Specification Reader (`UIC-PORTAL-READER`) establishes the reading-friendly stage for long-form technical documentation across the Eidos Living Web Portal:
* **Expansive Stage & Optimal Measure**: Renders within an enlarged modal dialog (`max-w-[94vw] 2xl:max-w-[1550px] h-[95vh]`) with optimal line length (`max-w-4xl xl:max-w-5xl`) to prevent ocular fatigue while utilizing modern wide displays.
* **Typographic Hierarchy**: Distinct, readable type sizes based on `DS-CORE` tokens:
  - Title (H1): `26px`–`30px` bold with tracking-tight.
  - Section Headings (H2): `20px`–`24px` bold with top breathing room and hoverable anchor links.
  - Subsection Headings (H3): `18px` semibold with visual hierarchy.
  - Body Copy: `15.5px`–`16px` with relaxed `1.8` line-height.
  - Code Snippets: `13px` monospace with syntax styling and one-click copy.
* **Human-Centric Specification Header**: Replaces raw JSON frontmatter dumps with clean status badges, bound invariants (`INV-*`), personas, and a collapsible metadata drawer.
* **High-Contrast Dark Theme**: Clean neutral zinc surfaces (`#121215`), elevated popovers (`#18181b`), readable muted foregrounds (`#a1a1aa`), and distinct borders (`#27272a`) ensuring effortless legibility comparable to light mode.

== 2. Dynamic Table of Contents (TOC) & On-This-Page Navigation
For multi-section specifications with two or more H2 headings:
* A sticky right-hand navigation rail renders the hierarchical section tree (`== ` and `=== `).
* Real-time scroll-spy tracks reading progress and highlights the current section.
* Clicking any outline entry smoothly scrolls the viewport to the target heading anchor.

== 3. Optimal Reading Ergonomics
To maximize cognitive focus and remove interface clutter, the reader eliminates redundant view-mode and font-scaling toggles in favor of carefully balanced defaults:
* **Always-Rendered Clean Prose**: Always presents the rendered specification document directly.
* **Locked Optimal Typography**: Standardizes on the ideal reading line-height and font size.
* **Section Permalinks**: Hovering over any section heading reveals an anchor link button for instant permalink copying.
