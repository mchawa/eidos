= UI Component: Dashboard Metric Card
:toc: left

== 1. Visual Presentation
The Dashboard Metric Card (`UIC-PORTAL-METRIC-CARD`) displays high-level system indicators (e.g. Total Specs, Domains, Capabilities, Invariants, C4 Containers, SpecDeltas).
Each card features:
* Numeric metric value with high visual weight.
* Categorical uppercase subtitle label.
* Subtle colored accent border on hover.

== 2. Accessibility & Verification
* **WCAG Conformance**: Level AA (`aria-role: region`).
* **Keyboard Navigation**: When clickable, Enter or Space activates navigation to the linked view.
* **Automated Verification**: Exercised by `tests/test_portal.py::test_portal_data_generation`.
