= UI Component: Portal Navigation Sidebar
:toc: left

== 1. Navigation Hierarchy & Ordering
The Portal Navigation Sidebar (`UIC-PORTAL-SIDEBAR`) establishes the primary plain-language navigation hierarchy of the Eidos Living Web Portal, paired with a `"Search documentation..."` quick-search trigger (`"Search documentation"` tooltip):
1. **Overview**: Executive overview, key metrics, workspace health, and recent changes.
2. **Business & Domains**: Product personas, business domains, capabilities, policies, and system rules.
3. **Architecture**: Interactive System Context, Containers, and Components explorer, interface contracts, and architectural decisions.
4. **Changes**: Interactive Kanban board and timeline displaying change proposals across humanized lifecycle statuses (`Proposed`, `In Review`, `Approved`, `Applied`, `Rejected`, `Archived`).
5. **Explorations**: Architectural research, hypotheses, spikes, outcomes, and links to resulting change proposals.
6. **Catalog**: Complete searchable, filterable specification catalog organized by human-readable categories.
7. **Design Systems**: Design systems catalog, Design Tokens Studio, UI components, screens, and user flows.

== 2. Visual States & Badges
The sidebar sits on the same unified canvas surface (`bg-background`) as the main reading area, separated by a quiet `border-r border-border/70` hairline, with an `h-14` top header bar aligned flush with the main shell header. Each navigation entry displays an SVG icon, section label, and live document counter badge; the active view uses a calm neutral surface highlight (`bg-muted text-foreground font-semibold`) and neutral count badges rather than heavy colored fills.

== 3. Desktop Collapsible Behavior & Persistence
The sidebar supports both full-width (`256px` / `w-64`) and icon-only collapsed (`80px` / `w-20`) modes on desktop displays:
* **Toggle Trigger**: Interactive collapse button (`#sidebarCollapseBtn`) in the brand row with animated chevron rotation and non-clipping vertical stack.
* **Shortcut Binding**: `Ctrl+B` or `Cmd+B` toggles the sidebar state from anywhere within the portal.
* **Material Design 3 Indicator Pills**: In collapsed mode, each destination item renders inside a prominent `48x36px` (`w-12 h-9`) rounded container pill with active tonal elevation (`md-elevation-1`), high-contrast `20px` (`h-5 w-5`) vector icons, and an elevated state layer on hover.
* **Badge Notification Pills**: Item count badges are repositioned as compact notification badges on the top-right corner of the indicator container pill in collapsed mode.
* **Tooltips & Accessibility**: Each condensed navigation button provides native `title` and `aria-label` attributes to maintain full WCAG AA accessibility.
* **State Persistence**: The user's preference is automatically saved to browser `localStorage.getItem('eidos_sidebar_collapsed')` and restored prior to paint to prevent layout flicker.

== 4. Iconography & Typography Specification
* **The Eidos Brand Mark**: Features the Eidos Form — a single continuous isometric impossible polygon skeleton (`M 16,3 L 27.3,9.5 L 19,14.2 L 27.3,22.5 L 16,29 L 16,19.5 L 4.7,22.5 L 4.7,9.5 L 13,14.3 Z`) rendered with an electric cyan-to-purple gradient (`#38bdf8` → `#6366f1` → `#a855f7`) at `strokeWidth="2.2"` with rounded joins and subtle translucent fill.
* **Typography**: Powered by the living `DS-CORE` design tokens (`Geist` UI sans-serif, `Geist Mono` for codes and IDs) with high-legibility sizing (`15px` navigation labels, `13px` captions).
* **Vector Iconography**: Clear 20px vector icons with 2px stroke weight (`Home`, `Briefcase`, `Network`, `GitBranch`, `Lightbulb`, `Layers`, `Palette`) ensuring crisp high-DPI rendering and dynamic CSS color inheritance across dark and light themes. Sized consistently across expanded and collapsed states.

== 5. Accessibility & Verification
* **WCAG Conformance**: Level AA (`aria-role: navigation`).
* **Keyboard Navigation**: Arrow keys (Up/Down) or Tab traverse menu links; Enter activates view switch.
* **Automated Verification**: Exercised by `tests/test_portal.py::test_static_portal_builder`.
