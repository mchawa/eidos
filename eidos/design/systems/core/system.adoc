= Eidos Core Design System
:toc: left

== 1. Design Principles & Tokens Foundation
The Eidos Core Design System (`DS-CORE`) defines the visual language, typography scales, spacing units, and color semantic tokens for the Eidos Living Web Portal and all agent interaction interfaces.

All tokens strictly conform to the W3C Design Tokens Community Group (DTCG) specification.

== 2. Color Modes & Visual Density Adaptation
The system provides zero-dependency CSS variable mapping supporting native dark mode (default) and high-legibility light mode, synchronized across all portal views, C4 diagram renderers, and SpecDelta Kanban boards.
