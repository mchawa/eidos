:toc: left

== 1. View Purpose & Engineering Scope
The Technical Architecture View (`SCR-PORTAL-ARCHITECTURE`) visualizes the technical runtime structures implementing the system's business capabilities:
* **C4 Level 1 (System Context)**: Interactive Mermaid topology depicting external personas and peer systems.
* **C4 Level 2 (Container Architecture)**: Container topology showing boundaries, runtimes, and dependencies.
* **Containers & Components Whitebox (CMP-*)**: Monorepo package manifests and internal C4 modules.
* **Interface & Protocol Contracts (CTR-*)**: Formal contract definitions governing CLI, MCP, and HTTP interfaces.
