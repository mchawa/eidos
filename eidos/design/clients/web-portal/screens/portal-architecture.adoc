= Screen: Technical Architecture & C4 Topologies View
:toc: left

== 1. View Purpose & Engineering Scope
The Technical Architecture View (`SCR-PORTAL-ARCHITECTURE`) visualizes the technical runtime structures implementing the system's business capabilities:
* **Hierarchical C4 Explorer**: Dynamic clickable zoom across Level 1 (System Context), Level 2 (Container Topology), and Level 3 (Component Whitebox Views).
* **Interactive Breadcrumbs & Navigation**: Seamless drill-down on click, ancestor navigation trail, container quick-switcher dropdown, and level-up controls.
* **Component Whitebox Inspector**: Slide-over details drawer revealing module responsibilities, string and object-style upstream/downstream container and external service dependencies, source file links, contract bindings, and automatic drawer dismissal when drilling down into whitebox diagrams.
* **Containers & Modules Matrix (CMP-*)**: Monorepo package manifests and internal C4 modules with direct one-click exploration links.
* **Interface & Protocol Contracts (CTR-*)**: Formal contract definitions governing CLI, REST, and HTTP interfaces.
