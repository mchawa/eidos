= Screen: Living Specifications Master Catalog View
:toc: left

== 1. View Purpose & Docs Reader Architecture
The Catalog View (`SCR-PORTAL-CATALOG`) opens by default into a **Docs Reader** (`#catalogDocsReader`) 3-pane documentation experience, with one-click switching to **Tree** and **List** tabular overviews (`#specsTreeGridTable`):
* **Left Navigation Tree**: Collapsible sticky specification directory organized across Overview & Policies, Domains & Capabilities, Architecture & Systems, Design Systems & Experience, Personas & Explorations, Change Proposals, and Team Memory, paired with `/` instant search and category filtering.
* **Center Borderless Reading Stage**: Renders the active specification inline through `SpecReader` (`UIC-PORTAL-READER`) with breadcrumbs, deduplicated title, clickable `xref:` navigation that updates the active document in place, and sequential Previous / Next links—eliminating modal popups for routine reading.
* **Right On-This-Page Outline**: Quiet borderless sticky Table of Contents synced to scroll progress.
* **Tree & List Table Modes**: Structured 4-column tabular view (`Document`, `Category`, `Section`, `Status`) inside a keyboard-scrollable `.table-wrapper` where clicking any document jumps straight into the inline Docs Reader.

== 2. Collapsible Navigation & Branch Controls
The Catalog toolbar provides rapid navigation and directory controls:
1. **Docs Reader / Tree / List Mode Switcher**: Toggles between the default 3-pane Docs Reader (`#catalogDocsReader`), hierarchical Tree table, and flat List table (`#specsTreeGridTable`).
2. **Category Filter**: Dropdown narrowing the left spec directory or table to a single pillar/type.
3. **Expand All / Collapse All**: One-click toggles across all nesting depths in Tree mode.

== 3. Table Column Integrity & Human-Readable Presentation
Each row preserves structured, tabular alignment across 4 clean, human-readable columns without raw ID slugs, raw schema type slugs, raw file paths, or ASCII tree characters:
* **Document**: Indented hierarchy with hardware-accelerated rotating SVG chevrons (`rotate(0deg)` to `rotate(90deg)`), category icons, human-readable document titles, and child counts. Clicking on any parent row toggles section expansion.
* **Category**: Color-coded human-readable category badges (e.g. `Container`, `UI Component`, `Capability`, `Change Proposal`, `Interface Contract`).
* **Section**: Resolved parent domain, container, or area title.
* **Status**: Plain-language validation health indicator (`Valid` or `Needs Attention`) paired with humanized lifecycle status.
* **Seamless Inspection**: Clicking or keyboard-activating any document row jumps directly into the inline `SpecReader` Docs Reader with resolved human-titled in-place cross-reference links, while keeping canonical IDs searchable in the background search bar (`"Search documents..."`) and Docs Reader / Tree / List switcher.

== 4. Real-Time Branch Unfolding & Search Experience
The enhanced search toolbar provides immediate, responsive discoverability:
* **Modern Search Bar**: Integrated SVG magnifying glass, keyboard shortcut indicator (`/`), and one-click clear button (`✕`).
* **Custom Dropdown Filter**: Pillar selector with sleek SVG chevron indicator and clean hover states.
* **Live Match Pill**: Dynamic counter showing active search matches in real time.
* **Automatic Branch Unfolding**: Ancestor parent branches of any matching item are automatically unfolded while non-matching subtrees are collapsed and hidden until the filter is cleared.
