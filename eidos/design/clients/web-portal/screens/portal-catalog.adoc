= Screen: Living Specifications Master Catalog View
:toc: left

== 1. View Purpose & Unified Hierarchical Tree-Grid Architecture
The Catalog View (`SCR-PORTAL-CATALOG`) provides an interactive, unified hierarchical tree-grid (tree-table) representing the entire Living Specification topology:
* **Level 0 (System Root)**: Represents the top-level repository system archetype (`SYS-EIDOS-001`).
* **Level 1 (Core Pillars)**: Groups specifications into the three core architectural dimensions plus mutations:
  - **Business & Governance**: Product Domains (`DOM-*`), System Policies (`POL-*`), Personas (`PER-*`), Explorations (`EXP-*`).
  - **Design & Experience**: Design Systems (`DS-*`), Screens (`SCR-*`), UI Component Contracts (`UIC-*`).
  - **Technical Architecture**: System Architecture (`ARCH-*`), Containers (`CMP-*`), Protocol Contracts (`CTR-*`).
  - **SpecDeltas & Mutations**: Active and completed mutation deltas (`DLT-*`).
* **Level 2 (Domains & Sub-Pillars)**: Domain boundaries (`DOM-PRODUCT-CORE`, `DOM-AGENT-HARNESS`, `DOM-VCS-SYNC`), Container manifests, Screen groups, and Policy invariants.
* **Level 3 (Leaf Living Specifications)**: Individual Capabilities (`CAP-*`), Screen State Machines (`SCR-*`), Container Manifests (`CMP-*`), and Contracts (`CTR-*`).

== 2. Collapsible Navigation & Level Zooming
The tree-grid toolbar provides instant macro/micro zoom controls:
1. **Level 1 (Pillars)**: Folds all sub-trees, displaying high-level system pillars with aggregated child counts.
2. **Level 2 (Domains)**: Expands pillars to reveal domain packages and container modules.
3. **Level 3 (All Specs)**: Unfolds all leaf specifications for complete system inspection.
4. **Expand All / Collapse All**: One-click toggles across all nesting depths.

== 3. Table Column Integrity & Traceability
Each row preserves structured, tabular alignment across 5 clean columns without visual clutter:
* **Specification Hierarchy**: Indented node hierarchy with hardware-accelerated rotating SVG chevrons (`rotate(0deg)` to `rotate(90deg)`), category icons, specification titles, and badge counts. Clicking on any parent row toggles section expansion.
* **Document ID**: Unique kebab-cased or prefixed ID with copy-on-click chip and toast confirmation (`SYS-*`, `DOM-*`, `CAP-*`, `DS-*`, `SCR-*`, `ARCH-*`, `CMP-*`, `CTR-*`, `POL-*`, `DLT-*`).
* **Type & Category**: Color-coded badges indicating schema archetype.
* **Invariants / Tests**: Direct count of test bindings and policy invariant coverage.
* **Status**: Validation health indicator (`● VALID`, `active`, `proposed`).
* **Seamless Inspection**: Clicking anywhere on a specification row directly opens the rich Spec Inspector Modal, removing the need for a dedicated actions column.

== 4. Real-Time Branch Unfolding & Search Experience
The enhanced search toolbar provides immediate, responsive discoverability:
* **Modern Search Bar**: Integrated SVG magnifying glass, keyboard shortcut indicator (`/`), and one-click clear button (`✕`).
* **Custom Dropdown Filter**: Pillar selector with sleek SVG chevron indicator and clean hover states.
* **Live Match Pill**: Dynamic counter showing active search matches in real time.
* **Automatic Branch Unfolding**: Ancestor parent branches of any matching item are automatically unfolded while non-matching subtrees are collapsed and hidden until the filter is cleared.
