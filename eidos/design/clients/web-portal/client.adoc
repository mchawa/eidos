= Client: Web Living Documentation Portal
:toc: left

== 1. Client Identity & Platform Archetype
The Web Living Documentation Portal (`CLT-WEB-PORTAL`) is the primary desktop and mobile web surface for Eidos:
* **Platform**: Responsive Web Application (SPA / SSR architecture).
* **Bound Design System**: Styled with `DS-CORE` and standard W3C Design Tokens Studio variables.
* **Technical Container**: Implemented and served by `CMP-EIDOS-PORTAL` over an embedded Python HTTP/JSON-RPC daemon.

== 2. Viewport & Shell Layout
* **Shell Navigation**: Collapsible responsive sidebar (`UIC-PORTAL-SIDEBAR`), top breadcrumbs, and real-time search.
* **Layout Breakpoints**: Desktop (>1024px), Tablet (768px-1024px), Mobile (<768px).
* **Accessibility**: WCAG 2.1 Level AA compliant with full keyboard navigation and high-contrast color tokens.
