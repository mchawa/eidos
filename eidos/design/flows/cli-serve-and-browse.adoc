= Flow: CLI to Living Web Portal Interaction Flow
:toc: left

== 1. Cross-Client Journey Overview
The CLI to Web Portal Flow (`FLOW-CLI-SERVE-AND-BROWSE`) illustrates the omnichannel interaction between the terminal CLI developer workflow and the visual Living Web Portal.

== 2. Sequence Diagram
[mermaid]
----
sequenceDiagram
  actor Dev as Developer
  participant CLI as Eidos CLI
  participant Server as Embedded HTTP Server
  participant Portal as CLT-WEB-PORTAL

  Dev->>CLI: eidos serve --path eidos
  CLI->>Server: Start daemon on port 3000
  Server-->>CLI: Listening on http://127.0.0.1:3000
  CLI->>Portal: Launch browser session
  Portal->>Server: GET /api/data
  Server-->>Portal: 200 OK (Living Specs JSON)
  Portal-->>Dev: Interactive Living Portal rendered
----
