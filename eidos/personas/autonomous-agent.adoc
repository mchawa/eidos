:toc: left

== Profile
The Autonomous Coding Agent represents any AI worker (such as Antigravity `agy`, Claude Code, Cursor Agent, or SWE-agent) plugged into Eidos. It queries the Eidos CLI for targeted context slices, inspects relevant invariants, executes TDD workflows, and deterministically validates its work before proposing pull requests.
